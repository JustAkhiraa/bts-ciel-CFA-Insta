Banc de test — rendu réel

Lire le code ne dit rien de la page rendue. Ce banc mesure, dans un vrai moteur, ce que le regard rate : le débordement horizontal (la page qui se décale au doigt), les cibles tactiles sous 34 px, et — depuis qu'une réécriture a effacé deux fonctions sans que rien ne le signale — les erreurs JavaScript et les ressources introuvables. Il relit aussi les schémas : deux étiquettes superposées donnent une bouillie illisible, et rien dans le HTML ne le signale. Il croise toutes les pages aux trois largeurs de référence, puis un échantillon sur les 41 thèmes.
