Logarithme & exponentielle

Deux fonctions qui se défont l'une l'autre. L'exponentielle multiplie, le logarithme ramène à une addition — et c'est exactement ce qu'il faut pour sortir l'inconnue d'un exposant.

📌

Résumé flash

ln n'existe que pour x > 0 ; e^x existe partout et est toujours strictement positif. Elles sont réciproques : ln(e^x) = x et eln x = x. Le logarithme transforme un produit en somme (ln(xy) = ln x + ln y), l'exponentielle fait l'inverse (ex+y = e^x e^y). Toute résolution commence par l'ensemble de définition — c'est là que se perdent les points.

01À quoi ça sert

Jusqu'ici, l'inconnue était toujours à la base : x², x³. Que faire quand elle passe à l'exposant ?

problème
Une revue a 5 000 abonnés. Leur nombre suit  aₙ = 25 000 − 20 000 × 0,8ⁿ.
Au bout de combien d'années les abonnés auront-ils quadruplé ?

     25 000 − 20 000 × 0,8ⁿ = 20 000
              20 000 × 0,8ⁿ =  5 000
                       0,8ⁿ =  0,25

Et maintenant ? Aucune des méthodes des chapitres précédents
ne sait extraire un n qui est en exposant.

C'est précisément ce que fait le logarithme : il fait descendre l'exposant.

ln(0,8ⁿ) = n × ln(0,8)
💡 Trois endroits où ça sert en CIEL
  • Décibels — le gain d'un amplificateur s'écrit G = 10 log(P₂/P₁) : une échelle logarithmique, parce que l'oreille et les puissances varient sur des ordres de grandeur énormes.
  • Charge et décharge d'un condensateur — u(t) = U(1 − e−t/RC) : l'exponentielle décrit toute la réponse d'un circuit RC. Le logarithme sert à retrouver le temps t à partir d'une tension.
  • Fiabilité — au chapitre 09, la fonction de fiabilité vaut R(t) = e−λt, et retrouver λ à partir d'une probabilité se fait par λ = −ln(p)/t. Ce chapitre-ci en donne les outils.

02Le logarithme népérien

🧰 Définition

On appelle logarithme népérien l'unique fonction, notée ln, définie et dérivable sur ]0 ; +∞[, vérifiant ln 1 = 0 et dont la dérivée est x ↦ 1/x.

ln : ]0 ; +∞[ → ℝ   ·   ln 1 = 0   ·   (ln x)' = 1/x
⚠️ ln x n'a de sens que si x > 0

Et strictement : ln 0 n'existe pas non plus. C'est la contrainte la plus importante du chapitre, celle qui gouverne toutes les résolutions du § 7.

Conséquence pratique : devant ln(x − 3), on n'a pas le droit d'écrire quoi que ce soit avant d'avoir posé x − 3 > 0. Ce n'est pas une précaution facultative — c'est ce qui élimine les fausses solutions.

💡 « Népérien », et le nombre e

L'adjectif renvoie à John Neper (ou Napier), 1550-1617, l'un des « inventeurs » du logarithme — inventé pour transformer les multiplications d'astronomes en additions, à une époque sans machine à calculer.

Le nombre e ≈ 2,718 28 est celui dont le logarithme vaut 1 : ln e = 1. C'est la base « naturelle », celle pour laquelle la dérivée de l'exponentielle est l'exponentielle elle-même.

03Les propriétés du ln

À retenir impérativement. Elles se ramènent toutes à la première.

🧰 Pour x, y ∈ ]0 ; +∞[ et r ∈ ℝ
PropriétéCe qu'elle transforme
ln(xy) = ln x + ln y un produit en somme
ln(1/x) = −ln x un inverse en opposé
ln(x/y) = ln x − ln y un quotient en différence
ln(x²) = 2 ln x un carré en double
ln(x^r) = r ln x une puissance en produit
ln(√x) = ½ ln x une racine en moitié
ln x = ln y ⟺ x = y permet de supprimer les ln
x < y ⟹ ln x < ln y ln est croissante : l'ordre est conservé
🔗 Une machine à baisser d'un cran

Le logarithme descend chaque opération d'un niveau :

puissance → produit → somme

ln(x⁵) devient 5 ln x — la puissance devient un produit. ln(xy) devient ln x + ln y — le produit devient une somme. C'est ce qui rendait les tables de logarithmes indispensables aux navigateurs : multiplier deux nombres à sept chiffres devenait une addition.

⚠️ Ce que le logarithme ne fait PAS
ln(x + y) ≠ ln x + ln y   ·   ln(x − y) ≠ ln x − ln y

La propriété concerne le produit, pas la somme. Contre-exemple d'une ligne : ln(1 + 1) = ln 2 ≈ 0,69, alors que ln 1 + ln 1 = 0 + 0 = 0. Ce n'est pas la même chose.

Autre confusion fréquente : ln(x²) vaut 2 ln x, mais (ln x)² vaut le carré du logarithme — deux objets différents. Les parenthèses comptent.

🤔 Exprimer en fonction de ln x, pour x > 0
calcul
t₁ = ln x³        = 3 ln x
t₂ = ln(1/x³)     = −ln x³      = −3 ln x
t₃ = ln √x        = ½ ln x
t₄ = ln(1/√x)     = −ln √x      = −½ ln x
t₅ = ln x^(−1/2)  = −½ ln x                ← même chose que t₄
t₆ = ln(x²/x³)    = ln x² − ln x³
                  = 2 ln x − 3 ln x  = −ln x
t₇ = ln(x√x)      = ln x + ln √x
                  = ln x + ½ ln x    = (3/2) ln x

Contrôle : x²/x³ = 1/x, et ln(1/x) = −ln x ✔ De même x√x = x^(3/2), et ln(x^(3/2)) = (3/2) ln x ✔ Simplifier l'intérieur d'abord est souvent plus rapide que d'appliquer les règles une par une.

04L'exponentielle

🧰 Définition

Pour tout réel x, il existe un unique réel y > 0 tel que x = ln y — on dit que ln est une bijection. On appelle exponentielle (de base e) la fonction qui, à tout réel x, associe ce réel y, noté e^x.

exp : ℝ → ]0 ; +∞[   ·   e^x > 0 toujours   ·   e⁰ = 1

e⁰ = 1 découle directement de ln 1 = 0.

⚠️ Une exponentielle ne s'annule JAMAIS
pour tout réel u,  e^u > 0

Deux conséquences que l'examen exploite systématiquement :

  • L'équation ex−1 = 0 n'a aucune solution. Beaucoup d'élèves écrivent « x − 1 = ln 0 » et bloquent — il suffit de dire que l'exponentielle est strictement positive.
  • Dans un produit, un facteur e^u ne change jamais le signe : le signe de (2x − 1)e−0,5x est celui de 2x − 1, tout simplement (§ 9).
💡 Pourquoi la notation en puissance ?

Si on note l'exponentielle sous forme de puissance e^x, c'est justement parce qu'elle vérifie toutes les propriétés des puissances — ex+y = e^x e^y se lit comme 23+4 = 2³ × 2⁴. Ce n'est pas une analogie : c'est la même règle.

05Les propriétés de exp

🧰 Pour x, y, r réels quelconques
PropriétéLe miroir côté ln
ex+y = e^x e^y ln(xy) = ln x + ln y
e−x = 1/e^x ln(1/x) = −ln x
ex−y = e^x / e^y ln(x/y) = ln x − ln y
erx = (e^x)^r ln(x^r) = r ln x
e^x = e^y ⟺ x = y ln x = ln y ⟺ x = y
x < y ⟹ e^x < e^y x < y ⟹ ln x < ln y

Les deux colonnes se répondent terme à terme. Il n'y a pas deux tableaux à apprendre, mais un seul, lu dans deux sens.

🤔 Exprimer en fonction de e^x
calcul
t₁ = e^(−x)          = 1 / e^x
t₂ = e^(2x)          = (e^x)²
t₃ = e^(2x) · e^(−x) = e^(2x − x)   = e^x
t₄ = √(e^(2x))       = (e^(2x))^½   = e^x
t₅ = √(e^(−2x))      = e^(−x)       = 1 / e^x
t₆ = e^(x/2)         = (e^x)^½      = √(e^x)
t₇ = e^(3x) / e^(2x) = e^(3x − 2x)  = e^x
t₈ = e^(5x) √(e^(−8x)) = e^(5x) · e^(−4x)
                       = e^(5x − 4x) = e^x

Cinq des huit se réduisent à e^x tout court — c'est le but de l'exercice. La méthode est toujours la même : tout ramener à un seul exposant, puis simplifier cet exposant. On ne touche jamais à la base.

Pour t₄ : √(e2x) = e^x et non ±e^x, parce qu'une racine carrée est positive et qu'une exponentielle l'est aussi. Les deux conditions concordent ✔

06Deux fonctions réciproques

C'est le cœur du chapitre : chacune défait ce que l'autre fait.

🧰 Les deux relations à connaître par cœur
ln(e^x) = x  pour tout x ∈ ℝ
eln x = x  pour tout x > 0

Attention aux domaines : la première vaut partout (car e^x est toujours défini et positif), la seconde seulement pour x > 0 (car ln x exige x > 0).

📐 Le geste central : composer pour supprimer

Puisque l'une défait l'autre, on peut faire disparaître un ln en appliquant l'exponentielle des deux côtés — et réciproquement. C'est la technique du § 7.

méthode
Pour supprimer un ln :         Pour supprimer une exponentielle :

  ln A = ln B                    e^A = e^B
  e^(ln A) = e^(ln B)            ln(e^A) = ln(e^B)
      A    =    B                    A   =   B

En pratique on abrège :  ln A = ln B  ⟺  A = B   (avec A, B > 0)
                         e^A  = e^B   ⟺  A = B
🤔 Simplifier sans calculatrice
calcul
t₁  = ln e²            = 2
t₂  = ln e^(−3)        = −3
t₃  = e^(ln 2)         = 2
t₄  = e^(−ln 3)        = e^(ln(1/3))     = 1/3
t₅  = ln(1/2) + ln 2   = −ln 2 + ln 2    = 0
t₆  = ln e⁴ − ln e³    = 4 − 3           = 1
t₇  = 2 e^(−ln 2)      = 2 × 1/2         = 1
t₈  = ln e² − e^(ln 2) = 2 − 2           = 0
t₉  = √(e^(−ln 4))     = √(1/4)          = 1/2
t₁₀ = ln(√(e^(−2)))    = ln(e^(−1))      = −1
t₁₁ = e^(ln 2 − ln 3)  = e^(ln(2/3))     = 2/3
t₁₂ = ln(e / e²)       = ln(e^(−1))      = −1

Deux réflexes couvrent les douze : faire apparaître un ln e^k (qui vaut k) ou un eln A (qui vaut A). Dès qu'on y arrive, la calculatrice devient inutile — et c'est bien ce que demande l'énoncé.

🤔 Simplifier l'expression de f(x)
calcul
f₁(x) = (e^x)³               = e^(3x)
f₂(x) = ln(e^(100x)/e^(99x)) = ln(e^(100x − 99x)) = ln(e^x)   = x
f₃(x) = e^(−ln x)            = 1/x                   (x > 0)
f₄(x) = e^(2 ln x)           = e^(ln x²)   = x²      (x > 0)
f₅(x) = e^(x + ln 2)         = e^x · e^(ln 2)  = 2 e^x
f₆(x) = e^(x − ln 3)         = e^x / e^(ln 3)  = e^x / 3
f₇(x) = ln x² − 3 ln x       = 2 ln x − 3 ln x = −ln x   (x > 0)
f₈(x) = e^x · e^(−x)         = e^0             = 1
f₉(x) = ln(3 e^(−x)) + 2x    = ln 3 + ln(e^(−x)) + 2x
                             = ln 3 − x + 2x   = ln 3 + x

Contrôle sur f₉ en x = 0 : ln(3 × 1) + 0 = ln 3, et la forme simplifiée donne ln 3 + 0 = ln 3 ✔ Une substitution numérique valide toute une chaîne de simplifications.

Ne pas oublier les domaines : f₃, f₄ et f₇ ne sont définies que pour x > 0, puisqu'elles contiennent un ln x. La forme simplifiée x² de f₄, elle, existerait partout — mais la fonction de départ, non.

07Résoudre une équation

📐 La méthode, dans cet ordre
  1. Ensemble de définition D — chaque ln(…) impose son contenu strictement positif. On intersecte toutes les conditions. Cette étape se fait AVANT tout calcul.
  2. Regrouper — ramener à ln A = ln B ou e^A = e^B, en utilisant les propriétés.
  3. Supprimer — ln A = ln B ⟹ A = B.
  4. Résoudre l'équation obtenue (affine, trinôme…).
  5. Confronter à D — écarter les solutions qui n'y sont pas. Cette étape est notée.
🧰 L'exemple du tableau — ln(x+1) + ln(x−3) = ln 5
calcul — ① le domaine
Il faut  x + 1 > 0   ET   x − 3 > 0

              x > −1   et       x > 3

Les deux conditions doivent être vraies EN MÊME TEMPS,
donc on garde la plus exigeante :

              D(E₄) = ]3 ; +∞[
calcul — ② à ④
ln(x+1) + ln(x−3) = ln 5
   ln((x+1)(x−3))  = ln 5          ← ln A + ln B = ln(AB)

e^(ln((x+1)(x−3))) = e^(ln 5)      ← on applique exp des deux côtés
      (x+1)(x−3)   = 5

    x² − 3x + x − 3 − 5 = 0
           x² − 2x − 8  = 0

Δ = (−2)² − 4 × 1 × (−8) = 4 + 32 = 36

x₁ = (2 − 6)/2 = −2        x₂ = (2 + 6)/2 = 4
calcul — ⑤ la confrontation
D = ]3 ; +∞[

  −2 ∉ D   →  REJETÉE
   4 ∈ D   →  acceptée

              S = {4}

Vérification : ln(4+1) + ln(4−3) = ln 5 + ln 1 = ln 5 + 0 = ln 5  ✔

Sans l'étape ①, on aurait répondu « −2 et 4 » — et ln(−2+1) = ln(−1) n'existe pas. C'est l'erreur la plus sanctionnée du chapitre, et la seule parade est de poser le domaine avant de calculer.

🤔 Quatre équations avec des logarithmes
calcul — E₁
ln(2x + 1) = 3

D : 2x + 1 > 0  →  x > −1/2      D = ]−1/2 ; +∞[

  ln(2x + 1) = 3
     2x + 1  = e³            ← on applique exp des deux côtés
        2x   = e³ − 1
         x   = (e³ − 1)/2 ≈ 9,54     ∈ D  ✔

S = { (e³ − 1)/2 }
calcul — E₂
1 + ln(x − 1) = 0

D : x − 1 > 0  →  x > 1          D = ]1 ; +∞[

  ln(x − 1) = −1
      x − 1 = e^(−1) = 1/e
        x   = 1 + 1/e ≈ 1,37        ∈ D  ✔

S = { 1 + 1/e }
calcul — E₃
ln(1 + x) = ln(1 − 2x)

D : 1 + x > 0 ET 1 − 2x > 0
        x > −1  et    x < 1/2     D = ]−1 ; 1/2[

  1 + x = 1 − 2x            ← ln A = ln B ⟹ A = B
     3x = 0
      x = 0                       ∈ D  ✔

S = { 0 }     Vérification : ln 1 = ln 1  ✔

Sur E₃, les deux conditions donnent un intervalle borné des deux côtés : x > −1 par la gauche, x < 1/2 par la droite. Attention au sens de l'inégalité sur la seconde — 1 − 2x > 0 donne −2x > −1 puis x < 1/2, le signe se retourne.

🤔 Cinq équations avec des exponentielles

Ici, pas de contrainte de domaine : une exponentielle est définie partout. En revanche elle ne s'annule jamais — et c'est là que se joue la difficulté.

calcul — E₅ à E₈
E₅ : e^(−x² + 1) = 1

     1 = e⁰, donc  −x² + 1 = 0  →  x² = 1  →  x = ±1
     S = { −1 ; 1 }

E₆ : e^(x − 1) = 0

     Une exponentielle est TOUJOURS strictement positive.
     Elle ne peut donc jamais valoir 0.
     S = ∅                            ← pas de calcul, un raisonnement

E₇ : e^(3 − x²) = e^(−1)

     e^A = e^B ⟹ A = B :  3 − x² = −1  →  x² = 4  →  x = ±2
     S = { −2 ; 2 }

E₈ : e^x − e^(−x) = 0

     e^x = e^(−x)  ⟹  x = −x  →  2x = 0  →  x = 0
     S = { 0 }       Vérification : e⁰ − e⁰ = 1 − 1 = 0  ✔
calcul — E₉, changement de variable
E₉ : 2e^(2x) + e^x − 3 = 0

On pose  X = e^x.  Alors  e^(2x) = (e^x)² = X².

     2X² + X − 3 = 0
     Δ = 1² − 4 × 2 × (−3) = 1 + 24 = 25

     X₁ = (−1 − 5)/4 = −6/4 = −3/2
     X₂ = (−1 + 5)/4 =  4/4 =  1

CONTRAINTE : X = e^x, donc X > 0 obligatoirement.
     X₁ = −3/2 < 0  →  REJETÉE
     X₂ = 1         →  acceptée

     e^x = 1 = e⁰  →  x = 0

S = { 0 }     Vérification : 2 × 1 + 1 − 3 = 0  ✔

Le changement de variable est le geste à retenir : dès qu'on voit e2x et e^x ensemble, on pose X = e^x et on retombe sur un trinôme du chapitre 03.

Et la contrainte X > 0 joue ici exactement le rôle que le domaine joue pour le logarithme : elle élimine une solution. L'oublier coûte la question.

08Résoudre une inéquation

Même méthode qu'au § 7, avec une propriété de plus : ln et exp sont croissantes, donc elles conservent le sens de l'inégalité.

🧰 La croissance conserve l'ordre
ln A < ln B  ⟺  A < B  (A, B > 0)
e^A < e^B  ⟺  A < B

Le sens ne change pas. C'est une différence importante avec la division par un négatif du chapitre 03, où l'inégalité se retourne.

📐 La solution est une INTERSECTION

On obtient deux informations : le domaine D et la condition issue de l'inéquation. La réponse est S = D ∩ condition — pas seulement la seconde.

🤔 Les deux inéquations du tableau
calcul — E₁
ln(2x) > 0

D : 2x > 0  →  x > 0              D = ]0 ; +∞[

  e^(ln(2x)) > e⁰                 ← exp des deux côtés, sens conservé
        2x   > 1
         x   > 1/2

S = D ∩ ]1/2 ; +∞[ = ]1/2 ; +∞[

(ici la condition est plus exigeante que le domaine : elle l'absorbe)
calcul — E₂
ln(x + 1) < ln 2

D : x + 1 > 0  →  x > −1          D = ]−1 ; +∞[

  e^(ln(x+1)) < e^(ln 2)
      x + 1   < 2
        x     < 1

S = D ∩ ]−∞ ; 1[ = ]−1 ; 1[       ← ici l'intersection MORD

Sur E₂, oublier le domaine donnerait ]−∞ ; 1[ — c'est-à-dire accepter x = −5, pour lequel ln(−4) n'existe pas. L'intersection n'est pas une formalité.

🤔 Quand le domaine est ℝ tout entier

Un ln dont le contenu est un trinôme sans racine et positif est défini partout. Deux exemples du devoir.

calcul — E₃
ln(x² + x + 1) > ln 3 − ln 4

D : Δ de x² + x + 1 vaut 1 − 4 = −3 < 0, et a = 1 > 0
    donc x² + x + 1 > 0 pour tout x          D = ℝ

  ln 3 − ln 4 = ln(3/4)

  ln(x² + x + 1) > ln(3/4)
       x² + x + 1 > 3/4
       x² + x + 1/4 > 0
          (x + 1/2)² > 0            ← identité remarquable

Un carré est positif SAUF s'il est nul : (x + 1/2)² = 0 en x = −1/2.

S = ℝ \ {−1/2}
calcul — E₄
ln(x² − x + 2) < 0

D : Δ de x² − x + 2 vaut 1 − 8 = −7 < 0, a > 0  →  D = ℝ

  0 = ln 1, donc :
  ln(x² − x + 2) < ln 1
       x² − x + 2 < 1
       x² − x + 1 < 0

  Δ de x² − x + 1 vaut 1 − 4 = −3 < 0, et a = 1 > 0
  → ce trinôme est TOUJOURS positif, jamais négatif.

S = ∅

Ces deux-là se résolvent entièrement avec le discriminant du chapitre 03 : le logarithme disparaît dès la troisième ligne. Un Δ négatif est une réponse, pas un échec — ici il donne D = ℝ pour l'un et S = ∅ pour l'autre.

🤔 Quatre inéquations exponentielles
calcul
E₅ : e^(2x) < e²          →  2x < 2  →  x < 1
     S = ]−∞ ; 1[

E₆ : e^(−x) − 2 > 0       →  e^(−x) > 2
                             −x > ln 2        ← ln des deux côtés
                              x < −ln 2       ← × (−1) : le sens se RETOURNE
     S = ]−∞ ; −ln 2[          −ln 2 ≈ −0,69

E₇ : 1 − e^(−0,75x + 0,5) > 0
                          →  e^(−0,75x + 0,5) < 1 = e⁰
                             −0,75x + 0,5 < 0
                                   −0,75x < −0,5
                                        x > 2/3        ← sens retourné
     S = ]2/3 ; +∞[

E₈ : 1 + e^(−2x) > 1      →  e^(−2x) > 0
                             VRAI pour tout x : une exponentielle
                             est toujours strictement positive.
     S = ℝ

Deux pièges dans ce lot. E₆ et E₇ : le passage au logarithme conserve le sens, mais la division par un coefficient négatif qui suit le retourne — ce sont deux étapes différentes. Contrôle sur E₇ : x = 1 > 2/3 donne 1 − e−0,25 ≈ 0,22 > 0 ✔ et x = 0 donne 1 − e0,5 ≈ −0,65 < 0 ✔

E₈ ne demande aucun calcul : c'est la propriété e^u > 0, et la réponse est ℝ tout entier.

09Signe et dérivées

Le signe d'une expression contenant e^u

🧰 L'exponentielle ne change jamais le signe
pour tout x ∈ ℝ,  e^u > 0

Dans un tableau de signe, la ligne e^u ne porte donc que des « + », sans aucun zéro. Le signe du produit est celui de l'autre facteur.

calcul
f₂(x) = (2x − 1) e^(−0,5x)

  2x − 1 > 0  ⟺  x > 1/2
  ∀x ∈ ℝ, e^(−0,5x) > 0

  x        │ −∞          1/2          +∞
  ─────────┼──────────────────────────────
  2x − 1   │      −       0       +
  e^(−0,5x)│      +               +        ← jamais de zéro
  ─────────┼──────────────────────────────
  f₂(x)    │      −       0       +

f₂ a exactement le signe de (2x − 1).
⚠️ Un quotient, lui, a une valeur interdite
calcul
f₃(x) = (x − 3) e^(−2x+1) / (x − 2)

L'exponentielle est définie partout et positive.
Mais le DÉNOMINATEUR s'annule en x = 2 :

           D(f₃) = ℝ \ {2}

Dans le tableau de signe, une DOUBLE BARRE en x = 2 —
pas un zéro : la fonction n'y existe pas.

La différence est visible au barème : un « 0 » et une « ‖ » ne disent pas la même chose. Le zéro dit « la fonction s'annule », la double barre dit « la fonction n'existe pas ».

Dériver avec e^u

🧰 Les deux formules
(e^x)' = e^x
(e^u)' = u' · e^u

L'exponentielle est sa propre dérivée — c'est ce qui la rend unique. Et comme pour uⁿ et √u au chapitre 04, il apparaît un facteur u' : la dérivée de l'exposant.

Pour mémoire, côté logarithme : (ln x)' = 1/x et (ln u)' = u'/u.

🤔 Dériver trois fonctions du tableau
calcul — 1
f(x) = e^(−2x)

On pose  u(x) = −2x   donc  u'(x) = −2

  (e^u)' = u' e^u

f'(x) = −2 e^(−2x)
calcul — 2
f(x) = 2 e^(−0,5x)

On pose  u(x) = −0,5x   donc  u'(x) = −0,5

  (k·e^u)' = k · u' · e^u

f'(x) = 2 × (−0,5) × e^(−0,5x)
      = −e^(−0,5x)
calcul — 3
f(x) = (2x − 1) e^(2x)         ← un PRODUIT

  u  = 2x − 1        v  = e^(2x)
  u' = 2             v' = 2 e^(2x)        ← (e^u)' avec u = 2x

  (uv)' = u'v + uv'

f'(x) = 2 e^(2x) + (2x − 1) × 2 e^(2x)
      = e^(2x) [ 2 + 2(2x − 1) ]          ← on FACTORISE par e^(2x)
      = e^(2x) [ 2 + 4x − 2 ]
      = 4x · e^(2x)

Le geste décisif de la troisième : factoriser par e2x, qui est commun aux deux termes. On obtient une forme courte dont le signe se lit — celui de 4x, puisque l'exponentielle est positive. Développer aurait donné 4x e2x aussi, mais le chemin factorisé est plus sûr, et c'est la même leçon qu'au chapitre 04.

Contrôle en x = 0 : la forme de départ dérivée « à la main » donne 2e⁰ + (−1)(2e⁰) = 2 − 2 = 0, et 4 × 0 × e⁰ = 0 ✔

10Les modèles

Le chapitre se termine sur ce qui lui donne son intérêt : décrire une grandeur qui croît ou décroît proportionnellement à elle-même.

🧰 Retrouver un exposant par le logarithme

C'est le problème posé en ouverture. Reprenons-le en entier.

calcul
aₙ = 25 000 − 20 000 × 0,8ⁿ     (abonnés au bout de n années)

a₀ = 25 000 − 20 000 × 0,8⁰ = 25 000 − 20 000 = 5 000

Quadrupler, c'est atteindre 4 × 5 000 = 20 000 :

     25 000 − 20 000 × 0,8ⁿ = 20 000
              20 000 × 0,8ⁿ =  5 000
                       0,8ⁿ =  0,25

  ln(0,8ⁿ) = ln(0,25)                ← ln des deux côtés
  n × ln(0,8) = ln(0,25)             ← l'exposant DESCEND
        n = ln(0,25) / ln(0,8)
        n ≈ 6,21

Comme n est un nombre d'années entier, il faut n = 7 années.

Contrôle : a₆ ≈ 19 757 (pas encore quadruplé) et a₇ ≈ 20 806 (dépassé) ✔ On arrondit vers le haut, parce qu'il faut atteindre le seuil.

⚠️ Diviser par un logarithme négatif retourne l'inégalité

ln(0,8) ≈ −0,223 est négatif, parce que 0,8 < 1. Règle générale :

ln a < 0 si 0 < a < 1  ·  ln a > 0 si a > 1

Dans une équation cela ne change rien. Dans une inéquation, si — diviser les deux membres par ln(0,8) retourne le sens. C'est le piège classique des problèmes de seuil.

🤔 Que devient le nombre d'abonnés à long terme ?
calcul
a₁₀ = 25 000 − 20 000 × 0,8¹⁰ ≈ 25 000 − 2 147 ≈ 22 853
a₂₀ = 25 000 − 20 000 × 0,8²⁰ ≈ 25 000 −   231 ≈ 24 769
a₅₀ = 25 000 − 20 000 × 0,8⁵⁰ ≈ 25 000 −     0 ≈ 25 000
a₇₀ ≈ 25 000

Interprétation : 0,8ⁿ tend vers 0 quand n grandit (car 0 < 0,8 < 1),
donc aₙ se rapproche de 25 000 sans jamais l'atteindre.

La revue plafonne à 25 000 abonnés : c'est la limite du modèle.

Une décroissance exponentielle ne s'annule jamais mais devient indétectable : à n = 50, l'écart au plafond vaut 0,29 abonné. C'est le même phénomène que la queue de la loi normale au-delà de 3σ, ou que la charge d'un condensateur après 5 RC.

🧰 Le modèle logistique — équipement en téléphones

Un second modèle très courant, qui décrit une adoption qui démarre lentement, s'emballe, puis sature.

f(t) = 100 / (1 + k eαt)
calcul
Données : 10 % des foyers équipés à t = 0, et 80 % cinq ans plus tard.

① À t = 0 :   100 / (1 + k e⁰) = 10
              100 / (1 + k)    = 10
                    1 + k      = 10
                          k    = 9

② À t = 5 :   100 / (1 + 9 e^(5α)) = 80
                    1 + 9 e^(5α)   = 100/80 = 1,25
                        9 e^(5α)   = 0,25
                          e^(5α)   = 0,25/9 = 1/36

  ln(e^(5α)) = ln(1/36)
        5α   = −ln 36
         α   = −ln(36)/5 ≈ −0,717

Vérification : f(0) = 100/(1+9) = 10 %  ✔
               f(5) = 100/(1+9×(1/36)) = 100/1,25 = 80 %  ✔
🔧 Corrigé — les dates de l'énoncé sont incohérentes

L'énoncé pose f définie sur [0 ; +∞[ avec « t = 0 au 1er janvier 2008 », puis donne les données pour « 2000 » et « 2005 ». Or si t = 0 correspond à 2008, alors 2000 correspond à t = −8 — hors de l'intervalle de définition.

Le corrigé ci-dessus prend t = 0 au 1er janvier 2000, ce qui rend l'énoncé cohérent et place les deux données à t = 0 et t = 5. C'est très probablement l'intention : un énoncé plus ancien, dont la date de référence a été actualisée sans reprendre les données.

À l'examen, face à ce genre d'incohérence : choisir une lecture, l'écrire explicitement, et poursuivre. Un correcteur valorise une hypothèse assumée ; il ne peut rien faire d'une copie blanche.

💡 Le changement de variable, une seconde fois

L'exercice le plus long du devoir combine les deux chapitres :

calcul
P(x) = 2x³ + 7x² − 14x + 5, avec P(x) = (x − 1)(ax² + bx + c)

En développant et en identifiant :  a = 2, b = 9, c = −5
     P(x) = (x − 1)(2x² + 9x − 5)

Racines de 2x² + 9x − 5 :  Δ = 81 + 40 = 121, √Δ = 11
     x = (−9 − 11)/4 = −5     et     x = (−9 + 11)/4 = 1/2

     P(x) = 0  ⟺  x ∈ { −5 ; 1/2 ; 1 }

E₁ : 2(ln x)³ + 7(ln x)² − 14 ln x + 5 = 0
     On pose X = ln x → X ∈ { −5 ; 1/2 ; 1 }
     ln x = −5 → x = e^(−5)      ln x = 1/2 → x = √e
     ln x = 1  → x = e
     S = { e^(−5) ; √e ; e }        (les trois sont > 0 ✔)

E₂ : 2e^(3x) + 7e^(2x) − 14e^x + 5 = 0
     On pose X = e^x, avec la contrainte X > 0.
     X = −5 REJETÉE (négative) ; restent X = 1/2 et X = 1.
     e^x = 1/2 → x = ln(1/2) = −ln 2
     e^x = 1   → x = 0
     S = { −ln 2 ; 0 }

La même factorisation sert deux fois. Et la différence entre les deux réponses tient à une seule chose : ln x peut être négatif, e^x jamais. C'est tout le chapitre en une phrase.

⚡ Récap 2 minutes

  • Domaines : ln x exige x > 0 strictement · e^x existe sur ℝ et vaut toujours > 0.
  • Valeurs repères : ln 1 = 0 · ln e = 1 · e⁰ = 1 · e ≈ 2,718.
  • Réciproques : ln(e^x) = x pour tout x · eln x = x pour x > 0. Les courbes sont symétriques par rapport à y = x.
  • ln transforme : produit → somme · quotient → différence · puissance → produit (ln x^r = r ln x) · racine → moitié.
  • exp transforme : somme → produit (ex+y = e^x e^y) · différence → quotient · erx = (e^x)^r.
  • Pas de propriété sur les sommes : ln(x+y) ≠ ln x + ln y.
  • Méthode d'une équation : ① domaine · ② regrouper · ③ supprimer (ln A = ln B ⟹ A = B) · ④ résoudre · ⑤ confronter au domaine. L'étape ⑤ est notée.
  • Inéquation : ln et exp sont croissantes, le sens est conservé. Mais la réponse est S = D ∩ condition.
  • Diviser par un négatif retourne le sens — et ln a < 0 dès que 0 < a < 1.
  • e^u = 0 est impossible : S = ∅, sans calcul. Et e^u > 0 ne change jamais le signe d'un produit.
  • Changement de variable : devant e2x et e^x, poser X = e^x — avec la contrainte X > 0, qui élimine les racines négatives.
  • Dérivées : (e^x)' = e^x · (e^u)' = u' e^u · (ln x)' = 1/x · (ln u)' = u'/u. Et on factorise par e^u pour lire le signe.
  • Faire descendre un exposant : ln(aⁿ) = n ln a. C'est ce qui résout tous les problèmes de seuil.
