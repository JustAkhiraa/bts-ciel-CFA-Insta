Logarithme & exponentielle — exercices

Les neuf exercices du polycopié, corrigés en entier, plus les résolutions détaillées au tableau.

🎯

Le réflexe d'attaque

Devant un ln, poser le domaine AVANT tout calcul. Devant une exponentielle, se rappeler qu'elle est toujours strictement positive — c'est ce qui élimine une racine dans un changement de variable, et ce qui rend e^u = 0 impossible.

01Simplifier

1Exprimer en fonction de ln x Facile

Pour x > 0, exprimer les réels suivants en fonction de ln x.

énoncé
t₁ = ln x³        t₂ = ln(1/x³)     t₃ = ln √x        t₄ = ln(1/√x)
t₅ = ln x^(−1/2)  t₆ = ln(x²/x³)    t₇ = ln(x√x)
✅ Correction
calcul
t₁ = ln x³        = 3 ln x                      (ln x^r = r ln x)

t₂ = ln(1/x³)     = −ln x³        = −3 ln x     (ln(1/A) = −ln A)

t₃ = ln √x        = ½ ln x                      (√x = x^½)

t₄ = ln(1/√x)     = −ln √x        = −½ ln x

t₅ = ln x^(−1/2)  = −½ ln x                     ← identique à t₄
                                                  car 1/√x = x^(−1/2)

t₆ = ln(x²/x³)    = ln x² − ln x³
                  = 2 ln x − 3 ln x = −ln x

t₇ = ln(x√x)      = ln x + ln √x
                  = ln x + ½ ln x   = (3/2) ln x

Contrôles en simplifiant l'intérieur d'abord : x²/x³ = x^(−1) = 1/x, donc t₆ = ln(1/x) = −ln x ✔ ; x√x = x^1 × x^½ = x^(3/2), donc t₇ = (3/2) ln x ✔ Quand l'intérieur se simplifie, le faire d'abord est toujours plus rapide.

t₄ et t₅ sont la même expression écrite autrement. Repérer ces doublons fait gagner du temps en devoir.

2Exprimer en fonction de e^x Facile

Pour x ∈ ℝ, exprimer les réels suivants en fonction de e^x.

énoncé
t₁ = e^(−x)    t₂ = e^(2x)         t₃ = e^(2x) e^(−x)   t₄ = √(e^(2x))
t₅ = √(e^(−2x))  t₆ = e^(x/2)      t₇ = e^(3x)/e^(2x)   t₈ = e^(5x)√(e^(−8x))
✅ Correction
calcul
t₁ = e^(−x)            = 1 / e^x

t₂ = e^(2x)            = (e^x)²                 (e^(rx) = (e^x)^r)

t₃ = e^(2x) · e^(−x)   = e^(2x − x)   = e^x     (e^a · e^b = e^(a+b))

t₄ = √(e^(2x))         = (e^(2x))^½   = e^x

t₅ = √(e^(−2x))        = e^(−x)       = 1 / e^x

t₆ = e^(x/2)           = (e^x)^½      = √(e^x)

t₇ = e^(3x) / e^(2x)   = e^(3x − 2x)  = e^x

t₈ = e^(5x) · √(e^(−8x)) = e^(5x) · e^(−4x)
                         = e^(5x − 4x) = e^x

Cinq des huit valent simplement e^x — c'est le but de l'exercice. La méthode est unique : tout ramener à un seul exposant, puis simplifier cet exposant. On ne touche jamais à la base.

⚠️ Pourquoi √(e2x) = e^x et non ±e^x

Une racine carrée est positive par définition, et une exponentielle l'est aussi. Les deux conditions concordent, il n'y a donc aucune ambiguïté de signe — contrairement à √(x²) = |x|, où le signe de x est inconnu.

02Les relations ln ↔ exp

3Douze simplifications, sans calculatrice Moyen

énoncé
t₁ = ln e²          t₂ = ln e^(−3)      t₃ = e^(ln 2)     t₄ = e^(−ln 3)
t₅ = ln(1/2) + ln 2 t₆ = ln e⁴ − ln e³  t₇ = 2 e^(−ln 2)  t₈ = ln e² − e^(ln 2)
t₉ = √(e^(−ln 4))   t₁₀ = ln(√(e^(−2))) t₁₁ = e^(ln 2 − ln 3)   t₁₂ = ln(e/e²)
✅ Correction

Deux réflexes suffisent : faire apparaître un ln(e^k), qui vaut k, ou un eln A, qui vaut A.

calcul
t₁  = ln e²              = 2
t₂  = ln e^(−3)          = −3
t₃  = e^(ln 2)           = 2
t₄  = e^(−ln 3)          = e^(ln(1/3))          = 1/3
t₅  = ln(1/2) + ln 2     = −ln 2 + ln 2         = 0
t₆  = ln e⁴ − ln e³      = 4 − 3                = 1
t₇  = 2 e^(−ln 2)        = 2 × (1/2)            = 1
t₈  = ln e² − e^(ln 2)   = 2 − 2                = 0
t₉  = √(e^(−ln 4))       = √(1/4)               = 1/2
t₁₀ = ln(√(e^(−2)))      = ln(e^(−1))           = −1
t₁₁ = e^(ln 2 − ln 3)    = e^(ln(2/3))          = 2/3
t₁₂ = ln(e / e²)         = ln(e^(1−2)) = ln(e^(−1))  = −1

Sur t₄ et t₇, la clé est qu'un signe moins devant un ln devient un inverse : −ln 3 = ln(1/3) pour t₄, −ln 2 = ln(1/2) pour t₇. Sur t₆, on aurait aussi pu écrire ln(e⁴/e³) = ln e = 1 — les deux chemins donnent 1 ✔

Tous les résultats sont des nombres simples : 2, −3, 1/3, 0, 1, 1/2, 2/3, −1. Si vous tombez sur un nombre à décimales, c'est qu'il reste une simplification à faire.

4Simplifier l'expression de f(x) Moyen

énoncé
f₁(x) = (e^x)³               f₂(x) = ln(e^(100x)/e^(99x))   f₃(x) = e^(−ln x)
f₄(x) = e^(2 ln x)           f₅(x) = e^(x + ln 2)           f₆(x) = e^(x − ln 3)
f₇(x) = ln x² − 3 ln x       f₈(x) = e^x e^(−x)             f₉(x) = ln(3e^(−x)) + 2x
✅ Correction
calcul
f₁(x) = (e^x)³               = e^(3x)

f₂(x) = ln(e^(100x)/e^(99x)) = ln(e^(100x − 99x))
                             = ln(e^x)        = x

f₃(x) = e^(−ln x)            = e^(ln(1/x))    = 1/x        (x > 0)

f₄(x) = e^(2 ln x)           = e^(ln x²)      = x²         (x > 0)

f₅(x) = e^(x + ln 2)         = e^x · e^(ln 2) = 2 e^x

f₆(x) = e^(x − ln 3)         = e^x / e^(ln 3) = e^x / 3

f₇(x) = ln x² − 3 ln x       = 2 ln x − 3 ln x = −ln x     (x > 0)

f₈(x) = e^x · e^(−x)         = e^(x − x) = e⁰  = 1

f₉(x) = ln(3 e^(−x)) + 2x    = ln 3 + ln(e^(−x)) + 2x
                             = ln 3 − x + 2x   = ln 3 + x

Contrôle de f₉ en x = 0 : la forme de départ donne ln(3 × e⁰) + 0 = ln 3, la forme simplifiée ln 3 + 0 = ln 3 ✔ Une seule substitution valide toute la chaîne.

⚠️ La simplification ne change pas le domaine

f₄(x) = e2 ln x se simplifie en x², qui existe pour tout réel. Mais f₄ n'est définie que pour x > 0, puisqu'elle contient un ln x. Idem pour f₃ et f₇.

Sur une copie : donner la forme simplifiée et préciser le domaine. Écrire « f₄(x) = x² » sans restriction est une réponse incomplète.

03Équations

5Quatre équations logarithmiques Moyen

Résoudre dans ℝ, en précisant à chaque fois l'ensemble de définition.

énoncé
E₁ : ln(2x + 1) = 3              E₂ : 1 + ln(x − 1) = 0
E₃ : ln(1 + x) = ln(1 − 2x)      E₄ : ln(x + 1) + ln(x − 3) = ln 5
✅ Correction
calcul — E₁
Domaine :  2x + 1 > 0  →  2x > −1  →  x > −1/2
           D = ]−1/2 ; +∞[

  ln(2x + 1) = 3
     2x + 1  = e³                  ← exp des deux côtés
        2x   = e³ − 1
         x   = (e³ − 1)/2  ≈  9,54

  9,54 > −1/2  →  ∈ D  ✔

S = { (e³ − 1)/2 }
calcul — E₂
Domaine :  x − 1 > 0  →  x > 1
           D = ]1 ; +∞[

  1 + ln(x − 1) = 0
      ln(x − 1) = −1
          x − 1 = e^(−1) = 1/e
            x   = 1 + 1/e  ≈  1,37

  1,37 > 1  →  ∈ D  ✔

S = { 1 + 1/e }
calcul — E₃
Domaine :  1 + x > 0   ET   1 − 2x > 0
               x > −1   et     −2x > −1
                                 x < 1/2      ← le sens se RETOURNE
           D = ]−1 ; 1/2[

  ln(1 + x) = ln(1 − 2x)
      1 + x = 1 − 2x              ← ln A = ln B ⟹ A = B
      x + 2x = 1 − 1
          3x = 0
           x = 0

  0 ∈ ]−1 ; 1/2[  ✔

S = { 0 }     Vérification : ln(1+0) = ln 1 = 0 = ln(1−0)  ✔
calcul — E₄
Domaine :  x + 1 > 0   ET   x − 3 > 0
               x > −1   et       x > 3
           Les DEUX doivent être vraies : on garde la plus exigeante.
           D = ]3 ; +∞[

  ln(x + 1) + ln(x − 3) = ln 5
     ln((x + 1)(x − 3))  = ln 5    ← ln A + ln B = ln(AB)
        (x + 1)(x − 3)   = 5
     x² − 3x + x − 3 − 5 = 0
            x² − 2x − 8  = 0

  Δ = (−2)² − 4 × 1 × (−8) = 4 + 32 = 36
  x₁ = (2 − 6)/2 = −2        x₂ = (2 + 6)/2 = 4

  −2 ∉ ]3 ; +∞[  →  REJETÉE
   4 ∈ ]3 ; +∞[  →  acceptée

S = { 4 }     Vérification : ln 5 + ln 1 = ln 5 + 0 = ln 5  ✔

E₄ est l'exercice-type du chapitre. Sans le domaine, on répond « −2 et 4 » — et ln(−2 + 1) = ln(−1) n'existe pas. C'est l'erreur la plus sanctionnée, et la seule parade est de poser D avant de calculer.

Sur E₃, attention au retournement : 1 − 2x > 0 donne −2x > −1, et diviser par −2 inverse le sens → x < 1/2.

6Cinq équations exponentielles Moyen

énoncé
E₅ : e^(−x² + 1) = 1      E₆ : e^(x − 1) = 0      E₇ : e^(3 − x²) = e^(−1)
E₈ : e^x − e^(−x) = 0     E₉ : 2e^(2x) + e^x − 3 = 0   (poser X = e^x)
✅ Correction

Une exponentielle est définie sur ℝ : pas de domaine à poser. En revanche elle ne s'annule jamais, et c'est là que tout se joue.

calcul — E₅
e^(−x² + 1) = 1

  1 = e⁰, donc :   e^(−x² + 1) = e⁰
                       −x² + 1 = 0
                            x² = 1
                             x = 1  ou  x = −1

S = { −1 ; 1 }     Vérification : e^(−1+1) = e⁰ = 1  ✔
calcul — E₆
e^(x − 1) = 0

Pour tout réel u,  e^u > 0 STRICTEMENT.
Une exponentielle ne peut donc jamais valoir 0.

S = ∅

(aucun calcul : c'est un raisonnement, et il rapporte
 exactement les mêmes points)
calcul — E₇
e^(3 − x²) = e^(−1)

  e^A = e^B ⟹ A = B :
       3 − x² = −1
          −x² = −4
           x² = 4
            x = 2  ou  x = −2

S = { −2 ; 2 }     Vérification : e^(3−4) = e^(−1)  ✔
calcul — E₈
e^x − e^(−x) = 0

       e^x = e^(−x)
         x = −x                    ← e^A = e^B ⟹ A = B
        2x = 0
         x = 0

S = { 0 }     Vérification : e⁰ − e⁰ = 1 − 1 = 0  ✔
calcul — E₉, changement de variable
2e^(2x) + e^x − 3 = 0

On pose X = e^x.  Alors e^(2x) = (e^x)² = X².
L'équation devient un TRINÔME :

     2X² + X − 3 = 0
     Δ = 1² − 4 × 2 × (−3) = 1 + 24 = 25,  √Δ = 5

     X₁ = (−1 − 5)/4 = −6/4 = −3/2
     X₂ = (−1 + 5)/4 =  4/4 =  1

CONTRAINTE : X = e^x, donc X > 0 obligatoirement.

     X₁ = −3/2 < 0   →  REJETÉE
     X₂ = 1          →  acceptée

  e^x = 1 = e⁰   →   x = 0

S = { 0 }     Vérification : 2 e⁰ + e⁰ − 3 = 2 + 1 − 3 = 0  ✔

La contrainte X > 0 joue pour l'exponentielle exactement le rôle que le domaine joue pour le logarithme : elle élimine une solution. L'oublier, c'est répondre « x = ln(−3/2) », qui n'existe pas.

04Inéquations

7Quatre inéquations logarithmiques Moyen

énoncé
E₁ : ln 2x > 0                    E₂ : ln(x + 1) < ln 2
E₃ : ln(x² + x + 1) > ln 3 − ln 4  E₄ : ln(x² − x + 2) < 0
✅ Correction

ln est croissante : le sens de l'inégalité est conservé. Et la solution est l'intersection du domaine et de la condition.

calcul — E₁
Domaine :  2x > 0  →  x > 0        D = ]0 ; +∞[

  ln(2x) > 0
  e^(ln 2x) > e⁰                   ← exp des deux côtés
       2x   > 1
        x   > 1/2

S = D ∩ ]1/2 ; +∞[ = ]1/2 ; +∞[

(la condition est plus exigeante que le domaine : elle l'absorbe)
calcul — E₂
Domaine :  x + 1 > 0  →  x > −1    D = ]−1 ; +∞[

  ln(x + 1) < ln 2
      x + 1 < 2
        x   < 1

S = D ∩ ]−∞ ; 1[ = ]−1 ; 1[       ← ici l'intersection MORD

Sur E₂, oublier le domaine donnerait ]−∞ ; 1[, c'est-à-dire accepter x = −5 — pour lequel ln(−4) n'existe pas. L'intersection n'est pas une formalité.

calcul — E₃
Domaine :  x² + x + 1 > 0 ?
           Δ = 1² − 4 × 1 × 1 = −3 < 0, et a = 1 > 0
           → le trinôme est TOUJOURS positif    D = ℝ

  ln 3 − ln 4 = ln(3/4)

  ln(x² + x + 1) > ln(3/4)
       x² + x + 1 > 3/4
       x² + x + 1 − 3/4 > 0
       x² + x + 1/4 > 0
          (x + 1/2)² > 0          ← identité remarquable

Un carré est positif, SAUF s'il est nul :
  (x + 1/2)² = 0  ⟺  x = −1/2

S = ℝ \ {−1/2}
calcul — E₄
Domaine :  x² − x + 2 > 0 ?
           Δ = 1 − 8 = −7 < 0, et a = 1 > 0   →   D = ℝ

  0 = ln 1, donc :
  ln(x² − x + 2) < ln 1
       x² − x + 2 < 1
       x² − x + 1 < 0

  Δ de x² − x + 1 : 1 − 4 = −3 < 0, et a = 1 > 0
  → ce trinôme est toujours POSITIF : il n'est jamais < 0.

S = ∅

E₃ et E₄ se résolvent entièrement avec le discriminant du chapitre 03 : le logarithme disparaît dès la troisième ligne. Un Δ négatif est une réponse — ici il donne D = ℝ pour l'un et S = ∅ pour l'autre.

8Quatre inéquations exponentielles Difficile

énoncé
E₅ : e^(2x) < e²            E₆ : e^(−x) − 2 > 0
E₇ : 1 − e^(−0,75x + 0,5) > 0     E₈ : 1 + e^(−2x) > 1
✅ Correction
calcul — E₅
e^(2x) < e²

  exp est croissante, le sens est conservé :
       2x < 2
        x < 1

S = ]−∞ ; 1[
calcul — E₆
e^(−x) − 2 > 0

    e^(−x) > 2
  ln(e^(−x)) > ln 2              ← ln des deux côtés, sens CONSERVÉ
        −x   > ln 2
         x   < −ln 2             ← × (−1) : le sens se RETOURNE

S = ]−∞ ; −ln 2[        −ln 2 ≈ −0,69

Contrôle : x = −1 < −0,69 → e^1 − 2 = 2,72 − 2 = 0,72 > 0  ✔
           x =  0 > −0,69 → e^0 − 2 = 1 − 2 = −1 < 0        ✔
calcul — E₇
1 − e^(−0,75x + 0,5) > 0

  e^(−0,75x + 0,5) < 1 = e⁰
       −0,75x + 0,5 < 0           ← sens conservé
             −0,75x < −0,5
                  x > 0,5/0,75 = 2/3     ← × (−1) : sens RETOURNÉ

S = ]2/3 ; +∞[          2/3 ≈ 0,67

Contrôle : x = 1 > 2/3 → 1 − e^(−0,25) ≈ 1 − 0,78 = 0,22 > 0  ✔
           x = 0 < 2/3 → 1 − e^( 0,50) ≈ 1 − 1,65 = −0,65 < 0 ✔
calcul — E₈
1 + e^(−2x) > 1

    e^(−2x) > 0

Or une exponentielle est TOUJOURS strictement positive.
L'inéquation est donc vraie pour tout réel x.

S = ℝ           ← aucun calcul, juste la propriété

Deux étapes différentes à ne pas confondre sur E₆ et E₇ : passer au logarithme conserve le sens (ln est croissante), mais la division par un coefficient négatif qui suit le retourne. Les deux contrôles numériques valident chaque réponse en dix secondes.

05Signe et dérivées

9Étudier le signe de trois fonctions Moyen

  1. f₁(x) = (x − 1)(−2x + 4)
  2. f₂(x) = (2x − 1) e−0,5x
  3. f₃(x) = (x − 3) e−2x+1 / (x − 2) — donner d'abord son ensemble de définition.
✅ Correction
calcul — f₁
Deux facteurs affines. On cherche le signe de chacun.

  x − 1 > 0   ⟺   x > 1
  −2x + 4 > 0 ⟺  −2x > −4  ⟺  x < 2       ← sens retourné

  x        │ −∞        1        2        +∞
  ─────────┼───────────────────────────────
  x − 1    │     −     0    +        +
  −2x + 4  │     +          +   0    −
  ─────────┼───────────────────────────────
  f₁(x)    │     −     0    +   0    −

f₁ > 0 sur ]1 ; 2[  ·  f₁ < 0 sur ]−∞ ; 1[ ∪ ]2 ; +∞[

Contrôle : f₁(0) = (−1)(4) = −4 < 0   ✔
           f₁(1,5) = (0,5)(1) = 0,5 > 0  ✔
           f₁(3) = (2)(−2) = −4 < 0   ✔
calcul — f₂
  2x − 1 > 0  ⟺  2x > 1  ⟺  x > 1/2

  ∀x ∈ ℝ,  e^(−0,5x) > 0        ← une exponentielle est toujours
                                   strictement positive

  x          │ −∞          1/2          +∞
  ───────────┼──────────────────────────────
  2x − 1     │      −       0       +
  e^(−0,5x)  │      +               +       ← que des « + », aucun zéro
  ───────────┼──────────────────────────────
  f₂(x)      │      −       0       +

f₂ a EXACTEMENT le signe de (2x − 1) :
f₂ < 0 sur ]−∞ ; 1/2[  ·  f₂ > 0 sur ]1/2 ; +∞[

C'est le point à retenir de l'exercice : un facteur exponentiel ne change jamais le signe. Il occupe une ligne du tableau, mais elle ne porte que des « + ».

calcul — f₃
Ensemble de définition : le DÉNOMINATEUR ne doit pas s'annuler.

     x − 2 = 0  ⟺  x = 2
     D(f₃) = ℝ \ {2}

(l'exponentielle, elle, est définie partout)

  x − 3 > 0 ⟺ x > 3        x − 2 > 0 ⟺ x > 2
  ∀x ∈ ℝ, e^(−2x+1) > 0

  x          │ −∞        2        3        +∞
  ───────────┼───────────────────────────────
  x − 3      │     −          −    0    +
  e^(−2x+1)  │     +          +        +
  x − 2      │     −     0    +        +
  ───────────┼───────────────────────────────
  f₃(x)      │     +     ‖    −    0    +
                         ↑
                    DOUBLE BARRE : f₃ n'existe pas en x = 2

f₃ > 0 sur ]−∞ ; 2[ ∪ ]3 ; +∞[   ·   f₃ < 0 sur ]2 ; 3[

Contrôle : f₃(0) = (−3)(e)/(−2) = 3e/2 > 0     ✔
           f₃(2,5) = (−0,5)(e^(−4))/(0,5) < 0  ✔
           f₃(4) = (1)(e^(−7))/(2) > 0         ✔
⚠️ Une double barre n'est pas un zéro

En x = 2, f₃ n'existe pas : on trace une double barre ‖, pas un « 0 ». Un zéro signifierait que la fonction s'annule, ce qui est faux. La différence est au barème.

10Dériver avec e^u Moyen

Calculer f'(x).

  1. f(x) = e−2x
  2. f(x) = 2 e−0,5x
  3. f(x) = (2x − 1) e2x
✅ Correction

Les deux formules : (e^x)' = e^x et (e^u)' = u' · e^u.

calcul — 1
f(x) = e^(−2x)

On pose  u(x) = −2x     donc  u'(x) = −2

  (e^u)' = u' e^u

f'(x) = −2 e^(−2x)
calcul — 2
f(x) = 2 e^(−0,5x)

On pose  u(x) = −0,5x   donc  u'(x) = −0,5

  (k e^u)' = k · u' · e^u

f'(x) = 2 × (−0,5) × e^(−0,5x)
      = −e^(−0,5x)
calcul — 3
f(x) = (2x − 1) e^(2x)          ← c'est un PRODUIT

  u  = 2x − 1         v  = e^(2x)
  u' = 2              v' = 2 e^(2x)       ← (e^u)' avec u = 2x

  (uv)' = u'v + uv'

f'(x) = 2 e^(2x) + (2x − 1) × 2 e^(2x)

On FACTORISE par e^(2x), commun aux deux termes :

      = e^(2x) [ 2 + 2(2x − 1) ]
      = e^(2x) [ 2 + 4x − 2 ]
      = 4x e^(2x)

Contrôle en x = 0 : 2e⁰ + (−1)(2e⁰) = 2 − 2 = 0, et 4 × 0 × e⁰ = 0 ✔ Et en x = 1 : 2e² + 1 × 2e² = 4e², contre 4 × 1 × e² = 4e² ✔

La factorisation par e2x donne une forme dont le signe se lit : f' a le signe de 4x, donc f décroît pour x < 0 et croît pour x > 0, avec un minimum en 0. Même leçon qu'au chapitre 04.

06Problèmes

11Factoriser, puis résoudre deux équations Difficile

Soit P(x) = 2x³ + 7x² − 14x + 5.

  1. Déterminer les réels a, b, c tels que P(x) = (x − 1)(ax² + bx + c) pour tout réel x, puis résoudre P(x) = 0.
  2. En déduire la résolution de :
    E₁ : 2(ln x)³ + 7(ln x)² − 14 ln x + 5 = 0
    E₂ : 2e3x + 7e2x − 14e^x + 5 = 0
✅ Correction
calcul — 1
On développe la forme voulue :

  (x − 1)(ax² + bx + c) = ax³ + bx² + cx − ax² − bx − c
                        = ax³ + (b − a)x² + (c − b)x − c

On identifie avec 2x³ + 7x² − 14x + 5 :

  coefficient de x³ :        a = 2
  coefficient de x²  :   b − a = 7    →  b = 7 + 2 = 9
  coefficient de x   :   c − b = −14  →  c = −14 + 9 = −5
  terme constant     :      −c = 5    →  c = −5     ✔ cohérent

  P(x) = (x − 1)(2x² + 9x − 5)

Racines du trinôme :  Δ = 9² − 4 × 2 × (−5) = 81 + 40 = 121,  √Δ = 11
  x = (−9 − 11)/4 = −20/4 = −5      x = (−9 + 11)/4 = 2/4 = 1/2

  P(x) = 0  ⟺  x = 1  ou  x = 1/2  ou  x = −5

Contrôle : P(1) = 2 + 7 − 14 + 5 = 0        ✔
           P(1/2) = 0,25 + 1,75 − 7 + 5 = 0 ✔
           P(−5) = −250 + 175 + 70 + 5 = 0  ✔
calcul — E₁
2(ln x)³ + 7(ln x)² − 14 ln x + 5 = 0

Domaine : il y a un ln x, donc  D = ]0 ; +∞[

On pose  X = ln x.  L'équation devient  P(X) = 0, déjà résolue :

     X = 1     ou     X = 1/2     ou     X = −5

On revient à x :
     ln x = 1    →  x = e^1  = e      ≈ 2,718
     ln x = 1/2  →  x = e^½  = √e     ≈ 1,649
     ln x = −5   →  x = e^(−5)        ≈ 0,0067

Les trois sont strictement positifs → tous dans D  ✔
(un ln peut valoir n'importe quel réel, y compris −5)

S = { e^(−5) ; √e ; e }
calcul — E₂
2e^(3x) + 7e^(2x) − 14e^x + 5 = 0

On pose X = e^x.  Alors e^(2x) = X² et e^(3x) = X³.
L'équation devient P(X) = 0 :

     X = 1     ou     X = 1/2     ou     X = −5

CONTRAINTE : X = e^x, donc X > 0 obligatoirement.

     X = −5 < 0  →  REJETÉE
     X = 1       →  e^x = 1 = e⁰       →  x = 0
     X = 1/2     →  e^x = 1/2          →  x = ln(1/2) = −ln 2 ≈ −0,693

S = { −ln 2 ; 0 }

La même factorisation sert deux fois, et les deux réponses diffèrent par une seule chose : ln x peut valoir −5, e^x ne le peut pas. C'est tout le chapitre en une ligne.

Contrôle de E₂ en x = 0 : 2 + 7 − 14 + 5 = 0 ✔ Et en x = −ln 2, e^x = 1/2 donne 2(1/8) + 7(1/4) − 14(1/2) + 5 = 0,25 + 1,75 − 7 + 5 = 0 ✔

12Les abonnés d'une revue Moyen

Une revue estime que le nombre aₙ de ses abonnés au bout de n années peut être modélisé par aₙ = 25 000 − 20 000 × (0,8)ⁿ pour tout entier n. Ainsi a₀ est le nombre d'abonnés à la date initiale.

  1. Combien faut-il d'années pour que le nombre initial d'abonnés soit quadruplé ?
  2. Calculer des valeurs approchées à l'unité près de aₙ pour n = 10, 20, 50 et 70. Comment s'interprètent les résultats observés ?
✅ Correction
calcul — 1
Nombre initial :
  a₀ = 25 000 − 20 000 × 0,8⁰
     = 25 000 − 20 000 × 1
     = 5 000 abonnés

Quadrupler, c'est atteindre 4 × 5 000 = 20 000 :

     25 000 − 20 000 × 0,8ⁿ = 20 000
            − 20 000 × 0,8ⁿ = −5 000
              20 000 × 0,8ⁿ =  5 000
                       0,8ⁿ =  5 000 / 20 000 = 0,25

On applique le logarithme pour faire DESCENDRE l'exposant :

     ln(0,8ⁿ) = ln(0,25)
   n × ln(0,8) = ln(0,25)
          n    = ln(0,25) / ln(0,8)
          n    ≈ (−1,386) / (−0,223)
          n    ≈ 6,21

n étant un nombre entier d'années, il faut n = 7 années.

Contrôle : a₆ = 25 000 − 20 000 × 0,8⁶ ≈ 19 757  (pas encore)
           a₇ = 25 000 − 20 000 × 0,8⁷ ≈ 20 806  (dépassé)  ✔

On arrondit vers le haut : il faut atteindre le seuil, donc la 7e année. Arrondir à 6 donnerait 19 757 abonnés — pas encore quadruplé.

⚠️ ln(0,8) est négatif

0,8 < 1, donc ln(0,8) ≈ −0,223 < 0. Ici les deux logarithmes sont négatifs et leur quotient est positif — tout va bien. Mais dans une inéquation, diviser par ln(0,8) retournerait le sens. Règle : ln a < 0 dès que 0 < a < 1.

calcul — 2
a₁₀ = 25 000 − 20 000 × 0,8¹⁰ ≈ 25 000 − 2 147 ≈ 22 853
a₂₀ = 25 000 − 20 000 × 0,8²⁰ ≈ 25 000 −   231 ≈ 24 769
a₅₀ = 25 000 − 20 000 × 0,8⁵⁰ ≈ 25 000 −  0,29 ≈ 25 000
a₇₀ = 25 000 − 20 000 × 0,8⁷⁰ ≈ 25 000 − 0,003 ≈ 25 000

INTERPRÉTATION

Comme 0 < 0,8 < 1, la puissance 0,8ⁿ tend vers 0 quand n grandit.
Donc aₙ se rapproche de 25 000 — sans jamais l'atteindre.

La revue PLAFONNE à 25 000 abonnés : c'est la limite du modèle,
et elle a un sens concret (taille du lectorat potentiel).

Une décroissance exponentielle ne s'annule jamais, mais devient indétectable : à n = 50, l'écart au plafond vaut 0,29 abonné. C'est le même phénomène que la queue de la loi normale au-delà de 3σ.

13L'équipement en téléphones portables Difficile

On modélise le pourcentage f(t) des foyers français équipés d'au moins un téléphone portable à la date t par

f(t) = 100 / (1 + k eαt)

où t est le temps en années. Déterminer les réels k et α sachant que 10 % des foyers étaient équipés à la date initiale et que cinq ans plus tard, c'était le cas de 80 % des foyers.

✅ Correction

Deux données, deux inconnues : on écrit deux équations et on les résout l'une après l'autre — k d'abord, car e⁰ = 1 le rend immédiat.

calcul — ① la valeur de k
À t = 0, f(0) = 10 :

     100 / (1 + k e^(α×0)) = 10
     100 / (1 + k e⁰)      = 10
     100 / (1 + k)         = 10        ← e⁰ = 1
           1 + k           = 100/10 = 10
                 k         = 9
calcul — ② la valeur de α
À t = 5, f(5) = 80, avec k = 9 :

     100 / (1 + 9 e^(5α)) = 80
           1 + 9 e^(5α)   = 100/80 = 1,25
               9 e^(5α)   = 0,25
                 e^(5α)   = 0,25/9 = 1/36

On applique le logarithme :

     ln(e^(5α)) = ln(1/36)
          5α    = −ln 36                ← ln(1/A) = −ln A
           α    = −ln(36)/5
           α    ≈ −3,584/5 ≈ −0,717
vérification
f(0) = 100/(1 + 9 × 1)        = 100/10   = 10 %    ✔
f(5) = 100/(1 + 9 × (1/36))   = 100/1,25 = 80 %    ✔

Le signe de α est négatif, et c'est bien ce qu'il faut : quand t grandit, eαt tend vers 0, donc f(t) tend vers 100/1 = 100 %. Le modèle sature à 100 % — ce qui est le comportement attendu d'une courbe d'équipement.

🔧 Corrigé — les dates de l'énoncé sont incohérentes

L'énoncé d'origine pose f définie sur [0 ; +∞[ avec « t = 0 au 1er janvier 2008 », puis donne les données pour « le 1er janvier 2000 » et « le 1er janvier 2005 ». Si t = 0 correspond à 2008, alors 2000 correspond à t = −8 — hors de l'intervalle de définition, et le problème n'a pas de solution.

L'énoncé a été repris ici avec « à la date initiale » et « cinq ans plus tard », ce qui place les deux données à t = 0 et t = 5 et rend le problème cohérent. C'est très probablement l'intention : un sujet plus ancien dont la date de référence a été actualisée sans reprendre les données.

À l'examen, face à ce genre d'incohérence : choisir une lecture, l'écrire explicitement (« on suppose t = 0 au 1er janvier 2000 »), et poursuivre. Un correcteur valorise une hypothèse assumée ; il ne peut rien faire d'une copie blanche.
