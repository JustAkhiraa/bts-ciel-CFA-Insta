Logarithme & exponentielle

Recto-verso. À relire la veille. Le cours · Les exercices

⚡ Les deux domaines — tout part de là

ln xe^x
Défini pourx > 0 strictement tout x ∈ ℝ
Valeurs prisestout ℝ (y compris négatives) toujours > 0
Valeur repèreln 1 = 0 · ln e = 1 e⁰ = 1 · e ≈ 2,718
Dérivée1/xe^x (elle-même)

Tout le chapitre tient dans ces deux lignes : un ln impose une condition sur ce qu'il contient · une exponentielle ne s'annule jamais.

⚡ Propriétés du ln

à retenir
ln(xy)   = ln x + ln y
ln(1/x)  = −ln x
ln(x/y)  = ln x − ln y
ln(x^r)  = r ln x
ln(√x)   = ½ ln x

ln x = ln y  ⟺  x = y
x < y        ⟹  ln x < ln y

ln descend d'un cran : puissance → produit → somme.

⚡ Propriétés de exp

à retenir
e^(x+y) = e^x · e^y
e^(−x)  = 1/e^x
e^(x−y) = e^x / e^y
e^(rx)  = (e^x)^r

e^x = e^y  ⟺  x = y
x < y      ⟹  e^x < e^y

Ce sont les règles des puissances. C'est pour cela qu'on note l'exponentielle e^x.

⚡ Ce qui n'existe PAS

ln(x + y) ≠ ln x + ln y

La propriété porte sur le produit, jamais sur la somme. Contre-exemple : ln 2 ≈ 0,69 mais ln 1 + ln 1 = 0.

Et ln(x²) = 2 ln x alors que (ln x)² est le carré du logarithme. Deux objets différents.

⚡ Réciproques

ln(e^x) = x  pour tout x ∈ ℝ
eln x = x  pour x > 0

Les deux courbes sont symétriques par rapport à y = x.

Le geste : pour supprimer un ln, appliquer exp des deux côtés ; pour supprimer une exp, appliquer ln.

⚡ Résoudre une équation — l'ordre compte

méthode
① DOMAINE    chaque ln(A) impose A > 0 — on intersecte
             ← AVANT tout calcul
② REGROUPER  ramener à ln A = ln B  ou  e^A = e^B
③ SUPPRIMER  ln A = ln B ⟹ A = B
④ RÉSOUDRE   affine, trinôme, changement de variable…
⑤ CONFRONTER écarter les solutions hors du domaine
             ← cette étape est NOTÉE
calcul
ln(x+1) + ln(x−3) = ln 5

① x+1>0 ET x−3>0 → x>−1 et x>3 → D = ]3 ; +∞[
② ln((x+1)(x−3)) = ln 5
③ (x+1)(x−3) = 5
④ x² − 2x − 8 = 0, Δ = 36 → x = −2 ou x = 4
⑤ −2 ∉ D → REJETÉE.  S = {4}

Sans l'étape ①, on répond « −2 et 4 » — et ln(−1) n'existe pas. C'est l'erreur la plus sanctionnée du chapitre.

⚡ e^u = 0 est impossible

pour tout u, e^u > 0
  • ex−1 = 0 → S = ∅, sans calcul.
  • 1 + e−2x > 1 → S = ℝ, sans calcul.
  • Dans un produit, e^u ne change jamais le signe.

⚡ Changement de variable

méthode
2e^(2x) + e^x − 3 = 0

On pose X = e^x   (donc e^(2x) = X²)
   2X² + X − 3 = 0, Δ = 25
   X = −3/2  ou  X = 1

CONTRAINTE X > 0 → −3/2 REJETÉE
   e^x = 1 → x = 0

Devant e2x et e^x ensemble, poser X = e^x. La contrainte X > 0 joue le rôle du domaine.

⚡ Inéquations : ln et exp sont croissantes

ln A < ln B ⟺ A < B
e^A < e^B ⟺ A < B

Le sens est conservé. Mais attention : la division par un coefficient négatif qui suit le retourne. Ce sont deux étapes différentes.

S = D ∩ condition

⚡ ln a < 0 si 0 < a < 1

calcul
ln(0,8) ≈ −0,223   < 0
ln(2)   ≈  0,693   > 0
ln(1)   =  0

Dans une équation, aucune importance. Dans une inéquation, diviser par ln(0,8) retourne le sens — piège classique des problèmes de seuil.

⚡ Faire descendre un exposant

ln(aⁿ) = n × ln a
calcul
0,8ⁿ = 0,25
n ln(0,8) = ln(0,25)
n = ln(0,25)/ln(0,8) ≈ 6,21  →  7 années

C'est la raison d'être du logarithme : sortir l'inconnue d'un exposant. On arrondit vers le haut quand il faut atteindre un seuil.

⚡ Signe avec e^u

calcul
f(x) = (2x − 1) e^(−0,5x)

  x          │ −∞      1/2      +∞
  ───────────┼─────────────────────
  2x − 1     │    −     0    +
  e^(−0,5x)  │    +          +     ← que des +
  ───────────┼─────────────────────
  f(x)       │    −     0    +

La ligne de l'exponentielle ne porte aucun zéro. Le signe est celui de l'autre facteur.

⚡ Double barre ≠ zéro

calcul
f(x) = (x−3) e^(−2x+1) / (x−2)

Dénominateur nul en x = 2 → D = ℝ \ {2}

  x    │ −∞     2     3     +∞
  ─────┼────────────────────────
  f(x) │   +    ‖  −  0  +
              ↑
      f n'EXISTE PAS ici

Un 0 dit « la fonction s'annule ». Une ‖ dit « elle n'existe pas ». La différence est au barème.

⚡ Dériver

(e^x)' = e^x  ·  (e^u)' = u' e^u
(ln x)' = 1/x  ·  (ln u)' = u'/u
calcul
e^(−2x)        → −2 e^(−2x)
2 e^(−0,5x)    → −e^(−0,5x)
(2x−1) e^(2x)  → e^(2x)[2 + 2(2x−1)]
               = 4x e^(2x)     ← FACTORISER

Factoriser par e^u rend le signe lisible.

⚡ Les six erreurs qui coûtent des points

  1. Oublier l'ensemble de définition — et garder une solution pour laquelle un ln n'existe pas.
  2. Oublier la contrainte X > 0 dans un changement de variable X = e^x.
  3. Écrire ln(x+y) = ln x + ln y — la propriété porte sur le produit.
  4. Donner la condition au lieu de l'intersection dans une inéquation : S = D ∩ condition.
  5. Confondre les deux retournements — passer au ln conserve le sens, diviser par un négatif le retourne.
  6. Mettre un 0 au lieu d'une double barre pour une valeur interdite.
