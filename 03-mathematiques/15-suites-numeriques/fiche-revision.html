Suites numériques

Recto-verso. À relire la veille. Le cours · Les exercices · Le QCM

⚡ Ajouter ou multiplier

Passageun+1 = un + run+1 = q·un
Expliciteun = u0 + n·run = u0 × qn
Depuis upup + (n−p)·rup × qn−p

Pour reconnaître :
différence constante, arithmétique ; quotient constant, géométrique.

Deux façons de définir une suite

Explicite :
un = f(n), chaque terme se calcule seul.

Récurrence :
un+1 = f(un), plus un premier terme, sans lequel la suite n'est pas définie.

un+1 est le terme suivant ; un + 1 ajoute 1 au terme.

Les sommes

Arithmétique :
nombre de termes × (premier + dernier) / 2.

Géométrique (q ≠ 1) :
premier × (1 − qnombre de termes) / (1 − q).

1 + 2 + … + n = n(n + 1) / 2. De u0 à un, il y a n + 1 termes.

Chercher un seuil

Balayage :
deux lignes du tableau qui encadrent le seuil, puis « la suite est croissante, donc… ».

Inéquation :
isoler qn, prendre ln,
utiliser ln(an) = n × ln(a),
diviser par ln(q).

Si ln(q) < 0 (raison entre 0 et 1), le sens de l'inégalité change.

Pourcentages

+ t % chaque année :
raison 1 + t/100. + 20 %, c'est × 1,2.

− t % chaque année :
raison 1 − t/100. − 20 %, c'est × 0,8.

Limites de qn

  • −1 < q < 1 : 0
  • q = 1 : 1
  • q > 1 : +∞
  • q ⩽ −1 : pas de limite

⚠️ Les pièges

  1. Oublier la croissance dans la conclusion d'un balayage.
  2. Compter n termes de u0 à un : il y en a n + 1.
  3. Traiter « + 20 % par an » comme « + 20 » : on multiplie.
  4. Répondre un rang quand la question demande une année.
