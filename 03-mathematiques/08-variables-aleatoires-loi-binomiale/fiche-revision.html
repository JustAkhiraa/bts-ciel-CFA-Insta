Variables aléatoires & loi binomiale

Recto-verso. À relire la veille. Le cours · Les exercices

⚡ La justification — à savoir par cœur

rédaction
★ L'expérience aléatoire consiste à répéter n = 40 fois de suite
  la même épreuve de Bernoulli.

★ Chaque épreuve n'a que deux issues contraires :
   – le sac est défectueux : SUCCÈS, de probabilité p = 0,0494
   – sinon : ÉCHEC, de probabilité q = 1 − 0,0494 = 0,9506

★ Les épreuves sont mutuellement indépendantes
  (tirage avec remise).

Conclusion :  X ↝ B(40 ; 0,0494)

Trois étoiles, une conclusion chiffrée. Les deux oublis qui coûtent : ne pas citer le « tirage avec remise » de l'énoncé, et ne pas donner les paramètres.

La loi de probabilité

xix₁x₂…Total
P(X = xi)p₁p₂… 1
  • valeurs dans l'ordre croissant
  • Σ pi = 1 — le contrôle systématique
  • chaque valeur une seule fois : on cumule les résultats qui y mènent

⚡ Espérance

E(X) = Σ pi xi
calcul
E(X) = (1/8)(−90) + (3/8)(5) + (4/8)(10)
     = −11,25 + 1,875 + 5
     = − 4,375 €

C'est la moyenne sur un très grand nombre de répétitions, pas une valeur possible.

jeu équitable ⟺ E(X) = 0

⚡ Variance et écart-type

V(X) = E(X²) − E(X)²
σ = √V(X)
calcul
E(X²) = (1/8)(8100)+(3/8)(25)+(4/8)(100)
      = 1071,875
V(X)  = 1071,875 − 19,140625 ≈ 1052,73
σ     = √1052,73 ≈ 32,4 €

E(X²) ≠ E(X)² : on élève chaque valeur au carré, puis on moyenne. Une variance négative est impossible — c'est le signal qu'on a inverti les deux termes.

Épreuve de Bernoulli

xi0 (échec)1 (succès)
Pq = 1 − pp
E(X) = p  ·  V(X) = pq  ·  σ = √(pq)

Le succès est l'issue que l'on compte, pas la bonne nouvelle : ici « le sac est défectueux ».

⚡ La loi binomiale

n épreuves de Bernoulli indépendantes
X = nombre de succès  →  X ↝ B(n ; p)
E(X) = n p   ·   σ = √(n p (1 − p))

Interprétation de E(X) : « en moyenne, un lot de n contient E(X) succès ». Elle est toujours demandée.

⚡ Tout ramener à « ⩽ »

P(X > k) = 1 − P(X ⩽ k)
X < k ⟺ X ⩽ k − 1
X ⩾ k ⟺ X > k − 1

Le second glissement n'est valable que parce que X est entière : il n'y a rien entre 2 et 3.

calcul
P(X ⩾ 3) = 1 − P(X < 3)
         = 1 − P(X ⩽ 2)
         = 1 − 0,055 = 0,945

⚠️ Le glissement se fait à l'intérieur d'une même probabilité, jamais entre deux seuils différents.

⚡ Ce qui coûte des points

  • ne pas citer le « tirage avec remise » ;
  • écrire « X suit une binomiale » sans les paramètres ;
  • donner 0,317 sans écrire P(X ⩾ 3) = 1 − P(X ⩽ 2) ;
  • ne pas interpréter E(X) par une phrase ;
  • arrondir trop tôt — on n'arrondit qu'au résultat final ;
  • ne pas dire ce qu'est le succès.

Les contrôles de vraisemblance

  1. Σ des probabilités = 1.
  2. Le maximum de la loi est voisin de np.
  3. Si k est en dessous de np, alors P(X ⩾ k) est grande.
  4. V(X) est toujours positive.
  5. E(X) n'a pas à être une valeur possible (1,976 sacs).
