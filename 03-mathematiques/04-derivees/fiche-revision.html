⚡ Nombre dérivé et tangente

  • f'(a) = un nombre, la pente en a
  • f' = une fonction, la formule
y = f'(a)(x − a) + f(a)

Exemple : f(x) = x² en a = 1,5 → f'(1,5) = 3, f(1,5) = 2,25, tangente y = 3x − 2,25.

⚡ Ce qui ne traverse pas

(u·v)' ≠ u'v'  ·  (u/v)' ≠ u'/v'
calcul
f(x) = x × x = x²   →   f'(x) = 2x

Si (uv)' = u'v' :  1 × 1 = 1 ≠ 2x   ✗

Seules ku et u + v se dérivent morceau par morceau.

⚡ Le quotient : moins, et ordre

(u/v)' = (u'v − uv') / v²
  • Le signe moins au milieu.
  • u'v d'abord : une soustraction n'est pas commutative.
  • Le dénominateur est v², laissé factorisé.

Distribuer le moins sur tous les termes : −(2x + 1) = −2x − 1.

⚡ Composées : ne pas oublier u'

(uⁿ)' = n·u'·uⁿ⁻¹  ·  (√u)' = u'/(2√u)
calcul
(3x² + 6x + 1)⁴   u' = 6x + 6

f' = 4 × (6x + 6) × (3x² + 6x + 1)³
   = (24x + 24)(3x² + 6x + 1)³

PAS « 24x + 24(…)³ » : le bloc 4·u' est
UN SEUL facteur → une parenthèse.

Le u' est la dérivée de l'intérieur : c'est lui qu'on oublie une fois sur deux.

⚡ Le gros calcul, en quatre étapes

calcul
f(x) = (4x² + 1)²(3x − 7)³

① dériver chaque facteur :
   u  = (4x²+1)²           v  = (3x−7)³
   u' = 16x(4x²+1)         v' = 9(3x−7)²

② (uv)' = u'v + uv' :
   f' = 16x(4x²+1)(3x−7)³ + (4x²+1)²·9(3x−7)²

③ SORTIR le commun (la plus petite puissance de chaque) :
   f' = (4x²+1)(3x−7)² [ 16x(3x−7) + 9(4x²+1) ]

④ développer SEULEMENT le crochet :
   f' = (4x²+1)(3x−7)²(84x² − 112x + 9)

Cette forme EST la réponse. Son signe se lit : (4x²+1) > 0, (3x−7)² ⩾ 0, reste un seul trinôme à étudier. Développée, elle ferait sept termes illisibles.

⚡ Les sept erreurs qui coûtent des points

  1. Dériver un produit comme u'v' — c'est u'v + uv'.
  2. Oublier le signe moins du quotient, ou intervertir les deux termes.
  3. Oublier u' dans (uⁿ)' et (√u)'.
  4. Donner un x à la dérivée d'une affine — c'est une constante.
  5. Perdre un exposant en développant (16x × 4x² = 64x³).
  6. Se tromper d'identité remarquable — (a − b)² = a² − 2ab + b².
  7. Oublier les parenthèses autour d'un facteur.

Les deux contrôles à faire systématiquement : le degré a-t-il baissé d'un cran ? Et une valeur numérique donne-t-elle le même résultat par deux chemins ?
