Dérivées — exercices

Les six exercices du devoir du 11/12, plus les séries d'entraînement. Chaque corrigé est contrôlé par un second chemin de calcul.

🎯

Le réflexe d'attaque

Reconnaître la structure avant de calculer. Somme → terme par terme. Produit → u'v + uv'. Quotient → (u'v − uv')/v². Puissance ou racine → ne pas oublier le u'. Et dans tous les cas : poser u, u', v, v' en quatre lignes avant d'écrire quoi que ce soit d'autre.

01Dérivées simples

1Trois polynômes Facile

Déterminer la dérivée f'(x) de :

  1. f(x) = 15
  2. f(x) = 6x⁵ − 4x³ + x² + x − 9
  3. f(x) = −2x¹⁰ + 23x⁴ − 41x
✅ Correction
calcul
1.  f(x) = 15   est une CONSTANTE

    f'(x) = 0

2.  f(x) = 6x⁵ − 4x³ + x² + x − 9

     6x⁵  →  6 × 5 x⁴  =  30x⁴
    −4x³  → −4 × 3 x²  = −12x²
      x²  →      2 x   =   2x
       x  →              =   1
      −9  →              =   0

    f'(x) = 30x⁴ − 12x² + 2x + 1

3.  f(x) = −2x¹⁰ + 23x⁴ − 41x

    −2x¹⁰  →  −2 × 10 x⁹  =  −20x⁹
     23x⁴  →  23 ×  4 x³  =   92x³
    −41x   →  −41         =  −41

    f'(x) = −20x⁹ + 92x³ − 41

Contrôle du degré : 5 → 4 ✔ et 10 → 9 ✔ Une constante devient 0, un terme en x devient une constante. Dériver baisse toujours le degré d'exactement un cran.

2Fractions et sens de variation Facile

  1. Dériver f(x) = ⅓x³ − x.
  2. Déterminer le sens de variation de f(x) = −1,5x + 3, g(x) = 0,2x − 10 et h(x) = 7, en passant par la dérivée.
✅ Correction
calcul — 1
f(x) = ⅓x³ − x

   ⅓x³  →  ⅓ × 3 x²  =  x²      ← le 3 annule le ⅓
    −x  →  −1

f'(x) = x² − 1
calcul — 2
f(x) = −1,5x + 3    →  f'(x) = −1,5
                       −1,5 < 0  →  f est DÉCROISSANTE sur ℝ

g(x) = 0,2x − 10    →  g'(x) = 0,2
                        0,2 > 0  →  g est CROISSANTE sur ℝ

h(x) = 7            →  h'(x) = 0
                          0   →  h est CONSTANTE sur ℝ

Contrôle croisé : on retrouve exactement la règle des fonctions affines du chapitre 03 — le signe de a donne le sens de variation. Normal : la dérivée d'une affine est son coefficient directeur.

⚠️ La dérivée d'une affine n'a pas de x

Un cahier de la classe écrit f'(x) = −2x pour f(x) = −2x + 1. La bonne réponse est −2, sans x : une droite a la même pente partout.

02Produits u·v

3Trois produits Moyen

Poser u, u', v, v', appliquer (uv)' = u'v + uv' et développer.

  1. f(x) = (x² + 1)(4x + 7)
  2. f₁(x) = (x² + 5x)(x − 3)
  3. f₂(x) = (−x³ + 2x)(4x² − 1)
✅ Correction
calcul — 1
  u  = x² + 1        v  = 4x + 7
  u' = 2x            v' = 4

f'(x) = (2x)(4x + 7) + (x² + 1)(4)
      = 8x² + 14x + 4x² + 4
      = 12x² + 14x + 4

Contrôle : (x²+1)(4x+7) = 4x³ + 7x² + 4x + 7, dérivée 12x² + 14x + 4 ✔

calcul — 2
  u  = x² + 5x       v  = x − 3
  u' = 2x + 5        v' = 1

f₁'(x) = (2x + 5)(x − 3) + (x² + 5x)(1)
       = 2x² − 6x + 5x − 15 + x² + 5x
       = 3x² + 4x − 15

Contrôle : (x²+5x)(x−3) = x³ + 2x² − 15x, dérivée 3x² + 4x − 15 ✔

calcul — 3
  u  = −x³ + 2x      v  = 4x² − 1
  u' = −3x² + 2      v' = 8x

f₂'(x) = (−3x² + 2)(4x² − 1) + (−x³ + 2x)(8x)

   premier produit  : −12x⁴ + 3x² + 8x² − 2
   second produit   : −8x⁴ + 16x²

f₂'(x) = −12x⁴ + 11x² − 2 − 8x⁴ + 16x²
       = −20x⁴ + 27x² − 2

Contrôle : (−x³+2x)(4x²−1) = −4x⁵ + 9x³ − 2x, dérivée −20x⁴ + 27x² − 2 ✔ Degré 5 → degré 4 ✔

🧰 Quand le contrôle croisé est possible, il est obligatoire

Sur un produit de deux polynômes, on peut toujours développer f d'abord puis dériver terme à terme. Les deux chemins doivent donner le même résultat. C'est trente secondes de brouillon, et c'est le contrôle le plus fiable du chapitre.

4Deux produits courts Facile

  1. f(x) = x²(3x − 1)
  2. f(x) = x(2x + 1)
  3. f(x) = x(x + 1)(x + 2)
✅ Correction
calcul — 1
  u  = x²        v  = 3x − 1
  u' = 2x        v' = 3

f'(x) = (2x)(3x − 1) + (x²)(3)
      = 6x² − 2x + 3x²
      = 9x² − 2x
calcul — 2
  u  = x         v  = 2x + 1
  u' = 1         v' = 2

f'(x) = (1)(2x + 1) + (x)(2)
      = 2x + 1 + 2x
      = 4x + 1
calcul — 3
Trois facteurs : le plus simple est de DÉVELOPPER d'abord.

f(x) = x(x + 1)(x + 2)
     = x(x² + 2x + x + 2)
     = x(x² + 3x + 2)
     = x³ + 3x² + 2x

f'(x) = 3x² + 6x + 2

Sur trois facteurs, la formule (uv)' s'applique deux fois et devient pénible. Quand les facteurs sont courts, développer d'abord est plus rapide et plus sûr. Contrôle : degré 3 → degré 2 ✔ et f'(0) = 2, ce qui correspond bien au terme 2x de f ✔

03Quotients u/v

5Trois quotients Moyen

Calculer f'(x) sur l'ensemble de définition de f.

  1. f(x) = (x² + 1)/(x − 1)
  2. f(x) = 1/(x² + 1)
  3. f(x) = (2x + 1)/(x + 2)
✅ Correction
calcul — 1
Ensemble de définition : x − 1 ≠ 0, donc x ≠ 1.

  u  = x² + 1        v  = x − 1
  u' = 2x            v' = 1

  (u/v)' = (u'v − uv') / v²

f'(x) = [ (2x)(x − 1) − (x² + 1)(1) ] / (x − 1)²
      = [ 2x² − 2x − x² − 1 ] / (x − 1)²
      = (x² − 2x − 1) / (x − 1)²
🔧 Corrigé — (x − 1)² = x² − 2x + 1

La copie développe le dénominateur en x² + 2x + 1. C'est faux : l'identité (a − b)² = a² − 2ab + b², rappelée juste à côté sur la copie, donne un moins au milieu.

Mais surtout, il ne fallait pas développer. Un dénominateur laissé en (x − 1)² est plus court, plus lisible, et son signe se lit — un carré est positif. Ici cela donne tout de suite : f' a le signe de x² − 2x − 1, et il suffit d'un discriminant pour conclure.

calcul — 2
Ensemble de définition : x² + 1 > 0 toujours → f définie sur ℝ.

  u  = 1             v  = x² + 1
  u' = 0             v' = 2x

f'(x) = [ (0)(x² + 1) − (1)(2x) ] / (x² + 1)²
      = −2x / (x² + 1)²

Le premier terme s'annule puisque u' = 0. Contrôle de signe : le dénominateur est un carré, donc positif ; f' a le signe de −2x. La fonction croît pour x < 0, décroît pour x > 0, avec un maximum f(0) = 1 — ce qui est bien la plus grande valeur possible de 1/(x²+1) ✔

calcul — 3
Ensemble de définition : x + 2 ≠ 0, donc x ≠ −2.

  u  = 2x + 1        v  = x + 2
  u' = 2             v' = 1

f'(x) = [ (2)(x + 2) − (2x + 1)(1) ] / (x + 2)²
      = [ 2x + 4 − 2x − 1 ] / (x + 2)²
      = 3 / (x + 2)²

Attention à la distribution : − (2x + 1) donne − 2x − 1, les deux termes changent de signe. Le numérateur se simplifie en une constante positive, donc f' > 0 sur chacun des deux intervalles — f y est croissante, sans aucune inéquation à résoudre.

04Puissances et racine

6Une puissance Moyen

Dériver f(x) = (3x² + 6x + 1)⁴.

✅ Correction
calcul
  u  = 3x² + 6x + 1          n = 4
  u' = 6x + 6

  (uⁿ)' = n · u' · uⁿ⁻¹

f'(x) = 4 × (6x + 6) × (3x² + 6x + 1)³
      = (24x + 24)(3x² + 6x + 1)³
      = 24(x + 1)(3x² + 6x + 1)³

Contrôle du degré : f est de degré 8 (2 × 4), donc f' doit être de degré 7. Ici (24x + 24) est de degré 1 et (…)³ de degré 6 : 1 + 6 = 7 ✔

🔧 Corrigé — les parenthèses de la copie

① La copie écrit d'abord 4 × 2 × 3x + 6 × (3x² + 6x + 1)³ : la dérivée de l'intérieur y est fausse, et écrite sans parenthèses. On a bien u' = 6x + 6, et ce bloc doit être entre parenthèses.

② La version corrigée = 24x + 24 (3x²+6x+1)³ reste ambiguë : telle quelle, elle se lit « 24x plus 24(3x²+6x+1)³ ». Il faut écrire (24x + 24)(3x² + 6x + 1)³ : le facteur 4 × u' forme un seul bloc.

C'est exactement ce que dit l'annotation portée sur la copie — « chaque lettre a une parenthèse ».

7Une racine Moyen

Dériver f(x) = √(x³ + 6x² + 1) sur son ensemble de définition.

✅ Correction
calcul
  u  = x³ + 6x² + 1
  u' = 3x² + 12x

  (√u)' = u' / (2√u)

f'(x) = (3x² + 12x) / (2√(x³ + 6x² + 1))

On peut factoriser le numérateur pour préparer l'étude du signe :

f'(x) = 3x(x + 4) / (2√(x³ + 6x² + 1))

Rien à développer : la réponse est finie. Le dénominateur est toujours positif (là où il existe), donc le signe de f' est celui de 3x(x + 4) — et sous cette forme factorisée, il se lit directement : positif hors de [−4 ; 0], négatif entre.

⚠️ « Sur son ensemble de définition »

Une racine exige un contenu ⩾ 0 ; le dénominateur 2√u exige en plus qu'il soit non nul. La dérivée n'existe donc que là où x³ + 6x² + 1 > 0, strictement. Quand l'énoncé emploie cette formule, il attend qu'on le mentionne.

05Le gros calcul

8f(x) = (4x² + 1)²(3x − 7)³ Difficile

Dériver f(x) = (4x² + 1)²(3x − 7)³, puis donner le résultat sous forme factorisée.

✅ Correction

Ce calcul combine les deux formules : un produit dont chaque facteur est une puissance.

calcul — étape 1
Dériver chaque facteur avec (uⁿ)' = n · u' · uⁿ⁻¹ :

  u  = (4x² + 1)²                v  = (3x − 7)³
  u' = 2 × (8x) × (4x² + 1)      v' = 3 × (3) × (3x − 7)²
     = 16x(4x² + 1)                 = 9(3x − 7)²
calcul — étape 2
Appliquer (uv)' = u'v + uv' :

f'(x) = 16x(4x² + 1) · (3x − 7)³  +  (4x² + 1)² · 9(3x − 7)²
calcul — étape 3
Repérer les facteurs COMMUNS aux deux termes :

  (4x² + 1)   : puissance 1 à gauche, 2 à droite → on sort la
                plus petite, donc (4x² + 1)
  (3x − 7)    : puissance 3 à gauche, 2 à droite → on sort (3x − 7)²

f'(x) = (4x² + 1)(3x − 7)² [ 16x(3x − 7) + 9(4x² + 1) ]
calcul — étape 4
Développer SEULEMENT le crochet :

  16x(3x − 7) =  48x² − 112x
  9(4x² + 1)  =  36x²        + 9
                ──────────────────
                  84x² − 112x + 9

f'(x) = (4x² + 1)(3x − 7)²(84x² − 112x + 9)

Contrôle numérique en x = 2 : forme factorisée 17 × 1 × (336 − 224 + 9) = 17 × 121 = 2 057 ; forme u'v + uv' = 32 × 17 × (−1) + 289 × 9 × 1 = −544 + 2 601 = 2 057 ✔ Les deux chemins concordent.

💡 Pourquoi s'arrêter là

Développée, cette dérivée est un polynôme de degré 6 à sept termes. Factorisée, son signe se lit :

  • (4x² + 1) > 0 toujours ;
  • (3x − 7)² ⩾ 0 toujours, nulle en x = 7/3 ;
  • reste 84x² − 112x + 9, un trinôme dont on étudie le signe par le discriminant.

Toute l'étude du signe se ramène donc à un seul trinôme. C'est ce qui rend la question suivante faisable — et c'est pour cela que la forme factorisée est la réponse attendue.

🔧 Corrigé — trois erreurs de la copie, une seule cause

① u' = 16x(4x² + 1) développé en 64x² + 16x : faux, car 16x × 4x² = 64x³. Les exposants s'ajoutent quand on multiplie. La forme développée correcte serait 64x³ + 16x.

② 9(3x − 7)² développé en 81x² + 378x + 441 : le terme du milieu est négatif. (3x − 7)² = 9x² − 42x + 49, donc 81x² − 378x + 441.

③ La factorisation finale notée (4x² + 1)(3x − 7)[16x(3x − 7) + 9(4x² − 1)] porte deux coquilles : (3x − 7) doit être au carré, et le dernier facteur est 9(4x² + 1) — c'est u, et il n'y a aucun « −1 » dans l'énoncé.

La cause est unique : avoir développé trop tôt. En restant factorisé, aucune des trois erreurs n'était possible.

06Applications

9Second degré : discriminant puis variations Moyen

Soit P(x) = 2x² − 6x − 8.

  1. Identifier a, b et c, calculer Δ, puis les deux racines.
  2. Établir le tableau de signe de P.
  3. Établir le tableau de variations de P, et donner son minimum.
✅ Correction
calcul — 1
a = 2,  b = −6,  c = −8

Δ = b² − 4ac
  = (−6)² − 4 × 2 × (−8)
  =  36   + 64              ← c < 0 fait grandir Δ
  = 100                     Δ > 0 → deux racines

x₁ = (6 − √100) / (2 × 2) = (6 − 10)/4 = −4/4 = −1
x₂ = (6 + √100) / (2 × 2) = (6 + 10)/4 = 16/4 =  4

Contrôle : P(−1) = 2 + 6 − 8 = 0    ✔
           P(4)  = 32 − 24 − 8 = 0  ✔
calcul — 2
Signe : a = 2 > 0, donc signe de a hors des racines.

  x    │ −∞       −1        4        +∞
  ─────┼──────────────────────────────────
  P(x) │    +     0    −    0    +
calcul — 3
Variations : on dérive.

P'(x) = 4x − 6            ← une affine : PAS de discriminant

4x − 6 = 0  →  4x = 6  →  x = 6/4 = 1,5

  x     │ −∞          1,5          +∞
  ──────┼───────────────────────────────
  P'(x) │     −        0       +
  ──────┼───────────────────────────────
  P(x)  │ +∞  ╲      −12,5    ╱  +∞

P(1,5) = 2 × 2,25 − 9 − 8 = 4,5 − 17 = −12,5

P admet un MINIMUM égal à −12,5, atteint en x = 1,5.

Trois contrôles : a = 2 > 0 donc la parabole ouvre vers le haut et doit avoir un minimum ✔ ; le sommet est en −b/2a = 6/4 = 1,5, l'abscisse trouvée ✔ ; et 1,5 est bien au milieu des deux racines (−1 + 4)/2 = 1,5 ✔

🧰 Deux tableaux, deux abscisses

Le tableau de signe s'articule sur −1 et 4 — les racines de P. Le tableau de variations s'articule sur 1,5 — la racine de P'. Ce ne sont pas les mêmes nombres, et ce ne sont pas les mêmes questions.

10Tableau de variations sur un intervalle fermé Moyen

Établir le tableau de variations de f(x) = x² − 6x + 10 sur [0 ; 5], en précisant les valeurs aux bornes et à l'extremum.

✅ Correction
calcul
① f'(x) = 2x − 6

② Signe :  2x − 6 = 0  →  x = 3
   3 ∈ [0 ; 5] : la colonne existe bien.  ✔

  x     │  0           3            5
  ──────┼───────────────────────────────
  f'(x) │     −        0       +

③ Les TROIS valeurs — bornes comprises :
   f(0) = 0  −  0 + 10 = 10
   f(3) = 9  − 18 + 10 =  1        ← le minimum
   f(5) = 25 − 30 + 10 =  5

④ Tableau :
  x     │  0           3            5
  ──────┼───────────────────────────────
  f'(x) │     −        0       +
  ──────┼───────────────────────────────
  f(x)  │  10  ╲       1      ╱   5

f est décroissante sur [0 ; 3], croissante sur [3 ; 5].
Minimum = 1 en x = 3 ; maximum sur l'intervalle = 10 en x = 0.

Le maximum sur [0 ; 5] vaut 10 et se trouve au bord gauche : il n'apparaît nulle part dans le signe de f'. Sur un intervalle fermé, il faut toujours comparer aussi les valeurs aux bornes. Contrôle : f(x) = (x−3)² + 1, forme canonique qui confirme le minimum 1 en x = 3 ✔

11La dérivée prédit la forme du tableau Facile

Sans calculer, indiquer combien de fois au plus le sens de variation peut changer, et pourquoi.

  1. f(x) = 0,2x − 10
  2. f(x) = 2x² + 3x + 1
  3. f(x) = x³ − 3x² − 9x + 5

Puis vérifier sur le cas 2 en établissant le tableau complet.

✅ Correction
fdegré de ff'degré de f' Changements de sens
0,2x − 1010,2 0 — constanteaucun : monotone
2x² + 3x + 124x + 3 1 — une droiteun : un seul extremum
x³ − 3x² − 9x + 53 3x² − 6x − 92 — un trinôme deux au plus : un max puis un min

Une fonction change de sens là où sa dérivée change de signe, donc au plus autant de fois que f' a de racines — c'est-à-dire au plus son degré.

calcul — cas 2
f(x) = 2x² + 3x + 1

① f'(x) = 4x + 3        ← une affine : pas de discriminant à calculer

② 4x + 3 = 0  →  4x = −3  →  x = −3/4

  x     │ −∞          −3/4          +∞
  ──────┼───────────────────────────────
  f'(x) │     −         0       +

③ f(−3/4) = 2 × (9/16) + 3 × (−3/4) + 1
          = 9/8 − 9/4 + 1
          = 9/8 − 18/8 + 8/8
          = −1/8

④ Tableau :
  x     │ −∞          −3/4          +∞
  ──────┼───────────────────────────────
  f'(x) │     −         0       +
  ──────┼───────────────────────────────
  f(x)  │ +∞  ╲       −1/8     ╱  +∞

Minimum = −1/8 en x = −3/4.

Contrôle : a = 2 > 0 → minimum ✔ ; sommet en −b/2a = −3/4 ✔ ; et f(0) = 1 > −1/8 ✔ Le discriminant de f vaut 9 − 8 = 1 > 0 : f a deux racines, donc son minimum est bien négatif — cohérent avec −1/8 ✔

12Un paramètre — pour quelles valeurs de m ? Difficile

Soit P(x) = x² + mx + 9, où m est un réel.

  1. Exprimer Δ en fonction de m.
  2. Calculer Δ pour m = 0, m = 3, m = −6 et m = 9, et conclure sur le nombre de racines dans chaque cas.
  3. Pour quelles valeurs de m le trinôme admet-il deux racines ?
✅ Correction
calcul — 1
a = 1,  b = m,  c = 9

Δ = b² − 4ac = m² − 4 × 1 × 9 = m² − 36
calcul — 2
m =  0  →  Δ =  0² − 36 = −36   < 0  →  AUCUNE racine
m =  3  →  Δ =  3² − 36 =  9 − 36 = −27   < 0  →  AUCUNE racine
m = −6  →  Δ = (−6)² − 36 = 36 − 36 = 0   = 0  →  UNE racine double
m =  9  →  Δ =  9² − 36 = 81 − 36 =  45   > 0  →  DEUX racines
🔧 Corrigé — 3² − 36 fait −27, pas −30

La copie annonce 3² − 36 = −30. Or 3² = 9 et 9 − 36 = −27. La conclusion — Δ < 0, donc aucune racine — reste la bonne, mais la valeur est fausse. Sur une copie notée, un calcul faux qui mène par chance à la bonne conclusion perd quand même les points du calcul.

calcul — 3
Deux racines ⟺ Δ > 0 ⟺ m² − 36 > 0

m² − 36 est lui-même un trinôme en m : a = 1, b = 0, c = −36.
Ses racines : m² = 36 → m = −6 ou m = 6.

Comme a = 1 > 0, il est POSITIF hors des racines :

  m      │ −∞       −6        6        +∞
  ───────┼──────────────────────────────────
  m²−36  │    +     0    −    0    +

Donc P admet deux racines pour  m ∈ ]−∞ ; −6[ ∪ ]6 ; +∞[.

Contrôle : m = 9 est bien > 6, et on avait trouvé Δ = 45 > 0  ✔
           m = 3 est bien entre −6 et 6, et Δ = −27 < 0        ✔

La réponse est une union de deux intervalles, avec des crochets ouverts — pour m = ±6, Δ vaut exactement 0, donc une seule racine double, pas deux.

⚠️ De m² > 36, on ne tire pas m > 6

Passer à la racine carrée perd la branche négative : m = −10 vérifie bien m² = 100 > 36. La bonne écriture est m < −6 ou m > 6, c'est-à-dire |m| > 6.

La même erreur figure sur une copie de la classe à propos de x² − 1 ⩾ 0, résolu en « x > 1 » — il manque x ⩽ −1. Le tableau de signe évite ce piège automatiquement, parce qu'il montre les deux côtés.
