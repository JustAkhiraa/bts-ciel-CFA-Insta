Calcul matriciel

Un tableau de nombres qu'on additionne et qu'on multiplie. L'addition ne réserve aucune surprise ; c'est la multiplication qui demande de l'attention, parce qu'elle n'est pas toujours possible, qu'elle change de résultat si on inverse l'ordre, et qu'elle peut donner zéro sans qu'aucun facteur soit nul. Résumé flash

Une matrice à n lignes et p colonnes. Le terme mij est celui de la ligne i, colonne j — la ligne d'abord, toujours.

Somme et soustraction : seulement entre matrices de mêmes dimensions, terme à terme. A − B = A + (−B).

Un terme du produit se lit ligne de la première × colonne de la seconde : on multiplie deux à deux, et on additionne.

01 Nommer une matrice, et ses termes

Une matrice est un tableau de nombres. On la décrit par deux nombres, dans cet ordre : d'abord ses lignes, ensuite ses colonnes. Une matrice à n lignes et p colonnes est dite de dimensions n × p.

calcul
         ( m11  m12  m13  ...  m1p )
         ( m21  m22   ...  ...  m2p )
   M  =  (  .                       )      n lignes, p colonnes
         (  .                       )
         ( mn1  mn2   ...  ...  mnp )

Le terme mij est celui qui se trouve ligne i, colonne j. Les deux indices ne sont pas interchangeables : m23 est le terme de la deuxième ligne et de la troisième colonne, m32 celui de la troisième ligne et de la deuxième colonne. Ce ne sont pas les mêmes.

🧭 La ligne d'abord, la colonne ensuite

C'est la seule convention à retenir, et elle sert partout dans le chapitre : pour nommer un terme, pour donner les dimensions d'une matrice, et pour calculer un produit. Un moyen de ne plus l'inverser : on lit un tableau comme on lit une page — on descend jusqu'à la bonne ligne, puis on avance jusqu'à la bonne colonne.

02 Somme et soustraction

Pour additionner ou soustraire deux matrices, elles doivent avoir exactement les mêmes dimensions. On additionne alors terme à terme : le terme de la ligne 1 colonne 1 de l'une avec le terme de la ligne 1 colonne 1 de l'autre, et ainsi de suite.

calcul
        ( 1    3   -2 )            ( -0,5   3      5   )
   A =  ( 0   1,5   6 )       B =  (  8     4      9   )
        ( 2    2    5 )            (  2    14   -12,1  )

               ( 0,5    6     3   )
   A + B  =    ( 8     5,5   15   )
               ( 4     16    -7,1 )

La soustraction n'est pas une opération nouvelle : c'est une addition, après avoir changé tous les signes de la seconde matrice.

calcul
                                   ( 0,5   -3     -5   )
   A - B  =  A + (-B)      avec   -B =  ( -8   -4     -9   )
                                   ( -2  -14    12,1  )

               ( 1,5    0    -7   )
   A - B  =    ( -8   -2,5   -3   )
               (  0   -12    17,1 )
⚠️ Dimensions différentes : la somme n'existe pas

Une matrice 2 × 3 et une matrice 3 × 3 ne s'additionnent pas. Il ne s'agit pas d'un calcul difficile : l'opération n'est pas définie. La réponse attendue est « impossible », pas un tableau rempli au mieux.

03 Multiplier par un nombre

Soit k un réel et A une matrice. Le produit k × A est la matrice dont tous les termes de A ont été multipliés par k. Aucune condition de dimensions : cela marche toujours, et le résultat a les mêmes dimensions que A.

calcul
        ( 1    3   -2 )
   A =  ( 0   1,5   6 )          k = 1,5
        ( 2    2    5 )

                ( 1,5   4,5   -3   )
   k x A  =     ( 0     2,25   9   )  =  A x k
                ( 3     3      7,5 )

Avec un nombre, l'ordre est sans importance : k × A = A × k. Retenez-le, parce que c'est la dernière fois du chapitre qu'on peut inverser l'ordre d'une multiplication sans y réfléchir.

04 Le produit : d'abord, est-il possible ?

Multiplier deux matrices n'est pas toujours possible. Avant tout calcul, on vérifie une condition, et une seule :

📐 La condition d'existence

Le produit M × N n'est réalisable que si le nombre de colonnes de M est égal au nombre de lignes de N.

On l'écrit en posant les deux dimensions côte à côte : les deux nombres du milieu doivent être identiques, et ce sont les deux nombres du bord qui donnent la taille du résultat.

calcul
   M (2 x 3)  x  N (3 x 4)
          ^-----^                 3 = 3  ->  le produit existe
      ^               ^
      2               4           le resultat est une matrice 2 x 4


   M (2 x 3)  x  N (2 x 3)
          ^-----^                 3 != 2 ->  impossible
⚠️ La condition n'est pas symétrique

A × B peut exister alors que B × A n'existe pas. Avec A de dimensions 2 × 3 et B de dimensions 3 × 3 : A × B est possible — 3 colonnes contre 3 lignes — mais B × A demanderait 3 colonnes contre 2 lignes, et n'est donc pas défini. Changer l'ordre n'est pas une commodité : c'est parfois un calcul qui n'existe pas.

05 Les dimensions du résultat

Quand le produit P = M × N existe, les dimensions de P sont connues avant même de calculer :

🧭 Les lignes du premier, les colonnes du second

P a le même nombre de lignes que M — la matrice de gauche — et le même nombre de colonnes que N — celle de droite.

C'est une vérification gratuite, et elle attrape la plupart des erreurs d'étourderie : si votre tableau de réponse n'a pas la bonne forme, inutile de relire les calculs, c'est la méthode qui a dérapé.

06 Calculer un terme : une ligne, une colonne

Chaque terme du produit se fabrique à partir d'une ligne de la matrice de gauche et d'une colonne de la matrice de droite. On multiplie deux à deux, dans l'ordre, puis on additionne tout.

calcul
   p_ij  =  ligne i de M   x   colonne j de N

          =  m_i1 x n_1j  +  m_i2 x n_2j  +  ...  +  m_ip x n_pj

Le terme p23 se calcule donc avec la 2e ligne de la matrice de gauche et la 3e colonne de celle de droite. La condition d'existence prend ici tout son sens : pour que les produits deux à deux tombent juste, il faut exactement autant de termes dans la ligne que dans la colonne — c'est-à-dire autant de colonnes à gauche que de lignes à droite.

🧭 Le geste, au doigt

Index gauche sur la ligne, index droit en haut de la colonne. On avance l'un vers la droite et l'autre vers le bas en même temps, on multiplie les deux nombres rencontrés, et on garde la somme. Quand la ligne est finie, la colonne l'est aussi : c'est la condition d'existence qui le garantit.

07 Un produit en entier

Avec N de dimensions 2 × 3 et M de dimensions 3 × 3, le produit P = N × M existe — 3 colonnes contre 3 lignes — et il sera de dimensions 2 × 3 : les 2 lignes de N, les 3 colonnes de M.

calcul
                                   (  1   2   3 )
   N =  ( 2    -1   0 )       M =  (  0  -1   2 )
        ( 0,5   1   2 )            (  1  -2   0 )

Les six termes, un par un. Chacun est une ligne de N rencontrant une colonne de M :

calcul
   p11 = 2 x 1   + (-1) x 0   + 0 x 1   =  2 +  0 + 0  =  2
   p12 = 2 x 2   + (-1) x(-1) + 0 x(-2) =  4 +  1 + 0  =  5
   p13 = 2 x 3   + (-1) x 2   + 0 x 0   =  6 + (-2)+ 0  =  4

   p21 = 0,5 x 1 +   1  x 0   + 2 x 1   = 0,5 + 0 + 2   =  2,5
   p22 = 0,5 x 2 +   1  x(-1) + 2 x(-2) =  1  -  1 - 4  = -4
   p23 = 0,5 x 3 +   1  x 2   + 2 x 0   = 1,5 + 2 + 0   =  3,5


               ( 2     5    4   )
   P = N x M = ( 2,5  -4    3,5 )

Deux lignes, trois colonnes : la forme annoncée. C'est le premier contrôle à faire, avant même de relire un seul produit.

08 Deux surprises qui n'existent pas chez les nombres

Le produit dépend de l'ordre

Avec les nombres, 3 × 7 et 7 × 3 donnent la même chose. Avec les matrices, non. On a déjà vu le cas extrême : B × A peut ne pas exister alors que A × B existe. Mais même quand les deux produits existent, ils n'ont aucune raison d'être égaux. L'ordre d'écriture fait partie du calcul, et « multiplier A et B » ne veut rien dire tant qu'on n'a pas dit lequel est à gauche.

Un produit nul sans facteur nul

Avec les nombres, si un produit vaut zéro, c'est qu'au moins un des deux facteurs est nul. Chez les matrices, cette règle tombe :

calcul
        (  4   2   0 )            ( -1   2   4 )
   A =  (  2   1   0 )       B =  (  2  -4  -8 )
        ( -2  -1   1 )            (  0   0   0 )

   p11 = 4 x(-1) + 2 x 2 + 0 x 0  = -4 + 4 + 0 = 0
   p12 = 4 x 2   + 2 x(-4)+ 0 x 0 =  8 - 8 + 0 = 0
   p13 = 4 x 4   + 2 x(-8)+ 0 x 0 = 16 -16 + 0 = 0
   ...                                   ( les neuf termes font 0 )

               ( 0   0   0 )
   A x B   =   ( 0   0   0 )
               ( 0   0   0 )
📐 Ce qu'il faut en retenir

La multiplication conduit ici à la matrice nulle alors que ni A ni B n'est une matrice nulle. On ne peut donc pas conclure, d'un produit égal à zéro, que l'un des facteurs est zéro — c'est un raisonnement qui marche avec les nombres et qui est faux avec les matrices.

09 Ce qui marche encore : l'associativité

On vient de perdre deux habitudes. En voici une qui reste : quand les trois produits existent, on peut regrouper comme on veut, à condition de ne jamais changer l'ordre d'écriture.

calcul
   (A x B) x C   =   A x (B x C)

Autrement dit, on a le choix de commencer par la gauche ou par la droite. Ce n'est pas un détail de confort : sur un calcul à trois matrices, l'un des deux chemins est souvent nettement plus court que l'autre — c'est l'objet du troisième exercice, où les deux chemins sont menés en entier et comparés.

⚠️ Associatif n'est pas commutatif

Déplacer les parenthèses est permis. Déplacer les matrices ne l'est pas. (A × B) × C et A × (B × C) sont égaux ; A × B et B × A n'ont aucune raison de l'être, quand le second existe seulement.

10 Récap en 2 minutes

⚡ Tout le chapitre

Nommer — n × p, c'est n lignes et p colonnes. mij, c'est ligne i colonne j. La ligne d'abord.

Somme et soustraction — mêmes dimensions obligatoires, terme à terme. A − B = A + (−B).

Par un nombre — tous les termes sont multipliés, toujours possible, et l'ordre est libre.

Produit — possible si colonnes de gauche = lignes de droite ; le résultat prend les lignes de gauche et les colonnes de droite ; chaque terme est une ligne × colonne.

Ce qui change — l'ordre compte, et un produit nul n'oblige aucun facteur à l'être. Ce qui reste — on peut déplacer les parenthèses.
