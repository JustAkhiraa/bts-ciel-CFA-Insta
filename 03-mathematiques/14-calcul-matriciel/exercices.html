Calcul matriciel — les exercices

Dix-neuf exercices, de la vérification des dimensions à la résolution d'un système à trois inconnues par une matrice inverse. Chaque résultat a été recalculé en fractions exactes, terme par terme. Le cours · La fiche · Le QCM

1Avant de calculer : les dimensions

Trois questions qui ne demandent aucun calcul — seulement de compter les lignes et les colonnes. C'est le réflexe qui évite la moitié des erreurs.

calcul
        ( 1   0  -2 )
   A =  ( 2   3   1 )

        ( 1   0   1 )
   B =  ( 2   1   3 )
        ( 3  -1  -2 )

        ( 3   0  -2   0 )
   C =  (-2   1   1   1 )
        ( 1  -1   0   3 )

1Donner les dimensions de A, B et C Facile

1. Pour chacune des trois matrices, donner ses dimensions sous la forme n × p.

✅ Correction
calcul
   A : 2 lignes, 3 colonnes  ->  2 x 3
   B : 3 lignes, 3 colonnes  ->  3 x 3
   C : 3 lignes, 4 colonnes  ->  3 x 4

La ligne d'abord, la colonne ensuite. A est « large » : 2 × 3, et non 3 × 2.

2Quels produits existent ? Moyen

2. Parmi A × B, B × A, B × C et C × B, dire lesquels sont réalisables, et donner les dimensions de ceux qui le sont.

✅ Correction

On pose les dimensions côte à côte : les deux nombres du milieu doivent être égaux.

calcul
   A x B : (2x3)(3x3)  3 = 3   -> 2 x 3
   B x A : (3x3)(2x3)  3 != 2  -> non
   B x C : (3x3)(3x4)  3 = 3   -> 3 x 4
   C x B : (3x4)(3x3)  4 != 3  -> non
📐 Deux produits sur quatre

Et dans les deux cas qui échouent, c'est l'ordre qui est en cause, pas les matrices. Inverser les facteurs n'est pas neutre : ici, cela supprime purement et simplement le calcul.

3Et les sommes ? Facile

3. A + B est-elle calculable ? Et B + C ?

✅ Correction

Une somme exige des dimensions identiques, pas seulement compatibles.

calcul
   A + B : 2 x 3 et 3 x 3  -> impossible
   B + C : 3 x 3 et 3 x 4  -> impossible

Aucune des deux. À retenir : la condition de la somme (dimensions égales) n'a rien à voir avec celle du produit (colonnes de gauche = lignes de droite). B × C existe, B + C non.

2Somme, différence, et multiple

Les trois opérations qui se font terme à terme, sur l'exemple du cours.

calcul
        ( 1    3   -2 )
   A =  ( 0   1,5   6 )
        ( 2    2    5 )

        ( -0,5   3      5   )
   B =  (  8     4      9   )
        (  2    14   -12,1  )

4Calculer A + B Facile

4. Les deux matrices sont de dimensions 3 × 3. Calculer A + B.

✅ Correction
calcul
   ligne 1 :    1 + (-0,5)  = 0,5
                 3 + 3       = 6
                -2 + 5       = 3

   ligne 2 :    0 + 8        = 8
               1,5 + 4       = 5,5
                 6 + 9       = 15

   ligne 3 :    2 + 2        = 4
                 2 + 14      = 16
                 5 + (-12,1) = -7,1

               ( 0,5    6     3   )
   A + B  =    ( 8     5,5   15   )
               ( 4     16    -7,1 )

5Calculer A − B en passant par −B Moyen

5. Écrire d'abord −B, puis en déduire A − B.

✅ Correction

−B, c'est B avec tous les signes changés.

calcul
         (  0,5   -3     -5   )
   -B =  ( -8     -4     -9   )
         ( -2    -14     12,1 )

   A - B = A + (-B) :

   ligne 1 :    1 + 0,5    = 1,5
                 3 + (-3)   = 0
                -2 + (-5)   = -7

   ligne 2 :    0 + (-8)   = -8
               1,5 + (-4)   = -2,5
                 6 + (-9)   = -3

   ligne 3 :    2 + (-2)   = 0
                 2 + (-14)  = -12
                 5 + 12,1   = 17,1

               ( 1,5    0    -7   )
   A - B  =    ( -8   -2,5   -3   )
               (  0   -12    17,1 )

Passer par −B fait une opération de plus, mais une erreur de signe de moins : on ne soustrait jamais, on additionne toujours.

6Multiplier A par 1,5 Facile

6. Calculer k × A pour k = 1,5.

✅ Correction

Tous les termes, sans exception, sont multipliés par k.

calcul
   1,5 x A  =  A x 1,5  =

                ( 1,5   4,5   -3   )
                ( 0     2,25   9   )
                ( 3     3      7,5 )

Le zéro reste zéro, et 1,5 × 1,5 = 2,25 — le seul terme où l'on se trompe.

3Un produit, terme par terme

Le produit du cours, repris en entier : la condition, la forme attendue, puis les six termes.

calcul
   N =  ( 2    -1   0 )
        ( 0,5   1   2 )

        (  1   2   3 )
   M =  (  0  -1   2 )
        (  1  -2   0 )

7Le produit N × M est-il possible, et de quelle forme ? Facile

7. Justifier que N × M est réalisable, et donner les dimensions du résultat sans le calculer.

✅ Correction
calcul
   N (2 x 3)  x  M (3 x 3)
          ^-----^
      ^               ^
      2               3

   3 colonnes de N = 3 lignes de M
   ->  possible, le resultat est 2 x 3

Deux lignes, trois colonnes : six termes à calculer, pas neuf.

8Calculer les six termes Moyen

8. Calculer P = N × M en détaillant chaque terme.

✅ Correction

Chaque terme est une ligne de N rencontrant une colonne de M.

calcul
   p11 = 2 x 1   + (-1) x 0   + 0 x 1
       = 2 +  0  + 0
       = 2
   p12 = 2 x 2   + (-1) x(-1) + 0 x(-2)
       = 4 +  1  + 0
       = 5
   p13 = 2 x 3   + (-1) x 2   + 0 x 0
       = 6 + (-2) + 0
       = 4

   p21 = 0,5 x 1 +   1  x 0   + 2 x 1
       = 0,5 + 0 + 2
       = 2,5
   p22 = 0,5 x 2 +   1  x(-1) + 2 x(-2)
       = 1  - 1 - 4
       = -4
   p23 = 0,5 x 3 +   1  x 2   + 2 x 0
       = 1,5 + 2 + 0
       = 3,5

               ( 2     5    4   )
   P = N x M = ( 2,5  -4    3,5 )
⚠️ Lire la colonne de haut en bas

Pour p12, la colonne 2 de M est 2, −1, −2 — pas la deuxième ligne 0, −1, 2. C'est l'erreur la plus fréquente, et elle donne un tableau de la bonne forme avec de mauvais nombres : rien ne la signale.

4Trois matrices, deux chemins

L'exercice donné à faire : « Produits de matrices de tailles différentes ». Les deux questions, en entier.

calcul
        ( 1   0  -2 )
   A =  ( 2   3   1 )

        ( 1   0   1 )
   B =  ( 2   1   3 )
        ( 3  -1  -2 )

        ( 3   0  -2   0 )
   C =  (-2   1   1   1 )
        ( 1  -1   0   3 )

9Calculer A × B, puis (A × B) × C Moyen

9. Calculer A × B, puis (A × B) × C.

✅ Correction

A est 2 × 3 et B est 3 × 3 : le produit existe et sera 2 × 3.

calcul
   p11 = 1x1 + 0x2 + (-2)x3
       = 1 + 0 - 6
       = -5
   p12 = 1x0 + 0x1 + (-2)x(-1)
       = 0 + 0 + 2
       = 2
   p13 = 1x1 + 0x3 + (-2)x(-2)
       = 1 + 0 + 4
       = 5
   p21 = 2x1 + 3x2 + 1x3
       = 2 + 6 + 3
       = 11
   p22 = 2x0 + 3x1 + 1x(-1)
       = 0 + 3 - 1
       = 2
   p23 = 2x1 + 3x3 + 1x(-2)
       = 2 + 9 - 2
       = 9

               ( -5   2   5 )
   A x B   =   ( 11   2   9 )

Ce résultat est 2 × 3 et C est 3 × 4 : le second produit existe, et sera 2 × 4.

calcul
   q11 = (-5)x3  + 2x(-2) + 5x1
       = -15 -  4 +  5
       = -14
   q12 = (-5)x0  + 2x1    + 5x(-1)
       = 0 +  2 -  5
       = -3
   q13 = (-5)x(-2)+2x1    + 5x0
       = 10 +  2 +  0
       = 12
   q14 = (-5)x0  + 2x1    + 5x3
       = 0 +  2 + 15
       = 17

   q21 = 11x3    + 2x(-2) + 9x1
       = 33 -  4 +  9
       = 38
   q22 = 11x0    + 2x1    + 9x(-1)
       = 0 +  2 -  9
       = -7
   q23 = 11x(-2) + 2x1    + 9x0
       = -22 +  2 +  0
       = -20
   q24 = 11x0    + 2x1    + 9x3
       = 0 +  2 + 27
       = 29

                  ( -14  -3   12  17 )
   (A x B) x C  =  (  38  -7  -20  29 )

10Calculer B × C, puis A × (B × C). Pouvait-on le prévoir ? Difficile

10. Calculer B × C, puis A × (B × C). Pouvait-on prévoir ce résultat ?

✅ Correction

B est 3 × 3 et C est 3 × 4 : le produit existe et sera 3 × 4.

calcul
   ligne 1 de B = ( 1  0  1 )
     r11 = 1x3 + 0x(-2) + 1x1
         = 3 + 0 + 1
         = 4
     r12 = 1x0 + 0x1    + 1x(-1)
         = 0 + 0 - 1
         = -1
     r13 = 1x(-2)+0x1   + 1x0
         = -2 + 0 + 0
         = -2
     r14 = 1x0 + 0x1    + 1x3
         = 0 + 0 + 3
         = 3

   ligne 2 de B = ( 2  1  3 )
     r21 = 2x3 + 1x(-2) + 3x1
         = 6 - 2 + 3
         = 7
     r22 = 2x0 + 1x1    + 3x(-1)
         = 0 + 1 - 3
         = -2
     r23 = 2x(-2)+1x1   + 3x0
         = -4 + 1 + 0
         = -3
     r24 = 2x0 + 1x1    + 3x3
         = 0 + 1 + 9
         = 10

   ligne 3 de B = ( 3 -1 -2 )
     r31 = 3x3 + (-1)x(-2) + (-2)x1
         = 9 + 2 - 2
         = 9
     r32 = 3x0 + (-1)x1    + (-2)x(-1)
         = 0 - 1 + 2
         = 1
     r33 = 3x(-2)+(-1)x1   + (-2)x0
         = -6 - 1 + 0
         = -7
     r34 = 3x0 + (-1)x1    + (-2)x3
         = 0 - 1 - 6
         = -7

               (  4  -1  -2   3 )
   B x C   =   (  7  -2  -3  10 )
               (  9   1  -7  -7 )

A est 2 × 3 et ce résultat est 3 × 4 : le produit final existe, et sera 2 × 4.

calcul
   ligne 1 de A = ( 1  0 -2 )
     s11 = 1x4 + 0x7 + (-2)x9
         = 4 + 0 - 18
         = -14
     s12 = 1x(-1)+0x(-2)+(-2)x1
         = -1 + 0 -  2
         = -3
     s13 = 1x(-2)+0x(-3)+(-2)x(-7)
         = -2 + 0 + 14
         = 12
     s14 = 1x3 + 0x10 + (-2)x(-7)
         = 3 + 0 + 14
         = 17

   ligne 2 de A = ( 2  3  1 )
     s21 = 2x4 + 3x7 + 1x9
         = 8 + 21 +  9
         = 38
     s22 = 2x(-1)+3x(-2)+1x1
         = -2 -  6 +  1
         = -7
     s23 = 2x(-2)+3x(-3)+1x(-7)
         = -4 -  9 -  7
         = -20
     s24 = 2x3 + 3x10 + 1x(-7)
         = 6 + 30 -  7
         = 29

                  ( -14  -3   12  17 )
   A x (B x C)  =  (  38  -7  -20  29 )
📐 Oui, on pouvait le prévoir

C'est exactement le résultat de la question précédente. Le produit matriciel est associatif : quand les produits existent, (A × B) × C = A × (B × C). On peut donc choisir par où commencer.

Et le choix n'est pas neutre pour la quantité de travail. Par la gauche : 6 termes pour A × B, puis 8 pour le produit par C, soit 14 termes. Par la droite : 12 termes pour B × C, puis 8, soit 20 termes. Le premier chemin est plus court d'un tiers — on regarde les dimensions avant de se lancer.

5Le produit nul

Un cas à connaître : il contredit une règle vraie chez les nombres.

11Calculer A × B, et conclure Difficile

11. Calculer le produit ci-dessous, puis dire ce qu'on peut en conclure sur A et sur B.

calcul
        (  4   2   0 )
   A =  (  2   1   0 )
        ( -2  -1   1 )

        ( -1   2   4 )
   B =  (  2  -4  -8 )
        (  0   0   0 )
✅ Correction

Les deux sont 3 × 3 : le produit existe et sera 3 × 3. Les neuf termes :

calcul
   p11 = 4x(-1) + 2x2    + 0x0
       = -4 +  4 + 0
       = 0
   p12 = 4x2    + 2x(-4) + 0x0
       = 8 -  8 + 0
       = 0
   p13 = 4x4    + 2x(-8) + 0x0
       = 16 - 16 + 0
       = 0

   p21 = 2x(-1) + 1x2    + 0x0
       = -2 +  2 + 0
       = 0
   p22 = 2x2    + 1x(-4) + 0x0
       = 4 -  4 + 0
       = 0
   p23 = 2x4    + 1x(-8) + 0x0
       = 8 -  8 + 0
       = 0

   p31 = (-2)x(-1) + (-1)x2    + 1x0
       = 2 - 2 + 0
       = 0
   p32 = (-2)x2    + (-1)x(-4) + 1x0
       = -4 + 4 + 0
       = 0
   p33 = (-2)x4    + (-1)x(-8) + 1x0
       = -8 + 8 + 0
       = 0

               ( 0   0   0 )
   A x B   =   ( 0   0   0 )
               ( 0   0   0 )
📐 La conclusion attendue

Le produit est la matrice nulle, alors que ni A ni B n'est nulle. On ne peut donc rien conclure sur les facteurs à partir d'un produit nul — le raisonnement « un produit est nul, donc un facteur est nul », valable avec les nombres, est faux avec les matrices.

6Exercice 8 — l'agence de voyages

Le problème complet du cours : un circuit dans trois villes, trois périodes de tarifs. Les matrices y servent à calculer un prix, puis à retrouver un séjour à partir de ses prix.

🎯 L'énoncé

Une agence propose un circuit dans trois villes A, B, C ; le client choisit la durée de son séjour dans chacune. Les tarifs dépendent de la période — haute, moyenne, basse. Les prix journaliers, en centaines d'euros par personne, sont :

Ville AVille BVille C
Période haute2,53,51,5
Période moyenne221,5
Période basse111
calcul
        ( 2,5   3,5   1,5 )
   P =  ( 2     2     1,5 )          prix journaliers, par période (lignes)
        ( 1     1     1   )          et par ville (colonnes)

12Le prix d'un circuit : P × M Facile

1. a. Monsieur M choisit un circuit de 14 jours : 6 jours en A, 5 en B et 3 en C. On lui associe M = ( 6 ; 5 ; 3 ), en colonne. Calculer P × M. Que représentent les termes obtenus ?

✅ Correction

P est 3 × 3 et M 3 × 1 : le produit existe et sera une colonne de 3 termes.

calcul
   ligne 1 :  2,5 x 6 + 3,5 x 5 + 1,5 x 3  =  15 + 17,5 + 4,5  =  37
   ligne 2 :  2   x 6 + 2   x 5 + 1,5 x 3  =  12 + 10   + 4,5  =  26,5
   ligne 3 :  1   x 6 + 1   x 5 + 1   x 3  =   6 +  5   + 3    =  14

              ( 37   )
   P x M  =   ( 26,5 )
              ( 14   )

Chaque terme est le prix total du circuit de M. M, par personne, selon la période — en centaines d'euros : 3 700 € en période haute, 2 650 € en période moyenne, 1 400 € en période basse.

Ces deux questions n'ont pas de correction dans les captures du cours : les calculs ci-dessus sont les nôtres, recalculés en fractions exactes.

13Avec 2 600 € de budget Facile

1. b. Monsieur M dispose d'un budget de 2 600 euros. À quelle période pourra-t-il voyager ?

✅ Correction

On compare le budget aux trois prix de la question a : 3 700 € et 2 650 € le dépassent ; 1 400 € tient dedans. Il ne pourra voyager qu'en période basse.

⚠️ La période moyenne échoue de 50 €

2 650 € contre 2 600 € : l'écart est faible, mais il suffit. Une réponse « période moyenne ou basse » est fausse — et c'est l'erreur qu'on fait en lisant 26,5 comme « environ 2 600 ».

14Calculer Q × P Moyen

2. a. On donne les matrices ci-dessous, I étant la matrice unité d'ordre 3. Calculer le produit Q × P.

calcul
        ( -1    4   -4,5 )             ( 1  0  0 )
   Q =  (  1   -2    1,5 )        I =  ( 0  1  0 )
        (  0   -2    4   )             ( 0  0  1 )
✅ Correction
calcul
   ligne 1 de Q :  ( -1   4   -4,5 )
      colonne 1 :  -1x2,5 + 4x2 + (-4,5)x1   =  -2,5 + 8 - 4,5  =  1
      colonne 2 :  -1x3,5 + 4x2 + (-4,5)x1   =  -3,5 + 8 - 4,5  =  0
      colonne 3 :  -1x1,5 + 4x1,5 + (-4,5)x1 =  -1,5 + 6 - 4,5  =  0

   ligne 2 de Q :  (  1  -2    1,5 )
      colonne 1 :  2,5 - 4 + 1,5             =  0
      colonne 2 :  3,5 - 4 + 1,5             =  1
      colonne 3 :  1,5 - 3 + 1,5             =  0

   ligne 3 de Q :  (  0  -2    4   )
      colonne 1 :  0 - 4 + 4                 =  0
      colonne 2 :  0 - 4 + 4                 =  0
      colonne 3 :  0 - 3 + 4                 =  1

               ( 1  0  0 )
   Q x P   =   ( 0  1  0 )   =   I
               ( 0  0  1 )

Q × P = I : Q est l'inverse de P, ce qui servira à la question suivante.

15P × X = Y ⇔ X = Q × Y Difficile

2. b. Montrer que, pour toutes les matrices colonnes X = ( x ; y ; z ) et Y = ( a ; b ; c ) : P × X = Y ⇔ X = Q × Y.

✅ Correction

Sens ⇒. On part de P X = Y et on multiplie par Q, à gauche des deux côtés :

calcul
        P X  =  Y
   =>   Q x P X  =  Q x Y          on multiplie par Q, à gauche
   =>   I x X    =  Q x Y          car Q x P = I
   =>   X        =  Q x Y          car I x X = X
💡 Le sens retour ⇐ — que la correction du cours ne détaille pas

L'énoncé demande une équivalence. Le sens retour part de X = Q Y et multiplie par P à gauche : P X = P × Q × Y. Il faut alors savoir que P × Q = I — et c'est le cas : pour des matrices carrées, Q × P = I entraîne P × Q = I (on peut le vérifier en calculant les neuf termes). D'où P X = I × Y = Y.

Écrire seulement le sens ⇒ ne démontre pas un « ⇔ ». En épreuve, les deux sens se rédigent.

16Retrouver le circuit à partir de ses prix Moyen

3. Une publicité affirme qu'un circuit complet de 14 jours est possible au prix de 2 600 € en période haute, 2 250 € en période moyenne et 1 400 € en période basse. Comment se compose ce voyage ?

✅ Correction

On cherche X tel que P X = Y. Les prix étant en centaines d'euros, Y = ( 26 ; 22,5 ; 14 ) — et non ( 2 600 ; 2 250 ; 1 400 ). D'après la question 2b, X = Q × Y :

calcul
   x  =  -1 x 26 + 4 x 22,5 + (-4,5) x 14  =  -26 + 90 - 63  =  1
   y  =   1 x 26 - 2 x 22,5 +   1,5  x 14  =   26 - 45 + 21  =  2
   z  =   0 x 26 - 2 x 22,5 +   4    x 14  =    0 - 45 + 56  =  11

              ( 1  )
   X  =       ( 2  )
              ( 11 )

Le voyage se compose de 1 jour dans la ville A, 2 jours dans la ville B et 11 jours dans la ville C — 14 jours en tout, comme annoncé.

⚠️ Les unités du tableau

Avec Y = ( 2 600 ; 2 250 ; 1 400 ), on obtiendrait 100, 200 et 1 100 « jours ». Le tableau est en centaines d'euros : les prix doivent l'être aussi. Vérification : P × X redonne bien 26 ; 22,5 ; 14.

7Devoir 1 — retrouver n

Le sujet est une égalité de matrices où un seul terme manque, écrit n en rouge. Tout le travail consiste à repérer les termes du résultat qui dépendent de n, et ceux-là seulement.

calcul
   ( 1   0   1 )     ( 3   0  -2   0 )     ( 4  -1  -2   3 )
   ( n   1   3 )  x  (-2   1   1   1 )  =  ( 7  -2  -3  10 )
   ( 3  -1  -2 )     ( 1  -1   0   3 )     ( 9   1  -7  -7 )

17Trouver n Moyen

Déterminer n pour que l'égalité soit vraie.

✅ Correction

n est sur la ligne 2 de la première matrice. Il n'intervient donc que dans la ligne 2 du résultat, et seulement quand il multiplie un terme non nul de la ligne 1 de la seconde matrice : 3 (colonne 1) et −2 (colonne 3). Deux termes à écrire, pas douze.

calcul
   ligne 2 x colonne 1 :  n x 3  + 1 x (-2) + 3 x 1   =  3n + 1   =  7
                                                  3n = 6    ->   n = 2
   ligne 2 x colonne 3 :  n x (-2) + 1 x 1  + 3 x 0   =  -2n + 1  =  -3
                                                 -2n = -4   ->   n = 2

n = 2. Les deux termes donnent la même valeur : l'égalité est donc possible. Avec n = 2, la première matrice est la matrice B de l'exercice 7, et le produit est celui de l'exercice 10.

⚠️ Une équation suffit, la seconde vérifie

Le premier terme donne déjà n. Le second ne sert pas à le trouver, il sert à savoir si l'égalité tient : si les deux termes avaient donné deux valeurs différentes, aucun n ne conviendrait, et c'est la réponse qu'il faudrait écrire.

8Devoir 2 — un système à trois inconnues

L'exercice donné à faire : résoudre un système de trois équations à trois inconnues par une inversion de matrice, l'inverse étant obtenu à la calculatrice.

calcul
        ( -4x +  y + 0,1z = 1
   S :  ( 11x - 3y - 0,2z = 1
        ( -6x + 2y + 0,1z = 2

        ( -4    1    0,1 )          ( x )          ( 1 )
   A =  ( 11   -3   -0,2 )     X =  ( y )     B =  ( 1 )
        ( -6    2    0,1 )          ( z )          ( 2 )

18Le système, écrit A X = B Facile

1. Vérifier que le système S est équivalent à l'égalité matricielle A X = B.

✅ Correction

A est 3 × 3, X 3 × 1 : le produit est une colonne de trois termes, chacun une ligne de A par X.

calcul
            ( -4x +  y + 0,1z )
   A X  =   ( 11x - 3y - 0,2z )
            ( -6x + 2y + 0,1z )

Deux colonnes sont égales quand leurs termes le sont un à un. A X = B dit donc exactement les trois équations de S.

19L'inverse, à la calculatrice Moyen

2. a. Déterminer A⁻¹, l'inverse de A, avec une calculatrice ou un logiciel. b. Vérifier que X = A⁻¹ · B.

✅ Correction

La calculatrice donne :

calcul
          ( 1    1    1  )
   A⁻¹ =  ( 1    2    3  )
          ( 40   20   10 )

Un résultat de calculatrice se vérifie : A × A⁻¹ doit donner l'identité. Trois termes, par exemple :

calcul
   ligne 1 x colonne 1 :  -4x1  + 1x1  + 0,1x40     =  -4 + 1 + 4    =  1
   ligne 2 x colonne 2 :  11x1  - 3x2  - 0,2x20     =  11 - 6 - 4    =  1
   ligne 2 x colonne 3 :  11x1  - 3x3  - 0,2x10     =  11 - 9 - 2    =  0

Les neuf termes donnent bien I. Pour b, c'est le raisonnement du cours (section 14) : on multiplie A X = B par A⁻¹ à gauche, d'où A⁻¹ A X = A⁻¹ B, soit I X = A⁻¹ B, soit X = A⁻¹ B.

20La solution du système Moyen

2. c. En déduire la solution du système S.

✅ Correction
calcul
   x  =   1 x 1 +  1 x 1 +  1 x 2   =   1 +  1 +  2   =  4
   y  =   1 x 1 +  2 x 1 +  3 x 2   =   1 +  2 +  6   =  9
   z  =  40 x 1 + 20 x 1 + 10 x 2   =  40 + 20 + 20   =  80

La solution est x = 4, y = 9 et z = 80. On la vérifie dans les trois équations :

calcul
   -4x4  + 9   + 0,1x80   =  -16 +  9 +  8   =  1     ✓
   11x4  - 3x9 - 0,2x80   =   44 - 27 - 16   =  1     ✓
   -6x4  + 2x9 + 0,1x80   =  -24 + 18 +  8   =  2     ✓
💡 Un système qu'on ne résoudrait pas à la main

Par substitution, ces coefficients — 0,1, −0,2 — rendraient le calcul long et fragile. Par les matrices, une fois A⁻¹ en main, la solution tient en un seul produit. C'est tout l'intérêt de la méthode.
