B × C peut exister quand B + C n'existe pas. Ce sont deux conditions sans rapport.

Nommer : la ligne d'abord

Une matrice n × p a n lignes et p colonnes.

Le terme mij est celui de la ligne i, colonne j. m23 n'est pas m32.

On lit un tableau comme une page : on descend jusqu'à la ligne, puis on avance jusqu'à la colonne.

Le test des dimensions, en une ligne

(2 × 3) (3 × 4) milieux égaux → possible, résultat 2 × 4
(2 × 3) (2 × 3) milieux différents → impossible

Les deux nombres du milieu décident si le produit existe ; les deux nombres du bord donnent sa forme.

Un terme du produit

Ligne de la matrice de gauche × colonne de celle de droite : on multiplie deux à deux, dans l'ordre, et on additionne.

pij = mi1n1j + mi2n2j + … + mipnpj

Ce n'est jamais un produit terme à terme. Et la colonne se lit de haut en bas — l'erreur la plus fréquente est d'y prendre une ligne, ce qui donne un tableau de la bonne forme avec de mauvais nombres.

Les trois propriétés

Associatif (A × B) × C = A × (B × C) — vrai, on déplace les parenthèses
Commutatif A × B = B × A — faux, et B × A peut ne pas exister
Produit nul A × B = 0 n'oblige ni A ni B à être nulle

Avec un nombre, en revanche, l'ordre reste libre : k × A = A × k.

Le contre-exemple à connaître

calcul
      (  4   2   0 )       ( -1   2   4 )       ( 0  0  0 )
      (  2   1   0 )   x   (  2  -4  -8 )   =   ( 0  0  0 )
      ( -2  -1   1 )       (  0   0   0 )       ( 0  0  0 )

Neuf termes nuls, et aucune des deux matrices n'est nulle. C'est la question qui tombe pour vérifier qu'on n'applique pas aux matrices un raisonnement de nombres.

Le réflexe qui fait gagner du temps

Sur un calcul à trois matrices, les deux chemins donnent le même résultat mais pas le même travail. Avec A 2 × 3, B 3 × 3, C 3 × 4 :

(A × B) × C6 + 8 = 14 termes
A × (B × C)12 + 8 = 20 termes

On regarde les dimensions avant de se lancer : un tiers de calculs en moins, pour la même réponse.

⚠️ Les quatre fautes qui coûtent le plus

  1. Inverser les indices — m32 au lieu de m23.
  2. Prendre une ligne pour une colonne dans la matrice de droite. Rien ne le signale : la forme du résultat reste juste.
  3. Calculer un produit qui n'existe pas, faute d'avoir posé les dimensions côte à côte.
  4. Conclure d'un produit nul qu'un facteur est nul.
