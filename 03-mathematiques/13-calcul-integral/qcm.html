Calcul intégral — QCM

10 questions. Une seule bonne réponse par question, et l'explication s'affiche dès que vous avez répondu. Le cours · La fiche

0 / 10

1∫₀² x³ dx est-il un nombre ou une fonction ?

Une intégrale définie est un nombre — ici 4. Les bornes 0 et 2 « consomment » la variable, qui disparaît du résultat. Test infaillible : s'il reste un x dans votre réponse, vous avez écrit une primitive, pas une intégrale.

2Quelle est une primitive de f(x) = e^(−0,1x) ?

La formule est e^(αx) → (1/α)·e^(αx). Ici α = −0,1, donc 1/α = −10. Le signe vient de 1/α avec α négatif : l'oublier change le signe du résultat final, donc l'aire.

3Devant f(x) = 2x/(x² + 1), quel est le réflexe ?

(x² + 1)′ = 2x, exactement le numérateur : la fraction est de la forme u′/u, donc une primitive est ln(x² + 1). Le réflexe est toujours le même : dérivez le dénominateur avant de conclure que l'exercice est infaisable.

4Une primitive de f(x) = 1/(2x + 1) est :

Ici u = 2x + 1 donc u′ = 2, mais le numérateur vaut 1 : la forme u′/u n'est pas donnée telle quelle. On écrit 1/(2x+1) = ½ × 2/(2x+1), et le ½ se traîne jusqu'à la primitive. Contrôle : dérivez ln|2x+1|, vous obtenez 2/(2x+1), soit le double.

5Que vaut la valeur moyenne de f(x) = x² sur [0 ; 10] ?

Vₘ = (1/10)·∫₀¹⁰ x² dx = (1/10)·(1000/3) = 100/3 ≈ 33,33. La demi-somme des extrémités donnerait 50 : elle ignore tout ce qui se passe entre les bornes. x² reste longtemps petite avant de s'envoler, donc sa moyenne est nettement sous 50.

6Pourquoi le + K disparaît-il dans une intégrale définie ?

(F(b) + K) − (F(a) + K) = F(b) − F(a) : la constante s'annule. On peut donc prendre n'importe quelle primitive. Mais dès que la question dit « déterminer les primitives », l'oublier rend la réponse fausse.

7Sur un intervalle où la courbe passe sous l'axe des abscisses :

Aire et intégrale ne coïncident que si f ⩾ 0. Une intégrale nulle ne veut donc pas dire « aucune aire » : elle peut vouloir dire « autant au-dessus qu'en dessous ». Dans les annales de BTS, les fonctions modélisent des quantités positives — vérifiez-le une fois et dites-le en une ligne.

8f′(x) = 80·e^(−0,2x)(1 − 0,2x). De quoi f′ est-elle du signe ?

80 > 0 et une exponentielle est toujours strictement positive. Par produit, le signe de f′ est celui du facteur restant — un polynôme, dont le signe se lit d'un coup. C'est pour cela qu'on factorise systématiquement par l'exponentielle : la question du signe devient gratuite.

9Pour montrer que F est une primitive de f, que fait-on ?

C'est la définition même d'une primitive : F′ = f. Les trois annales du chapitre posent la question sous la forme « montrer que F est une primitive » — elles demandent donc une dérivation, pas une intégration. C'est la question la plus rentable du sujet.

10Une valeur moyenne calculée doit toujours être :

C'est le contrôle de cohérence qui coûte dix secondes. Sur l'annale du béton, f varie de 0 à 28,5 MPa : une moyenne de 18,0 est plausible. Si vous trouviez 40, vous sauriez immédiatement qu'il y a une erreur, sans relire le calcul.
