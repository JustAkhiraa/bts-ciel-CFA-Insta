⚡ Le code R.O.I.

Réel (non nul) · zérO · Infini. On lit numérateur · dénominateur · résultat.

CodeTraductionRésultatL'idée
IRI∞ / R∞ un très grand divisé par un nombre ordinaire reste très grand
ORO0 / R0 zéro partagé, ça reste zéro
ROIR / 0∞ diviser par presque rien donne presque l'infini
RIOR / ∞0 partager entre une infinité, chacun n'a rien
IOI∞ / 0∞ très grand divisé par presque rien : encore plus grand
OIO0 / ∞0 presque rien partagé entre une infinité : rien

Un seul principe : diviser par très petit agrandit, diviser par très grand réduit.

⚡ Le R est NON NUL

Les codes IRI, ORO et ROI supposent tous R ≠ 0. Sinon on bascule dans une forme indéterminée.

calcul
x/3 quand x → 0   : ORO  →  0      ✔ (3 ≠ 0)
x/x quand x → 0   : 0/0  →  INDÉTERMINÉE
                    mais x/x = 1   →  limite 1

⚡ « ∞ » ne dit pas le signe

calcul
1/x  près de 0 :

  x → 0⁺  (dénominateur petit POSITIF)  →  +∞
  x → 0⁻  (dénominateur petit NÉGATIF)  →  −∞

DEUX limites différentes.

Pour R/0, il faut le signe de R et le côté par lequel le dénominateur atteint 0. On annonce toujours les deux limites.

⚡ Déterminer le signe

méthode
① repérer la valeur interdite
② tableau de SIGNE du dénominateur
③ combiner avec le signe du numérateur
④ annoncer lim à gauche ET lim à droite
calcul
(x+4)/(x−12) près de 12 :
  numérateur → 16 > 0
  x−12 : − avant 12, + après

  x → 12⁻ : −∞      x → 12⁺ : +∞

⚡ Les quatre formes indéterminées

0 / 0  ·  ∞ / ∞  ·  0 × ∞  ·  ∞ − ∞

« Indéterminée » ne veut pas dire « pas de limite » : la forme ne suffit pas à conclure, il faut transformer l'expression.

calcul
Quand x → 0, trois fois la forme 0/0 :

   x  / x   = 1      →  limite 1
   x² / x   = x      →  limite 0
   x  / x²  = 1/x    →  limite ∞

Même forme, trois réponses. D'où « indéterminée ».

Réflexe : simplifier ou factoriser, puis relire le tableau R.O.I.

⚡ Vérifier que la valeur interdite est dans l'intervalle

(x+4)/(x−12) étudiée sur [−10 ; 10] : la valeur interdite 12 est hors de l'intervalle.

→ aucune limite à calculer, aucune asymptote, aucune double barre. La fonction est continue sur tout I.

Quatre de ces six disent la même chose : une décroissance exponentielle tend vers 0 sans jamais s'annuler. En CIEL, c'est la décharge d'un condensateur : après 5 RC il reste e−5 ≈ 0,67 %, et on le déclare déchargé.

⚡ Les quatre erreurs qui coûtent des points

  1. Appliquer R.O.I. avec un R nul — c'est une forme indéterminée, pas un cas du tableau.
  2. Écrire « ∞ » sans le signe — il faut +∞ ou −∞, et les deux côtés.
  3. Oublier une racine du dénominateur — x² = 4 donne deux valeurs interdites, donc deux asymptotes.
  4. Chercher une asymptote hors de l'intervalle d'étude.
