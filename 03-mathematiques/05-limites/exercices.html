Limites — exercices

Aucun exercice d'origine n'existe pour ce chapitre. Ceux-ci sont construits sur le code R.O.I. et sur les limites qui servent réellement dans les autres chapitres.

⚠️ Exercices reconstitués, pas d'origine

Le chapitre ne dispose que d'un tableau d'une page — voir l'état du chapitre. Les exercices ci-dessous sont ajoutés : ils appliquent le code R.O.I. et reprennent les limites utilisées aux chapitres 03, 06, 09 et 10. Toutes les valeurs ont été recalculées.

Ils ne remplacent pas un vrai devoir sur les limites, en particulier sur la levée des formes indéterminées, qui n'est couverte par aucun document disponible.

01Appliquer le code R.O.I.

1Nommer le code Facile

Pour chaque limite, dire quel code R.O.I. s'applique et donner le résultat.

  1. lim (x → +∞) 5/x
  2. lim (x → +∞) (x² + 1)/7
  3. lim (x → 0) x/4
  4. lim (x → 0⁺) 3/x
  5. lim (x → 0⁺) (1/x²)/x
  6. lim (x → +∞) (1/x)/x
✅ Correction
#NumérateurDénominateurCode Résultat
15 → Rx → I RIO0
2x²+1 → I7 → R IRI+∞
3x → O4 → R ORO0
43 → Rx → O ROI+∞
51/x² → Ix → O IOI+∞
61/x → Ox → I OIO0

La méthode est toujours la même : identifier la nature du numérateur, puis celle du dénominateur — les deux premières lettres — et lire la troisième. Aucun calcul.

Contrôles numériques : pour 4, 3/0,001 = 3 000 ✔ ; pour 6, (1/1000)/1000 = 0,000 001 ✔ Deux substitutions avec une valeur extrême suffisent à confirmer le sens.

⚠️ Pourquoi « x → 0⁺ » aux questions 4 et 5

Sans le petit « + », le résultat serait ambigu : par la gauche, 3/x tend vers −∞. Le code R.O.I. donne « ∞ », pas son signe — c'est l'objet de la section 2.

2Le piège du R nul Moyen

Pour chacune, dire si le code R.O.I. s'applique, et conclure.

  1. lim (x → 0) x/3
  2. lim (x → 0) x/x
  3. lim (x → 0) x²/x
  4. lim (x → 0⁺) x/x²
✅ Correction
calcul
1.  x / 3        →  0 / 3      Le dénominateur est un RÉEL NON NUL.
                               Code ORO applicable  →  limite 0    ✔

2.  x / x        →  0 / 0      Le dénominateur tend vers 0 : ce n'est
                               PAS un R. Le code ne s'applique pas.
                               FORME INDÉTERMINÉE.
                               Mais x/x = 1 pour tout x ≠ 0 → limite 1

3.  x² / x       →  0 / 0      Indéterminée aussi.
                               Or x²/x = x → limite 0

4.  x / x²       →  0 / 0      Indéterminée encore.
                               Or x/x² = 1/x → limite +∞  (x → 0⁺)

Trois fois la même forme 0/0, trois résultats différents : 1, 0 et +∞. C'est exactement ce que signifie « indéterminée » — et c'est pourquoi le tableau R.O.I. précise implicitement que le R doit être non nul.

Dans les trois cas, la simplification résout tout. C'est le premier réflexe devant une indétermination.

02Le signe de l'infini

3De part et d'autre d'une valeur interdite Moyen

Soit f(x) = (x + 4)/(x − 12).

  1. Donner l'ensemble de définition de f.
  2. Déterminer lim (x → 12⁻) f(x) et lim (x → 12⁺) f(x).
  3. En déduire l'équation de l'asymptote verticale.
✅ Correction
calcul — 1
Le dénominateur ne doit pas s'annuler :
     x − 12 = 0  ⟺  x = 12

     D(f) = ℝ \ {12}
calcul — 2
NUMÉRATEUR en x = 12 :   12 + 4 = 16
     C'est un réel NON NUL et POSITIF → c'est bien le « R » du code.

DÉNOMINATEUR : signe de x − 12

  x       │ −∞            12            +∞
  ────────┼───────────────────────────────
  x − 12  │      −         0       +

Donc, code ROI (R/0 → ∞), avec le signe donné par le dénominateur :

  x → 12⁻ :  16 / (petit NÉGATIF)  →  lim = −∞
  x → 12⁺ :  16 / (petit POSITIF)  →  lim = +∞

Contrôles : f(11,9) = 15,9/(−0,1) = −159 et f(12,1) = 16,1/0,1 = 161 ✔ En se rapprochant encore : f(11,99) = −1 599 et f(12,01) = 1 601 ✔ Les valeurs divergent bien, et dans des directions opposées.

calcul — 3
Les deux limites sont infinies en x = 12.

La droite d'équation  x = 12  est une ASYMPTOTE VERTICALE à la courbe.
💡 Et sur [−10 ; 10] ?

Au chapitre 03, cette même fonction est étudiée sur [−10 ; 10]. Or 12 ∉ [−10 ; 10] : sur cet intervalle, f est parfaitement définie et continue, il n'y a aucune asymptote à mentionner.

Toujours comparer la valeur interdite aux bornes avant de conclure.

4Un dénominateur à deux racines Difficile

Soit g(x) = (3x² + 1)/(x² − 4). Déterminer le domaine, puis les limites à gauche et à droite de x = 2.

✅ Correction
calcul
DOMAINE :  x² − 4 = 0  ⟺  x² = 4  ⟺  x = 2  ou  x = −2
           (ne pas oublier la racine négative !)

     D(g) = ℝ \ {−2 ; 2}

NUMÉRATEUR en x = 2 :  3 × 4 + 1 = 13
     Réel non nul et positif  →  c'est le « R »

DÉNOMINATEUR : x² − 4 = (x − 2)(x + 2), racines −2 et 2, a = 1 > 0
     signe de a hors des racines, contraire entre :

  x        │ −∞      −2        2        +∞
  ─────────┼──────────────────────────────
  x² − 4   │    +    0    −    0    +

Près de 2 :
  x → 2⁻ :  13 / (petit NÉGATIF)  →  lim = −∞
  x → 2⁺ :  13 / (petit POSITIF)  →  lim = +∞

Asymptote verticale d'équation  x = 2.

Contrôles : g(1,99) ≈ −322,8 et g(2,01) ≈ 327,2 ✔ Signes opposés, valeurs déjà grandes.

Le piège est au domaine : x² = 4 a deux solutions. Écrire « x = 2 » seulement fait rater la seconde asymptote, en x = −2 — c'est la même erreur que « m² > 36 ⟹ m > 6 du chapitre 04.

03Formes indéterminées

5Reconnaître et lever Moyen

  1. lim (x → 3) (x² − 9)/(x − 3)
  2. lim (x → +∞) (2x + 1)/(x − 5)

Pour chacune : identifier la forme, puis conclure.

✅ Correction
calcul — 1
En x = 3 :   numérateur  3² − 9 = 0
             dénominateur    3 − 3 = 0

     Forme  0/0  →  INDÉTERMINÉE, le code R.O.I. ne dit rien.

On FACTORISE le numérateur (identité remarquable) :

     x² − 9 = (x − 3)(x + 3)

     (x² − 9)/(x − 3) = (x − 3)(x + 3)/(x − 3)
                      = x + 3            pour x ≠ 3

     lim (x → 3) (x + 3) = 6

Contrôle : g(2,999) ≈ 5,999 ✔ La fonction n'existe pas en 3, mais elle s'approche de 6 d'aussi près qu'on veut. C'est exactement ce qu'est une limite.

calcul — 2
Quand x → +∞ :   numérateur  2x + 1  →  +∞
                 dénominateur  x − 5  →  +∞

     Forme  ∞/∞  →  INDÉTERMINÉE.

On factorise par le terme de plus haut degré, en haut et en bas :

     (2x + 1)/(x − 5) = x(2 + 1/x) / x(1 − 5/x)
                      =   (2 + 1/x) / (1 − 5/x)

Or  1/x → 0  et  5/x → 0       (code RIO)

     lim = (2 + 0)/(1 − 0) = 2

Contrôle : x = 1 000 donne 2 001/995 ≈ 2,011 ✔ La courbe admet l'asymptote horizontale y = 2.

⚠️ Cette technique n'est pas dans les documents disponibles

La factorisation par le terme de plus haut degré est la méthode standard pour lever une forme ∞/∞. Elle est présentée ici parce qu'elle est indispensable, mais elle ne figure dans aucun document de la copie A — voir l'état du chapitre. À confirmer avec le professeur avant de s'appuyer dessus en devoir.

04Les limites du dépôt

6Le plafond des abonnés Moyen

Le nombre d'abonnés d'une revue est modélisé par aₙ = 25 000 − 20 000 × (0,8)ⁿ (chapitre 06).

  1. Déterminer lim (n → +∞) aₙ.
  2. Interpréter, et donner l'équation de l'asymptote.
✅ Correction
calcul
Comme  0 < 0,8 < 1,  la puissance 0,8ⁿ s'écrase quand n grandit :

     0,8¹⁰ ≈ 0,107     0,8²⁰ ≈ 0,0115     0,8⁵⁰ ≈ 0,000 014

     lim (n → +∞) 0,8ⁿ = 0

Donc  20 000 × 0,8ⁿ → 0,  et :

     lim (n → +∞) aₙ = 25 000 − 0 = 25 000

INTERPRÉTATION : la revue PLAFONNE à 25 000 abonnés. Le modèle
prévoit qu'elle s'en approche indéfiniment, sans jamais les atteindre.

ASYMPTOTE HORIZONTALE d'équation  y = 25 000.

Contrôles : a₂₀ ≈ 24 769, et à n = 50 l'écart au plafond vaut 0,29 abonné ✔ La suite monte vers 25 000 sans l'atteindre.

7La fiabilité d'un composant Moyen

La fonction de fiabilité d'un composant est R(t) = e^{−λt} avec λ > 0 (chapitre 09).

  1. Déterminer lim (t → +∞) R(t), et l'interpréter.
  2. Pour λ = 0,5, calculer R(10) et R(20). Le résultat est-il cohérent ?
✅ Correction
calcul — 1
R(t) = e^(−λt) = 1 / e^(λt)          car e^(−u) = 1/e^(u)

Comme λ > 0,  λt → +∞  quand t → +∞,  donc  e^(λt) → +∞.

On a donc  1 / (très grand)  →  code RIO  →  limite 0

     lim (t → +∞) R(t) = 0

INTERPRÉTATION : la probabilité qu'un composant fonctionne encore
tend vers 0. Aucun composant ne dure éternellement — mais R(t) ne
s'annule JAMAIS : il reste toujours une chance infime.

ASYMPTOTE HORIZONTALE d'équation  y = 0 (l'axe des abscisses).
calcul — 2
λ = 0,5 :

     R(10) = e^(−0,5 × 10) = e^(−5)  ≈ 0,006 74   →  0,67 %
     R(20) = e^(−0,5 × 20) = e^(−10) ≈ 0,000 045  →  0,0045 %

COHÉRENT : R décroît, reste strictement positive, et s'approche
de 0 très vite. En doublant la durée, la fiabilité est divisée
par environ 150.

C'est exactement le comportement d'une décharge de condensateur : après 5 RC, il reste e^{−5} ≈ 0,67 % de la tension initiale — et l'ingénieur considère le condensateur déchargé, alors que le mathématicien précise qu'il ne l'est jamais tout à fait.

8Le modèle logistique Difficile

On modélise le pourcentage de foyers équipés par f(t) = 100/(1 + 9e^{αt}) avec α ≈ −0,717 (chapitre 06).

  1. Déterminer lim (t → +∞) f(t).
  2. Ce résultat a-t-il un sens concret ?
✅ Correction
calcul — 1
On traite le DÉNOMINATEUR d'abord.

α ≈ −0,717 est NÉGATIF, donc  αt → −∞  quand t → +∞,
et  e^(αt) → 0.

     dénominateur  1 + 9 e^(αt)  →  1 + 9 × 0 = 1

Le numérateur, lui, vaut 100 : c'est une constante.

     lim (t → +∞) f(t) = 100 / 1 = 100

Ici le code R.O.I. ne s'applique pas directement : le dénominateur ne tend ni vers 0, ni vers l'infini, mais vers 1. C'est le cas le plus simple — R/R — et il n'est pas dans le tableau, qui ne traite que les cas limites.

calcul — 2
OUI, et c'est même ce qui valide le modèle :

f(t) est un POURCENTAGE de foyers équipés. Il ne peut pas
dépasser 100 %.

Le modèle prévoit donc un équipement qui s'approche de 100 %
sans jamais l'atteindre — ce qui est le comportement attendu
d'une courbe d'adoption.

ASYMPTOTE HORIZONTALE d'équation  y = 100.

Contrôle : f(0) = 10 %, f(5) = 80 % — et f reste toujours < 100.

Un modèle dont la limite serait 150 % serait à rejeter : vérifier que la limite a un sens physique fait partie de la réponse. C'est une question classique de fin d'exercice.
