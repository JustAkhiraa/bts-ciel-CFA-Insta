Limites

Vers quoi une expression tend-elle quand x s'approche d'une valeur interdite, ou part vers l'infini ? Six cas se lisent directement — et quatre ne se lisent pas du tout.

📌

Résumé flash

Le code R.O.I. — Réel, zérO, Infini — donne le résultat de six quotients d'un coup d'œil. Le principe : diviser par quelque chose de très petit donne quelque chose de très grand, et inversement. Restent quatre formes indéterminées — 0/0, ∞/∞, 0 × ∞, ∞ − ∞ — où le tableau ne dit rien : il faut transformer l'expression.

01L'idée d'une limite

Une limite répond à une question de tendance, pas de valeur : « quand x s'approche de quelque chose, vers quoi f(x) s'approche-t-il ? » Deux situations la rendent nécessaire.

SituationQuestionExemple du dépôt
Une valeur interdite que se passe-t-il tout près du point où la fonction n'existe pas ? (x+4)/(x−12) près de x = 12 (chapitre 03)
L'infini que devient f(x) quand x devient très grand ? 25 000 − 20 000 × 0,8ⁿ quand n grandit (chapitre 06)
🔗 Partager un gâteau

Un gâteau (un réel) partagé entre de plus en plus de convives : la part de chacun devient minuscule. R / ∞ → 0.

Le même gâteau partagé entre de moins en moins de monde : la part devient énorme. R / 0 → ∞.

Tout le code R.O.I. tient dans cette intuition : diviser par très petit agrandit, diviser par très grand réduit.

02Le code R.O.I.

C'est le seul document du chapitre. Un moyen mnémotechnique en trois lettres, où chaque lettre désigne une nature :

🧰 Les trois lettres
LettreSignifieC'est-à-dire
RRéel un nombre ordinaire, non nul
OzérO la valeur 0, ou une quantité qui tend vers 0
IInfini +∞ ou −∞

Le code se lit dans l'ordre : numérateur · dénominateur · résultat.

🧰 Le tableau, tel qu'il figure dans le document
CodeTraduction mathématiqueRésultat Comment le lire
IRI∞ / R∞ un très grand divisé par un nombre ordinaire reste très grand
ORO0 / R0 zéro partagé, ça reste zéro
ROIR / 0∞ diviser par presque rien donne presque l'infini
RIOR / ∞0 partager entre une infinité, chacun n'a rien
IOI∞ / 0∞ très grand divisé par presque rien : encore plus grand
OIO0 / ∞0 presque rien partagé entre une infinité : rien
💡 Pourquoi ce code est bien construit

La première lettre est le numérateur, la deuxième le dénominateur, la troisième le résultat. Les six codes ne sont donc pas à apprendre par cœur : il suffit de lire les deux premières lettres et de raisonner. Le mot « ROI » se retient tout seul, et les cinq autres se déduisent du même principe.

Remarquez la symétrie : les trois codes finissant par I ont un dénominateur petit ou un numérateur immense ; les trois finissant par O ont un dénominateur immense ou un numérateur nul.

03Lire le tableau

⚠️ Dans R.O.I., le R est un réel non nul

Le document ne le précise pas, et c'est la précision la plus importante du chapitre. Les trois codes qui contiennent un R au numérateur ou au dénominateur — IRI, ORO, ROI — supposent tous R ≠ 0.

Si R valait 0, on retomberait sur 0/0, ∞/0 lu autrement, ou 0/0 — c'est-à-dire sur les formes indéterminées du § 5, où le tableau ne donne aucune réponse.

calcul
ORO :  0 / R  →  0     mais seulement si R ≠ 0

  lim (x → 0)  x / 3    = 0 / 3 = 0        ← ORO, R = 3 ≠ 0  ✔

  lim (x → 0)  x / x    = 0 / 0            ← FORME INDÉTERMINÉE
                        Or x/x = 1 pour tout x ≠ 0, donc la limite vaut 1.
                        Le tableau ne pouvait pas le dire.

04Le signe de l'infini

⚠️ « ∞ » ne dit pas de quel côté

Dans le tableau, ROI et IOI donnent « ∞ ». Mais est-ce +∞ ou −∞ ? Le code ne le dit pas — et sur une copie, il faut le préciser.

Pour R / 0, la réponse dépend de deux choses : le signe du réel R, et le côté par lequel le dénominateur s'approche de 0.

calcul
f(x) = 1/x   près de 0 :

  x → 0⁺  (par la droite, x > 0)   le dénominateur est petit et POSITIF
          1/0,001 = 1 000  ·  1/0,000 001 = 1 000 000
          lim = +∞

  x → 0⁻  (par la gauche, x < 0)   le dénominateur est petit et NÉGATIF
          1/(−0,001) = −1 000  ·  1/(−0,000 001) = −1 000 000
          lim = −∞

Les deux limites sont DIFFÉRENTES : la courbe s'envole vers le haut
d'un côté, plonge vers le bas de l'autre. Le dessin du § 3 le montre.
📐 Déterminer le signe en pratique
  1. Repérer la valeur interdite — celle qui annule le dénominateur.
  2. Étudier le signe du dénominateur de part et d'autre, avec un tableau de signe du chapitre 03.
  3. Combiner avec le signe du numérateur, par la règle des signes.
  4. Annoncer deux limites : à gauche et à droite.
calcul
f(x) = (x + 4) / (x − 12)      près de x = 12

Numérateur en 12 :  12 + 4 = 16  →  positif, et non nul  ✔ (c'est le R)

Dénominateur :  x − 12 est NÉGATIF pour x < 12
                x − 12 est POSITIF pour x > 12

  x → 12⁻ :  16 / (petit négatif)  →  −∞
  x → 12⁺ :  16 / (petit positif)  →  +∞

La droite d'équation x = 12 est une asymptote verticale.

Contrôle numérique : f(11,9) = 15,9/(−0,1) = −159 et f(12,1) = 16,1/0,1 = 161 ✔ Les deux signes sont bien opposés, et les valeurs déjà très grandes.

💡 Quand la valeur interdite est hors de l'intervalle

Au chapitre 03, cette même fonction est étudiée sur [−10 ; 10] — et 12 n'y est pas. Il n'y a donc aucune limite à calculer, aucune asymptote à tracer : la fonction est parfaitement continue sur tout l'intervalle.

Toujours comparer la valeur interdite aux bornes avant de se lancer.

05Les formes indéterminées

Le tableau R.O.I. couvre six cas. Il en existe quatre autres où il ne dit rien — et ce sont précisément ceux qui tombent en devoir.

🧰 Les quatre formes indéterminées
0 / 0  ·  ∞ / ∞  ·  0 × ∞  ·  ∞ − ∞

« Indéterminée » ne veut pas dire « pas de limite » : cela veut dire que la forme ne suffit pas à conclure. Il faut transformer l'expression pour faire disparaître le conflit.

⚠️ Une même forme peut donner n'importe quoi

C'est ce qui rend ces cas indéterminés : trois quotients de la forme 0/0, trois résultats différents.

calcul
Quand x → 0 :

   x  / x     →  0/0      mais x/x = 1        →  limite 1
   x² / x     →  0/0      mais x²/x = x       →  limite 0
   x  / x²    →  0/0      mais x/x² = 1/x     →  limite ∞

Trois fois la même « forme », trois réponses différentes.
Le tableau R.O.I. ne pouvait donc pas trancher.
📐 Le réflexe : simplifier avant de conclure

Dans les trois exemples ci-dessus, la simplification résout l'indétermination. C'est le geste de base : si la forme est indéterminée, c'est que l'écriture est mal choisie — on factorise, on simplifie, on réécrit, puis on relit le tableau.

Les techniques complètes (factorisation par le terme de plus haut degré, quantité conjuguée, croissances comparées) ne figurent pas dans les documents disponibles — voir l'état du chapitre.

💡 Une constante qui revient : « tend vers 0 sans jamais l'atteindre »

Quatre des six lignes disent la même chose. C'est le comportement de toute décroissance exponentielle : elle devient indétectable sans jamais s'annuler.

En CIEL, c'est exactement la décharge d'un condensateur : u(t) = U e^{−t/RC} ne vaut jamais zéro, mais après 5 constantes de temps il reste moins de 1 % de la tension initiale — et on considère le condensateur déchargé. La limite mathématique dit « 0 à l'infini » ; l'ingénieur dit « 0 au bout de 5 RC ».

07Lire une asymptote

Une limite se lit sur un dessin : c'est une asymptote, une droite dont la courbe se rapproche indéfiniment.

TypeSe produit quandÉquation Exemple
Asymptote verticale la limite est infinie en une valeur finie x = a x = 12 pour (x+4)/(x−12)
Asymptote horizontale la limite est finie quand x → ±∞ y = L y = 25 000 pour les abonnés · y = 0 pour 1/x
🔗 Deux façons de ne jamais arriver

L'asymptote verticale est un mur : la courbe monte le long sans jamais le franchir. L'asymptote horizontale est un plafond : la courbe s'en approche par en dessous, indéfiniment, sans le toucher.

Dans les deux cas, le mot-clé est jamais — et c'est ce qui distingue une limite d'une valeur : la fonction ne prend pas la valeur limite, elle s'en approche.

🤔 Quelle asymptote pour aₙ = 25 000 − 20 000 × 0,8ⁿ ?
calcul
Quand n → +∞ :

  0 < 0,8 < 1,  donc  0,8ⁿ → 0
  donc  20 000 × 0,8ⁿ → 0
  donc  aₙ → 25 000 − 0 = 25 000

C'est une asymptote HORIZONTALE d'équation  y = 25 000.

Contrôle :  a₂₀ ≈ 24 769   ·   a₅₀ ≈ 25 000 (à 0,29 près)
            la suite monte vers 25 000 sans l'atteindre  ✔

Interprétation concrète : la revue plafonne à 25 000 abonnés. Le modèle ne prévoit pas qu'elle les atteigne — seulement qu'elle s'en approche autant qu'on veut. C'est souvent la question finale d'un exercice de modélisation : « comment s'interprètent les résultats observés ? »

⚡ Récap 2 minutes

  • Une limite est une tendance, pas une valeur : la fonction s'approche, elle n'atteint pas.
  • Code R.O.I. — Réel (non nul) · zérO · Infini. On lit numérateur · dénominateur · résultat.
  • IRI : ∞/R → ∞ · ORO : 0/R → 0 · ROI : R/0 → ∞ · RIO : R/∞ → 0 · IOI : ∞/0 → ∞ · OIO : 0/∞ → 0.
  • Le principe unique : diviser par très petit agrandit, diviser par très grand réduit.
  • Le R du code est non nul — sinon on bascule dans une forme indéterminée.
  • « ∞ » ne dit pas le signe : pour R/0, il faut étudier le côté (gauche ou droite) et le signe du numérateur. On annonce deux limites.
  • Quatre formes indéterminées : 0/0 · ∞/∞ · 0 × ∞ · ∞ − ∞. Elles ne veulent pas dire « pas de limite », mais « la forme ne suffit pas ».
  • Réflexe : devant une indétermination, simplifier ou factoriser, puis relire le tableau.
  • Asymptote verticale x = a : limite infinie en une valeur finie. Horizontale y = L : limite finie à l'infini.
  • Vérifier que la valeur interdite est dans l'intervalle avant de chercher une asymptote.
  • Les limites qui servent vraiment : 0,8ⁿ → 0 · e^{−λt} → 0 · le plafond du modèle logistique · les queues de la loi normale.
