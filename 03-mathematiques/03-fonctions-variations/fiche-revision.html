⚡ Image et antécédent

x  →  f  →  f(x)
antécédent  ·  image
  • Image de 3 : on calcule f(3).
  • Antécédent de 5 : on résout f(x) = 5.

Une image est unique ; un nombre peut avoir plusieurs antécédents.

⚡ Orthogonal ≠ orthonormal

  • Orthogonal : axes perpendiculaires, unités éventuellement différentes.
  • Orthonormal : en plus, même unité sur les deux axes.

Ortho = l'angle droit · normé = l'unité commune. Tout orthonormal est orthogonal, l'inverse est faux.

⚡ Fonction affine

f(x) = ax + b
  • a = coefficient directeur (la pente)
  • b = ordonnée à l'origine, car f(0) = b
a > 0croissante
a < 0décroissante
a = 0constante (horizontale)

Signe : signe de a après la racine, contraire avant.

⚡ Diviser par un négatif retourne l'inégalité

calcul
−3x + 6 > 0
    −3x > −6
      x < 2       ← le signe s'est RETOURNÉ

Contrôle : x = 0 → −3×0+6 = 6 > 0 ✔ et 0 < 2 ✔

La valeur-test coûte cinq secondes et attrape l'erreur à coup sûr.

⚡ Racine → facteur : le signe s'inverse

calcul
racines −5 et 1  →  (x + 5)(x − 1)
                        ↑ le signe s'INVERSE

x² + 4x − 5 = (x + 5)(x − 1)
Contrôle : x² − x + 5x − 5 = x² + 4x − 5 ✔

Et ne jamais oublier le a devant : invisible quand a = 1, fatal quand a = 2.

⚡ L'ordre, pas le nom

Selon les manuels, x₁ désigne la racine avec −√Δ ou avec +√Δ. Peu importe.

Dans le tableau de signe, les racines vont dans l'ordre croissant sur l'axe. On calcule les deux valeurs, on les compare, on met la plus petite à gauche. Un tableau où 3 précède 2 est faux.

⚡ Crochets ouverts ou fermés ?

f(x) < 0 stricte]2 ; 3[ ouverts
f(x) ⩽ 0 large[2 ; 3] fermés
borne infinietoujours ouverte

Une inégalité large inclut les racines, puisqu'elles annulent la fonction.

⚡ Du signe de f' aux variations de f

f'(x) > 0  ⟹  f croissante  ·  f'(x) < 0  ⟹  f décroissante  ·  f'(x) = 0  ⟹  extremum
méthode
  x     │ −∞        racine de f'        +∞
  ──────┼─────────────────────────────────
  f'(x) │     −          0         +
  ──────┼─────────────────────────────────
  f(x)  │     ╲      valeur de f    ╱
                      └── extremum

« − » sur f'  →  flèche qui DESCEND
« + » sur f'  →  flèche qui MONTE
« 0 » isolé   →  extremum, dont on CALCULE la valeur

Les racines de f' sont les abscisses des extremums de f. Analogie : f = l'altitude, f' = la pente sous les roues.

⚡ Local ≠ sur l'intervalle

calcul
f(x) = x³ − x² − x + 7 sur [−5 ; 5]

max LOCAL     ≈ 7,19  en x = −1/3
max SUR I     =  102  en x =  5    ← au BORD

Sur un intervalle fermé, comparer aussi les valeurs aux bornes. Le plus haut des environs n'est pas le plus haut de tous.

⚡ Quotient : la valeur interdite

calcul
f(x) = (x+4)/(x−12)   sur [−10 ; 10]

x − 12 = 0 → x = 12,  MAIS 12 ∉ [−10 ; 10]
→ aucune double barre, f définie sur tout I

     numérateur < 0, dénominateur = carré > 0
→ f' < 0 partout : f STRICTEMENT DÉCROISSANTE

Toujours comparer la valeur interdite aux bornes avant de dessiner le tableau.

⚡ Les six erreurs qui coûtent des points

  1. Confondre signe de f et signe de f' — deux tableaux, deux questions, deux jeux d'abscisses.
  2. Perdre un signe dans Δ — b garde le sien, et un c négatif fait grandir Δ.
  3. Oublier le a dans la factorisation a(x − x₁)(x − x₂).
  4. Ne pas retourner l'inégalité en divisant par un négatif.
  5. Un tableau sans valeurs — il faut les bornes de I et la valeur de chaque extremum, pas seulement des flèches.
  6. Mettre une racine de f' hors de I dans le tableau, ou oublier de commencer et finir aux bornes de I.
