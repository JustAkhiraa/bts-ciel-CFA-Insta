Fonctions et variations

Deux tableaux, et tout est dit d'une fonction : celui du signe — où est-elle positive ? — et celui des variations — où monte-t-elle, où atteint-elle son maximum ?

📌

Résumé flash

Une fonction affine f(x) = ax + b a le signe de a après sa racine, le signe contraire avant. Un trinôme ax² + bx + c se lit par son discriminant Δ = b² − 4ac : deux racines si Δ > 0, une si Δ = 0, aucune si Δ < 0 — et son signe est celui de a partout, sauf entre les racines. Enfin, le signe de la dérivée donne les variations : f' > 0 ⟹ f monte, f' < 0 ⟹ f descend.

01Le vocabulaire

Une fonction est une machine : on lui donne un nombre, elle en rend un autre. Les deux mots qui désignent l'entrée et la sortie sont constamment confondus, alors qu'ils désignent des choses opposées.

⚠️ Image ou antécédent ?

L'image est du côté du résultat : f(x). L' antécédent est ce qui vient avant — c'est dans le mot : anté, comme antérieur. C'est le x.

Les deux questions n'ont pas la même difficulté :

QuestionOn chercheCe qu'on fait
« image de 3 ? »f(3) on remplace : 2 × 3 − 1 = 5
« antécédent de 5 ? »x tel que f(x) = 5 on résout : 2x − 1 = 5 ⟹ x = 3

Une image se calcule, un antécédent se résout. Et une image est toujours unique, alors qu'un nombre peut avoir plusieurs antécédents — un trinôme en a souvent deux.

🔧 Corrigé — orthogonal ≠ orthonormal

Le cahier note deux définitions, toutes deux introduites par le mot « orthonormal » :

cahier
Orthonormal = même unité en abscisse et ordonnée
Orthonormal = différente unité                    ← le second est « orthogonal »

Les deux mots désignent des repères différents :

RepèreAxesUnités
orthogonalperpendiculaires peuvent être différentes sur les deux axes
orthonormal (ou orthonormé)perpendiculaires identiques sur les deux axes

Dans le mot orthonormal, ortho dit l'angle droit et normé dit l'unité commune. Tout repère orthonormal est orthogonal ; l'inverse est faux. L'énoncé du cahier — « un repère orthonormal d'unité 2 cm » — est bien cohérent : une seule unité annoncée, donc la même sur les deux axes.

02Les fonctions affines

🧰 Forme et paramètres
f(x) = ax + b
  • a est le coefficient directeur — la pente. Il dit de combien f monte quand x avance de 1.
  • b est l'ordonnée à l'origine — la valeur en 0, puisque f(0) = b. C'est là que la droite coupe l'axe vertical.

La courbe est toujours une droite. Deux points suffisent donc à la tracer.

Signe de aAllureVariation
a > 0la droite monte f est croissante
a < 0la droite descend f est décroissante
a = 0droite horizontale f est constante — parallèle à l'axe des abscisses
🔗 La rampe d'accès

b, c'est la hauteur du départ ; a, c'est l'inclinaison. Changer b déplace la rampe vers le haut ou le bas sans la pencher davantage ; changer a la redresse ou l'aplatit sans bouger son point de départ. Une rampe de pente nulle, c'est un palier.

🤔 Tracer f(x) = 2x − 1 et calculer trois images
calcul
f(1)  = 2 × 1  − 1 =  1
f(3)  = 2 × 3  − 1 =  5
f(−2) = 2 × (−2) − 1 = −5

  x    │  1  │  3  │ −2
  f(x) │  1  │  5  │ −5

a = 2 > 0  → la droite monte, f est croissante
b = −1     → elle coupe l'axe vertical en −1

Contrôle : entre x = 1 et x = 3, x avance de 2 et f passe de 1 à 5, soit +4. Or 4 / 2 = 2 = a ✔ Le coefficient directeur se relit toujours comme un rapport « montée ÷ avancée » entre deux points.

03Signe d'une fonction affine

« Étudier le signe de f », c'est répondre à : pour quels x la courbe est-elle au-dessus de l'axe des abscisses ? La méthode tient en deux temps, et elle vaut pour toutes les fonctions du chapitre.

📐 La méthode en deux temps
  1. Trouver la racine — résoudre f(x) = 0. C'est le seul point où la courbe traverse l'axe.
  2. Déterminer le signe de part et d'autre — par le signe de a, ou en résolvant l'inéquation f(x) > 0.
calcul
Soit f(x) = 2x − 1.

① La racine :
     2x − 1 = 0
     2x     = 1
      x     = 1/2 = 0,5

② Le signe :
     f(x) > 0  ⟺  2x − 1 > 0
               ⟺  2x     > 1
               ⟺   x     > 0,5

  x    │ −∞        0,5        +∞
  ─────┼───────────────────────────
  f(x) │     −      0      +

Donc  f(x) < 0 sur ]−∞ ; 0,5[
      f(x) = 0 en x = 0,5
      f(x) > 0 sur ]0,5 ; +∞[

Vérification :  f(0,5) = 2 × 0,5 − 1 = 1 − 1 = 0  ✔
🧰 La règle générale, sans calcul
une affine a le signe de a après sa racine,
le signe contraire avant

Autrement dit : quand a > 0, la droite monte, donc elle est négative puis positive. Quand a < 0, elle descend, donc positive puis négative. On n'a jamais besoin de résoudre l'inéquation — il suffit de placer la racine et de regarder le signe de a.

⚠️ Le sens de l'inégalité change quand on divise par un négatif
calcul
−3x + 6 > 0
    −3x > −6
      x < 2          ← le signe s'est RETOURNÉ

Contrôle avec x = 0 :  −3 × 0 + 6 = 6 > 0  ✔  et 0 < 2  ✔
Contrôle avec x = 5 :  −3 × 5 + 6 = −9 < 0  ✔  et 5 > 2  ✔

Diviser (ou multiplier) les deux membres par un nombre négatif inverse le sens de l'inégalité. Le contrôle par une valeur-test, comme ci-dessus, coûte cinq secondes et attrape l'erreur à coup sûr.

🤔 Que dit exactement la ligne « f(x) : − 0 + » ?

Trois informations, et elles se traduisent en trois phrases de rédaction :

  • « − » à gauche : la droite est en dessous de l'axe des abscisses, donc f(x) < 0 sur ]−∞ ; 0,5[.
  • « 0 » au milieu : elle croise l'axe, f(0,5) = 0.
  • « + » à droite : elle est au-dessus, f(x) > 0 sur ]0,5 ; +∞[.

Sur une copie, le tableau seul ne suffit pas : il faut écrire les trois phrases, avec les intervalles. C'est la traduction qui est notée, pas le dessin.

04Les polynômes

Une fonction affine n'est qu'un cas particulier. La famille complète s'écrit avec des puissances de x, et le degré est la plus grande d'entre elles.

DegréForme généraleExempleCourbe
1 P(x) = a₁x¹ + a₀x⁰ 2x − 1une droite
2 P(x) = a₂x² + a₁x¹ + a₀x⁰ x² − 5x + 6une parabole
3 P(x) = a₃x³ + a₂x² + a₁x¹ + a₀x⁰ x³ − x² − x + 7une courbe en S
💡 Pourquoi écrire a₀x⁰ plutôt que a₀ ?

Parce que x⁰ = 1 toujours (quel que soit x non nul) : a₀x⁰ = a₀ × 1 = a₀. L'écriture avec les exposants explicites n'est pas une coquetterie — elle rend la régularité visible : chaque terme est un coefficient multiplié par une puissance de x, et les exposants descendent de n jusqu'à 0, sans en sauter un seul.

C'est cette régularité qui rend la dérivation mécanique au chapitre suivant : chaque aₖxᵏ devient k·aₖxᵏ⁻¹, terme par terme.

⚠️ Les coefficients peuvent être négatifs — et nuls

Dans x³ − x² − x + 7, on lit a₃ = 1, a₂ = −1, a₁ = −1, a₀ = 7 : le signe fait partie du coefficient. C'est la première source d'erreur au calcul du discriminant, où un b = −5 mal recopié en 5 donne pourtant le même Δ — mais des racines fausses.

Et un coefficient nul fait disparaître son terme : x² − 9 est bien un trinôme, avec b = 0.

05Le second degré

C'est le cœur du chapitre, et de loin ce qui tombe le plus en devoir.

🧰 Le discriminant
f(x) = ax² + bx + c   avec   a ≠ 0
Δ = b² − 4ac   (« delta »)

Sa valeur — et son seul signe, en réalité — décide de tout :

ΔRacinesFormulesLa courbe…
Δ > 0deux racines distinctes x₁ = (−b − √Δ) / 2a
x₂ = (−b + √Δ) / 2a		 traverse l'axe deux fois
Δ = 0une racine double x₀ = −b / 2a touche l'axe sans le traverser
Δ < 0aucune racine réelle — ne touche jamais l'axe
⚠️ Le carré de b se calcule sur b avec son signe
calcul
Pour x² − 5x + 6 :   a = 1,  b = −5,  c = 6

Δ = b² − 4ac = (−5)² − 4 × 1 × 6
             =  25   − 24
             =   1

Écrire « 5² » au lieu de « (−5)² » donne ici le même résultat, mais
c'est une habitude dangereuse : le b garde son signe dans −b/2a,
et c'est là qu'elle se paie.

Autre piège, plus coûteux : dans −4ac, si c est négatif, le produit devient positif. Pour 3x² − 2x − 1 : Δ = (−2)² − 4 × 3 × (−1) = 4 + 12 = 16. Un signe oublié ici, et Δ devient négatif : on conclut « pas de racine » alors qu'il y en a deux.

🤔 Les trois cas, sur trois exemples du cours
calcul — Δ > 0
P₄(x) = x² − 5x + 6        a = 1, b = −5, c = 6

Δ = (−5)² − 4 × 1 × 6 = 25 − 24 = 1        Δ > 0 → deux racines

x₁ = (−(−5) − √1) / (2 × 1) = (5 − 1)/2 = 2
x₂ = (−(−5) + √1) / (2 × 1) = (5 + 1)/2 = 3

Contrôle : 2² − 5×2 + 6 = 4 − 10 + 6 = 0  ✔
           3² − 5×3 + 6 = 9 − 15 + 6 = 0  ✔
calcul — Δ = 0
P₅(x) = x² − 4x + 4        a = 1, b = −4, c = 4

Δ = (−4)² − 4 × 1 × 4 = 16 − 16 = 0        Δ = 0 → une racine double

x₀ = −(−4) / (2 × 1) = 4/2 = 2

Contrôle : 2² − 4×2 + 4 = 4 − 8 + 4 = 0  ✔
Et en effet  x² − 4x + 4 = (x − 2)²  — un carré parfait.
calcul — Δ < 0
P₆(x) = 2x² − 4x + 3       a = 2, b = −4, c = 3

Δ = (−4)² − 4 × 2 × 3 = 16 − 24 = −8       Δ < 0 → aucune racine

La parabole ne coupe jamais l'axe des abscisses.
Comme a = 2 > 0, elle est entièrement AU-DESSUS : P₆(x) > 0 partout.

Contrôle : P₆(1) = 2 − 4 + 3 = 1 > 0  ✔  (et 1 est le minimum)

Un Δ négatif ne signale pas une erreur de calcul : c'est un résultat, et il répond même complètement à la question du signe. Beaucoup d'élèves refont trois fois le calcul en croyant s'être trompés.

🔧 Corrigé — deux coquilles du cahier

① Le cahier écrit le trinôme P₄(x) = x² − 5 + 6 : il manque le x du terme en −5x. Tel quel, x² − 5 + 6 vaut x² + 1, qui n'a aucune racine — alors que la suite du calcul utilise correctement b = −5 et trouve 2 et 3. Il faut lire x² − 5x + 6. La même coquille revient page 9 sur 1x² + 4 − 5, à lire x² + 4x − 5.

② Les deux schémas de parabole de la page 8 sont tous deux intitulés « Si Δ > 0 ». Le second — la parabole qui ne touche jamais l'axe, avec « signe de a » sur tout l'intervalle — est le cas Δ < 0. Le cas Δ > 0 est celui de la page précédente, avec deux zéros dans le tableau.

06Signe d'un trinôme

Une seule phrase à retenir, et elle couvre les trois cas.

🧰 La règle du signe
un trinôme est du signe de a partout,
sauf entre les racines où il est du signe contraire

S'il n'y a pas deux racines, il n'y a pas d'« entre » : le trinôme garde alors le signe de a sur tout ℝ. C'est pour cela que la phrase suffit aux trois cas.

CasTableau de signeLecture
Δ > 0 x │ −∞ ⋯ x₁ ⋯ x₂ ⋯ +∞
P │ signe a │0│ −a │0│ signe a		 signe de a · 0 · signe contraire · 0 · signe de a
Δ = 0 x │ −∞ ⋯ x₀ ⋯ +∞
P │ signe a │0│ signe a		 signe de a partout, avec un zéro isolé
Δ < 0 x │ −∞ ⋯⋯⋯ +∞
P │ signe de a		 signe de a partout, sans jamais s'annuler
⚠️ L'ordre des racines dans le tableau, pas leur nom

Selon les manuels, x₁ désigne la racine avec −√Δ ou celle avec +√Δ — les deux conventions circulent, et le tableau de référence du cours n'utilise pas la même que le cahier. Peu importe.

Ce qui compte, c'est que le tableau de signe range les racines dans l'ordre croissant sur l'axe. Après avoir calculé les deux valeurs, on les compare et on met la plus petite à gauche — quel que soit le nom qu'on lui a donné. Un tableau où 3 précède 2 est faux, même si les deux racines sont justes.

07Factoriser un trinôme

Une fois les racines connues, le trinôme se réécrit en produit. C'est souvent ce qui est demandé après le calcul du discriminant.

🧰 Les trois factorisations
CasFactorisation de ax² + bx + c
Δ > 0 a(x − x₁)(x − x₂)
Δ = 0 a(x − x₀)²
Δ < 0 pas de factorisation possible (dans ℝ)

Ne pas oublier le « a » devant : c'est l'erreur la plus fréquente, et elle est invisible quand a = 1 — donc on la prend justement sur les exemples où a = 1, et on la paie le jour où a = 2.

calcul
x² − 5x + 6   racines 2 et 3, a = 1
            = 1 × (x − 2)(x − 3)
            = (x − 2)(x − 3)

Contrôle par développement :
  (x − 2)(x − 3) = x² − 3x − 2x + 6 = x² − 5x + 6   ✔

x² − 4x + 4   racine double 2, a = 1
            = (x − 2)²

Contrôle : (x − 2)² = x² − 4x + 4   ✔

2x² − 4x + 3  Δ = −8 < 0
            → aucune factorisation dans ℝ
💡 Pourquoi la factorisation redonne le signe

Écrit a(x − x₁)(x − x₂), le signe se lit sans aucune règle à retenir. Prenons (x − 2)(x − 3) :

xx − 2x − 3 produit
x < 2−−+
2 < x < 3+−−
x > 3+++

On retrouve « + 0 − 0 + », c'est-à-dire le signe de a hors des racines et le signe contraire entre elles. La règle du § 6 n'est donc pas une formule à apprendre : c'est une conséquence de la règle des signes d'un produit.

08Le tableau de variations

Jusqu'ici on cherchait où f est positive. On cherche maintenant où f monte. Ce sont deux questions différentes, et c'est la dérivée qui répond à la seconde.

🧰 Le théorème central

Soit f définie et dérivable sur un intervalle I. On note f' sa fonction dérivée. Alors, sur I :

f'(x) > 0  ⟹  f est strictement croissante
f'(x) < 0  ⟹  f est strictement décroissante
f'(x) = 0  ⟹  f est constante

Le calcul de f' lui-même fait l'objet du chapitre 04. Ici, on l'utilise comme outil — voici les seules formules dont ce chapitre a besoin :

f(x)f'(x)
k (une constante)0
x1
x²2x
xⁿn·xⁿ⁻¹
k·uk·u'
u + vu' + v'

En pratique : on dérive terme par terme, chaque aₓⁿ devenant a·n·xⁿ⁻¹, et la constante disparaissant.

🔗 La route et la pente

f est l'altitude, f' est la pente sous les roues. Pente positive, ça monte ; pente négative, ça descend ; pente nulle, on est exactement au sommet d'une côte ou au fond d'un vallon — un extremum.

D'où la conséquence pratique : les racines de f' sont les abscisses des extremums de f. Le tableau de signe de f' se transforme donc directement en tableau de variations de f.

📐 De f' à f : les flèches

Le tableau de variations empile trois lignes. Les deux premières viennent du signe de f' ; la troisième s'en déduit mécaniquement.

méthode
  x     │ −∞          racine de f'          +∞
  ──────┼──────────────────────────────────────────
  f'(x) │      −            0            +
  ──────┼──────────────────────────────────────────
  f(x)  │  ╲ (descend)      ●      ╱ (monte)
                            └── extremum : on y calcule f

Un « − » sur la ligne f' → une flèche qui DESCEND sur la ligne f.
Un « + » sur la ligne f' → une flèche qui MONTE.
Un « 0 » isolé entre les deux → un extremum, dont on calcule la valeur.
🤔 Exemple 1 — f(x) = −2x + 1 (premier degré)
calcul
① Dérivée :   f'(x) = −2

② Signe :     −2 < 0, donc f'(x) < 0 sur tout ℝ
              (une constante ne change jamais de signe)

③ Tableau :
  x     │ −∞                          +∞
  ──────┼─────────────────────────────────
  f'(x) │              −
  ──────┼─────────────────────────────────
  f(x)  │ +∞  ╲────────────────────╲  −∞

f est strictement décroissante sur ℝ.

Pas de racine, donc pas de colonne intermédiaire, donc pas d'extremum : une droite n'a ni maximum ni minimum. On retrouve la règle du § 2 — a = −2 < 0 donc f décroissante — par un autre chemin. Les deux méthodes doivent toujours concorder ✔

🤔 Exemple 2 — f(x) = x² + 4x − 5 (second degré)
calcul
① Dérivée :   f'(x) = 2x + 4

② Signe de f' :   2x + 4 > 0
                      2x > −4
                       x > −4/2 = −2

  x     │ −∞          −2          +∞
  ──────┼─────────────────────────────
  f'(x) │      −       0      +

③ L'extremum :  f(−2) = (−2)² + 4 × (−2) − 5
                      = 4 − 8 − 5
                      = −9

④ Tableau de variations :
  x     │ −∞          −2          +∞
  ──────┼─────────────────────────────
  f'(x) │      −       0      +
  ──────┼─────────────────────────────
  f(x)  │ +∞  ╲       −9      ╱  +∞
                       └── MINIMUM de f

Trois contrôles : a = 1 > 0, donc la parabole ouvre vers le haut et doit avoir un minimum — c'est bien ce qu'on trouve ✔ ; le sommet d'une parabole est en −b/2a = −4/2 = −2, ce qui concorde avec la racine de f' ✔ ; et f(0) = −5, qui est bien supérieur à −9, donc −9 est plausible comme minimum ✔

💡 Signe et variations sur la même fonction

Attention à ne pas confondre les deux études. Pour ce même f(x) = x² + 4x − 5 :

  • Signe : Δ = 16 + 20 = 36, racines −5 et 1. f est positive hors de [−5 ; 1], négative entre.
  • Variations : f' s'annule en −2. f décroît avant, croît après.

Les abscisses n'ont rien à voir : −5 et 1 pour le signe, −2 pour la variation. Et −2 est bien au milieu de [−5 ; 1] : le sommet d'une parabole est toujours à égale distance de ses deux racines.

🤔 Exemple 3 — f(x) = x³ − x² − x + 7 sur [−5 ; 5] (troisième degré)
calcul
① Dérivée :   f'(x) = 3x² − 2x − 1

② Signe de f' — c'est un trinôme, donc discriminant :
   a = 3, b = −2, c = −1
   Δ = (−2)² − 4 × 3 × (−1) = 4 + 12 = 16     Δ > 0 → deux racines

   x₁ = (2 − √16) / (2 × 3) = (2 − 4)/6 = −2/6 = −1/3
   x₂ = (2 + √16) / (2 × 3) = (2 + 4)/6 =  6/6 =  1

   a = 3 > 0 → f' est du signe de a hors des racines :
  x     │ −5        −1/3         1          5
  ──────┼──────────────────────────────────────
  f'(x) │    +       0     −     0     +

③ Tableau de variations :
  x     │ −5        −1/3         1          5
  ──────┼──────────────────────────────────────
  f'(x) │    +       0     −     0     +
  ──────┼──────────────────────────────────────
  f(x)  │ −138 ╱   7,19   ╲      6     ╱   102
                  max            min
                 local          local

④ Les valeurs aux bornes et aux extremums :
   f(−5)   = −125 − 25 + 5 + 7 = −138
   f(−1/3) = −1/27 − 1/9 + 1/3 + 7 = 194/27 ≈ 7,19
   f(1)    = 1 − 1 − 1 + 7 = 6
   f(5)    = 125 − 25 − 5 + 7 = 102

Contrôles : le maximum local vaut 7,19 mais le maximum sur l'intervalle est 102, atteint au bord — c'est la différence entre extremum local et global, et elle se voit sur le tableau ✔ Une table de valeurs confirme le sens des flèches : f(−3) = −26, f(−2) = −3, f(−1) = 6 — ça monte ✔ puis f(0) = 7, f(1) = 6 — ça descend ✔ puis f(3) = 22, f(4) = 51 — ça remonte ✔

⚠️ Dériver un cube donne un trinôme

C'est le mécanisme du chapitre : pour étudier une fonction de degré 3, on dérive et on retombe sur un degré 2 — donc sur le discriminant du § 5. Rien de nouveau n'est nécessaire : tout le chapitre se boucle sur lui-même.

09La méthode complète

📐 Étudier une fonction, pas à pas
  1. Identifier le degré et l'intervalle d'étude. L'énoncé donne presque toujours un I fermé, du type [−10 ; 10].
  2. Dériver terme par terme.
  3. Étudier le signe de f' — affine si f est du second degré (§ 3), trinôme si f est du troisième (§ 5-6).
  4. Dresser le tableau : ligne x avec les bornes de I et les racines de f' · ligne f' avec les signes · ligne f avec les flèches.
  5. Calculer les valeurs aux bornes de I et à chaque extremum. Un tableau sans valeurs est incomplet.
  6. Conclure par une phrase : « f est croissante sur […], décroissante sur […], et atteint son minimum en x = … où elle vaut … ».
⚠️ Les quatre oublis classiques
  1. Les bornes de l'intervalle — si l'énoncé dit [−10 ; 10], le tableau commence à −10 et finit à 10, pas à ±∞.
  2. Les valeurs aux extremums — le tableau doit porter des nombres, pas seulement des flèches.
  3. Une racine de f' hors de I — elle ne figure pas dans le tableau. Si f' s'annule en 12 et que I = [−10 ; 10], la colonne n'existe pas : f est monotone sur tout I.
  4. Confondre « signe de f » et « signe de f' » — ce sont deux tableaux différents pour deux questions différentes.
💡 À quoi ça sert, concrètement

En BTS CIEL, ces tableaux répondent à des questions d'optimisation : pour quelle charge le temps de réponse d'un serveur est-il minimal ? à quel instant la température d'un composant atteint-elle son maximum ? pour quelle taille de lot le coût unitaire est-il le plus bas ?

Dans les trois cas, la démarche est identique : modéliser par une fonction, dériver, chercher où la dérivée s'annule. Le minimum d'un coût est une racine de sa dérivée — c'est tout ce que dit le chapitre, et c'est ce qui le rend utile.

10À l'examen

🧰 Le sujet type — DST « Partie B : Fonctions »

L'énoncé récupéré du devoir surveillé est révélateur du format attendu :

énoncé
Établir le tableau de variations des fonctions suivantes sur
l'intervalle [−10 ; 10]. Détailler toutes les étapes nécessaires.

  1.  f(x) = −2x² + 4x − 9
  2.  f(x) = x³ − 3x² − 9x + 5
  3.  f(x) = (x + 4) / (x − 12)

Trois degrés de difficulté croissante : un trinôme (dérivée affine), un cube (dérivée trinôme, donc discriminant), et un quotient — qui exige la formule (u/v)' du chapitre 04. Les trois sont corrigés dans les exercices.

La consigne « détailler toutes les étapes » n'est pas décorative : le barème répartit les points sur la dérivée, le signe, le tableau et les valeurs. Un tableau juste sans calcul de f' rapporte peu.

⚠️ La valeur interdite d'un quotient

Pour f(x) = (x + 4)/(x − 12), le dénominateur s'annule en x = 12 : la fonction n'y est pas définie. Mais l'énoncé demande l'étude sur [−10 ; 10], et 12 ∉ [−10 ; 10].

La valeur interdite est donc hors de l'intervalle : aucune double barre dans le tableau, f est définie et continue sur tout I. C'est un piège de lecture, pas de calcul — et il se désamorce en comparant la valeur interdite aux bornes avant de dresser quoi que ce soit.

📐 Le réflexe de sortie
  • Mes racines annulent-elles vraiment la fonction ? Une substitution suffit à le vérifier.
  • Ma factorisation redonne-t-elle le trinôme de départ, une fois développée ?
  • Mon tableau commence et finit-il bien aux bornes de I ?
  • Ai-je calculé les valeurs aux extremums et aux bornes ?
  • Le sens des flèches est-il cohérent avec une ou deux valeurs testées ?

⚡ Récap 2 minutes

  • Image = f(x), on la calcule. Antécédent = x, on le résout. Une image est unique, un antécédent peut être multiple.
  • Repère orthogonal : axes perpendiculaires. Orthonormal : en plus, même unité sur les deux axes.
  • Affine f(x) = ax + b : a = coefficient directeur (la pente), b = ordonnée à l'origine (f(0) = b). a > 0 croît · a < 0 décroît · a = 0 constante.
  • Signe d'une affine : signe de a après la racine, signe contraire avant.
  • Diviser par un négatif retourne l'inégalité. Contrôler avec une valeur-test.
  • Discriminant : Δ = b² − 4ac, avec les signes. Δ > 0 → 2 racines (−b ∓ √Δ)/2a · Δ = 0 → 1 racine −b/2a · Δ < 0 → aucune.
  • Signe d'un trinôme : signe de a partout, sauf entre les racines.
  • Factorisation : a(x − x₁)(x − x₂) · a(x − x₀)² · impossible si Δ < 0. Ne pas oublier le a.
  • Dans un tableau de signe, les racines vont dans l'ordre croissant — leur nom (x₁ ou x₂) n'a aucune importance.
  • Variations : f' > 0 → f monte · f' < 0 → f descend · f' = 0 → extremum.
  • Les racines de f' sont les abscisses des extremums de f.
  • Dériver un degré 3 donne un degré 2 : on repasse par le discriminant. Le chapitre boucle sur lui-même.
  • Toujours : les bornes de I dans le tableau, les valeurs aux extremums, et une phrase de conclusion.
