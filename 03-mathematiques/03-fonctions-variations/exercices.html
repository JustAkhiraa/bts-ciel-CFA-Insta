Fonctions et variations — exercices

Du calcul d'une image jusqu'au sujet de DST complet. Chaque corrigé se termine par un contrôle indépendant du calcul.

🎯

Le réflexe d'attaque

Avant de calculer quoi que ce soit, se demander quelle question est posée : « signe » ou « variations » ? Le signe vient des racines de f ; les variations viennent des racines de f'. Ce sont deux tableaux différents, avec des abscisses différentes. Les confondre coûte tous les points de la question.

01Lire une fonction

1Images, antécédents et tracé Facile

Soit f(x) = 2x − 1.

  1. Calculer f(1), f(3) et f(−2).
  2. Déterminer l'antécédent de 5, puis celui de 0.
  3. Donner le coefficient directeur et l'ordonnée à l'origine, et en déduire le sens de variation.
  4. Tracer la courbe dans un repère orthonormal d'unité 2 cm.
✅ Correction

1. Une image se calcule : on remplace x par la valeur.

calcul — 1
f(1)  = 2 × 1    − 1 =  2 − 1 =  1
f(3)  = 2 × 3    − 1 =  6 − 1 =  5
f(−2) = 2 × (−2) − 1 = −4 − 1 = −5

  x    │  1  │  3  │ −2
  f(x) │  1  │  5  │ −5

2. Un antécédent se résout : on pose l'équation.

calcul — 2
Antécédent de 5 :        Antécédent de 0 :
   f(x) = 5                 f(x) = 0
  2x − 1 = 5               2x − 1 = 0
      2x = 6                   2x = 1
       x = 3                    x = 1/2 = 0,5

L'antécédent de 5 est 3.   L'antécédent de 0 est 0,5.
                           (c'est la racine de f)

3. On lit les coefficients directement dans l'écriture.

calcul — 3
f(x) = 2x − 1   est de la forme  ax + b

  a = 2   → coefficient directeur (la pente)
  b = −1  → ordonnée à l'origine, car f(0) = −1

a = 2 > 0  →  f est CROISSANTE sur ℝ.

4. Deux points suffisent pour une droite ; on en place trois pour se contrôler.

méthode — 4
Repère orthonormal d'unité 2 cm : 1 unité = 2 cm sur les DEUX axes.

Placer (1 ; 1), (3 ; 5) et (−2 ; −5), puis tracer la droite.
Elle coupe l'axe vertical en −1 (= b) et l'axe horizontal en 0,5.

Contrôle de la pente : entre x = 1 et x = 3, x avance de 2 et f monte de 1 à 5, soit +4. Le rapport 4 / 2 = 2 redonne bien a ✔ Et les trois points doivent être alignés : si l'un sort de la droite, c'est une image mal calculée.

02Signe d'une affine

2Étudier le signe de f(x) = 2x − 1 Facile

Étudier le signe de f(x) = 2x − 1 sur ℝ, et interpréter graphiquement : quand la droite D est-elle au-dessus de l'axe des abscisses ?

✅ Correction
calcul
① La racine — on résout f(x) = 0 :
     2x − 1 = 0
     2x     = 1
      x     = 1/2 = 0,5

  Vérification :  f(0,5) = 2 × 0,5 − 1 = 1 − 1 = 0  ✔

② Le signe — on résout f(x) > 0 :
     2x − 1 > 0
     2x     > 1
      x     > 0,5

③ Tableau de signe :

  x    │ −∞           0,5           +∞
  ─────┼──────────────────────────────
  f(x) │      −        0        +
rédaction
La droite D se situe EN DESSOUS de l'axe des abscisses
lorsque x < 0,5 :        f(x) < 0 sur ]−∞ ; 0,5[

D se situe AU-DESSUS de l'axe des abscisses
lorsque x > 0,5 :        f(x) > 0 sur ]0,5 ; +∞[

D CROISE l'axe des abscisses lorsque x = 0,5 :   f(0,5) = 0

Contrôle par deux valeurs-test : f(0) = −1 < 0 et 0 est bien à gauche de 0,5 ✔ ; f(1) = 1 > 0 et 1 est bien à droite ✔ Ces deux substitutions valident tout le tableau en dix secondes.

🧰 La lecture immédiate, sans résoudre l'inéquation

a = 2 > 0 : la droite monte, donc elle est négative avant sa racine et positive après. On peut remplir le tableau sans écrire une seule ligne de calcul — mais en devoir, il faut quand même montrer la résolution, c'est elle qui est notée.

3Trois affines, dont une piégée Facile

Étudier le signe de chacune de ces fonctions sur ℝ.

  1. g(x) = 3x + 12
  2. h(x) = −3x + 6
  3. k(x) = −5
✅ Correction
calcul — 1
g(x) = 3x + 12      a = 3 > 0

Racine :  3x + 12 = 0  →  3x = −12  →  x = −4

  x    │ −∞           −4           +∞
  ─────┼──────────────────────────────
  g(x) │      −        0        +

g(x) < 0 sur ]−∞ ; −4[  ·  g(x) > 0 sur ]−4 ; +∞[
Contrôle : g(0) = 12 > 0, et 0 > −4  ✔
calcul — 2
h(x) = −3x + 6      a = −3 < 0

Racine :  −3x + 6 = 0  →  −3x = −6  →  x = 2

Inéquation :  −3x + 6 > 0
                  −3x > −6
                    x < 2       ← le signe SE RETOURNE

  x    │ −∞            2            +∞
  ─────┼──────────────────────────────
  h(x) │      +        0        −

Contrôle : h(0) = 6 > 0, et 0 < 2  ✔
           h(5) = −9 < 0, et 5 > 2  ✔
calcul — 3
k(x) = −5           a = 0, b = −5 : fonction CONSTANTE

Racine :  −5 = 0  →  aucune solution.
La droite est horizontale, à l'altitude −5 : elle ne croise
jamais l'axe des abscisses.

  x    │ −∞                         +∞
  ─────┼──────────────────────────────
  k(x) │              −

k(x) < 0 sur ℝ tout entier.

Le troisième cas est celui qu'on rate : on cherche une racine qui n'existe pas, et on bloque. Une fonction constante non nulle garde son signe partout — il n'y a rien à résoudre, il suffit de lire la valeur. C'est exactement ce qui se produira au § 5 avec la dérivée d'une affine.

03Discriminant et racines

4Les trois cas du cours Moyen

Pour chaque trinôme : calculer Δ, en déduire le nombre de racines, les calculer le cas échéant, puis factoriser si c'est possible.

  1. P₄(x) = x² − 5x + 6
  2. P₅(x) = x² − 4x + 4
  3. P₆(x) = 2x² − 4x + 3
✅ Correction
calcul — P₄
P₄(x) = x² − 5x + 6        a = 1,  b = −5,  c = 6

Δ = b² − 4ac
  = (−5)² − 4 × 1 × 6
  =  25   − 24
  =   1                    Δ > 0  →  DEUX racines

x₁ = (−b − √Δ) / 2a = (5 − √1) / 2 = (5 − 1)/2 = 4/2 = 2
x₂ = (−b + √Δ) / 2a = (5 + √1) / 2 = (5 + 1)/2 = 6/2 = 3

Factorisation :  P₄(x) = 1 × (x − 2)(x − 3) = (x − 2)(x − 3)

Deux contrôles indépendants : P₄(2) = 4 − 10 + 6 = 0 ✔ et P₄(3) = 9 − 15 + 6 = 0 ✔ ; puis le développement (x−2)(x−3) = x² − 3x − 2x + 6 = x² − 5x + 6 ✔ Le second contrôle vérifie aussi le coefficient a, que le premier ne voit pas.

calcul — P₅
P₅(x) = x² − 4x + 4        a = 1,  b = −4,  c = 4

Δ = (−4)² − 4 × 1 × 4
  =  16   − 16
  =   0                    Δ = 0  →  UNE racine double

x₀ = −b / 2a = 4 / 2 = 2

Factorisation :  P₅(x) = 1 × (x − 2)² = (x − 2)²

Contrôle : P₅(2) = 4 − 8 + 4 = 0 ✔ et (x − 2)² = x² − 4x + 4 ✔ Un Δ nul signale toujours un carré parfait — ici x² − 4x + 4, dont on aurait pu reconnaître l'identité remarquable directement.

calcul — P₆
P₆(x) = 2x² − 4x + 3       a = 2,  b = −4,  c = 3

Δ = (−4)² − 4 × 2 × 3
  =  16   − 24
  =  −8                    Δ < 0  →  AUCUNE racine réelle

Factorisation : impossible dans ℝ.

Le trinôme ne s'annule jamais : il garde donc le signe de a
sur tout ℝ. Comme a = 2 > 0, on a P₆(x) > 0 pour tout x.

Contrôle : le minimum d'une parabole est en −b/2a = 4/4 = 1, et P₆(1) = 2 − 4 + 3 = 1. Le point le plus bas de la courbe est à l'altitude 1, donc strictement au-dessus de zéro ✔ Cela confirme qu'elle ne croise jamais l'axe.

🔧 Corrigé — le x manquant du cahier

Le cahier note ce trinôme P₄(x) = x² − 5 + 6, sans le x du terme central. Écrit ainsi, il vaudrait x² + 1, dont le discriminant serait 0 − 4 = −4 < 0 : aucune racine. La suite du calcul utilise pourtant b = −5 et aboutit à 2 et 3, ce qui confirme qu'il s'agit d'une coquille de recopie. À lire x² − 5x + 6.

5Attention aux signes Moyen

Calculer le discriminant et les racines de :

  1. f(x) = 3x² − 2x − 1
  2. g(x) = x² + 4x − 5
  3. h(x) = −2x² + 4x − 9
✅ Correction
calcul — 1
f(x) = 3x² − 2x − 1        a = 3,  b = −2,  c = −1

Δ = (−2)² − 4 × 3 × (−1)
  =   4   + 12              ← DEUX signes moins → un PLUS
  =  16                     Δ > 0 → deux racines

x₁ = (2 − √16) / (2 × 3) = (2 − 4)/6 = −2/6 = −1/3
x₂ = (2 + √16) / (2 × 3) = (2 + 4)/6 =  6/6 =  1

Contrôle : f(−1/3) = 3 × 1/9 + 2/3 − 1 = 1/3 + 2/3 − 1 = 0  ✔
           f(1)    = 3 − 2 − 1 = 0                           ✔

C'est le piège du chapitre : avec c = −1, le terme −4ac devient −4 × 3 × (−1) = +12. Un signe oublié donnerait Δ = 4 − 12 = −8 < 0, et on conclurait « pas de racine » alors qu'il y en a deux. Quand c est négatif, Δ grandit.

calcul — 2
g(x) = x² + 4x − 5         a = 1,  b = 4,  c = −5

Δ = 4² − 4 × 1 × (−5)
  = 16 + 20
  = 36                      Δ > 0 → deux racines

x₁ = (−4 − √36) / 2 = (−4 − 6)/2 = −10/2 = −5
x₂ = (−4 + √36) / 2 = (−4 + 6)/2 =   2/2 =  1

Factorisation :  g(x) = (x + 5)(x − 1)

Contrôle : (x + 5)(x − 1) = x² − x + 5x − 5 = x² + 4x − 5  ✔

Attention à la factorisation : la racine est −5, donc le facteur est (x − (−5)) = (x + 5). Le signe s'inverse en passant de la racine au facteur — deuxième erreur la plus fréquente après l'oubli du a.

calcul — 3
h(x) = −2x² + 4x − 9       a = −2,  b = 4,  c = −9

Δ = 4² − 4 × (−2) × (−9)
  = 16 − 72                 ← (−2) × (−9) = +18, puis −4 × 18 = −72
  = −56                     Δ < 0 → aucune racine

a = −2 < 0 : la parabole ouvre vers le BAS et ne touche
jamais l'axe → elle est entièrement EN DESSOUS.

h(x) < 0 pour tout x réel.

Contrôle : le maximum est en −b/2a = −4/(−4) = 1,
           et h(1) = −2 + 4 − 9 = −7 < 0  ✔

Ici les deux signes négatifs de a et c se multiplient en positif, puis le −4 ramène du négatif : −4ac = −72. Compter les signes un par un, sans raccourci.

04Tableaux de signe

6Les tableaux des trois trinômes Moyen

Dresser le tableau de signe de P₄(x) = x² − 5x + 6, P₅(x) = x² − 4x + 4 et P₆(x) = 2x² − 4x + 3, puis résoudre P₄(x) ⩽ 0.

✅ Correction

On reprend les racines de l'exercice 4, et on applique la règle : signe de a partout, sauf entre les racines.

calcul — P₄
Racines 2 et 3, dans cet ordre sur l'axe.  a = 1 > 0.

  x     │ −∞        2        3        +∞
  ──────┼──────────────────────────────────
  P₄(x) │    +      0    −   0    +

Hors de [2 ; 3] : signe de a, donc +
Entre 2 et 3    : signe contraire, donc −

Contrôle : P₄(0)   = 6  > 0   et 0 < 2      ✔
           P₄(2,5) = 6,25 − 12,5 + 6 = −0,25 < 0
                     et 2,5 est bien entre 2 et 3  ✔
           P₄(4)   = 16 − 20 + 6 = 2 > 0  et 4 > 3  ✔
calcul — P₅
Racine double 2.  a = 1 > 0.

  x     │ −∞            2            +∞
  ──────┼──────────────────────────────
  P₅(x) │     +         0         +

Pas d'« entre les racines » : il n'y en a qu'une.
Le signe de a règne partout, avec un zéro isolé.

Contrôle : P₅(x) = (x − 2)², et un carré est toujours ⩾ 0  ✔
calcul — P₆
Aucune racine (Δ = −8).  a = 2 > 0.

  x     │ −∞                         +∞
  ──────┼──────────────────────────────
  P₆(x) │             +

Le signe de a sur tout ℝ, sans jamais s'annuler.

Contrôle : minimum en x = 1, P₆(1) = 1 > 0  ✔

Résolution de P₄(x) ⩽ 0 :

calcul
Le tableau donne P₄(x) < 0 sur ]2 ; 3[, et P₄(x) = 0 en 2 et 3.

Comme l'inéquation est LARGE (⩽), les racines sont incluses :

   S = [2 ; 3]              ← crochets FERMÉS

Si l'énoncé avait demandé P₄(x) < 0 (stricte), on aurait ]2 ; 3[.

Le sens des crochets est une source de points perdus à chaque devoir. Inégalité large ⩽ ou ⩾ → crochets fermés (la racine fait partie de la solution, puisqu'elle annule). Inégalité stricte < ou > → crochets ouverts. Et les bornes infinies sont toujours ouvertes.

05Tableaux de variations

7Une affine — f(x) = −2x + 1 Facile

Établir le tableau de variations de f(x) = −2x + 1 sur ℝ.

✅ Correction
calcul
① Calcul de f'(x) :
     f(x) = −2x + 1
     f'(x) = −2            (dérivée de −2x est −2, celle de 1 est 0)

② Signe de f'(x) :
     −2 < 0, donc f'(x) < 0 sur ℝ tout entier.
     C'est une constante : elle ne change jamais de signe,
     il n'y a donc AUCUNE colonne intermédiaire.

③ Tableau de variations :

  x     │ −∞                          +∞
  ──────┼──────────────────────────────────
  f'(x) │               −
  ──────┼──────────────────────────────────
  f(x)  │ +∞  ╲──────────────────────╲  −∞

f est strictement décroissante sur ℝ.

Double contrôle : a = −2 < 0 donne « décroissante » par la règle des affines du § 2 du cours, et le signe de f' donne la même conclusion ✔ Les deux méthodes doivent toujours concorder — si elles divergent, c'est la dérivée qui est fausse.

Et une droite n'a ni maximum ni minimum : pas de « 0 » sur la ligne f', donc pas d'extremum.

8Un trinôme — f(x) = x² + 4x − 5 Moyen

  1. Établir le tableau de variations de f(x) = x² + 4x − 5 sur ℝ.
  2. En déduire le minimum de f et la valeur de x où il est atteint.
  3. Établir aussi le tableau de signe de f, et comparer les deux.
✅ Correction
calcul — 1
① Calcul de f'(x) :
     f(x)  = x² + 4x − 5
     f'(x) = 2x + 4        (x² → 2x · 4x → 4 · −5 → 0)

② Signe de f'(x) :
     2x + 4 > 0
         2x > −4
          x > −4/2 = −2

  x     │ −∞          −2          +∞
  ──────┼──────────────────────────────
  f'(x) │     −        0      +

③ Valeur de l'extremum :
     f(−2) = (−2)² + 4 × (−2) − 5
           = 4 − 8 − 5
           = −9

④ Tableau de variations :

  x     │ −∞          −2          +∞
  ──────┼──────────────────────────────
  f'(x) │     −        0      +
  ──────┼──────────────────────────────
  f(x)  │ +∞  ╲       −9     ╱  +∞

2. La flèche descend puis remonte : le point de rebroussement est un minimum.

rédaction
f admet un MINIMUM égal à −9, atteint en x = −2.

f est strictement décroissante sur ]−∞ ; −2]
et strictement croissante sur [−2 ; +∞[.

Trois contrôles : a = 1 > 0 donc la parabole ouvre vers le haut et doit avoir un minimum ✔ ; le sommet d'une parabole est en −b/2a = −4/2 = −2, la même abscisse que la racine de f' ✔ ; f(0) = −5, qui est bien supérieur à −9 ✔

3. Le signe est une tout autre étude.

calcul — 3
Δ = 4² − 4 × 1 × (−5) = 16 + 20 = 36    →  deux racines

x₁ = (−4 − 6)/2 = −5        x₂ = (−4 + 6)/2 = 1

  x    │ −∞       −5        1        +∞
  ─────┼──────────────────────────────────
  f(x) │    +     0    −    0    +
🧰 Les deux tableaux, côte à côte
Tableau de signeTableau de variations
On étudieles racines de f les racines de f'
Abscisses−5 et 1 −2
Question à laquelle il répondoù f est-elle positive ? où f monte-t-elle ?

Les abscisses n'ont rien à voir. Et −2 est exactement au milieu de −5 et 1 : (−5 + 1)/2 = −2 ✔ Ce n'est pas un hasard — le sommet d'une parabole est toujours à égale distance de ses deux racines, par symétrie.

9Un cube — f(x) = x³ − x² − x + 7 sur [−5 ; 5] Difficile

  1. Établir le tableau de variations de f sur I = [−5 ; 5].
  2. Préciser les extremums locaux et les extremums sur I.
  3. Dresser une table de valeurs et vérifier la cohérence des flèches.
✅ Correction
calcul — 1
① Calcul de f'(x) :
     f(x)  = x³ − x² − x + 7
     f'(x) = 3x² − 2x − 1

② Signe de f' — c'est un TRINÔME, donc discriminant :
     a = 3,  b = −2,  c = −1

     Δ = (−2)² − 4 × 3 × (−1) = 4 + 12 = 16     Δ > 0 → deux racines

     x₁ = (2 − √16)/(2 × 3) = (2 − 4)/6 = −2/6 = −1/3
     x₂ = (2 + √16)/(2 × 3) = (2 + 4)/6 =  6/6 =  1

     a = 3 > 0 → f' du signe de a hors des racines, contraire entre :

  x     │ −5       −1/3        1         5
  ──────┼──────────────────────────────────
  f'(x) │    +      0     −    0    +

③ Les valeurs :
     f(−5)   = −125 − 25 + 5 + 7 = −138
     f(−1/3) = −1/27 − 1/9 + 1/3 + 7 = 194/27 ≈ 7,19
     f(1)    = 1 − 1 − 1 + 7 = 6
     f(5)    = 125 − 25 − 5 + 7 = 102

④ Tableau de variations :

  x     │ −5       −1/3        1         5
  ──────┼──────────────────────────────────
  f'(x) │    +      0     −    0    +
  ──────┼──────────────────────────────────
  f(x)  │ −138 ╱  7,19  ╲     6    ╱   102

2. Attention à la distinction local / global.

rédaction
Extremums LOCAUX (là où f' s'annule) :
  · maximum local  ≈ 7,19  atteint en x = −1/3
  · minimum local  =  6    atteint en x =  1

Extremums SUR I (en comparant TOUTES les valeurs, bornes comprises) :
  · maximum sur I  =  102   atteint en x =  5   (au bord)
  · minimum sur I  = −138   atteint en x = −5   (au bord)

Le maximum local (7,19) n'est pas le maximum de f sur l'intervalle (102). C'est exactement ce que le mot « local » veut dire : le plus haut des environs, pas le plus haut de tous. Sur un intervalle fermé, il faut toujours comparer aussi les valeurs aux bornes.

3. La table de valeurs valide les flèches.

calcul — 3
  x    │ −5  │ −4  │ −3  │ −2 │ −1 │ 0 │ 1 │ 3  │ 4  │  5
  f(x) │−138 │ −69 │ −26 │ −3 │  6 │ 7 │ 6 │ 22 │ 51 │ 102

De −5 à −1/3  : −138 → −69 → −26 → −3 → 6  ça MONTE       ✔
De −1/3 à 1   : 7 (en 0) → 6 (en 1)        ça DESCEND     ✔
De 1 à 5      : 6 → 22 → 51 → 102          ça REMONTE     ✔

Cette table est un contrôle gratuit et redoutable : si une valeur contredit le sens d'une flèche, c'est le signe de f' qui est faux. Trois ou quatre points bien choisis suffisent — un de chaque côté de chaque racine de f'.

06Le sujet de DST

10Partie B : Fonctions — trois tableaux sur [−10 ; 10] Difficile

Établir le tableau de variations des fonctions suivantes sur l'intervalle [−10 ; 10]. Détailler toutes les étapes nécessaires.

  1. f(x) = −2x² + 4x − 9
  2. f(x) = x³ − 3x² − 9x + 5
  3. f(x) = (x + 4) / (x − 12)
✅ Correction

1. f(x) = −2x² + 4x − 9 — dérivée affine.

calcul — 1
① f'(x) = −4x + 4

② Signe de f' :
     −4x + 4 > 0
         −4x > −4
           x < 1          ← division par −4 : le signe se RETOURNE

  x     │ −10          1          10
  ──────┼─────────────────────────────
  f'(x) │      +       0      −

③ Valeurs :
     f(−10) = −2 × 100 + 4 × (−10) − 9 = −200 − 40 − 9 = −249
     f(1)   = −2 + 4 − 9 = −7
     f(10)  = −2 × 100 + 40 − 9 = −200 + 40 − 9 = −169

④ Tableau de variations :

  x     │ −10          1          10
  ──────┼─────────────────────────────
  f'(x) │      +       0      −
  ──────┼─────────────────────────────
  f(x)  │ −249 ╱      −7     ╲  −169

f est croissante sur [−10 ; 1], décroissante sur [1 ; 10],
et admet un MAXIMUM égal à −7 en x = 1.

Contrôles : a = −2 < 0, la parabole ouvre vers le bas, elle doit donc avoir un maximum ✔ ; le sommet est en −b/2a = −4/(−4) = 1, l'abscisse trouvée ✔ ; et f(0) = −9 < −7, cohérent avec un maximum de −7 ✔ Notez que le maximum est négatif — normal, puisque Δ = −56 < 0 : la courbe reste entièrement sous l'axe.

2. f(x) = x³ − 3x² − 9x + 5 — dérivée trinôme.

calcul — 2
① f'(x) = 3x² − 6x − 9

② Signe de f' — discriminant :
     a = 3,  b = −6,  c = −9
     Δ = (−6)² − 4 × 3 × (−9) = 36 + 108 = 144    Δ > 0 → deux racines

     x₁ = (6 − √144)/(2 × 3) = (6 − 12)/6 = −6/6 = −1
     x₂ = (6 + √144)/(2 × 3) = (6 + 12)/6 = 18/6 =  3

     a = 3 > 0 → signe de a hors des racines :

  x     │ −10      −1        3        10
  ──────┼─────────────────────────────────
  f'(x) │    +     0    −    0    +

③ Valeurs :
     f(−10) = −1000 − 300 + 90 + 5 = −1205
     f(−1)  = −1 − 3 + 9 + 5 = 10
     f(3)   = 27 − 27 − 27 + 5 = −22
     f(10)  = 1000 − 300 − 90 + 5 = 615

④ Tableau de variations :

  x     │ −10      −1        3        10
  ──────┼─────────────────────────────────
  f'(x) │    +     0    −    0    +
  ──────┼─────────────────────────────────
  f(x)  │−1205 ╱  10   ╲   −22   ╱   615

Maximum local 10 en x = −1 ; minimum local −22 en x = 3.
Sur I : maximum 615 en x = 10, minimum −1205 en x = −10.

Contrôle par factorisation de f' : 3x² − 6x − 9 = 3(x² − 2x − 3) = 3(x − 3)(x + 1), qui s'annule bien en 3 et −1 ✔ Et une valeur-test entre les racines : f'(0) = −9 < 0, cohérent avec le « − » central ✔

3. f(x) = (x + 4) / (x − 12) — un quotient.

calcul — 3
① Domaine — un dénominateur ne s'annule pas :
     x − 12 = 0  ⟺  x = 12

     Or 12 ∉ [−10 ; 10]  →  la valeur interdite est HORS de l'intervalle.
     f est donc définie et dérivable sur tout I.

② Dérivée — formule du quotient (u/v)' = (u'v − uv') / v² :
     u = x + 4      u' = 1
     v = x − 12     v' = 1

     f'(x) = [1 × (x − 12) − (x + 4) × 1] / (x − 12)²
           = (x − 12 − x − 4) / (x − 12)²
           =      −16         / (x − 12)²

③ Signe de f' :
     Le numérateur vaut −16 : toujours NÉGATIF.
     Le dénominateur est un CARRÉ : toujours positif (et non nul sur I).

     Donc f'(x) < 0 sur tout l'intervalle [−10 ; 10].

  x     │ −10                        10
  ──────┼─────────────────────────────
  f'(x) │              −

④ Valeurs :
     f(−10) = (−10 + 4)/(−10 − 12) = −6/−22 = 3/11 ≈ 0,27
     f(10)  = ( 10 + 4)/( 10 − 12) = 14/−2  = −7

⑤ Tableau de variations :

  x     │ −10                        10
  ──────┼─────────────────────────────
  f'(x) │              −
  ──────┼─────────────────────────────
  f(x)  │ 3/11 ╲──────────────────╲  −7

f est strictement décroissante sur [−10 ; 10].

Contrôle par valeurs intermédiaires : f(−5) = 1/17 ≈ 0,06, f(0) = −1/3 ≈ −0,33, f(5) = −9/7 ≈ −1,29. La suite 0,27 → 0,06 → −0,33 → −1,29 → −7 décroît bien ✔

⚠️ Les deux pièges de cette question
  1. La valeur interdite est hors de I. On est tenté de mettre une double barre à 12 dans le tableau — mais 12 > 10, la colonne n'existe pas. Toujours comparer la valeur interdite aux bornes avant de dessiner.
  2. Un dénominateur au carré est toujours positif. Le signe de f' ne dépend donc que du numérateur : ici la constante −16. Aucune inéquation à résoudre — beaucoup d'élèves en cherchent une.

Si l'énoncé avait dit [−10 ; 20], tout changerait : double barre en 12, et deux branches décroissantes séparées — sans pouvoir dire que f décroît sur tout l'intervalle, puisqu'elle y est discontinue.

🧰 La formule du quotient
(u / v)' = (u'v − uv') / v²

Le signe moins et l'ordre des termes comptent : u'v puis − uv', jamais l'inverse. Elle est démontrée et travaillée au chapitre 04.
