⚡ Les poids binaires — à savoir par cœur

2¹⁰2⁹2⁸2⁷2⁶2⁵ 2⁴2³2²2¹2⁰
102451225612864 32168421

Chaque valeur est le double de sa voisine de droite. On numérote les positions à partir de 0, en partant de la droite.

n bits → 2n valeurs → de 0 à 2n − 1

Le principe de position

calcul
247₁₀ = 2×10² + 4×10¹ + 7×10⁰
1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
       = 8 + 0 + 2 + 1 = 11₁₀

En base b : b chiffres (0 à b−1), poids bn.

x0 = 1 — la colonne de droite vaut 1 dans toutes les bases.

⚡ Binaire → décimal

  1. compter les bits → l'exposant de gauche = nb − 1
  2. écrire les poids au-dessus
  3. additionner seulement les colonnes à 1
calcul
101 1101₂  (7 bits → 2⁶ à gauche)
 64 32 16 8 4 2 1
  1  0  1 1 1 0 1
= 64+16+8+4+1 = 93₁₀

Finit par 1 → impair. Contrôle gratuit.

⚡ Addition binaire

0+0=00+1=1
1+0=11+1=10

1+1 : on pose 0, on retient 1.

Trois ou quatre 1 dans une colonne : on additionne deux par deux. 1+1+1 = 11₂ (3) · 1+1+1+1 = 100₂ (4).

⚡ Soustraction binaire

0−0=01−0=1
1−1=00−1=1 + emprunt de 2

Aligner sur le même nombre de bits avant de poser — compléter à gauche par des zéros.

Contrôle : le résultat doit être plus petit que le premier opérande.

⚡ Si A < B

A − B = − (B − A)
  1. comparer : premier bit qui diffère, de gauche à droite
  2. poser B − A
  3. écrire le signe moins

Un résultat plus grand que l'opérande = un négatif en complément à deux, pas une erreur.

sur n bits : −x s'écrit 2n − x

Sur 8 bits : −4 → 256 − 4 = 252 = 1111 1100. Plage signée : −128 à +127.

⚡ Les 6 contrôles gratuits

  1. Parité : un binaire finissant par 1 est impair.
  2. Nombre de bits : 2k ⩽ N < 2k+1 → k+1 bits.
  3. Reconvertir dans l'autre sens.
  4. Soustraction : le résultat doit être plus petit.
  5. Division : r < b, toujours.
  6. Base en indice : 10₂ ≠ 10₁₀ ≠ 10₁₆.
