Intégrales et primitives — QCM

10 questions. Une seule bonne réponse par question, et l'explication s'affiche dès que vous avez répondu. Le cours · La fiche

1F est une primitive de f lorsque :

F′ = f : la primitive est ce qu'on dérivait pour obtenir f. D'où la seule méthode de contrôle qui vaille : dérivez votre réponse. Si vous retombez sur f, c'est juste — vous n'avez besoin de personne pour corriger.

2Quel est l'ensemble des primitives de f(x) = 2x ?

(x²)′ = (x² + 12)′ = (x² − 7)′ = 2x : une fonction n'a jamais une primitive mais une famille entière, parce que la dérivée d'une constante est nulle. « Une primitive » → pas besoin du K. « Les primitives » → le K fait partie de la réponse.

3La formule xᵅ → x^(α+1)/(α+1) vaut pour :

Pour α = −1, la formule donnerait une division par zéro. C'est exactement le cas de 1/x, dont la primitive n'est pas une puissance mais ln|x|. L'exception n'est pas arbitraire : elle est arithmétique.

4Que vaut ∫₀² x dx ?

F(x) = ½x², donc F(2) − F(0) = 2 − 0 = 2. Contrôle géométrique, sans aucun calcul d'intégrale : la courbe de f(x) = x est une droite, la surface sous elle entre 0 et 2 est un triangle de base 2 et de hauteur 2, d'aire (2 × 2)/2 = 2. ✔

5Une primitive de f(x) = e^(3x) est :

e^(ax) → (1/a)·e^(ax). Le 1/3 annule le facteur 3 que la dérivation ferait apparaître : ((1/3)e^(3x))′ = (1/3) × 3 × e^(3x) = e^(3x) ✔

6Dans ∫ₐᵇ f = F(b) − F(a), quel est l'ordre ?

Haut moins bas, toujours. Inverser change le signe du résultat — et sur un calcul d'aire, une aire négative est un signal d'erreur, pas un résultat.

7Laquelle de ces opérations ne « passe » PAS dans une intégrale ?

Somme et facteur constant traversent l'intégrale ; produit et quotient ne la traversent pas. C'est la même règle que pour les dérivées, où (uv)′ ≠ u′v′. Écrire ∫(f × g) = ∫f × ∫g est faux dans le cas général.

8Une primitive de f(x) = x⁵ est :

On monte l'exposant d'un cran puis on divise par le nouvel exposant : x⁵ → x⁶/6. Contrôle : (x⁶/6)′ = 6x⁵/6 = x⁵ ✔

9Une primitive de f(x) = 7 (constante) est :

Une constante a a pour primitives ax + K. Contrôle : (7x + K)′ = 7 ✔ Ne pas confondre avec la dérivée d'une constante, qui vaut 0 — c'est l'opération inverse.
