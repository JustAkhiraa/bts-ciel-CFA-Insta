Primitives et calcul intégral — QCM

20 questions. Une seule bonne réponse par question, et l'explication s'affiche dès que vous avez répondu. Le cours · La fiche

1F est une primitive de f lorsque :

F′ = f : la primitive est ce qu'on dérivait pour obtenir f. D'où la seule méthode de contrôle qui vaille : dérivez votre réponse. Si vous retombez sur f, c'est juste — vous n'avez besoin de personne pour corriger.

2Quel est l'ensemble des primitives de f(x) = 2x ?

(x²)′ = (x² + 12)′ = (x² − 7)′ = 2x : une fonction n'a jamais une primitive mais une famille entière, parce que la dérivée d'une constante est nulle. « Une primitive » → pas besoin du K. « Les primitives » → le K fait partie de la réponse.

3La formule xᵅ → x^(α+1)/(α+1) vaut pour :

Pour α = −1, la formule donnerait une division par zéro. C'est exactement le cas de 1/x, dont la primitive n'est pas une puissance mais ln|x|. L'exception n'est pas arbitraire : elle est arithmétique.

4Que vaut ∫₀² x dx ?

F(x) = ½x², donc F(2) − F(0) = 2 − 0 = 2. Contrôle géométrique, sans aucun calcul d'intégrale : la courbe de f(x) = x est une droite, la surface sous elle entre 0 et 2 est un triangle de base 2 et de hauteur 2, d'aire (2 × 2)/2 = 2. ✔

5Une primitive de f(x) = e^(3x) est :

e^(ax) → (1/a)·e^(ax). Le 1/3 annule le facteur 3 que la dérivation ferait apparaître : ((1/3)e^(3x))′ = (1/3) × 3 × e^(3x) = e^(3x) ✔

6Dans ∫ₐᵇ f = F(b) − F(a), quel est l'ordre ?

Haut moins bas, toujours. Inverser change le signe du résultat — et sur un calcul d'aire, une aire négative est un signal d'erreur, pas un résultat.

7Laquelle de ces opérations ne « passe » PAS dans une intégrale ?

Somme et facteur constant traversent l'intégrale ; produit et quotient ne la traversent pas. C'est la même règle que pour les dérivées, où (uv)′ ≠ u′v′. Écrire ∫(f × g) = ∫f × ∫g est faux dans le cas général.

8Une primitive de f(x) = x⁵ est :

On monte l'exposant d'un cran puis on divise par le nouvel exposant : x⁵ → x⁶/6. Contrôle : (x⁶/6)′ = 6x⁵/6 = x⁵ ✔

9Une primitive de f(x) = 7 (constante) est :

Une constante a a pour primitives ax + K. Contrôle : (7x + K)′ = 7 ✔ Ne pas confondre avec la dérivée d'une constante, qui vaut 0 — c'est l'opération inverse.

10Le chapitre déclare que certains points du programme ne sont pas couverts. Lequel l'est désormais ?

Le chapitre 12 annonçait cinq manques ; le chapitre 13, Calcul intégral, en a comblé deux : la primitive de 1/x avec la forme u′/u, et la valeur moyenne. Les trois autres restent absents des sources — et la fiche le dit plutôt que de combler les trous en devinant.

11∫₀² x³ dx est-il un nombre ou une fonction ?

Une intégrale définie est un nombre — ici 4. Les bornes 0 et 2 « consomment » la variable, qui disparaît du résultat. Test infaillible : s'il reste un x dans votre réponse, vous avez écrit une primitive, pas une intégrale.

12Quelle est une primitive de f(x) = e^(−0,1x) ?

La formule est e^(αx) → (1/α)·e^(αx). Ici α = −0,1, donc 1/α = −10. Le signe vient de 1/α avec α négatif : l'oublier change le signe du résultat final, donc l'aire.

13Devant f(x) = 2x/(x² + 1), quel est le réflexe ?

(x² + 1)′ = 2x, exactement le numérateur : la fraction est de la forme u′/u, donc une primitive est ln(x² + 1). Le réflexe est toujours le même : dérivez le dénominateur avant de conclure que l'exercice est infaisable.

14Une primitive de f(x) = 1/(2x + 1) est :

Ici u = 2x + 1 donc u′ = 2, mais le numérateur vaut 1 : la forme u′/u n'est pas donnée telle quelle. On écrit 1/(2x+1) = ½ × 2/(2x+1), et le ½ se traîne jusqu'à la primitive. Contrôle : dérivez ln|2x+1|, vous obtenez 2/(2x+1), soit le double.

15Que vaut la valeur moyenne de f(x) = x² sur [0 ; 10] ?

Vₘ = (1/10)·∫₀¹⁰ x² dx = (1/10)·(1000/3) = 100/3 ≈ 33,33. La demi-somme des extrémités donnerait 50 : elle ignore tout ce qui se passe entre les bornes. x² reste longtemps petite avant de s'envoler, donc sa moyenne est nettement sous 50.

16Pourquoi le + K disparaît-il dans une intégrale définie ?

(F(b) + K) − (F(a) + K) = F(b) − F(a) : la constante s'annule. On peut donc prendre n'importe quelle primitive. Mais dès que la question dit « déterminer les primitives », l'oublier rend la réponse fausse.

17Sur un intervalle où la courbe passe sous l'axe des abscisses :

Aire et intégrale ne coïncident que si f ⩾ 0. Une intégrale nulle ne veut donc pas dire « aucune aire » : elle peut vouloir dire « autant au-dessus qu'en dessous ». Dans les annales de BTS, les fonctions modélisent des quantités positives — vérifiez-le une fois et dites-le en une ligne.

18f′(x) = 80·e^(−0,2x)(1 − 0,2x). De quoi f′ est-elle du signe ?

80 > 0 et une exponentielle est toujours strictement positive. Par produit, le signe de f′ est celui du facteur restant — un polynôme, dont le signe se lit d'un coup. C'est pour cela qu'on factorise systématiquement par l'exponentielle : la question du signe devient gratuite.

19Pour montrer que F est une primitive de f, que fait-on ?

C'est la définition même d'une primitive : F′ = f. Les trois annales du chapitre posent la question sous la forme « montrer que F est une primitive » — elles demandent donc une dérivation, pas une intégration. C'est la question la plus rentable du sujet.

20Une valeur moyenne calculée doit toujours être :

C'est le contrôle de cohérence qui coûte dix secondes. Sur l'annale du béton, f varie de 0 à 28,5 MPa : une moyenne de 18,0 est plausible. Si vous trouviez 40, vous sauriez immédiatement qu'il y a une erreur, sans relire le calcul.
