Aide-mémoire Linux

Chaque commande est écrite telle qu'on la tape, avec ce qu'elle fait en une phrase. Un clic la copie ; cherchez par nom, par usage, par mot.

Les adresses et les noms sont des exemples : remplacez-les par ceux de votre TP. sudo demande votre mot de passe, pas celui de root.

Aucune commande ne correspond.

◎ Se repérer

CommandeCe qu'elle fait
pwdLe dossier où l'on se trouve.
ls -laTout le contenu du dossier, fichiers cachés compris, avec droits, propriétaire et taille.
cd ..Remonter d'un dossier. cd seul ramène chez soi, cd - au dossier précédent.
cat /etc/os-releaseQuelle distribution, et quelle version.
less /var/log/syslogLire un long fichier page par page : / pour chercher, q pour quitter.
tail -f /var/log/auth.logSuivre un journal en direct ; Ctrl C pour arrêter.
find / -name "sshd_config" 2>/dev/nullChercher un fichier par son nom dans tout le disque, sans afficher les refus d'accès.
grep -rn "PermitRootLogin" /etc/ssh/Chercher un mot dans tous les fichiers d'un dossier, avec le numéro de ligne.
man ssLe manuel d'une commande : ses options, avec des exemples en bas.
historyLes commandes déjà tapées ; !42 relance la 42ᵉ.

▤ Fichiers et droits

CommandeCe qu'elle fait
mkdir -p tp/lab1Créer un dossier, et ses parents s'ils manquent.
cp -r source/ copie/Copier un dossier entier.
mv ancien.txt nouveau.txtRenommer, ou déplacer, si la destination est un dossier.
rm -r dossier/Supprimer un dossier et tout ce qu'il contient. Pas de corbeille : c'est définitif.
nano /etc/hostsModifier un fichier : Ctrl O enregistre, Ctrl X quitte.
chmod 640 secret.txtDroits en octal, un chiffre par public : 6 = rw- pour le propriétaire, 4 = r-- pour le groupe, 0 pour les autres. (r = 4, w = 2, x = 1.)
chmod u+x script.shRendre un script exécutable par son propriétaire.
chown alice:profs rapport.txtChanger le propriétaire et le groupe d'un fichier.
df -hLa place libre sur chaque disque, en Go.
du -sh dossier/La taille d'un dossier.
tar -czf sauvegarde.tar.gz dossier/Archiver et compresser ; tar -xzf sauvegarde.tar.gz pour extraire.

☺ Utilisateurs

CommandeCe qu'elle fait
idQui suis-je : mon identifiant et mes groupes.
sudo apt updatesudo devant une commande l'exécute avec les droits d'administrateur, après votre mot de passe.
sudo -iOuvrir un terminal root ; exit pour le refermer.
sudo adduser bobCréer un utilisateur, avec son dossier personnel et son mot de passe.
sudo usermod -aG sudo bobAjouter bob au groupe sudo. Sans le -a, il serait RETIRÉ de tous ses autres groupes.
passwdChanger son mot de passe ; sudo passwd bob pour celui d'un autre.
whoQui est connecté en ce moment.
lastLes dernières connexions, avec leur origine.

⚙ Paquets, services, processus

CommandeCe qu'elle fait
sudo apt updateRelire la liste des paquets disponibles. N'installe rien.
sudo apt upgradeMettre à jour les paquets installés.
sudo apt install openssh-serverInstaller un paquet.
sudo apt purge apache2Désinstaller un paquet, configuration comprise.
systemctl status sshLe service tourne-t-il, depuis quand, et ses dernières lignes de journal.
sudo systemctl restart sshRedémarrer un service : après avoir modifié sa configuration.
sudo systemctl enable --now sshDémarrer un service maintenant, et à chaque démarrage de la machine.
journalctl -u ssh -fLe journal d'un service, en direct.
journalctl -p err -bLes erreurs depuis le dernier démarrage.
ps auxTous les processus, avec leur numéro (PID) et ce qu'ils consomment.
topLes processus en direct, les plus gourmands en haut ; q pour quitter.
kill 1234Demander au processus 1234 de s'arrêter ; kill -9 1234 s'il refuse.

◈ Réseau

CommandeCe qu'elle fait
ip aLes interfaces, leurs adresses IP et MAC, et leur état (UP / DOWN).
ip routeLa table de routage ; la ligne default via donne la passerelle.
ip neighLa table ARP : quelle adresse MAC derrière chaque IP du réseau local.
ping -c 4 192.168.1.1Quatre échos ICMP. Sans -c, Linux ne s'arrête pas : Ctrl C.
traceroute 8.8.8.8Les routeurs traversés, un par ligne (paquet traceroute).
ss -tulpnLes ports en écoute, TCP et UDP, et le programme derrière chacun (avec sudo pour voir les programmes).
dig www.example.comInterroger le DNS ; la section ANSWER donne l'adresse (paquet dnsutils).
cat /etc/resolv.confLe serveur DNS que la machine utilise.
curl -I https://example.comSeulement les en-têtes de la réponse HTTP : le code (200, 301, 404…) et le serveur.
sudo ip addr add 192.168.1.50/24 dev eth0Ajouter une adresse à la main : perdue au redémarrage.
sudo hostnamectl set-hostname srv-webRenommer la machine.

▥ Pare-feu

CommandeCe qu'elle fait
sudo iptables -L -n -vLes règles en place, adresses en chiffres, avec le compteur de paquets de chacune.
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPTAutoriser SSH en entrée. -A ajoute à la FIN de la chaîne : l'ordre des règles compte.
sudo iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPTLaisser revenir les réponses aux connexions que la machine a elle-même ouvertes.
sudo iptables -P INPUT DROPPolitique par défaut : tout ce qu'aucune règle n'autorise est jeté. À taper APRÈS avoir autorisé SSH, sinon on se coupe soi-même.
sudo sysctl -w net.ipv4.ip_forward=1Autoriser la machine à router d'une interface à l'autre.
sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADELe NAT d'un routeur Linux : tout ce qui sort par eth0 prend son adresse (c'est du PAT).
sudo nft list rulesetLes règles de nftables, le successeur d'iptables.
sudo ufw allow 22/tcpUbuntu : autoriser SSH avec le pare-feu simplifié ; puis sudo ufw enable, et sudo ufw status verbose.

⌁ SSH

CommandeCe qu'elle fait
ssh utilisateur@192.168.1.10Se connecter à une machine ; -p 2222 si le serveur écoute sur un autre port.
ssh-keygen -t ed25519Créer une paire de clés : la privée reste chez vous, la publique part sur les serveurs.
ssh-copy-id utilisateur@192.168.1.10Déposer sa clé publique sur le serveur : la connexion se fera sans mot de passe.
scp rapport.txt utilisateur@192.168.1.10:/tmp/Copier un fichier vers le serveur, à travers SSH.
ssh-keygen -R 192.168.1.10Oublier l'empreinte connue d'un serveur, après sa réinstallation. Si elle change SANS raison, ce peut être une attaque de l'homme du milieu.
PermitRootLogin noDans /etc/ssh/sshd_config : interdire la connexion directe en root.
PasswordAuthentication noDans le même fichier : n'accepter que les clés. Vérifier d'abord que sa clé passe.
sudo sshd -tVérifier la syntaxe de sshd_config AVANT de redémarrer le service.

⚑ Analyse et cybersécurité

CommandeCe qu'elle fait
sudo tcpdump -i eth0 -nn port 22Capturer le trafic SSH sur eth0, adresses et ports en chiffres.
sudo tcpdump -i eth0 -w capture.pcapEnregistrer la capture, pour l'ouvrir ensuite dans Wireshark.
sudo tcpdump -nn arpVoir passer les requêtes et réponses ARP, c'est là qu'une usurpation se trahit.
nmap -sn 192.168.56.0/24Quelles machines répondent sur le réseau, sans scanner leurs ports.
nmap -sV 192.168.56.10Les ports ouverts d'une machine, et la version du service derrière chacun.
sudo grep "Failed password" /var/log/auth.logLes connexions SSH refusées : une rafale venue d'une même adresse est une attaque par force brute.
sha256sum debian.isoL'empreinte d'un fichier, à comparer à celle que publie le site officiel.
openssl s_client -connect example.com:443Le certificat TLS d'un site : qui l'a émis, pour quel nom, jusqu'à quand.
ip.addr == 192.168.1.10Filtre d'affichage Wireshark : tout ce qui part de cette adresse ou y arrive.
tcp.port == 22Filtre Wireshark : un port, en source ou en destination. Aussi arp, dns, http.request.

▣ Docker

CommandeCe qu'elle fait
docker ps -aLes conteneurs, y compris ceux qui sont arrêtés.
docker imagesLes images présentes sur la machine.
docker run -d -p 8080:80 --name web nginxLancer un conteneur en arrière-plan, son port 80 publié sur le 8080 de l'hôte.
docker exec -it web bashOuvrir un terminal dans un conteneur qui tourne.
docker logs -f webLe journal d'un conteneur, en direct.
docker stop webArrêter un conteneur ; docker rm web le supprime.
docker volume lsLes volumes : les données qui survivent aux conteneurs.
docker network inspect bridgeUn réseau Docker : son sous-réseau, et les conteneurs branchés dessus.
⚠️ Scanner et capturer : seulement chez soi

nmap, tcpdump et les outils de Kali sont faits pour le laboratoire : votre maquette, ou un réseau dont on vous a confié le test. Sur le réseau de l'école, d'un voisin ou d'une entreprise, sans autorisation écrite, c'est une infraction : l'accès et le maintien frauduleux dans un système sont punis par les articles 323-1 et suivants du Code pénal.
