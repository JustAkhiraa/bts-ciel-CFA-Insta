Lecteur de fichiers .pkt

Déposez votre fichier : pour une activité, la page dit ce qu'il reste à faire, réglage par réglage, avec les commandes à taper. Le réseau entier se lit aussi, et s'ouvre dans le labo réseau pour être testé.

Déposez ici un fichier .pkt ou .pka

Il est lu dans cette page, sur votre appareil : rien n'est envoyé.

  • Ce qu'il reste à faire. Pour une activité .pka : chaque réglage et chaque câble qui manquent, avec les valeurs et les commandes à taper.
  • Tout le réseau. Les appareils, leurs adresses, leurs câbles, leur configuration complète, et le schéma.
  • Le labo réseau. Un bouton y ouvre la maquette pour la tester : ping, show, simulation.

Deux fichiers déposés ensemble : ce qui a changé de l'un à l'autre.
