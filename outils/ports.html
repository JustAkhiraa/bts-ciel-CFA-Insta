▤ Les trois plages

Un numéro de port tient sur 16 bits : de 0 à 65 535. L'IANA le découpe en trois, et on vous demande la frontière.

PlageNomQui s'en sert
0 – 1023Ports bien connus Les services standards. Sous Linux, il faut être root pour en ouvrir un.
1024 – 49151Ports enregistrés Applications déclarées à l'IANA : MySQL 3306, RDP 3389, PostgreSQL 5432.
49152 – 65535Ports dynamiques Le port source que votre machine tire au sort pour chaque connexion. C'est lui que le PAT réécrit.
⚠️ ICMP et ARP n'ont pas de port

Un port est un champ de l'en-tête TCP ou UDP — donc de la couche 4. ping utilise ICMP, qui vit directement sur IP, en couche 3 : il n'y a aucun port à ouvrir pour lui. ARP, lui, ne monte même pas jusqu'à IP. Répondre « le port du ping » à un examinateur, c'est se tromper de couche.
