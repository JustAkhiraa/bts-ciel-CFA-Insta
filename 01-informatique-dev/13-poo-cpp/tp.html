POO en C++ · les TP

Trois TP. Le premier pose les bases du C++ (deux exercices, neuf questions). Le second passe aux classes, aux objets et à l'encapsulation (trois exercices, vingt-sept questions). Le troisième fait naître et mourir des objets :
constructeurs et destructeurs (deux exercices, douze questions). Chaque question a sa correction repliable, puis le programme complet, compilé et exécuté.

🎯 Compiler et lancer

Un programme C++ s'écrit dans un fichier .cpp. On le compile, puis on lance le programme obtenu :

terminal
c++ -std=c++17 tp1-ex1.cpp -o tp1-ex1
./tp1-ex1

Cherche chaque question avant d'ouvrir sa correction.

0 étape

1TP 1 · Les machines d'une salle

Un entier n représente le nombre de machines d'une salle informatique. On lui applique quatre traitements, chacun avec une boucle différente.

1La saisie contrôlée Facile

1. Demander un entier positif n. Tant que la valeur saisie est inférieure ou égale à zéro, redemander.

✅ Correction

« Tant que c'est faux, redemander » :
on demande au moins une fois, donc do...while.

C++
int n;
do
{
    cout << "Nombre de machines : ";
    cin >> n;
} while (n <= 0);

2Les numéros, avec for Facile

2. Avec une boucle for, afficher les numéros des machines de 1 à n.

✅ Correction

On connaît le nombre de tours : c'est le cas du for.

C++
for (int i = 1; i <= n; i++)
{
    cout << "Machine " << i << endl;
}

3Le produit, avec while Moyen

3. Avec une boucle while, calculer et afficher le produit des entiers de 1 à n.

✅ Correction

Le produit part de 1, pas de 0 :
multiplier par 0 donnerait toujours 0.

C++
long long produit = 1;
int k = 1;
while (k <= n)
{
    produit = produit * k;
    k++;
}
cout << "Produit de 1 a " << n << " : " << produit << endl;

Pourquoi long long :
voir le piège juste après l'exercice.

4La table, avec do...while Facile

4. Avec une boucle do...while, afficher la table de multiplication de n, de 1 à 10.

✅ Correction
C++
int j = 1;
do
{
    cout << n << " x " << j << " = " << n * j << endl;
    j++;
} while (j <= 10);
C++ · tp1-ex1.cpp
#include <iostream>
using namespace std;

int main()
{
    int n;

    // 1. Saisie contrôlée : on redemande tant que n <= 0
    do
    {
        cout << "Nombre de machines : ";
        cin >> n;
    } while (n <= 0);

    // 2. Les numéros des machines, avec for
    for (int i = 1; i <= n; i++)
    {
        cout << "Machine " << i << endl;
    }

    // 3. Le produit 1 x 2 x ... x n, avec while
    long long produit = 1;
    int k = 1;
    while (k <= n)
    {
        produit = produit * k;
        k++;
    }
    cout << "Produit de 1 a " << n << " : " << produit << endl;

    // 4. La table de multiplication de n, avec do...while
    int j = 1;
    do
    {
        cout << n << " x " << j << " = " << n * j << endl;
        j++;
    } while (j <= 10);

    return 0;
}

Avec int produit, le résultat est juste jusqu'à 12, puis devient faux :

2TP 1 · La fiche d'un serveur

On saisit puis on affiche les informations d'un serveur de l'entreprise :
son numéro, son nom, son système d'exploitation et sa capacité de stockage en Go.

5Les variables Facile

1. Déclarer les variables nécessaires.

✅ Correction

Un type par information :
des nombres entiers pour le numéro et la capacité, du texte pour le nom et le système.

C++
int numero;
string nom;
string systeme;
int capacite;      // en Go

string demande #include <string>.

6Le numéro, puis le nom en plusieurs mots Moyen

2. Saisir le numéro du serveur. 3. Saisir son nom, qui peut contenir plusieurs mots.

✅ Correction

cin >> s'arrête à la première espace :
pour un nom en plusieurs mots, il faut getline. Et un getline qui suit un cin >> doit être précédé de cin.ignore() (cours, section 11).

C++
cout << "Numero du serveur : ";
cin >> numero;
cin.ignore();      // retire le \n laissé par Entrée

cout << "Nom du serveur : ";
getline(cin, nom);

7Le système et la capacité Facile

4. Saisir le système d'exploitation et la capacité de stockage.

✅ Correction

Le système peut lui aussi avoir plusieurs mots : getline encore. Pas de cin.ignore() ici :
deux getline de suite n'en ont pas besoin.

C++
cout << "Systeme d'exploitation : ";
getline(cin, systeme);

cout << "Capacite de stockage (Go) : ";
cin >> capacite;

8L'affichage Facile

5. Afficher toutes les informations saisies.

✅ Correction
C++
cout << endl;
cout << "Serveur n " << numero << endl;
cout << "Nom      : " << nom << endl;
cout << "Systeme  : " << systeme << endl;
cout << "Stockage : " << capacite << " Go" << endl;
C++ · tp1-ex2.cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
    int numero;
    string nom;
    string systeme;
    int capacite;      // en Go

    cout << "Numero du serveur : ";
    cin >> numero;
    cin.ignore();      // retire le \n laissé par Entrée

    cout << "Nom du serveur : ";
    getline(cin, nom); // le nom peut contenir plusieurs mots

    cout << "Systeme d'exploitation : ";
    getline(cin, systeme);

    cout << "Capacite de stockage (Go) : ";
    cin >> capacite;

    cout << endl;
    cout << "Serveur n " << numero << endl;
    cout << "Nom      : " << nom << endl;
    cout << "Systeme  : " << systeme << endl;
    cout << "Stockage : " << capacite << " Go" << endl;
    return 0;
}

le nom du serveur finit dans le système, et le stockage vaut 0.

3TP 2 · Le capteur

On gère les informations d'un capteur électronique. Un capteur a un type (string), une valeur (float) et une unité (string).

9La classe et ses attributs privés Facile

1. Déclarer une classe Capteur. 2. Déclarer les trois attributs en utilisant private.

✅ Correction

Les attributs viennent après private:. Sans rien écrire, ils seraient privés aussi (cours, section 20), mais l'écrire dit l'intention.

C++
class Capteur
{
private:
    string type;
    float valeur;
    string unite;

public:
    // les méthodes viendront ici
};

10Les setters Facile

3. Ajouter les setters permettant de modifier les attributs.

✅ Correction

Un setter par attribut, dans la partie public. Le paramètre a le type de l'attribut qu'il remplit.

C++
void setType(string t)
{
    type = t;
}

void setValeur(float v)
{
    valeur = v;
}

void setUnite(string u)
{
    unite = u;
}

11Les getters Facile

4. Ajouter les getters permettant de récupérer les valeurs.

✅ Correction

Le type de retour est celui de l'attribut renvoyé. Un getter ne prend aucun paramètre.

C++
string getType()
{
    return type;
}

float getValeur()
{
    return valeur;
}

string getUnite()
{
    return unite;
}

12La méthode afficher() Facile

5. Ajouter une méthode afficher() permettant d'afficher les informations du capteur.

✅ Correction

La méthode appartient à la classe :
elle lit les attributs privés directement, sans passer par les getters.

C++
void afficher()
{
    cout << "Type   : " << type << endl;
    cout << "Valeur : " << valeur << endl;
    cout << "Unite  : " << unite << endl;
}

13L'objet c1 Facile

6. Dans main(), créer un objet c1. 7. Lui affecter le type Temperature, la valeur 25.5 et l'unité °C. 8. Afficher les informations du capteur.

✅ Correction

Les attributs sont privés :
c1.type = "Temperature"; ne compilerait pas. On passe par les setters.

C++
Capteur c1;

c1.setType("Temperature");
c1.setValeur(25.5);
c1.setUnite("°C");

c1.afficher();
C++ · tp2-ex1.cpp
#include <iostream>
#include <string>
using namespace std;

class Capteur
{
private:
    string type;
    float valeur;
    string unite;

public:
    // Setters : modifier les attributs
    void setType(string t)
    {
        type = t;
    }

    void setValeur(float v)
    {
        valeur = v;
    }

    void setUnite(string u)
    {
        unite = u;
    }

    // Getters : récupérer les valeurs
    string getType()
    {
        return type;
    }

    float getValeur()
    {
        return valeur;
    }

    string getUnite()
    {
        return unite;
    }

    void afficher()
    {
        cout << "Type   : " << type << endl;
        cout << "Valeur : " << valeur << endl;
        cout << "Unite  : " << unite << endl;
    }
};

int main()
{
    Capteur c1;

    c1.setType("Temperature");
    c1.setValeur(25.5);
    c1.setUnite("°C");

    c1.afficher();

    // Les getters, pour relire une valeur depuis main()
    cout << endl;
    cout << c1.getType() << " = " << c1.getValeur() << " " << c1.getUnite() << endl;

    return 0;
}

Valeur : 25.5

15Setters et getters, mémoire contrôlée Moyen

3. Ajouter un setter et un getter pour chaque attribut. 4. Pour la capacité mémoire, vérifier que la valeur est strictement positive avant de la modifier.

✅ Correction

Seul setMemoire contrôle :
« strictement positive » s'écrit > 0, pas >= 0. Le message montre la valeur refusée, pour qu'on sache laquelle.

C++
void setMemoire(int m)
{
    if (m > 0)
    {
        memoire = m;
    }
    else
    {
        cout << "Memoire invalide : " << m << " Go refuse" << endl;
    }
}

int getMemoire()
{
    return memoire;
}

Les setters et getters de nom et adresseIP ont la même forme que ceux du capteur, sans condition.

17Deux serveurs Facile

6. Dans main(), créer deux objets s1 et s2. 7. Leur affecter des informations différentes. 8. Afficher les informations des deux serveurs.

✅ Correction

Les valeurs sont libres. Deux objets de la même classe ont chacun leurs attributs :
modifier s1 ne change rien à s2.

C++
Serveur s1;
s1.setNom("SRV-WEB");

s1.setMemoire(16);

Serveur s2;

cout << "Serveur 2 :" << endl;
s2.afficherInformations();

18Une mémoire négative Moyen

9. Tester l'affectation d'une valeur négative à la capacité mémoire.

✅ Correction

Le test n'est complet que si on relit la mémoire après coup :
le message prouve le refus, la relecture prouve que l'ancienne valeur est restée.

C++
s1.setMemoire(-8);
cout << "Memoire de " << s1.getNom() << " : " << s1.getMemoire() << " Go" << endl;

5TP 2 · Les équipements réseau

20Getters et setters, deux contrôles Moyen

3. Ajouter les getters et les setters correspondants. 4. Vérifier que le débit et le nombre de ports sont strictement positifs avant leur modification.

Deux setters contrôlés, chacun avec son propre message : on sait lequel a refusé.

22La méthode estHautDebit() Moyen

6. Ajouter une méthode estHautDebit() qui retourne true si le débit est supérieur ou égal à 1000 Mbps, et false sinon.

✅ Correction

La méthode répond par oui ou non : son type de retour est bool. La comparaison debit >= 1000 vaut déjà true ou false, on la renvoie telle quelle.

C++
bool estHautDebit()
{
    return debit >= 1000;
}

« Supérieur ou égal » s'écrit >=. Avec un débit de 1000 exactement, >= donne true et > donnerait false :
vérifié en compilant les deux.

23Deux équipements, et leur débit Facile

Un équipement au-dessus de 1000 Mbps, l'autre en dessous : on voit les deux messages. estHautDebit() se place directement dans le if.

35Observer la création et la destruction Moyen

7 e. Observer les messages affichés à la création et à la destruction des objets.

✅ Correction

À la création, trois messages différents, dans l'ordre des lignes :
défaut pour s1, paramètres pour s2, copie pour s3.

À la destruction, trois « Destruction du serveur », à la sortie de main, dans l'ordre inverse : s3, puis s2, puis s1. Le dernier créé part le premier (cours, section 35).

Les trois messages de destruction sont identiques. Pour voir lequel est lequel, ajoute le nom ou la référence au message du destructeur.

⚡ Les TP en dix réflexes

TP 1 · les bases

  • Au moins une fois : do...while. Un nombre de tours connu : for. Tant que : while.
  • Un produit part de 1, une somme de 0.
  • Un grand produit déborde un int : long long.
  • cin >> puis getline :
    cin.ignore() entre les deux.

TP 2 · l'encapsulation

  • Attributs private, et l'accès par des getters et des setters public.
  • Le setter contrôle :
    if (valeur > 0), sinon un message, et l'attribut garde son ancienne valeur.
  • Une méthode qui répond oui ou non renvoie un bool :
    return debit >= 1000;

TP 3 · constructeurs et destructeurs

  • Un constructeur porte le nom de la classe, sans type de retour, dans la partie public.
  • Le constructeur de copie reçoit const Serveur& autre et recopie chaque attribut.
  • Le destructeur parle à la sortie de main, et les objets partent dans l'ordre inverse de leur création.
