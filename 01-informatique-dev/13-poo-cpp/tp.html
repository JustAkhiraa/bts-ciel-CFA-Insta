1Exercice 1 · les machines d'une salle

Un entier n représente le nombre de machines d'une salle informatique. On lui applique quatre traitements, chacun avec une boucle différente.

1La saisie contrôlée Facile

1. Demander un entier positif n. Tant que la valeur saisie est inférieure ou égale à zéro, redemander.

✅ Correction

« Tant que c'est faux, redemander » : on demande au moins une fois, donc do...while.

C++
int n;
do
{
    cout << "Nombre de machines : ";
    cin >> n;
} while (n <= 0);

2Les numéros, avec for Facile

2. Avec une boucle for, afficher les numéros des machines de 1 à n.

✅ Correction

On connaît le nombre de tours : c'est le cas du for.

C++
for (int i = 1; i <= n; i++)
{
    cout << "Machine " << i << endl;
}

3Le produit, avec while Moyen

3. Avec une boucle while, calculer et afficher le produit des entiers de 1 à n.

✅ Correction

Le produit part de 1, pas de 0 : multiplier par 0 donnerait toujours 0.

C++
long long produit = 1;
int k = 1;
while (k <= n)
{
    produit = produit * k;
    k++;
}
cout << "Produit de 1 a " << n << " : " << produit << endl;

Pourquoi long long : voir le piège juste après l'exercice.

4La table, avec do...while Facile

4. Avec une boucle do...while, afficher la table de multiplication de n, de 1 à 10.

✅ Correction
C++
int j = 1;
do
{
    cout << n << " x " << j << " = " << n * j << endl;
    j++;
} while (j <= 10);
C++ · tp1-ex1.cpp
#include <iostream>
using namespace std;

int main()
{
    int n;

    // 1. Saisie contrôlée : on redemande tant que n <= 0
    do
    {
        cout << "Nombre de machines : ";
        cin >> n;
    } while (n <= 0);

    // 2. Les numéros des machines, avec for
    for (int i = 1; i <= n; i++)
    {
        cout << "Machine " << i << endl;
    }

    // 3. Le produit 1 x 2 x ... x n, avec while
    long long produit = 1;
    int k = 1;
    while (k <= n)
    {
        produit = produit * k;
        k++;
    }
    cout << "Produit de 1 a " << n << " : " << produit << endl;

    // 4. La table de multiplication de n, avec do...while
    int j = 1;
    do
    {
        cout << n << " x " << j << " = " << n * j << endl;
        j++;
    } while (j <= 10);

    return 0;
}

⚠️ Le produit déborde vite

Avec int produit, le résultat est juste jusqu'à 12, puis devient faux :

sortie réelle · les deux versions
n = 13
  int       : 1932053504
  long long : 6227020800

n = 20
  int       : -2102132736
  long long : 2432902008176640000

Un int ne dépasse pas 2 147 483 647. long long tient jusqu'à n = 20 ; à 21, il déborde à son tour.

2Exercice 2 · la fiche d'un serveur

On saisit puis on affiche les informations d'un serveur de l'entreprise : son numéro, son nom, son système d'exploitation et sa capacité de stockage en Go.

5Les variables Facile

1. Déclarer les variables nécessaires.

✅ Correction

Un type par information : des nombres entiers pour le numéro et la capacité, du texte pour le nom et le système.

C++
int numero;
string nom;
string systeme;
int capacite;      // en Go

string demande #include <string>.

6Le numéro, puis le nom en plusieurs mots Moyen

2. Saisir le numéro du serveur. 3. Saisir son nom, qui peut contenir plusieurs mots.

✅ Correction

cin >> s'arrête à la première espace : pour un nom en plusieurs mots, il faut getline. Et un getline qui suit un cin >> doit être précédé de cin.ignore() (cours, section 11).

C++
cout << "Numero du serveur : ";
cin >> numero;
cin.ignore();      // retire le \n laissé par Entrée

cout << "Nom du serveur : ";
getline(cin, nom);

7Le système et la capacité Facile

4. Saisir le système d'exploitation et la capacité de stockage.

✅ Correction

Le système peut lui aussi avoir plusieurs mots : getline encore. Pas de cin.ignore() ici : deux getline de suite n'en ont pas besoin.

C++
cout << "Systeme d'exploitation : ";
getline(cin, systeme);

cout << "Capacite de stockage (Go) : ";
cin >> capacite;

8L'affichage Facile

5. Afficher toutes les informations saisies.

✅ Correction
C++
cout << endl;
cout << "Serveur n " << numero << endl;
cout << "Nom      : " << nom << endl;
cout << "Systeme  : " << systeme << endl;
cout << "Stockage : " << capacite << " Go" << endl;
C++ · tp1-ex2.cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
    int numero;
    string nom;
    string systeme;
    int capacite;      // en Go

    cout << "Numero du serveur : ";
    cin >> numero;
    cin.ignore();      // retire le \n laissé par Entrée

    cout << "Nom du serveur : ";
    getline(cin, nom); // le nom peut contenir plusieurs mots

    cout << "Systeme d'exploitation : ";
    getline(cin, systeme);

    cout << "Capacite de stockage (Go) : ";
    cin >> capacite;

    cout << endl;
    cout << "Serveur n " << numero << endl;
    cout << "Nom      : " << nom << endl;
    cout << "Systeme  : " << systeme << endl;
    cout << "Stockage : " << capacite << " Go" << endl;
    return 0;
}

⚠️ Sans cin.ignore(), tout se décale

Le même programme, ligne cin.ignore(); retirée, avec les mêmes saisies :

sortie réelle · sans cin.ignore()
Serveur n 3
Nom      : 
Systeme  : Serveur de fichiers
Stockage : 0 Go

Le nom est vide, et chaque réponse tombe dans la variable suivante : le nom du serveur finit dans le système, et le stockage vaut 0.

⚡ Le TP en quatre réflexes

  • Au moins une fois : do...while. Un nombre de tours connu : for. Tant que : while.
  • Un produit part de 1, une somme de 0.
  • Un grand produit déborde un int : long long.
  • cin >> puis getline : cin.ignore() entre les deux.
