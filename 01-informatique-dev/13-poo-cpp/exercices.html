L'exercice du cours d'abord, corrigé, compilé puis exécuté : il fait travailler cin, getline, et le piège de cin.ignore(). Puis deux exercices d'entraînement, ajoutés ici et construits sur les exemples du cours : ils ne viennent pas du sujet distribué.

01Les informations d'un étudiant

1Saisir puis afficher un étudiant Facile

On souhaite écrire un programme qui permet de saisir les informations d'un étudiant, puis de les afficher à l'écran. Le fichier sera enregistré avec l'extension .cpp.

Les informations à saisir sont : le nom complet de l'étudiant, son âge, sa moyenne générale et son établissement de formation.

  1. Déclarer les variables nécessaires pour stocker les informations de l'étudiant.
  2. Demander à l'utilisateur de saisir son nom complet.
  3. Demander à l'utilisateur de saisir son âge.
  4. Demander à l'utilisateur de saisir sa moyenne générale.
  5. Demander à l'utilisateur de saisir son établissement de formation.
  6. Afficher toutes les informations saisies.
✅ Correction
C++
/* ========================================
 Exercice : les informations d'un étudiant
 ========================================
On souhaite écrire un programme qui permet de saisir les informations d'un
étudiant, puis de les afficher à l'écran. Le fichier sera enregistré avec
l'extension .cpp

Les informations à saisir sont : le nom complet de l'étudiant, son âge, sa
moyenne générale et son établissement de formation.

    1. Déclarer les variables nécessaires pour stocker les informations de l'étudiant.
    2. Demander à l'utilisateur de saisir son nom complet.
    3. Demander à l'utilisateur de saisir son âge.
    4. Demander à l'utilisateur de saisir sa moyenne générale.
    5. Demander à l'utilisateur de saisir son établissement de formation.
    6. Afficher toutes les informations saisies.
*/

#include <iostream>
#include <string>
using namespace std;

int main()
{
    // 1. Déclarer les variables nécessaires pour stocker les informations de l'étudiant.
    string nomComplet;
    int age;
    float moyenne;
    string etablissement;

    // 2. Demander à l'utilisateur de saisir son nom complet.
    cout << "Nom complet : ";
    getline(cin, nomComplet);

    // 3. Demander à l'utilisateur de saisir son âge.
    cout << "Age : ";
    cin >> age;

    // 4. Demander à l'utilisateur de saisir sa moyenne générale.
    cout << "Moyenne generale : ";
    cin >> moyenne;
    cin.ignore();                 // le \n laisse par Entree, avant le getline

    // 5. Demander à l'utilisateur de saisir son établissement de formation.
    cout << "Etablissement : ";
    getline(cin, etablissement);

    // 6. Afficher toutes les informations saisies.
    cout << endl;
    cout << "Nom complet   : " << nomComplet << endl;
    cout << "Age           : " << age << " ans" << endl;
    cout << "Moyenne       : " << moyenne << endl;
    cout << "Etablissement : " << etablissement << endl;

    return 0;
}
sortie réelle · saisies : Jean Dupont puis 20 puis 15.5 puis CFA du numerique
Nom complet : Age : Moyenne generale : Etablissement : 
Nom complet   : Jean Dupont
Age           : 20 ans
Moyenne       : 15.5
Etablissement : CFA du numerique
⚠️ Le cin.ignore() est entre la moyenne et l'établissement

Le nom complet est lu en premier, par getline : rien ne le précède, il n'a besoin de rien. Mais l'établissement est lu par getline juste après cin >> moyenne, qui laisse le \n de la touche Entrée dans le flux.

Sans cin.ignore(), l'établissement serait vide, et le programme ne laisserait même pas le temps de le taper (cours, section 11).

Un nom complet et un établissement contiennent des espaces : c'est pour cela que ce sont des getline, et non des cin >>.

💡 15.5, et non 15.50

cout affiche la moyenne sans décimale inutile. Pour en imposer deux : #include <iomanip>, puis cout << fixed << setprecision(2) << moyenne.

02Reconnaître les quatre mots

2Classe, attribut, méthode, objet Facile

Exercice d'entraînement. Dans le programme ci-dessous, nommer :

  1. la classe ;
  2. ses attributs ;
  3. ses méthodes ;
  4. les objets créés dans main.
C++
#include <iostream>
#include <string>
using namespace std;

class Routeur {
public:
    string nom;
    int nbPorts;

    void afficher() {
        cout << nom << " : " << nbPorts << " ports" << endl;
    }
};

int main()
{
    Routeur r1;
    Routeur r2;

    r1.nom = "R-Paris";
    r1.nbPorts = 4;
    r2.nom = "R-Lyon";
    r2.nbPorts = 8;

    r1.afficher();
    r2.afficher();
    return 0;
}
sortie réelle
R-Paris : 4 ports
R-Lyon : 8 ports
✅ Correction
QuestionRéponse
1. la classeRouteur
2. ses attributsnom et nbPorts
3. ses méthodesafficher()
4. les objetsr1 et r2
💡 Une classe, deux objets, deux affichages différents

r1 et r2 sont fabriqués d'après le même modèle, mais chacun a ses propres valeurs. r1.afficher() lit le nom et les ports de r1, r2.afficher() ceux de r2 : la même méthode, appelée sur deux objets.

03Écrire une classe

3La classe Ordinateur du cours Moyen

Exercice d'entraînement. Le cours décrit un ordinateur par trois attributs et trois méthodes (section 1). Écrire la classe Ordinateur qui :

  1. possède les attributs marque, memoireRAM (en Go) et allume (vrai ou faux) ;
  2. possède une méthode demarrer() qui passe l'état à « allumé » et l'annonce ;
  3. possède une méthode arreter() qui passe l'état à « éteint » et l'annonce ;
  4. possède une méthode afficher() qui affiche les trois caractéristiques ;
  5. dans main, crée un ordinateur Alpha de 16 Go éteint, l'affiche, le démarre, puis l'affiche de nouveau.
✅ Correction
C++
#include <iostream>
#include <string>
using namespace std;

class Ordinateur {
public:
    string marque;
    int memoireRAM;               // en Go
    bool allume;

    void demarrer() {
        allume = true;
        cout << marque << " demarre." << endl;
    }

    void arreter() {
        allume = false;
        cout << marque << " s'arrete." << endl;
    }

    void afficher() {
        cout << "Marque : " << marque << endl;
        cout << "RAM    : " << memoireRAM << " Go" << endl;
        if (allume) {
            cout << "Etat   : allume" << endl;
        } else {
            cout << "Etat   : eteint" << endl;
        }
    }
};

int main()
{
    Ordinateur pc;

    pc.marque = "Alpha";
    pc.memoireRAM = 16;
    pc.allume = false;

    pc.afficher();
    pc.demarrer();
    pc.afficher();

    return 0;
}
sortie réelle
Marque : Alpha
RAM    : 16 Go
Etat   : eteint
Alpha demarre.
Marque : Alpha
RAM    : 16 Go
Etat   : allume
💡 bool : vrai ou faux, enfin un type pour ça

En C, on rangeait un état dans un int valant 0 ou 1. Le C++ a un vrai type : bool, qui vaut true ou false.

Les méthodes demarrer() et arreter() changent l'attribut allume de l'objet sur lequel on les appelle, sans paramètre, puisque l'attribut est dans le même objet.

⚠️ Sans public:, rien ne compile

Dans une classe, les membres sont privés par défaut : pc.marque = "Alpha"; serait refusé depuis main. Le public: les ouvre. Pourquoi ce choix par défaut ? C'est l'encapsulation, le premier des quatre principes : le prochain chapitre.

04Classes : les erreurs, et l'opérateur ::

Les deux réflexes de la séance du 6 novembre : ce qu'une classe exige pour compiler, et une méthode définie hors de sa classe.

4Deux erreurs dans une classe Facile

Ce programme ne compile pas. Trouver les deux erreurs, et les corriger.

C++ · ne compile pas
#include <iostream>
#include <string>
using namespace std;

class Imprimante
{
    string modele;
    int pages;
}

int main()
{
    Imprimante imp;
    imp.pages = 120;
    return 0;
}
✅ Correction

Le compilateur donne les deux :

erreurs réelles du compilateur
ligne 9 : expected ';' after class
ligne 14 : 'pages' is a private member of 'Imprimante'

1. La classe se ferme par }; : il manque le point-virgule après l'accolade.

2. Sans public:, les attributs sont privés : main ne peut pas écrire imp.pages. On ajoute public: en tête de la classe (cours, section 14).

5La classe Serveur, méthode définie dehors Moyen

Écrire une classe Serveur qui :

  1. possède les attributs publics nom, adresseIP et stockage (en Go) ;
  2. déclare une méthode afficher(), définie hors de la classe avec ::, qui affiche les trois informations sur une ligne ;
  3. dans main, crée deux serveurs, srv-web (192.168.10.10, 250 Go) et srv-sauvegarde (192.168.10.20, 2000 Go), puis les affiche.
✅ Correction
C++
#include <iostream>
#include <string>
using namespace std;

class Serveur
{
public:
    string nom;
    string adresseIP;
    int stockage;          // en Go

    void afficher();       // definie plus bas
};

void Serveur::afficher()
{
    cout << nom << " (" << adresseIP << ") : "
         << stockage << " Go" << endl;
}

int main()
{
    Serveur web;
    web.nom = "srv-web";
    web.adresseIP = "192.168.10.10";
    web.stockage = 250;

    Serveur sauvegarde;
    sauvegarde.nom = "srv-sauvegarde";
    sauvegarde.adresseIP = "192.168.10.20";
    sauvegarde.stockage = 2000;

    web.afficher();
    sauvegarde.afficher();
    return 0;
}
sortie réelle
srv-web (192.168.10.10) : 250 Go
srv-sauvegarde (192.168.10.20) : 2000 Go

Dans la classe, void afficher(); : la déclaration seule. Dehors, void Serveur::afficher() : le contenu. Sans Serveur::, ce serait une fonction ordinaire, qui ne connaît pas nom.

⚡ Ce que ces exercices font travailler

  • Exercice 1 : getline pour ce qui contient des espaces, cin >> pour les nombres, et cin.ignore() entre un cin >> et le getline qui le suit.
  • Exercice 2 : une classe est un modèle ; chaque objet a ses propres valeurs.
  • Exercice 3 : une classe complète : attributs, méthodes, public:, et l'accolade fermée par };.
  • Exercices 4 et 5 : le point-virgule final, le privé par défaut, et une méthode définie hors de la classe avec ::.
