POO en C++

Jusqu'ici, un programme était une suite d'instructions qui manipulent des données. La programmation orientée objet range ensemble les données et ce qu'on en fait, dans des objets. Le chapitre pose les idées, objet, classe, attribut, méthode, et les quatre principes, puis les bases du C++, le langage dans lequel on les pratiquera : afficher, lire, et manipuler des chaînes.

📌

Résumé flash

Un objet a des attributs (ce qu'il est) et des méthodes (ce qu'il fait). La classe est le modèle, l'objet un exemplaire fabriqué d'après lui. Quatre principes : encapsulation, abstraction, héritage, polymorphisme.

En C++ : #include <iostream>, using namespace std;, puis cout << pour afficher et cin >> pour lire, sans code de format ni &.

string remplace le tableau de char, getline lit une ligne entière, et après un cin >>, il faut un cin.ignore().

01Qu'est-ce qu'un objet ?

La programmation orientée objet, la POO, est une manière de concevoir un programme en l'organisant autour d'objets. Un objet représente un élément, concret ou abstrait, du système qu'on veut programmer :

DomaineDes objets
Informatiqueordinateur, serveur, capteur
Réseaurouteur, commutateur, pare-feu
Gestionutilisateur, compte, produit

Chaque objet possède deux choses : des informations qui le décrivent et des actions qu'il sait faire. Les premières s'appellent des attributs, les secondes des méthodes.

🧠 Un nom et des verbes

Pour trouver les attributs et les méthodes d'un objet, on le décrit en français. Les noms et adjectifs (« sa marque », « sa mémoire », « allumé ») sont ses attributs ; les verbes (« démarrer », « afficher ») sont ses méthodes.

02Procédural ou objet : deux façons d'organiser

Il y a plusieurs façons d'organiser un programme. Celle que vous connaissez déjà, c'est la programmation procédurale : le programme est une suite de fonctions et d'instructions qui manipulent des données. C'est celle du langage C.

C
#include <stdio.h>

int main()
{
    int temperature = 25;
    printf("Temperature : %d degres\n", temperature);
    return 0;
}
sortie réelle
Temperature : 25 degres

temperature est une variable qui contient une donnée ; printf() est une fonction qui l'affiche. La donnée et ce qu'on en fait sont séparés.

En programmation orientée objet, on les regroupe. En C++, l'outil pour cela est la classe : elle réunit les données et les opérations qui leur sont associées.

C++
#include <iostream>
using namespace std;

class Capteur {
public:
    int temperature;

    void afficher() {
        cout << "Temperature : "
             << temperature << " degres" << endl;
    }
};

int main()
{
    Capteur c;
    c.temperature = 25;
    c.afficher();
    return 0;
}
sortie réelle
Temperature : 25 degres
Quatre mots, et ce qu'ils désignent dans ce programme
MotIciC'est…
classeCapteurle modèle : ce que tout capteur possède et sait faire
attributtemperatureune donnée rangée dans l'objet
méthodeafficher()une fonction qui appartient à la classe
objetcun capteur précis, fabriqué d'après le modèle
💡 Vous avez déjà vu la moitié de l'idée : la struct

Une struct du C regroupait déjà des données de types différents (chapitre 12, section 27). La classe va plus loin : elle range aussi les fonctions avec les données.

La méthode afficher() lit temperature directement, sans qu'on la lui passe en paramètre, parce qu'elles sont dans le même objet.

Et le point de c.temperature est celui de la structure : « le champ temperature de c ».

⚠️ Le point-virgule après l'accolade de la classe

Comme pour une struct, la définition d'une classe se termine par };. L'oublier provoque une erreur de compilation souvent signalée… à la ligne suivante.

03Ce que la POO apporte

AvantageCe que cela veut dire
Organisationle programme est structuré en classes et en objets
Réutilisationune classe sert dans plusieurs parties d'un programme, ou dans un autre
Maintenancele code est plus facile à comprendre et à modifier : s'il est bien conçu
Évolutivitéajouter une fonctionnalité est plus simple quand l'organisation s'y prête
Modélisationle programme représente directement les éléments du système : un routeur, un capteur, un compte

« S'il est bien conçu » n'est pas une précaution de style : une mauvaise découpe en classes rend un programme plus difficile à lire qu'une bonne découpe en fonctions. La POO est un outil, pas une garantie.

04Les quatre principes fondamentaux

Quatre idées font la POO. Elles seront étudiées une par une dans les chapitres suivants ; il suffit pour l'instant de savoir les nommer et de reconnaître un exemple.

PrincipeDéfinitionExemple
Encapsulationregrouper les données et les méthodes, tout en contrôlant l'accès aux donnéesprotéger les informations d'un compte utilisateur
Abstractionne présenter que les caractéristiques utiles d'un objet, en masquant les détails internesutiliser un équipement réseau sans connaître tous ses mécanismes internes
Héritagecréer une classe spécialisée à partir d'une classe existantecréer une classe Routeur à partir d'une classe EquipementReseau
Polymorphismepermettre à une même opération d'avoir des comportements différents selon l'objetafficher l'état d'un serveur ou d'un routeur avec une opération commune
🧠 Les quatre, sur une box Internet

Encapsulation : le mot de passe d'administration est dans la box, et on ne peut le changer que par son interface.

Abstraction : on la branche et elle marche, sans savoir comment elle négocie avec l'opérateur. Héritage : une « box fibre » est une box, avec en plus un module optique.

Polymorphisme : « redémarrer » marche sur toutes les box, mais chaque modèle le fait à sa façon.

💡 Les mêmes idées, déjà vues en Python

Classes, encapsulation, héritage et polymorphisme ont été travaillés en Python (chapitre 8). Les principes sont les mêmes ; ce qui change en C++, c'est l'écriture : les types déclarés, public:, le point-virgule.

05Les bibliothèques : #include

Une bibliothèque est un ensemble de fonctionnalités déjà écrites et mises à disposition des programmeurs : des fonctions, des classes, des types de données, des constantes, des outils.

On réutilise ce code au lieu de tout programmer à partir de zéro.

🛠️ La syntaxe
C++
#include <nom_bibliotheque>

#include <iostream>       // entrees et sorties : cout, cin

Le préprocesseur traite cette directive avant la compilation : il insère à sa place ce que la bibliothèque déclare. C'est le même mécanisme que #include <stdio.h> en C.

Les bibliothèques standard les plus utilisées
BibliothèqueRôleSon équivalent en C
<iostream>entrées et sorties standard<stdio.h>
<string>chaînes de caractères<string.h>
<cmath>fonctions mathématiques<math.h>
<iomanip>mise en forme de l'affichageles formats de printf
<fstream>lecture et écriture de fichiersfopen, fprintf…
<vector>tableaux dynamiquesmalloc et un tableau
<cstdlib>fonctions générales et conversions<stdlib.h>

Les bibliothèques du C++ s'écrivent sans .h. Et la troisième colonne n'est pas une curiosité : un programme C++ peut encore utiliser printf, mais on ne mélange pas les deux styles dans un même affichage.

06L'espace de noms std

Un espace de noms (namespace) regroupe des éléments sous un même nom. Il sert à éviter les conflits : deux bibliothèques peuvent chacune avoir une fonction afficher sans se gêner, si elles sont dans deux espaces différents.

La bibliothèque standard du C++ range tout dans un espace appelé std, notamment cout, cin, endl et string. Pour s'en servir, on précise l'espace devant chaque nom, avec l'opérateur :: :

C++
#include <iostream>

int main()
{
    std::cout << "Bonjour BTS CIEL" << std::endl;
    return 0;
}
sortie réelle
Bonjour BTS CIEL

std désigne l'espace de noms standard · :: est l'opérateur de résolution de portée · cout affiche · endl passe à la ligne.

Pour ne pas répéter std:: partout, on écrit une fois using namespace std; :

C++
#include <iostream>
using namespace std;

int main()
{
    cout << "Bonjour BTS CIEL" << endl;
    return 0;
}
sortie réelle
Bonjour BTS CIEL

Les deux écritures sont correctes et donnent exactement le même programme.

💡 Pourquoi les professionnels écrivent souvent std::

using namespace std; fait entrer tous les noms de la bibliothèque standard : il y en a des centaines. Dans un petit programme d'exercice, c'est pratique.

Dans un gros projet, cela peut créer exactement les conflits que l'espace de noms devait éviter. D'où les deux usages, qu'il faut savoir lire.

07Le squelette d'un programme C++

C++
#include <iostream>
#include <string>
using namespace std;

int main()
{
    // Declaration des variables

    // Instructions du programme

    return 0;
}

Les bibliothèques d'abord, puis l'espace de noms, puis main. Le fichier s'enregistre avec l'extension .cpp, et non .c, que le compilateur traiterait comme du C.

💡 Ce qui ne change pas depuis le C

int main(), return 0;, les { }, le ; à la fin de chaque instruction, les types int, float, char, les if, for, while : tout ce qui a été appris en C s'écrit de la même façon en C++. Ce qui change d'abord, c'est l'affichage et la saisie.

08Afficher : cout et <<

cout est le flux de sortie standard : ce qu'on lui envoie apparaît à l'écran. On envoie avec <<, l'opérateur d'insertion.

🛠️ La syntaxe
C++
cout << expression;
C++
#include <iostream>
using namespace std;

int main()
{
    cout << "Bienvenue en C++";
    return 0;
}
sortie réelle
Bienvenue en C++

Pour afficher une variable, on l'insère à la suite, et on peut enchaîner autant de << qu'on veut :

C++
#include <iostream>
using namespace std;

int main()
{
    int age = 20;
    float moyenne = 15.5;

    cout << "Age : " << age << endl;
    cout << "Moyenne : " << moyenne << endl;
    return 0;
}
sortie réelle
Age : 20
Moyenne : 15.5
💡 Plus de code de format

printf demandait de dire le type : %d, %f. cout le devine d'après la variable. Contrepartie : 15.5 s'affiche 15.5, et non 15.50 comme avec %.2f.

Pour fixer le nombre de décimales, il faut <iomanip> : cout << fixed << setprecision(2) << moyenne.

Passer à la ligne : endl ou \n

C++
cout << "Premiere ligne" << endl;
cout << "Deuxieme ligne" << endl;
sortie réelle
Premiere ligne
Deuxieme ligne
C++
cout << "Premiere ligne\n";
cout << "Deuxieme ligne\n";
sortie réelle
Premiere ligne
Deuxieme ligne

Les deux passent à la ligne. endl fait en plus vider immédiatement l'affichage ; pour un exercice, la différence ne se voit pas.

⚠️ cout n'ajoute aucun espace

cout << "Age :" << age affiche Age :20. Les espaces sont à mettre dans les guillemets : "Age : ".

09Lire : cin et >>

cin est le flux d'entrée standard : il récupère ce qui est tapé au clavier. On le lit avec >>, l'opérateur d'extraction, qui range la valeur dans une variable.

🛠️ La syntaxe · les chevrons pointent vers la variable
C++
cin >> variable;
C++
#include <iostream>
using namespace std;

int main()
{
    int age;

    cout << "Saisir votre age : ";
    cin >> age;
    cout << "Votre age est : " << age << endl;
    return 0;
}
sortie réelle · saisies : 20
Saisir votre age : Votre age est : 20

Pas de & : cin sait écrire dans la variable sans qu'on lui donne son adresse. C'est l'une des premières simplifications par rapport à scanf.

🔧 Corrigé · des guillemets droits, et la ligne affichée qui va avec

L'exemple du cours écrit cout << « votre age est " << age : il ouvre la chaîne par un guillemet français «.

Le compilateur ne connaît que le guillemet droit " et refuse le programme. (C'est souvent un traitement de texte qui remplace les guillemets tout seul.)

C++ · ne compile pas
#include <iostream>
using namespace std;

int main()
{
    int age;
    cout << "Saisir votre age : ";
    cin >> age;
    cout << « votre age est " << age << endl;
    return 0;
}

L'exécution annoncée, Votre age est : 20, avec une majuscule et deux points, ne correspondait pas non plus au texte du programme. L'exemple corrigé ci-dessus écrit la chaîne qui donne cette ligne.

On peut lire plusieurs valeurs d'un coup, en enchaînant les >>. Elles se tapent séparées par une espace ou par Entrée :

C++
#include <iostream>
using namespace std;

int main()
{
    int a, b;

    cout << "Saisir deux entiers : ";
    cin >> a >> b;
    cout << "Somme : " << a + b << endl;
    return 0;
}
sortie réelle · saisies : 10 puis 5
Saisir deux entiers : Somme : 15

10Les chaînes : string et getline

Le C++ a un vrai type chaîne : string, fourni par <string>. Plus de tableau de char à dimensionner, plus de '\0' à prévoir : la chaîne prend la taille dont elle a besoin.

C++
#include <iostream>
#include <string>
using namespace std;

int main()
{
    string nom;

    cout << "Saisir votre nom : ";
    cin >> nom;
    cout << "Nom : " << nom << endl;
    return 0;
}
sortie réelle · saisies : BTS CIEL
Saisir votre nom : Nom : BTS

Tapé BTS CIEL, lu BTS : comme scanf("%s"), cin >> s'arrête au premier espace. Pour lire une ligne entière, espaces compris, on utilise getline :

🛠️ La syntaxe
C++
getline(cin, variable);
C++
#include <iostream>
#include <string>
using namespace std;

int main()
{
    string nom;

    cout << "Saisir votre nom complet : ";
    getline(cin, nom);
    cout << "Nom complet : " << nom << endl;
    return 0;
}
sortie réelle · saisies : Jean Dupont
Saisir votre nom complet : Nom complet : Jean Dupont
Saisie : BTS CIEL
InstructionCe qu'elle faitValeur récupérée
cin >> nomlit une valeur, s'arrête au premier espace ou caractère blanc, laisse le retour à la ligne dans le fluxBTS
getline(cin, nom)lit la ligne complète, espaces compris, et s'arrête au \nBTS CIEL

C'est le même couple qu'en C : scanf("%s") s'arrêtait à l'espace, fgets lisait la ligne entière (chapitre 12, section 34).

11Le piège : getline après cin

Ce programme semble juste. Il demande un âge, puis un nom complet :

C++
#include <iostream>
#include <string>
using namespace std;

int main()
{
    int age;
    string nom;

    cout << "Age : ";
    cin >> age;
    cout << "Nom complet : ";
    getline(cin, nom);
    cout << "[" << nom << "]" << endl;
    return 0;
}
sortie réelle · saisies : 20 puis Jean Dupont
Age : Nom complet : []

Le programme ne laisse pas le temps de taper le nom : nom reste vide. Que s'est-il passé ? L'utilisateur a tapé 20 puis Entrée.

La touche Entrée ajoute un caractère \n dans le flux d'entrée. cin >> age prend le 20… et laisse le \n.

La solution : cin.ignore(); juste après le cin >>. Elle retire le caractère resté dans le flux.

C++
#include <iostream>
#include <string>
using namespace std;

int main()
{
    int age;
    string nom;

    cout << "Age : ";
    cin >> age;
    cin.ignore();                 // retire le \n laisse par la touche Entree
    cout << "Nom complet : ";
    getline(cin, nom);
    cout << "[" << nom << "]" << endl;
    return 0;
}
sortie réelle · saisies : 20 puis Jean Dupont
Age : Nom complet : [Jean Dupont]
  1. cin >> age récupère l'âge ;
  2. cin.ignore() supprime le retour à la ligne ;
  3. getline() attend vraiment la saisie du nom complet.
💡 cin.ignore() n'enlève qu'UN caractère

Si l'utilisateur tape 20, puis une espace, puis Entrée, il reste deux caractères : l'espace et le \n. cin.ignore() retire l'espace, et getline retombe sur le \n : le nom est de nouveau vide. Vérifié au compilateur.

Deux écritures règlent aussi ce cas : cin >> ws; (« saute tous les blancs ») ou cin.ignore(numeric_limits<streamsize>::max(), '\n'); (« jette tout jusqu'au retour à la ligne », avec <limits>). Pour les exercices du cours, cin.ignore() suffit.

La règle à retenir : un getline qui suit un cin >> doit être précédé d'un cin.ignore(). Deux getline de suite, eux, n'en ont pas besoin.

⚡ Récap 2 minutes

Les idées de la POO

  • Objet = des attributs (ce qu'il est) + des méthodes (ce qu'il fait).
  • Classe = le modèle ; objet = un exemplaire. Capteur c; fabrique l'objet c.
  • Procédural : données et fonctions séparées (le C). Objet : regroupées dans la classe (le C++).
  • Les quatre principes : encapsulation (regrouper et protéger), abstraction (montrer l'utile), héritage (spécialiser une classe), polymorphisme (une opération, plusieurs comportements).
  • La classe se ferme par };, comme une struct.

Les bases du C++

  • #include <iostream>, sans .h ; fichier en .cpp.
  • std::cout ou using namespace std; puis cout : les deux sont justes.
  • cout << affiche, cin >> lit : les chevrons pointent dans le sens où va la donnée.
  • Ni code de format, ni & : le type est deviné.
  • endl ou \n pour passer à la ligne.
  • Des guillemets droits ", jamais « » ni les guillemets courbes d'un traitement de texte.
  • cin >> s'arrête à l'espace, getline(cin, nom) lit la ligne.
  • cin >> age; puis getline → il faut cin.ignore(); entre les deux, sinon le nom reste vide.
