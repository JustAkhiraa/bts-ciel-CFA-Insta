1Dans la POO, comment appelle-t-on les informations qui décrivent un objet ?

Les attributs décrivent l'objet (une marque, une quantité de RAM, un état) ; les méthodes sont les actions qu'il sait faire.

2Dans Capteur c; c.afficher();, que désigne c ?

Capteur est la classe, le modèle ; c est un objet, un capteur précis fabriqué d'après ce modèle.

3Qu'est-ce qui distingue une classe C++ d'une struct du C ?

Une struct regroupait déjà des données. La classe range aussi les fonctions, les méthodes, qui s'en servent. Et elle se ferme aussi par };.

4Créer une classe Routeur à partir d'une classe EquipementReseau illustre quel principe ?

L'héritage crée une classe spécialisée à partir d'une classe existante : un routeur EST un équipement réseau, avec quelque chose en plus.

5Afficher l'état d'un serveur ou d'un routeur avec une opération commune, qui se comporte différemment selon l'objet, c'est…

Le polymorphisme : une même opération, plusieurs comportements selon l'objet sur lequel on l'appelle.

6À quoi sert using namespace std; ?

Les éléments de la bibliothèque standard sont rangés dans l'espace de noms std. La directive permet de les écrire sans le préfixe std::. L'inclusion, elle, reste le rôle de #include.

7Comment s'appelle l'opérateur :: dans std::cout ?

:: est l'opérateur de résolution de portée : « le cout qui est dans std ». << est l'insertion, >> l'extraction.

8Laquelle de ces lignes lit un entier au clavier en C++ ?

On lit avec cin et l'opérateur d'extraction >> : les chevrons pointent vers la variable. Pas de & comme avec scanf, et scanf ne s'utilise pas avec >>.

9float moyenne = 15.5; cout << moyenne; affiche…

cout n'affiche pas de décimales inutiles : 15.5. Pour en imposer deux, il faut fixed et setprecision(2) de <iomanip>.

10L'utilisateur tape BTS CIEL. Que contient nom après cin >> nom; ?

cin >> s'arrête au premier espace : seul BTS est lu. Pour la ligne entière, c'est getline(cin, nom).

11Après cin >> age;, un getline(cin, nom); rend une chaîne vide. Pourquoi ?

cin >> age prend le nombre et laisse le \n. getline le trouve immédiatement : pour lui, la ligne est finie. D'où le cin.ignore(); entre les deux.

12Pourquoi cout << « votre age est " << age; ne compile-t-il pas ?

Le C++ ne connaît que le guillemet droit ". Un «, souvent inséré tout seul par un traitement de texte, n'ouvre aucune chaîne, et le compilateur refuse.

13Une classe est déclarée sans public:. Dans main, on écrit pc1.marque = "Alpha";. Que se passe-t-il ?

Dans une class, tout est privé par défaut. Le compilateur répond 'marque' is a private member of 'Ordinateur'.

14Comment appelle-t-on la création d'un objet à partir d'une classe ?

Ordinateur pc1; instancie la classe : pc1 est une instance de Ordinateur.

15Quelle ligne appelle la méthode afficherInformations de l'objet pc1 ?

L'opérateur point, puis les parenthèses : c'est un appel de fonction.

16Dans void Ordinateur::afficher(), que signifie :: ?

:: est l'opérateur de résolution de portée : il rattache la définition à sa classe.

17Le compilateur affiche expected ';' after class. Que manque-t-il ?

Une classe se ferme par };, comme une struct.

18Quel spécificateur rend un attribut accessible uniquement depuis l'intérieur de sa classe ?

private ferme l'attribut à tout ce qui n'est pas la classe. protected l'ouvre en plus aux classes dérivées, public à tout le monde.

19marque est un attribut private. Que fait le compilateur devant pc.marque = "Alpha"; écrit dans main() ?

La faute est attrapée à la compilation (« is a private member of »). Un programme qui touche à un attribut privé depuis l'extérieur ne peut même pas être lancé.

20Dans une class, sans aucun spécificateur d'accès, les membres sont :

Dans une classe, tout est privé par défaut : seul le code de la classe y touche. C'est l'inverse d'une struct, publique par défaut.

21À quoi sert un getter ?

get veut dire récupérer : int getMemoireRAM() { return memoireRAM; } lit la valeur sans donner d'accès direct à l'attribut. C'est le setter qui modifie.

22setMemoireRAM n'accepte que ram > 0. Après pc1.setMemoireRAM(16); puis pc1.setMemoireRAM(-8);, que vaut la mémoire ?

Le second appel est refusé : le setter affiche son message et ne touche pas à l'attribut. La valeur acceptée avant, 16, reste en place.

23Pourquoi la méthode publique afficherInformations() peut-elle lire l'attribut privé marque ?

Le privé ferme la classe à l'extérieur, pas à ses propres méthodes. Toute méthode de la classe, publique ou privée, voit ses attributs privés.

24Un membre protected est accessible :

protected se place entre les deux : fermé depuis main() comme private, mais ouvert aux classes filles. La différence n'apparaît qu'avec l'héritage.

25Quel est le bon getter pour l'attribut float valeur; ?

Un getter ne prend rien et renvoie la valeur : son type de retour est celui de l'attribut, float. Un type void ne pourrait rien renvoyer.
