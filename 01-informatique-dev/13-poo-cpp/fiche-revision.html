POO en C++

Les idées de la POO et les bases du C++ sur une seule fiche. À relire la veille. Le cours · Les exercices

⚡ Les quatre mots

classe → le modèle · Capteur
objet → un exemplaire · Capteur c;
attribut → ce qu'il EST · c.temperature
méthode → ce qu'il FAIT · c.afficher()

La classe se ferme par };, comme une struct.

Procédural ou objet

Procédural (le C) : les données d'un côté, les fonctions de l'autre.

Objet (le C++) : la classe regroupe les données et les fonctions qui s'en servent.

⚡ Les quatre principes

Encapsulation → regrouper, et contrôler l'accès
Abstraction → ne montrer que l'utile
Héritage → une classe à partir d'une autre
Polymorphisme → une opération, plusieurs comportements

Routeur hérite d'EquipementReseau · « afficher l'état » marche sur un serveur comme sur un routeur.

Organisation · réutilisation · maintenance · évolutivité · modélisation : à condition que les classes soient bien découpées.

⚡ Le squelette C++

#include <iostream>
#include <string>
using namespace std;
int main() { … return 0; }

Fichier en .cpp. Bibliothèques sans .h.

L'espace de noms std

std::cout << "Bonjour" << std::endl;
using namespace std; → cout << "Bonjour" << endl;

:: = opérateur de résolution de portée. Les deux formes sont justes.

⚡ Afficher et lire

cout << "Age : " << age << endl; ← insertion
cin >> age; ← extraction
cin >> a >> b; ← deux valeurs

Ni %d, ni &. endl ou \n pour la ligne.

string, cin et getline

Saisie « BTS CIEL »
cin >> nom → BTS (s'arrête à l'espace)
getline(cin, nom) → BTS CIEL (toute la ligne)

⚠️ Le piège de getline après cin

cin >> age;
cin.ignore(); ← retire le \n laissé par Entrée
getline(cin, nom);

Sans cin.ignore(), getline trouve le \n et rend une chaîne vide.

Une espace avant Entrée suffit à le déjouer : cin >> ws; règle les deux cas.

⚠️ Des guillemets droits

"texte" compile ; « texte » et les guillemets courbes d'un traitement de texte, non.

⚡ Classes et objets

class Ordinateur
{
public:
    string marque;
    void afficher();
};
  • Le ; final est obligatoire.
  • Privé par défaut : sans public:, main ne touche pas aux attributs.
  • Ordinateur pc1; crée l'objet ; pc1.marque et pc1.afficher() s'en servent.
  • void Ordinateur::afficher() { ... } : la méthode, définie hors de la classe.
