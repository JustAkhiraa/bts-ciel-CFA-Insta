⚡ <a> ou <button>

<a> = aller quelque part
<button> = déclencher

Jamais l'un dans l'autre : deux contenus interactifs imbriqués sont interdits par la spécification.

html
✘ <button><a href="#x">Voir</a></button>
✔ <a class="bouton" href="#x">Voir</a>

Un lien s'habille en bouton avec display: inline-block + padding.

Flexbox — aligner une file

css
.menu {
  display: flex;
  justify-content: center;  /* axe principal */
  align-items: center;      /* axe secondaire */
  gap: 30px;
  margin: 0; padding: 0;    /* un <ul> en a par défaut */
}
.menu li { list-style: none; }

flex-wrap: wrap autorise le passage à la ligne ; flex-shrink: 0 empêche un élément de se comprimer.

⚡ Grid — la ligne à retenir

repeat(auto-fit,
minmax(220px, 1fr))

« Autant de colonnes que possible, d'au moins 220 px, le reste partagé. »

1000 px4 colonnes
700 px3 colonnes
480 px2 colonnes
375 px1 colonne

Responsive sans media query.

auto-fit ≠ auto-fill

auto-fitreplie les colonnes vides → les cartes s'étalent
auto-fillgarde les colonnes vides → les cartes restent serrées à gauche

Pour un CV : auto-fit.

minmax(min, max) — dans cet ordre. minmax(1fr, 220px) est invalide et la règle est ignorée.

⚡ Dimensionner une image

Une dimension → l'autre suit
Deux dimensions → object-fit: cover
css
/* vignette régulière */
img {
  width: 100%;
  aspect-ratio: 16 / 10;
  object-fit: cover;
  display: block;
}

Sur le web, une image se dimensionne en %, jamais en pixels figés. display: block supprime l'espace fantôme sous l'image.

Fonds et voiles

css
header {
  background-image:
    linear-gradient(rgba(0,0,0,.55),
                    rgba(0,0,0,.55)),
    url("asset/background.jpg");
  background-size: cover;
  background-position: center;
}

La première couche déclarée est celle du dessus. Sans background-size, l'image se répète en mosaïque.

⚡ Les 3 conditions du responsive

  1. <meta name="viewport" content="width=device-width, initial-scale=1.0">
  2. *, *::before, *::after { box-sizing: border-box; }
  3. des dimensions souples : %, fr, minmax(), max-width

Les media queries vont à la fin du fichier : à spécificité égale, la dernière règle gagne.

La media query type

css
@media (max-width: 768px) {
  .menu { flex-wrap: wrap; height: auto; }
  header { min-height: 55vh; }
  .content-a-propos { flex-direction: column;
                      text-align: center; }
  fieldset { padding: 20px; }
}

Une media query ne sert qu'à ce que le contenu ne peut pas régler seul.

Nommer les fichiers

minuscules · sans accent
sans espace · tiret

Les serveurs web distinguent majuscules et minuscules, contrairement à macOS et Windows : PP.jpg pour un fichier pp.jpg marche chez vous et nulle part ailleurs.

⚡ Les 7 contrôles avant de rendre

  1. Copier le dossier ailleurs et l'ouvrir — ce qu'on voit est ce que le correcteur verra.
  2. Relire le cahier des charges — les 5 blocs, le CSS externe, les noms de fichiers exacts.
  3. Validateur W3C (validator.w3.org) — imbrications interdites, id dupliqués, balises mal fermées.
  4. Console F12 — zéro erreur rouge, zéro 404 d'image.
  5. 375 px — aucune barre de défilement horizontale.
  6. Chaque lien du menu, chaque intitulé de champ — cliqués.
  7. Orthographe — titres compris : ce sont eux qu'on lit en premier.

Aucun de ces contrôles n'écrit de code. Ils rapportent pourtant plus que dix minutes de CSS supplémentaires : ils corrigent ce qui coûte des points.
