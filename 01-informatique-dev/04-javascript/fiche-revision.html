Variables

letsi ça change

Types : number, string, boolean, undefined, null, array, object.

typeof x donne le type.

⚡ Toujours ===

js
5 ==  "5"   // true  ✘
5 === "5"   // false ✔
0 ==  ""    // true  ✘

== convertit avant de comparer. === compare valeur + type.

⚡ Le piège du +

js
2 + 3          // 5
"2" + 3        // "23"  ✘
Number("2")+3  // 5     ✔

.value et prompt() rendent toujours du texte. Convertir avant de calculer.

Boucles

js
for (let i=0; i<n; i++) { }

while (cond) { }

do { } while (cond);

do…while tourne au moins une fois. Toute boucle doit faire évoluer sa condition.
