⚡ Les cardinalités

0,1au plus une fois
1,1exactement une fois
0,Nautant qu'on veut, zéro compris
1,Nau moins une fois, sans maximum

Se lit dans les deux sens, la cardinalité étant celle du côté opposé : « un USER possède 1 à N PC » · « un PC est possédé par exactement un USER ».

MaximumsTraduction
1 et Nune FK, du côté 1,1
N et Nune table intermédiaire (deux FK en PK)
1 et 1fusion, ou FK UNIQUE

⚠️ La FK descend du côté qui ne peut en avoir qu'un — une colonne ne contient qu'une valeur.

Créer

sql
CREATE TABLE etudiants (
  id     INT AUTO_INCREMENT
         PRIMARY KEY,
  nom    VARCHAR(50) NOT NULL,
  classe VARCHAR(50) NOT NULL
);

FOREIGN KEY (id_etudiant)
  REFERENCES etudiants(id)

La table référencée se crée en premier.

⚡ Le WHERE oublié

sql

DELETE FROM etudiants;

Touche toutes les lignes. Aucun avertissement, aucune annulation.

D'abord SELECT,
ensuite DELETE

Agrégats

sql
SELECT classe, COUNT(*) AS nb
FROM etudiants
GROUP BY classe
HAVING COUNT(*) > 16;

⚡ Injection SQL

php — vulnérable
"... WHERE login = '$login'"

Saisir ' OR '1'='1 → connecté sans mot de passe.

php — sûr
$r = $pdo->prepare(
  "... WHERE login = :login");
$r->execute([':login' => $x]);
Une variable dans une requête ?
prepare() + execute()
