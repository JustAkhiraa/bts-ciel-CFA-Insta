Langage C

Les deux séances sur une seule fiche : le langage, puis les fonctions et les tableaux. À relire la veille. Le cours · Les exercices

⚡ Le squelette, par cœur

C
#include <stdio.h>

int main()
{
    int age = 20;
    printf("%d\n", age);
    return 0;
}

#include donne printf/scanf · l'exécution commence à main · return 0 = tout s'est bien passé.

Trois règles de forme

  • Chaque instruction finit par ;
  • Chaque bloc tient entre { }
  • La casse compte : age ≠ Age, et Int n'existe pas

L'indentation ne fait pas la syntaxe — contrairement à Python.

⚡ printf lit · scanf écrit

C
printf("%d\n", age);      /* pas de & */
scanf("%d", &age);        /* & OBLIGATOIRE */

scanf doit ranger quelque chose dans la variable : elle a besoin de son adresse, pas de son contenu. On donne l'adresse de la boîte aux lettres, pas ce qu'il y a dedans.

Conditions

C
if (n > 0) {
    printf("positif\n");
} else if (n < 0) {
    printf("negatif\n");
} else {
    printf("nul\n");
}

Intervalle → if…else if. Liste de valeurs → switch.

switch

C
switch (choix) {
    case 1:
        printf("un\n");
        break;
    case 'o':
    case 'O':
        printf("oui\n");
        break;
    default:
        printf("autre\n");
}

Un break par case, sinon l'exécution continue en cascade. Deux case collés = regroupement volontaire.

Les trois boucles

C
while (i <= 5) { … }        /* 0 tour possible */

do { … } while (i <= 5);    /* 1 tour minimum  */

for (i = 1; i <= 5; i++) { … }

Nombre de tours connu → for · au moins un passage (saisie à valider) → do…while · sinon while.

Le ; final de do…while est obligatoire.

break = je quitte la salle · continue = je saute mon tour. goto existe : à savoir lire, à ne pas écrire.

⚡ Les huit pièges qui coûtent des points

  1. = affecte, == compare. if (a = 5) est toujours vrai et écrase a.
  2. 6 / 7 vaut 0 : entre entiers, division entière.
  3. for (…) ; — ce point-virgule vide la boucle.
  4. scanf sans & : compile parfois, plante à l'exécution.
  5. break oublié dans un switch : exécution en cascade.
  6. int somme; non initialisé : contient n'importe quoi. Écrire = 0.
  7. Code de format ≠ type de la variable : affichage aberrant, aucune alerte.
  8. Accolades omises : un if sans { } ne gouverne qu'une instruction, quelle que soit l'indentation.

⚡ L'anatomie

type_retour nom(paramètres)
{ instructions ; return valeur ; }

Quatre éléments, toujours dans cet ordre. void quand il n'y a rien à rendre.

Définition → se termine par }, sans point-virgule.

Les quatre formes

sans retouravec retour
sans par.void f()int f()
avec par.void f(int n)int f(int n)

Deux questions indépendantes : reçoit-elle ? et rend-elle ?

Paramètre ≠ argument

Paramètre — la variable de la définition.
Argument — la valeur de l'appel.

int additionner(int a, int b) → a, b paramètres
additionner(10, 20); → 10, 20 arguments

Le paramètre est le contenant, l'argument le contenu.

⚡ Le prototype

int additionner(int a, int b);

Le point-virgule est ce qui le distingue d'une définition.

Il permet d'écrire main en premier. Sans prototype, la définition doit précéder l'appel.

C'est exactement ce que contient <stdio.h> : le prototype de printf, pas son code.

Portée des variables

Locale — déclarée dans une fonction, n'existe que là, disparaît à la sortie.

Globale — déclarée hors de toute fonction, visible partout.

Bonne pratique : locale par défaut, et on passe ce dont la fonction a besoin en paramètre. Une fonction qui reçoit tout se lit seule et se réutilise.

⚡ Les tableaux

float temperatures[7];

Indices de 0 à taille − 1. La boucle s'écrit i < n, jamais i <= n.

Saisie : scanf("%f", &t[i]); — le & ne disparaît pas.

Le C ne vérifie aucun indice. Sortir du tableau ne provoque aucune erreur : juste un bogue, plus tard.

⚡ Passer un tableau

float Moyenne(float t[], int n)

Un tableau passé perd sa taille. sizeof y rend 8 — la taille d'une adresse — et non 40.

Donc : toujours n en second paramètre.

En échange, la fonction reçoit l'adresse : elle peut remplir le tableau. C'est pour ça que SaisirTableau() ne retourne rien.

Moyenne et maximum

somme = 0.0f; avant la boucle — toujours initialiser.

max = t[0]; puis boucle i = 1.

Partir de max = 0 est faux dès qu'une valeur est négative : on renverrait 0, qui n'est pas dans le tableau.

⚡ La division entière

(float) perdus / envoyes * 100

Deux int divisés donnent un int : 25 / 500 vaut 0.

Ça compile, ça tourne, et ça affiche 0.00 %.

Autre écriture juste : perdus * 100.0 / envoyes.

⚡ Les fautes silencieuses

La casse. afficherCarre ≠ affichercarre. Deux exemples du polycopié ne compilent pas pour ça.

0 <= v <= 255 compile et est toujours vraie. Il faut 0 <= v && v <= 255.

carre(4); seul — le résultat part à la poubelle.

(a + b) / 2 — sans parenthèses, la division passe avant.

%% pour afficher un pourcentage.

Écrire une fonction, dans l'ordre

1. de quoi a-t-elle besoin ? → les paramètres
2. rend-elle une valeur ? → le type, ou void
3. le corps — une seule tâche
4. l'appel — où ranger le résultat ?

Le test : une fonction se décrit en une phrase sans « et ». S'il y a un « et », il y a deux fonctions.
