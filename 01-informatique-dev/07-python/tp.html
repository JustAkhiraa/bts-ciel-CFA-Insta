Python · les TP

Les neuf TP de Python. Ceux que la fiche d'exercices corrige déjà (TP 1, 3 et 6) y renvoient ; tous les autres sont ici, question par question, avec le programme complet et sa sortie réelle.

🎯 Lancer un programme Python

Un programme Python s'écrit dans un fichier .py, et se lance sans compiler :

terminal
python3 tp2-ex1.py

Sur Windows, la commande s'appelle souvent py ou python.

Cherche chaque question avant d'ouvrir sa correction.

1TP 1 · le parc d'attractions

Les trois premiers exercices du TP 1 sont corrigés dans la fiche d'exercices :
le signe d'un produit, les catégories de niveau et le crédit logement. Reste l'exercice 4.

Un parc impose trois règles :
12 ans minimum pour l'attraction A, 16 ans minimum pour l'attraction B, et un adulte pour accompagner les moins de 18 ans.

1Lire les deux réponses Facile

1. Demander l'âge (age) et si la personne est accompagnée (accompagne), en répondant True ou False.

✅ Correction

L'âge est un nombre :
int(input(...)).
La seconde réponse, elle, reste du texte, et c'est le piège de l'exercice.

python
age = int(input("Ton âge : "))
reponse = input("Accompagné par un adulte (True/False) : ")
accompagne = reponse == "True"

On compare au mot "True" :
le résultat est un vrai booléen, True ou False.

⚠️ bool("False") vaut True

Le réflexe accompagne = bool(input(...)) ne marche pas. Toute chaîne non vide est vraie, même le mot "False" :

python · piege.py
reponse = "False"
print(bool(reponse))
print(reponse == "True")
sortie réelle
True
False

Le programme ne plante pas, il répond faux. C'est le pire des défauts : rien ne le signale.

2Décider pour A et pour B Moyen

2. Afficher si l'utilisateur peut aller à l'attraction A, à l'attraction B, ou s'il ne peut pas aller à certaines attractions.

✅ Correction

La règle des moins de 18 ans est la même pour les deux attractions :
on l'écrit une seule fois, entre parenthèses.

python
peut_a = age >= 12 and (age >= 18 or accompagne)
peut_b = age >= 16 and (age >= 18 or accompagne)

Sans les parenthèses, and passe avant or :
la ligne se lirait (age >= 12 and age >= 18) or accompagne, et un enfant de 10 ans accompagné serait accepté partout.

python · tp1-ex4.py
age = int(input("Ton âge : "))
reponse = input("Accompagné par un adulte (True/False) : ")

# input() rend du TEXTE : on compare au mot "True"
accompagne = reponse == "True"

# la règle des moins de 18 ans, écrite une seule fois
peut_a = age >= 12 and (age >= 18 or accompagne)
peut_b = age >= 16 and (age >= 18 or accompagne)

if peut_a:
    print("Tu peux aller à l'attraction A.")
if peut_b:
    print("Tu peux aller à l'attraction B.")
if not peut_a and not peut_b:
    print("Tu ne peux aller à aucune de ces attractions.")
elif not peut_a or not peut_b:
    print("Certaines attractions ne te sont pas accessibles.")
sortie réelle · saisies : 13 puis True
Ton âge : 13
Accompagné par un adulte (True/False) : True
Tu peux aller à l'attraction A.
Certaines attractions ne te sont pas accessibles.
sortie réelle · saisies : 16 puis False
Ton âge : 16
Accompagné par un adulte (True/False) : False
Tu ne peux aller à aucune de ces attractions.
sortie réelle · saisies : 20 puis False
Ton âge : 20
Accompagné par un adulte (True/False) : False
Tu peux aller à l'attraction A.
Tu peux aller à l'attraction B.

2TP 2 · les boucles

Trois boucles, et une seule question à se poser pour chacune :
sait-on combien de tours avant de commencer ? Oui : for. Non : while.

1La somme des impairs Facile

Exercice 1. Demander 10 nombres à l'utilisateur et calculer la somme des nombres impairs uniquement.

✅ Correction

Dix tours connus d'avance : for. Un nombre est impair quand le reste de sa division par 2 n'est pas nul : n % 2 != 0.

python · tp2-ex1.py
somme = 0
for i in range(10):
    n = int(input("Nombre " + str(i + 1) + " : "))
    if n % 2 != 0:
        somme = somme + n
print("Somme des nombres impairs :", somme)
sortie réelle · saisies : 1 puis 2 puis 3 puis 4 puis 5 puis 6 puis 7 puis 8 puis 9 puis 10
Nombre 1 : 1
Nombre 2 : 2
Nombre 3 : 3
Nombre 4 : 4
Nombre 5 : 5
Nombre 6 : 6
Nombre 7 : 7
Nombre 8 : 8
Nombre 9 : 9
Nombre 10 : 10
Somme des nombres impairs : 25

Impairs : 1 + 3 + 5 + 7 + 9 = 25.

2S'arrêter sur zéro Facile

Exercice 2. Demander des nombres en boucle. La boucle s'arrête quand l'utilisateur entre 0.

✅ Correction

Le nombre de tours dépend de ce qu'on tape : while. La saisie s'écrit deux fois, une avant la boucle et une à la fin du tour, sinon n garderait sa première valeur et la boucle ne s'arrêterait jamais.

python · tp2-ex2.py
n = int(input("Un nombre (0 pour arrêter) : "))
while n != 0:
    print("Reçu :", n)
    n = int(input("Un nombre (0 pour arrêter) : "))
print("Fin de la saisie.")
sortie réelle · saisies : 5 puis -3 puis 12 puis 0
Un nombre (0 pour arrêter) : 5
Reçu : 5
Un nombre (0 pour arrêter) : -3
Reçu : -3
Un nombre (0 pour arrêter) : 12
Reçu : 12
Un nombre (0 pour arrêter) : 0
Fin de la saisie.

La variante sans saisie en double :
while True:, puis if n == 0: break juste après la saisie.

3Les nombres pairs de 0 à n Facile

Exercice 3. Demander un entier n et afficher tous les nombres pairs de 0 à n.

✅ Correction

Le troisième argument de range() est le pas :
en partant de 0 et en avançant de 2, on ne tombe que sur des pairs, sans aucun test.

python · tp2-ex3.py
n = int(input("Jusqu'à quel nombre ? "))
for k in range(0, n + 1, 2):
    print(k, end=" ")
print()
sortie réelle · saisies : 10
Jusqu'à quel nombre ? 10
0 2 4 6 8 10
sortie réelle · saisies : 7
Jusqu'à quel nombre ? 7
0 2 4 6

range s'arrête avant sa borne : pour inclure n, on écrit n + 1. Avec 7, le dernier pair est 6, et c'est juste.

3TP 3 · listes et dictionnaires

Les exercices 1 à 3 sont corrigés dans la fiche d'exercices :
les listes de postes, dédupliquer des IP et le dictionnaire de matériel. Restent les exercices 4 et 5.

4Une liste de dictionnaires Moyen

Exercice 4. Une entreprise décrit chaque poste par un dictionnaire (nom, service, état), et les range dans une liste postes.

  1. Afficher le nom et le service de chaque poste.
  2. Afficher uniquement les postes en panne.
  3. Ajouter un nouveau poste à la liste.
  4. Modifier l'état du poste "PC03" en "actif".
  5. Compter et afficher le nombre total de postes.
  6. Afficher tous les postes d'un service donné (par exemple Informatique).
✅ Correction

Une liste de dictionnaires se parcourt avec for p in postes :
p est un dictionnaire, et on lit ses champs avec p["nom"].

python · tp3-ex4.py
postes = [
    {"nom": "PC01", "service": "Comptabilité", "etat": "actif"},
    {"nom": "PC02", "service": "RH", "etat": "actif"},
    {"nom": "PC03", "service": "Informatique", "etat": "en panne"},
    {"nom": "PC04", "service": "Marketing", "etat": "actif"},
    {"nom": "PC05", "service": "Direction", "etat": "en panne"}
]

# 1. le nom et le service de chaque poste
for p in postes:
    print(p["nom"], ":", p["service"])

# 2. les postes en panne
print("En panne :")
for p in postes:
    if p["etat"] == "en panne":
        print("-", p["nom"])

# 3. ajouter un poste
postes.append({"nom": "PC06", "service": "Informatique", "etat": "actif"})

# 4. PC03 repasse en actif
for p in postes:
    if p["nom"] == "PC03":
        p["etat"] = "actif"

# 5. le nombre de postes
print("Nombre de postes :", len(postes))

# 6. les postes d'un service
service = "Informatique"
print("Service", service, ":")
for p in postes:
    if p["service"] == service:
        print("-", p["nom"], "(" + p["etat"] + ")")
sortie réelle
PC01 : Comptabilité
PC02 : RH
PC03 : Informatique
PC04 : Marketing
PC05 : Direction
En panne :
- PC03
- PC05
Nombre de postes : 6
Service Informatique :
- PC03 (actif)
- PC06 (actif)

Question 4 :
p n'est pas une copie du poste, c'est le poste lui-même. Modifier p["etat"] modifie donc la liste.

On cherche PC03 par son nom plutôt que d'écrire postes[2] :
l'indice changerait le jour où un poste est inséré avant lui.

5Les comptes utilisateurs Facile

Exercice 5. Les comptes sont rangés dans un dictionnaire utilisateurs :
la clé est le nom, la valeur le statut.

  1. Afficher chaque utilisateur et son statut.
  2. Ajouter un nouvel utilisateur.
  3. Modifier le statut d'un utilisateur existant.
  4. Compter les comptes actifs et inactifs.
✅ Correction

.items() rend des couples (clé, valeur), qu'on sépare directement dans la boucle :
for nom, statut in utilisateurs.items().

Ajouter et modifier s'écrivent de la même façon, utilisateurs[cle] = valeur :
la clé existe, elle est remplacée ; sinon, elle est créée.

python · tp3-ex5.py
utilisateurs = {
    "admin": "actif",
    "jdupont": "actif",
    "mmartin": "inactif"
}

# 1. chaque utilisateur et son statut
for nom, statut in utilisateurs.items():
    print(nom, ":", statut)

# 2. ajouter un utilisateur
utilisateurs["lbernard"] = "inactif"

# 3. modifier un statut existant
utilisateurs["mmartin"] = "actif"

# 4. compter
actifs = 0
inactifs = 0
for statut in utilisateurs.values():
    if statut == "actif":
        actifs = actifs + 1
    else:
        inactifs = inactifs + 1
print("Actifs :", actifs)
print("Inactifs :", inactifs)
sortie réelle
admin : actif
jdupont : actif
mmartin : inactif
Actifs : 3
Inactifs : 1

4TP 4 · tuples et sets

Deux structures qui ressemblent à la liste, et qui refusent chacune quelque chose :
le tuple refuse d'être modifié, le set refuse les doublons et n'a pas d'ordre.

1Un serveur dans un tuple Moyen

  1. Créer le tuple ("SRV-DB2", "10.0.0.25", "Ubuntu", 8) dans la variable serveur.
  2. Afficher le nom, l'adresse IP et le nombre de CPU.
  3. Remplacer "Ubuntu" par "CentOS".
  4. Ajouter l'élément "v9".
  5. Supprimer "v9".
  6. Afficher le tuple final.
✅ Correction

Les questions 3 à 5 sont un piège : un tuple ne se modifie pas. Essayer donne une erreur :

python · essai.py
serveur = ("SRV-DB2", "10.0.0.25", "Ubuntu", 8)
serveur[2] = "CentOS"
sortie réelle
Traceback (most recent call last):
  File "essai.py", line 2, in <module>
    serveur[2] = "CentOS"
    ~~~~~~~^^^
TypeError: 'tuple' object does not support item assignment

On ne modifie pas le tuple :
on en fabrique un nouveau avec les morceaux de l'ancien. Les tranches découpent, le + recolle.

python · tp4-ex1.py
# 1.
serveur = ("SRV-DB2", "10.0.0.25", "Ubuntu", 8)

# 2.
print("Nom :", serveur[0])
print("IP :", serveur[1])
print("CPU :", serveur[3])

# 3. on fabrique un NOUVEAU tuple avec les morceaux de l'ancien
serveur = serveur[:2] + ("CentOS",) + serveur[3:]
print("Après 3 :", serveur)

# 4. ajouter "v9"
serveur = serveur + ("v9",)
print("Après 4 :", serveur)

# 5. retirer le dernier élément
serveur = serveur[:-1]

# 6.
print("Tuple final :", serveur)
sortie réelle
Nom : SRV-DB2
IP : 10.0.0.25
CPU : 8
Après 3 : ('SRV-DB2', '10.0.0.25', 'CentOS', 8)
Après 4 : ('SRV-DB2', '10.0.0.25', 'CentOS', 8, 'v9')
Tuple final : ('SRV-DB2', '10.0.0.25', 'CentOS', 8)

La virgule de ("CentOS",) est obligatoire :
sans elle, ("CentOS") est une simple chaîne entre parenthèses, et le + échoue.

Autre chemin :
l = list(serveur), on modifie la liste, puis serveur = tuple(l).

2Les ports, dans un set Moyen

  1. Créer le set ports_actifs avec 21, 53, 110, 443, 21 (observer le doublon 21).
  2. Afficher le set et sa taille.
  3. Ajouter le port 25.
  4. Supprimer le port 110.
  5. Vérifier si le port 53 est présent.
  6. Créer ports_autorises = {21, 53, 443}.
  7. Afficher les ports communs, les ports actifs non autorisés, et tous les ports réunis.
  8. Afficher le set final.
✅ Correction

Cinq valeurs écrites, quatre gardées :
le doublon 21 disparaît sans un mot. Les trois opérations s'écrivent avec des symboles :
& (communs), - (dans l'un mais pas l'autre), | (tout réunir).

python · tp4-ex2.py
# 1.
ports_actifs = {21, 53, 110, 443, 21}

# 2.
print("Ports actifs :", ports_actifs)
print("Nombre de ports :", len(ports_actifs))

# 3. et 4.
ports_actifs.add(25)
ports_actifs.remove(110)

# 5.
print("Le port 53 est présent :", 53 in ports_actifs)

# 6.
ports_autorises = {21, 53, 443}

# 7.
print("Communs :", ports_actifs & ports_autorises)
print("Actifs non autorisés :", ports_actifs - ports_autorises)
print("Tous réunis :", ports_actifs | ports_autorises)

# 8.
print("Set final :", ports_actifs)
sortie réelle
Ports actifs : {443, 53, 21, 110}
Nombre de ports : 4
Le port 53 est présent : True
Communs : {21, 443, 53}
Actifs non autorisés : {25}
Tous réunis : {21, 53, 25, 443}
Set final : {53, 21, 25, 443}

L'ordre d'affichage d'un set n'est pas garanti :
il ne suit ni l'ordre d'écriture, ni l'ordre croissant. Pour un affichage stable, sorted(ports_actifs).

3Serveurs, ports et configuration Difficile

Dix-huit questions, en trois temps.

Tuples et liste (1 à 7). Créer trois tuples (SRV-APP1, SRV-DB2, SRV-FILE1), afficher seulement les noms, puis les IP, puis les CPU ; les ranger dans une liste serveurs, y ajouter SRV-MONITOR1, et tout afficher avec une boucle.

Le set des ports (8 à 12). Créer ports_ouverts avec 21, 22, 80, 443, 22, 9000 ; l'afficher ; ajouter 8080 ; retirer 9000 sans risque d'erreur ; afficher « Port <numéro> autorisé » pour chaque port.

Le dictionnaire config (13 à 18). Pour chaque serveur :
son IP, son OS, ses CPU et un set de ports. Y mettre les 4 serveurs ; afficher ceux sous Ubuntu ou Debian ; la liste des IP ; « Nom → nombre de ports » ; et les ports communs à tous les serveurs.

✅ Correction

Question 11 :
remove(9000) lève une erreur si 9000 n'y est pas ; discard(9000) ne dit rien. C'est le sens de « sans provoquer d'erreur ».

Question 14 :
for nom, ip, systeme, cpu in serveurs sépare chaque tuple en quatre variables. La variable s'appelle systeme, pas os :
os est le nom d'un module de Python, et le masquer prépare des erreurs incompréhensibles.

Question 18 :
on part des ports du premier serveur, puis on garde à chaque tour ce qui est commun (&) avec le suivant.

python · tp4-ex3.py
# 1. trois serveurs : (nom, ip, os, cpu)
srv1 = ("SRV-APP1", "10.10.1.11", "Ubuntu", 4)
srv2 = ("SRV-DB2", "10.10.1.12", "Debian", 8)
srv3 = ("SRV-FILE1", "10.10.1.13", "Windows", 2)

# 2. à 4. un seul champ à la fois
for s in (srv1, srv2, srv3):
    print("Nom :", s[0])
for s in (srv1, srv2, srv3):
    print("IP :", s[1])
for s in (srv1, srv2, srv3):
    print("CPU :", s[3])

# 5. et 6. la liste, puis un quatrième serveur
serveurs = [srv1, srv2, srv3]
serveurs.append(("SRV-MONITOR1", "10.10.1.20", "Ubuntu", 2))

# 7.
for s in serveurs:
    print(s)

# 8. à 12. le set des ports
ports_ouverts = {21, 22, 80, 443, 22, 9000}

ports_ouverts.add(8080)
ports_ouverts.discard(9000)
for port in sorted(ports_ouverts):
    print("Port", port, "autorisé")

ports_du_serveur = {

    "SRV-DB2": {22, 5432},
    "SRV-FILE1": {22, 445},

config = {}

# 15. les serveurs Ubuntu ou Debian
for nom, infos in config.items():

# 16. toutes les adresses IP
adresses = []
for infos in config.values():

print(adresses)

# 17. nom -> nombre de ports ouverts
for nom, infos in config.items():
    print(nom, "→", len(infos["ports"]))

# 18. les ports communs à TOUS les serveurs
communs = None
for infos in config.values():
    if communs is None:
        communs = set(infos["ports"])
    else:
        communs = communs & infos["ports"]
print("Ports communs :", communs)

5TP 5 · les fonctions

Une fonction qui retourne une valeur ne l'affiche pas :
c'est le programme principal qui décide quoi en faire. C'est ce qui la rend réutilisable.

1L'alerte de température Facile

Exercice 1. Écrire alerte_temperature(temp) :
"OK" si temp < 70, "Attention" si temp ≤ 85, "ALERTE" au-delà. Le programme principal demande la température et affiche l'état.

✅ Correction

Les tests s'enchaînent avec elif :
arrivé au deuxième, on sait déjà que temp vaut au moins 70, inutile de le retester.

python · tp5-ex1.py
def alerte_temperature(temp):
    if temp < 70:
        return "OK"
    elif temp <= 85:
        return "Attention"
    else:
        return "ALERTE"

t = float(input("Température du CPU : "))
print("État :", alerte_temperature(t))

# vérifier les bornes, là où on se trompe
for essai in [69, 70, 85, 86]:
    print(essai, "->", alerte_temperature(essai))
sortie réelle · saisies : 78
Température du CPU : 78
État : Attention
69 -> OK
70 -> Attention
85 -> Attention
86 -> ALERTE

Les bornes sont l'endroit où l'on se trompe :
70 donne Attention, 85 aussi, 86 donne ALERTE.

2Le port autorisé Facile

Exercice 2. Écrire port_autorise(port), qui retourne True si le port est dans [22, 80, 443, 8080]. Le programme principal demande un port et affiche « Autorisé » ou « Bloqué ».

✅ Correction

port in ports vaut déjà True ou False :
on le retourne directement, sans if.

python · tp5-ex2.py
ports = [22, 80, 443, 8080]

def port_autorise(port):
    return port in ports

p = int(input("Numéro de port : "))
if port_autorise(p):
    print("Autorisé")
else:
    print("Bloqué")
sortie réelle · saisies : 443
Numéro de port : 443
Autorisé
sortie réelle · saisies : 21
Numéro de port : 21
Bloqué

3Additionner autant de nombres qu'on veut Moyen

Exercice 3. Écrire total(*args), qui additionne tous les nombres reçus :
total(1, 2, 3, 5, 8) donne 19, total(5, 10) donne 15.

✅ Correction

L'étoile range tous les arguments dans un tuple appelé args, qu'on parcourt comme n'importe quel tuple.

python · tp5-ex3.py
def total(*args):
    somme = 0
    for n in args:
        somme = somme + n
    return somme

print(total(1, 2, 3, 5, 8))
print(total(5, 10))
print(total())
sortie réelle
19
15
0

Sans argument, le tuple est vide et la boucle ne tourne pas : la somme reste 0.

4Le menu Facile

Exercice 4. Écrire menu(), qui affiche trois choix (Hello, l'heure système, quitter). Le programme principal affiche le menu, demande un choix et exécute l'action.

✅ Correction

Le choix est comparé à "1", en texte :
input() rend une chaîne, inutile de la convertir. L'heure vient du module datetime.

python · tp5-ex4.py
from datetime import datetime

def menu():
    print("1 - Afficher Hello")
    print("2 - Afficher l'heure système")
    print("3 - Quitter")

menu()
choix = input("Ton choix : ")
if choix == "1":
    print("Hello")
elif choix == "2":
    print("Il est", datetime.now().strftime("%H:%M:%S"))
elif choix == "3":
    print("Au revoir.")
else:
    print("Choix inconnu.")
sortie réelle · saisies : 1
1 - Afficher Hello
2 - Afficher l'heure système
3 - Quitter
Ton choix : 1
Hello
sortie réelle · saisies : 2
1 - Afficher Hello
2 - Afficher l'heure système
3 - Quitter
Ton choix : 2

7TP 7 · modules et packages

Un module est un fichier .py qu'un autre fichier importe. Un package est un dossier de modules, marqué par un fichier __init__.py (il peut rester vide).

🎯 Où lancer le programme

On lance main.py, le fichier du programme principal :

terminal
cd outil_admin
python3 main.py

Python cherche les modules à côté du fichier lancé :
services/ doit être dans le même dossier que main.py.

1Un premier module Facile

Exercice 1. Dans outil.py, écrire message(nom_classe), qui affiche « Bonjour <nom_classe> ». Depuis main.py, importer outil et appeler message("BTS CIEL").

✅ Correction

import outil importe le fichier outil.py, sans écrire .py. On appelle ensuite la fonction par son nom complet :
outil.message(...).

4Les calculs réseau Moyen

Exercice 4. Dans un package services, créer reseau.py avec deux fonctions :
le pourcentage de bande passante utilisée, et le temps estimé pour transférer un fichier.

Pourcentage utilisé = bande passante utilisée (Mbps) ÷ bande passante totale (Mbps) × 100.

✅ Correction

Le pourcentage ne pose pas de difficulté. Pour le temps, la taille est en mégaoctets et la vitesse en mégabits par seconde :
on multiplie par 8 pour tout mettre en bits (1 Mo = 8 Mbit), puis on divise par la vitesse.

python · services/reseau.py
def pourcentage_bande_passante(utilisee, totale):
    return utilisee / totale * 100

def temps_transfert(taille_mo, vitesse_mbps):
    # 1 Mo = 8 Mbit : la taille passe en bits, puis on divise
    return taille_mo * 8 / vitesse_mbps
python · main.py
from services.reseau import pourcentage_bande_passante, temps_transfert

print("Bande passante utilisée :", pourcentage_bande_passante(250, 1000), "%")
print("Transfert de 700 Mo à 100 Mbps :", temps_transfert(700, 100), "s")
sortie réelle
Bande passante utilisée : 25.0 %
Transfert de 700 Mo à 100 Mbps : 56.0 s

Vérification à la main :
250 sur 1000 font 25 % ; 700 Mo valent 5 600 Mbit, et 5 600 ÷ 100 = 56 secondes.

🔧 Corrigé · le temps de transfert n'est pas multiplié par 100

Le sujet écrit :
temps (s) = taille (Mo) × 8 ÷ vitesse (Mbps) × 100. Le × 100 est de trop. Il vient sans doute de la formule du pourcentage, juste au-dessus.

Avec lui, un fichier de 100 Mo sur un lien à 100 Mbps prendrait 800 secondes. Il en faut 8 :
100 × 8 = 800 Mbit, à 100 Mbit par seconde.

Temps (s) = taille (Mo) × 8 ÷ vitesse (Mbps). Rien d'autre.

💡 Un module s'exécute quand on l'importe

import outil exécute tout le fichier outil.py. Un print posé hors d'une fonction s'afficherait donc à chaque import.

C'est pour cela qu'on range les essais d'un module sous if __name__ == "__main__": :
ils ne s'exécutent que si on lance le fichier lui-même.

8TP 8 · les fichiers

Une entreprise range ses employés dans employes.txt, un par ligne :
prénom, nom et heures par semaine, séparés par ;. Le fichier peut contenir des lignes vides.

employes.txt
Alice;Dupont;35
Bob;Martin;40

Charlie;Durand;20
David;Moreau;38
🎯 Le geste qui revient dans les quatre exercices
python
with open("employes.txt", "r", encoding="utf-8") as f:
    for ligne in f:
        ligne = ligne.strip()
        if ligne == "":
            continue
        prenom, nom, heures = ligne.split(";")

with referme le fichier tout seul. strip() retire le retour à la ligne et les espaces :
une ligne vide devient "", et continue passe à la suivante.

Le nom du fichier est cherché dans le dossier d'où l'on lance le programme. Lancé depuis un autre dossier, le même programme répond FileNotFoundError :
on se place d'abord dans le dossier du TP (cd).

Attention à l'ordre :
le fichier commence par le prénom, pas par le nom.

4Les statistiques Facile

Exercice 4. Calculer le total des heures travaillées et la moyenne par employé.

✅ Correction

Deux compteurs :
la somme des heures, et le nombre d'employés vraiment lus. Les lignes vides ne comptent pas, sinon la moyenne serait fausse.

python · tp8-ex4.py
total = 0
nombre = 0

with open("employes.txt", "r", encoding="utf-8") as f:
    for ligne in f:
        ligne = ligne.strip()
        if ligne == "":
            continue
        heures = int(ligne.split(";")[2])
        total = total + heures
        nombre = nombre + 1

print("Total des heures :", total)
if nombre > 0:
    print("Moyenne :", round(total / nombre, 2), "heures par employé")
else:
    print("Aucun employé dans le fichier.")
sortie réelle
Total des heures : 133
Moyenne : 33.25 heures par employé

Sur le fichier de départ :
35 + 40 + 20 + 38 = 133 heures, et 133 ÷ 4 = 33,25. En comptant la ligne vide, on aurait divisé par 5.

9TP 9 · la gestion des erreurs

try essaie, except rattrape une erreur précise. Un script « qui ne plante jamais » n'est pas un script sans erreurs :
c'est un script qui les attend.

1Vérifier un port réseau Facile

Exercice 1. Demander un port réseau, vérifier que c'est un entier entre 1 et 65535, et afficher un message clair sinon. Le script ne doit jamais planter.

✅ Correction

Deux erreurs différentes :
« ce n'est pas un nombre » (int() lève ValueError) et « ce nombre n'est pas un port » (un simple if).

python · tp9-ex1.py
saisie = input("Port réseau : ")

try:
    port = int(saisie)
    if 1 <= port <= 65535:
        print("Port valide :", port)
    else:
        print("Erreur : un port va de 1 à 65535.")
except ValueError:
    print("Erreur :", saisie, "n'est pas un nombre entier.")
sortie réelle · saisies : 443
Port réseau : 443
Port valide : 443
sortie réelle · saisies : 70000
Port réseau : 70000
Erreur : un port va de 1 à 65535.
sortie réelle · saisies : http
Port réseau : http
Erreur : http n'est pas un nombre entier.

On attrape ValueError, pas toutes les erreurs :
un except: seul cacherait aussi une faute de frappe dans le code.

python · tp9-ex2.py
def verifier_ip(texte):
    parties = texte.split(".")
    if len(parties) != 4:
        raise ValueError("il faut quatre nombres séparés par des points")
    for p in parties:
        if not p.isdigit():
            raise ValueError(p + " n'est pas un nombre")
        if int(p) > 255:
            raise ValueError(p + " dépasse 255")


try:
    with open("ips.txt", "r", encoding="utf-8") as f:
        numero = 0
        for ligne in f:

                print("IP lue :", ligne)
            except ValueError as e:
                print("Ligne", numero, "incorrecte (" + ligne + ") :", e)
except FileNotFoundError:
    print("Erreur : le fichier ips.txt n'existe pas.")
except PermissionError:

⚡ Les TP en six réflexes

  • input() rend du texte :
    int() pour un nombre, et bool("False") vaut True.
  • Tours connus : for. Tours inconnus : while. range(n) s'arrête avant n.
  • Un tuple ne se modifie pas, on en refait un. Un set n'a ni doublon, ni ordre.
  • Une fonction retourne, le programme principal affiche.
  • Un fichier :
    with open(...), strip(), et "a" pour ajouter (jamais "w").
  • try / except sur une erreur précise, au plus près de ce qui peut échouer.
