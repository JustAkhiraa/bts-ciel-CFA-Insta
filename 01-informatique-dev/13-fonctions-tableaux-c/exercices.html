01Quatre fonctions simples

1La moyenne de deux mesures Facile

Écrire une fonction Moyenne qui reçoit deux nombres réels et retourne leur moyenne. Le programme principal doit demander deux mesures, appeler la fonction et afficher le résultat.

✅ Correction
C
#include <stdio.h>

float Moyenne(float a, float b)
{
    return (a + b) / 2;
}

int main(void)
{
    float m1, m2;

    printf("Saisir la première mesure : ");
    scanf("%f", &m1);
    printf("Saisir la deuxième mesure : ");
    scanf("%f", &m2);

    printf("\nLa moyenne est : %.2f\n", Moyenne(m1, m2));
    return 0;
}
sortie réelle — saisies : 18.5 puis 21.5
Saisir la première mesure : 18.5
Saisir la deuxième mesure : 21.5

La moyenne est : 20.00
⚠️ (a + b) / 2 et non a + b / 2

La division est prioritaire sur l'addition. Sans les parenthèses, le programme calcule a + (b / 2), soit 29,25 au lieu de 20. Il compile, il tourne, et il se trompe.

Ici les deux opérandes sont des float, donc la division est réelle. Avec des entiers, (a + b) / 2 tronquerait — c'est le piège de l'exercice 4.

2Un octet IPv4 est-il valide ? Facile

Écrire une fonction EstValide qui reçoit un entier représentant un octet d'adresse IPv4 et retourne 1 si la valeur est comprise entre 0 et 255, 0 sinon.

✅ Correction
C
#include <stdio.h>

int EstValide(int valeur)
{
    if (valeur >= 0 && valeur <= 255)
    {
        return 1;
    }
    return 0;
}

int main(void)
{
    int valeur;

    printf("Saisir une valeur : ");
    scanf("%d", &valeur);

    if (EstValide(valeur))
    {
        printf("La valeur est valide.\n");
    }
    else
    {
        printf("La valeur est invalide.\n");
    }
    return 0;
}
sortie réelle — saisies : 192
Saisir une valeur : 192
La valeur est valide.
sortie réelle — saisies : 300
Saisir une valeur : 300
La valeur est invalide.
💡 if (EstValide(valeur)) se suffit à lui-même

Écrire if (EstValide(valeur) == 1) fonctionne, mais c'est redondant : en C, toute valeur non nulle est vraie. Une fonction qui rend 1 ou 0 s'utilise directement comme condition.

C'est d'ailleurs pour cela que la consigne demande 1 et 0 plutôt que, disons, 1 et 2 : le résultat s'emboîte dans un if.

⚠️ 0 <= valeur <= 255 ne veut pas dire ce que vous croyez

Cette écriture, juste en mathématiques, est acceptée par le compilateur et toujours vraie. Le C évalue 0 <= valeur, ce qui donne 0 ou 1, puis compare ce résultat à 255 — toujours inférieur.

Il faut deux comparaisons reliées par &&. C'est une des rares fautes que le compilateur ne signale pas du tout.

3Le débit moyen d'un téléchargement Facile

Écrire une fonction CalculerDebit qui reçoit la taille d'un fichier en Mo et le temps de téléchargement en secondes, et retourne le débit moyen en Mo/s.

✅ Correction
C
#include <stdio.h>

float CalculerDebit(float taille, float temps)
{
    return taille / temps;
}

int main(void)
{
    float taille, temps;

    printf("Taille du fichier : ");
    scanf("%f", &taille);
    printf("Temps de téléchargement : ");
    scanf("%f", &temps);

    printf("\nDébit moyen : %.2f Mo/s\n", CalculerDebit(taille, temps));
    return 0;
}
sortie réelle — saisies : 120 puis 10
Taille du fichier : 120
Temps de téléchargement : 10

Débit moyen : 12.00 Mo/s
⚠️ Mo/s et Mb/s ne sont pas la même unité

L'énoncé demande des Mo/s — des méga-octets. Les débits des fournisseurs d'accès s'annoncent en Mb/s, des méga-bits. Un octet valant huit bits, 12 Mo/s font 96 Mb/s.

L'exercice 6 du même TP parle, lui, de Mb/s. Lire l'unité avant d'écrire la formule.

4Le taux de perte de paquets Moyen

Écrire une fonction CalculerTauxPerte qui reçoit le nombre de paquets envoyés et le nombre de paquets perdus, et retourne le taux de perte en pourcentage.

✅ Correction
C
#include <stdio.h>

float CalculerTauxPerte(int envoyes, int perdus)
{
    return (float) perdus / envoyes * 100;
}

int main(void)
{
    int envoyes, perdus;

    printf("Nombre de paquets envoyés : ");
    scanf("%d", &envoyes);
    printf("Nombre de paquets perdus : ");
    scanf("%d", &perdus);

    printf("\nTaux de perte : %.2f %%\n", CalculerTauxPerte(envoyes, perdus));
    return 0;
}
sortie réelle — saisies : 500 puis 25
Nombre de paquets envoyés : 500
Nombre de paquets perdus : 25

Taux de perte : 5.00 %
⚠️ Le piège de cet exercice : (float)

Les deux paramètres sont des int. En C, entier divisé par entier donne un entier : 25 / 500 vaut 0, pas 0,05. Le taux affiché serait alors 0.00 %.

La conversion (float) perdus force la division à se faire en réels.

C — les trois écritures
(float) perdus / envoyes * 100     /* juste : division réelle */
perdus * 100.0 / envoyes           /* juste aussi : 100.0 est un réel */
perdus / envoyes * 100             /* FAUX : donne 0 */

La deuxième forme marche parce que multiplier par 100.0 avant de diviser rend l'expression réelle. Les deux sont acceptables ; la troisième est l'erreur classique.

💡 Pourquoi %% dans le printf

Le caractère % introduit un format. Pour afficher un pourcentage littéral, il faut le doubler : %%. Écrire un seul % en fin de chaîne produit un affichage imprévisible.

02Trois tableaux à parcourir

5Sept températures Moyen

Un technicien relève la température d'un équipement réseau pendant 7 jours. Déclarer un tableau de 7 réels, demander les 7 températures, les afficher toutes, puis calculer et afficher la moyenne.

✅ Correction
C
#include <stdio.h>

int main(void)
{
    float temperatures[7];
    float somme = 0.0f;
    int i;

    for (i = 0; i < 7; i++)
    {
        printf("Température %d : ", i + 1);
        scanf("%f", &temperatures[i]);
        somme = somme + temperatures[i];
    }

    printf("\nTempératures relevées :\n");
    for (i = 0; i < 7; i++)
    {
        printf("%.1f  ", temperatures[i]);
    }
    printf("\n\nTempérature moyenne : %.1f °C\n", somme / 7);
    return 0;
}
sortie réelle — saisies : 21.5, 22.0, 23.5, 22.5, 21.0, 23.0, 23.5
Température 1 : 21.5
Température 2 : 22.0
Température 3 : 23.5
Température 4 : 22.5
Température 5 : 21.0
Température 6 : 23.0
Température 7 : 23.5

Températures relevées :
21.5  22.0  23.5  22.5  21.0  23.0  23.5

Température moyenne : 22.4 °C
🧭 Additionner pendant la saisie, ou après ?

Ici la somme s'accumule dans la boucle de saisie : un seul parcours suffit. On aurait pu faire une deuxième boucle pour la somme — le résultat serait identique.

Le premier choix est plus court ; le second sépare mieux « saisir » de « calculer », ce qui devient utile dès que le programme grandit. C'est exactement le raisonnement qui mène aux exercices 8 et 9.

⚠️ somme doit être initialisée

Écrire float somme; sans = 0.0f laisse la variable avec une valeur indéterminée — ce qui traînait en mémoire à cet endroit. La moyenne sera fausse, parfois de peu, parfois de beaucoup, et différemment à chaque exécution.

6Huit débits : moyenne et maximum Moyen

Un administrateur mesure le débit d'une connexion à 8 moments. Déclarer un tableau de 8 réels, saisir les valeurs, les afficher, calculer le débit moyen et déterminer le débit maximum.

✅ Correction
C
#include <stdio.h>

int main(void)
{
    float debits[8];
    float somme = 0.0f, max;
    int i;

    for (i = 0; i < 8; i++)
    {
        printf("Débit %d : ", i + 1);
        scanf("%f", &debits[i]);
        somme = somme + debits[i];
    }

    max = debits[0];
    for (i = 1; i < 8; i++)
    {
        if (debits[i] > max)
        {
            max = debits[i];
        }
    }

    printf("\nDébits mesurés :\n");
    for (i = 0; i < 8; i++)
    {
        printf("%.0f  ", debits[i]);
    }
    printf("\n\nDébit moyen : %.2f Mb/s\n", somme / 8);
    printf("Débit maximum : %.0f Mb/s\n", max);
    return 0;
}
sortie réelle — saisies : 95, 102, 98, 110, 105, 97, 115, 101
Débit 1 : 95
Débit 2 : 102
Débit 3 : 98
Débit 4 : 110
Débit 5 : 105
Débit 6 : 97
Débit 7 : 115
Débit 8 : 101

Débits mesurés :
95  102  98  110  105  97  115  101

Débit moyen : 102.88 Mb/s
Débit maximum : 115 Mb/s
⚠️ Le maximum part de debits[0], pas de zéro

Initialiser max = 0 semble naturel et marche ici, parce que tous les débits sont positifs. Mais sur des valeurs négatives — un écart, une variation — la fonction renverrait 0, une valeur absente du tableau.

Partir de la première valeur réelle et boucler à partir de i = 1 est juste dans tous les cas. C'est la forme à retenir.

7Chercher une valeur, et dire où Moyen

On considère les derniers octets de dix adresses IP. Déclarer un tableau de 10 entiers, saisir les valeurs, les afficher, demander une valeur à rechercher, indiquer si elle existe et afficher sa position.

✅ Correction
C
#include <stdio.h>

int main(void)
{
    int octets[10];
    int i, cherche, position = -1;

    for (i = 0; i < 10; i++)
    {
        printf("Valeur %d : ", i + 1);
        scanf("%d", &octets[i]);
    }

    printf("\nValeurs :\n");
    for (i = 0; i < 10; i++)
    {
        printf("%d  ", octets[i]);
    }

    printf("\n\nValeur recherchée : ");
    scanf("%d", &cherche);

    for (i = 0; i < 10; i++)
    {
        if (octets[i] == cherche)
        {
            position = i;
            break;
        }
    }

    if (position >= 0)
    {
        printf("\nLa valeur %d a été trouvée à la position %d.\n", cherche, position);
    }
    else
    {
        printf("\nLa valeur %d ne figure pas dans le tableau.\n", cherche);
    }
    return 0;
}
sortie réelle — saisies : 10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 30
Valeur 1 : 10
Valeur 2 : 15
Valeur 3 : 20
Valeur 4 : 25
Valeur 5 : 30
Valeur 6 : 35
Valeur 7 : 40
Valeur 8 : 45
Valeur 9 : 50
Valeur 10 : 55

Valeurs :
10  15  20  25  30  35  40  45  50  55

Valeur recherchée : 30

La valeur 30 a été trouvée à la position 4.
🔧 Corrigé — « position 4 », c'est l'indice, pas le rang

Dans le tableau 10 15 20 25 30 …, la valeur 30 est la cinquième. L'énoncé annonce pourtant « position 4 » : il donne donc l'indice (i), pas le rang humain.

Le programme ci-dessus affiche l'indice, pour coller exactement à l'exemple du sujet. Si le professeur attend le rang, une seule ligne change :

C — pour afficher le rang
printf("\nLa valeur %d est la %d° du tableau.\n", cherche, position + 1);

Dans un compte rendu, dites laquelle des deux vous affichez. Une ligne suffit : « la position est donnée en indice, de 0 à 9 ».

🧭 Pourquoi position = -1 au départ

Il faut une valeur qui signifie « pas encore trouvé » et qui ne puisse pas être confondue avec un indice valide. Les indices vont de 0 à 9, donc -1 convient — 0 ne conviendrait pas, c'est un indice réel.

break arrête la boucle dès la première occurrence. Sans lui, on obtiendrait la dernière position en cas de doublon.

8L'utilisation du processeur, en quatre fonctions Moyen

Un administrateur relève l'utilisation du processeur d'un serveur sur 10 mesures. Le programme doit utiliser SaisirTableau(), AfficherTableau(), CalculerMoyenne() et Maximum(), et le programme principal doit appeler ces fonctions.

✅ Correction
C
#include <stdio.h>

void  SaisirTableau(float t[], int n);
void  AfficherTableau(float t[], int n);
float CalculerMoyenne(float t[], int n);
float Maximum(float t[], int n);

int main(void)
{
    float cpu[10];

    SaisirTableau(cpu, 10);

    printf("\nUtilisation CPU :\n");
    AfficherTableau(cpu, 10);

    printf("\n\nUtilisation moyenne : %.2f %%\n", CalculerMoyenne(cpu, 10));
    printf("Utilisation maximale : %.0f %%\n", Maximum(cpu, 10));
    return 0;
}

void SaisirTableau(float t[], int n)
{
    int i;
    for (i = 0; i < n; i++)
    {
        printf("Mesure %d : ", i + 1);
        scanf("%f", &t[i]);
    }
}

void AfficherTableau(float t[], int n)
{
    int i;
    for (i = 0; i < n; i++)
    {
        printf("%.0f  ", t[i]);
    }
}

float CalculerMoyenne(float t[], int n)
{
    float somme = 0.0f;
    int i;
    for (i = 0; i < n; i++)
    {
        somme = somme + t[i];
    }
    return somme / n;
}

float Maximum(float t[], int n)
{
    float max = t[0];
    int i;
    for (i = 1; i < n; i++)
    {
        if (t[i] > max)
        {
            max = t[i];
        }
    }
    return max;
}
sortie réelle — saisies : 45, 52, 61, 70, 55, 48, 63, 72, 68, 50
Mesure 1 : 45
Mesure 2 : 52
…
Mesure 10 : 50

Utilisation CPU :
45  52  61  70  55  48  63  72  68  50

Utilisation moyenne : 58.40 %
Utilisation maximale : 72 %
🧰 Les deux choses à comprendre ici

1. SaisirTableau ne retourne rien, et pourtant elle remplit le tableau. Parce qu'elle en reçoit l'adresse : ce qu'elle écrit dans t[i] est écrit dans cpu[i]. Avec une variable simple, ce serait impossible.

2. Chaque fonction reçoit n. Un tableau passé en paramètre perd sa taille — sizeof(t) vaudrait 8, la taille d'une adresse, et non 40. Sans le second paramètre, aucune de ces boucles ne saurait où s'arrêter.

Les deux points sont démontrés dans le cours, section 8, sorties à l'appui.

💡 float t[] ou float *t : c'est pareil

Les deux écritures sont strictement équivalentes pour le compilateur. La première dit l'intention — « je reçois un tableau » — la seconde dit la réalité — « je reçois une adresse ».

Préférez float t[] en TP : elle se lit mieux, et le jour où vous verrez les pointeurs, vous saurez déjà que c'est la même chose.

9Les notes d'un groupe, en cinq fonctions Moyen

Un tableau de 10 notes sur 20. Écrire un programme utilisant SaisirNotes(), AfficherNotes(), CalculerMoyenne(), CompterAdmis() — le nombre de notes supérieures ou égales à 10 — et NoteMax().

✅ Correction
C
#include <stdio.h>

void  SaisirNotes(float t[], int n);
void  AfficherNotes(float t[], int n);
float CalculerMoyenne(float t[], int n);
int   CompterAdmis(float t[], int n);
float NoteMax(float t[], int n);

int main(void)
{
    float notes[10];

    SaisirNotes(notes, 10);

    printf("\nNotes :\n");
    AfficherNotes(notes, 10);

    printf("\n\nMoyenne : %.2f\n", CalculerMoyenne(notes, 10));
    printf("Nombre d'admis : %d\n", CompterAdmis(notes, 10));
    printf("Meilleure note : %.0f\n", NoteMax(notes, 10));
    return 0;
}

void SaisirNotes(float t[], int n)
{
    int i;
    for (i = 0; i < n; i++)
    {
        printf("Note %d : ", i + 1);
        scanf("%f", &t[i]);
    }
}

void AfficherNotes(float t[], int n)
{
    int i;
    for (i = 0; i < n; i++)
    {
        printf("%.0f  ", t[i]);
    }
}

float CalculerMoyenne(float t[], int n)
{
    float somme = 0.0f;
    int i;
    for (i = 0; i < n; i++)
    {
        somme = somme + t[i];
    }
    return somme / n;
}

int CompterAdmis(float t[], int n)
{
    int i, admis = 0;
    for (i = 0; i < n; i++)
    {
        if (t[i] >= 10)
        {
            admis = admis + 1;
        }
    }
    return admis;
}

float NoteMax(float t[], int n)
{
    float max = t[0];
    int i;
    for (i = 1; i < n; i++)
    {
        if (t[i] > max)
        {
            max = t[i];
        }
    }
    return max;
}

Note 1 : 12
Note 2 : 8
…
Note 10 : 13

12  8  15  11  9  14  16  10  7  13

⚠️ >= et non > pour les admis

« Supérieures ou égales à 10 » : la note de 10 compte. Avec >, on obtiendrait 6 admis au lieu de 7 — et rien ne le signalerait.

Contrôle de cohérence à faire de tête : dans 12 8 15 11 9 14 16 10 7 13, les notes sous 10 sont 8, 9 et 7. Trois recalés, donc sept admis. ✔

🧭 CompterAdmis retourne un int

Les quatre autres fonctions rendent des float, parce qu'elles manipulent des notes. Celle-ci compte des personnes : le type de retour suit ce qu'on compte, pas ce qu'on parcourt.

C'est le genre de détail qui se voit sur une copie : un float pour un nombre d'étudiants ferait afficher « 7.00 admis ».

10Vérifier ses résultats sans tout ressaisir Facile

Retaper dix valeurs pour contrôler un chiffre est une perte de temps — et une source d'erreurs de plus. Ce petit programme reprend les mêmes fonctions avec les données de l'énoncé déjà écrites dans le code, et affiche tous les résultats attendus d'un coup.

Compilez-le une fois, gardez-le : il vous dira en une seconde si votre version interactive calcule juste.

✅ Le programme de contrôle
C — contrôle, sans saisie

float CalculerMoyenne(float t[], int n)

    int i;
    for (i = 0; i < n; i++)
    {
        somme = somme + t[i];

    return somme / n;

💡 Pourquoi ce programme existe aussi pour le dépôt

Les neuf corrections utilisent scanf. Le contrôle du dépôt les compile et les exécute, mais il ne peut pas comparer leur affichage : un programme qui lit au clavier mélange ses questions et vos réponses, et la transcription ne correspond plus à ce qu'il écrit vraiment.

Celui-ci ne lit rien. Sa sortie est donc recomparée caractère pour caractère à chaque contrôle — et avec elle les six chiffres du TP.

Une valeur juste une fois le reste : si un jour quelqu'un retouche CompterAdmis, le dépôt le dira le jour même.

🧭 Maximum sert deux fois

La même fonction trouve le débit le plus élevé, l'utilisation CPU maximale et la meilleure note. Elle ne sait pas ce qu'elle compare — elle compare des float.

C'est tout l'intérêt du découpage : l'exercice 9 n'avait pas besoin d'une fonction NoteMax séparée, celle de l'exercice 8 suffisait. Le sujet en demande une, on la lui donne — mais son corps est identique.

04La méthode, en quatre gestes

Les neuf exercices suivent le même schéma. Une fois qu'on l'a vu, le TP se déroule tout seul.

Écrire une fonction, dans l'ordre
#GesteLa question à se poser
1Ce qu'elle reçoitde quoi a-t-elle besoin pour travailler ? → les paramètres
2Ce qu'elle rendune valeur, ou un affichage ? → le type de retour, ou void
3Le corpsle calcul, une seule tâche à la fois
4L'appeloù ranger le résultat ? → variable = fonction(…)
🧭 Le test qui dit si le découpage est bon

Une fonction doit pouvoir se décrire en une phrase sans « et ».

« Calcule la moyenne d'un tableau » — bonne fonction. « Saisit les notes et calcule la moyenne et affiche le résultat » — trois fonctions déguisées en une.

C'est précisément pour cela que l'exercice 9 en demande cinq : chacune fait une chose, et main ne fait qu'orchestrer.

⚠️ Les quatre fautes qui reviennent dans ce TP

La casse. Moyenne et moyenne sont deux fonctions différentes. Choisissez une convention et tenez-la.

La division entière. perdus / envoyes entre deux int donne 0. Il faut (float).

La borne de boucle. i < n, jamais i <= n.

La taille oubliée. Un tableau passé à une fonction a besoin de son n.

🤔 Pourquoi les prototypes sont-ils groupés en haut, aux exercices 8 et 9 ?

Pour que main vienne en premier. Le compilateur a besoin de connaître chaque fonction avant le premier appel ; les prototypes le lui disent, et les définitions peuvent alors venir après.

L'autre organisation — toutes les définitions avant main — marche aussi. Mais à cinq fonctions, il faut descendre au bas du fichier pour trouver le programme principal.

Sur une copie, grouper les prototypes montre qu'on a compris à quoi ils servent. C'est gratuit, et ça se voit.

⚡ Récap 2 minutes

  • Une fonction, une phrase sans « et ». Si la description en contient un, il y a deux fonctions.
  • (a + b) / 2 — les parenthèses, sinon la division passe avant l'addition.
  • (float) perdus / envoyes — sans la conversion, deux entiers donnent un entier, et le taux vaut 0.
  • 0 <= v && v <= 255 — l'écriture mathématique 0 <= v <= 255 compile et est toujours vraie.
  • %% pour afficher un pourcentage.
  • max = t[0], boucle à partir de i = 1 — partir de 0 est faux dès qu'une valeur est négative.
  • position = -1 pour dire « pas trouvé » : 0 est un indice valide.
  • « Position » veut dire indice dans ce sujet — dites-le sur la copie.
  • Un tableau passé à une fonction perd sa taille : on passe toujours n.
  • Mais la fonction peut le remplir : c'est pour cela que SaisirTableau() ne retourne rien.
