Getter / setter

python
def get_age(self):
    return self.__age

def set_age(self, a):
    if a >= 0:
        self.__age = a
    else:
        print("Âge invalide")

Le setter contrôle — sinon il ne sert à rien.

@property

python
@property
def age(self):
    return self.__age

@age.setter
def age(self, v):
    if v >= 0:
        self.__age = v

p.age = 35     # appelle le setter
print(p.age)   # appelle le getter

La forme moderne : syntaxe d'attribut, contrôle de méthode.

Héritage

python
class Serveur(Equipement):
    def __init__(self, ip, os):
        super().__init__(ip)
        self.os = os

La fille reçoit attributs et méthodes de la mère.

⚡ super().__init__()

Dès que la fille a son propre __init__, il remplace celui de la mère.

Sans l'appel, les attributs de la mère n'existent pas → AttributeError: '_Classe__x'

1ʳᵉ ligne du constructeur d'une fille :
super().__init__(…)

Override

python
class Admin(Utilisateur):
    def se_connecter(self):

        print("+ privilèges")    # puis le sien
