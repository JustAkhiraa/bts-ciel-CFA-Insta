Exercice 1 · 3 points · somme, différence et multiple

On donne les matrices :

les matrices
     ( 2  -1 )        (  1  4 )
A =  ( 0   3 )   B =  ( -2  1 )

Les questions

  1. Calculer A + B.
  2. Calculer 3A.
  3. Calculer 2A − B.

Question 1

Une somme se fait terme à terme. A et B ont les mêmes dimensions, 2 × 2 : elle existe.

le calcul
2 + 1      =  3
-1 + 4     =  3
0 + (-2)   = -2
3 + 1      =  4
le résultat
         (  3  3 )
A + B =  ( -2  4 )

A + B est la matrice ci-dessus.

Question 2

Chaque terme de A est multiplié par 3.

le calcul
3x2        =  6
3x(-1)     = -3
3x0        =  0
3x3        =  9
le résultat
      ( 6  -3 )
3A =  ( 0   9 )

3A est la matrice ci-dessus.

Question 3

On calcule d'abord 2A, puis on retire B terme à terme.

la matrice 2A
      ( 4  -2 )
2A =  ( 0   6 )
le calcul
4 - 1      =  3
-2 - 4     = -6
0 - (-2)   =  2
6 - 1      =  5
le résultat
          ( 3  -6 )
2A - B =  ( 2   5 )

2A − B est la matrice ci-dessus.

Exercice 2 · 4 points · un produit, puis un seul terme

On donne les matrices :

la matrice A
     (  1  0  2 )
A =  ( -1  3  1 )
la matrice B
     ( 2   1 )
B =  ( 0  -1 )
     ( 1   4 )

Les questions

  1. Donner les dimensions de A × B, puis la calculer.
  2. Donner les dimensions de B × A. Calculer seulement le terme de la ligne 3, colonne 2.

Question 1

A est 2 × 3 et B 3 × 2 : A × B est 2 × 2.

Chaque terme est une ligne de A par une colonne de B.

le calcul
ligne 1 de A : (1 ; 0 ; 2)
  1x2 + 0x0 + 2x1     =   4
  1x1 + 0x(-1) + 2x4  =   9

ligne 2 de A : (-1 ; 3 ; 1)
  (-1)x2 + 3x0 + 1x1     =  -1
  (-1)x1 + 3x(-1) + 1x4  =   0
le résultat
         (  4  9 )
A x B =  ( -1  0 )

A × B est la matrice 2 × 2 ci-dessus.

Question 2

B est 3 × 2 et A 2 × 3 : B × A est 3 × 3.

Le terme de la ligne 3, colonne 2 : la ligne 3 de B par la colonne 2 de A. Inutile de calculer les huit autres.

le calcul
ligne 3 de B :   (1 ; 4)
colonne 2 de A : (0 ; 3)

1x0 + 4x3 = 12

B × A est 3 × 3, et son terme ligne 3, colonne 2 vaut 12.

Exercice 3 · 3 points · le produit nul

On donne les matrices :

les matrices
     ( 1  2 )        (  2  -4 )
A =  ( 2  4 )   B =  ( -1   2 )

Les questions

  1. Calculer A × B.
  2. Calculer B × A.
  3. Que montre cet exercice ?

Question 1

le calcul
1x2 + 2x(-1)  =   0
1x(-4) + 2x2  =   0
2x2 + 4x(-1)  =   0
2x(-4) + 4x2  =   0
le résultat
         ( 0  0 )
A x B =  ( 0  0 )

A × B est la matrice nulle.

Question 2

le calcul
2x1 + (-4)x2  =  -6
2x2 + (-4)x4  = -12
(-1)x1 + 2x2  =   3
(-1)x2 + 2x4  =   6
le résultat
         ( -6  -12 )
B x A =  (  3    6 )

B × A n'est pas nulle.

Question 3

Ni A ni B n'est nulle, et pourtant leur produit l'est.

Avec des matrices, un produit nul n'oblige aucun des deux facteurs à être nul.

Et A × B ≠ B × A : l'ordre compte.

Exercice 4 · 4 points · vérifier une inverse, puis résoudre

On donne les matrices A et B, et un système :

les matrices
     ( 2  3 )        (  2  -3 )
A =  ( 1  2 )   B =  ( -1   2 )
le système
( 2x + 3y = 13
(  x + 2y =  8

Les questions

  1. Calculer B × A. Que peut-on en conclure ?
  2. Écrire le système sous la forme A X = C.
  3. En déduire x et y.

Question 1

le calcul
2x2 + (-3)x1  =   1
2x3 + (-3)x2  =   0
(-1)x2 + 2x1  =   0
(-1)x3 + 2x2  =   1

B × A = I2 : B est la matrice inverse de A.

Question 2

Le produit A X redonne les membres de gauche.

les matrices
     ( x )        ( 13 )
X =  ( y )   C =  (  8 )

Le système s'écrit A X = C.

Question 3

On multiplie par B, à gauche des deux côtés :

la justification
     A X = C
<=>  B A X = B C
<=>  I2 X = B C
<=>  X = B C
le calcul
x = 2x13 + (-3)x8
  = 26 - 24
  = 2

y = (-1)x13 + 2x8
  = -13 + 16
  = 3

x = 2 et y = 3.

Vérification :

2×2 + 3×3 = 13 ✓

2 + 2×3 = 8 ✓

Exercice 5 · 6 points · le matériel d'un étage

Pour équiper un nouvel étage, on achète 26 équipements : x switchs, y routeurs et z points d'accès Wi-Fi.

  • Il y a 6 switchs de plus que de routeurs.
  • Il y a deux fois plus de points d'accès que de routeurs.
le système
( x +  y + z = 26
( x -  y     =  6
(     2y - z =  0
la matrice B
     ( 0,25   0,75  0,25 )
B =  ( 0,25  -0,25  0,25 )
     (  0,5   -0,5  -0,5 )

Les questions

  1. Montrer que x, y et z vérifient le système.
  2. Écrire ce système sous la forme A X = Y.
  3. Calculer B × A. Que peut-on en conclure ?
  4. En déduire que X = B × Y, puis calculer X.
  5. Conclure par une phrase.

Question 1

Une phrase de l'énoncé, une équation.

la traduction
Total de 26 :
  x + y + z = 26

6 switchs de plus :
  x = y + 6
  soit x - y = 6

2 fois plus de points d'accès :
  z = 2y
  soit 2y - z = 0

On retrouve les trois équations du système.

Question 2

Un 0 pour chaque inconnue absente.

les matrices
     ( 1   1   1 )
A =  ( 1  -1   0 )
     ( 0   2  -1 )

     ( x )        ( 26 )
X =  ( y )   Y =  (  6 )
     ( z )        (  0 )

Le système s'écrit A X = Y.

Question 3

Un produit par ligne, signe compris. D'abord la diagonale :

la diagonale
L1 x C1 :
  0,25 x 1  =  0,25
  0,75 x 1  =  0,75
  0,25 x 0  =     0
     somme  =     1

L2 x C2 :
  0,25 x 1        =  0,25
  (-0,25) x (-1)  =  0,25
  0,25 x 2        =   0,5
           somme  =     1

L3 x C3 :
  0,5 x 1        =   0,5
  (-0,5) x 0     =     0
  (-0,5) x (-1)  =   0,5
          somme  =     1

Puis les six autres termes, qui doivent valoir 0 :

hors de la diagonale
L1 x C2 : 0,25 - 0,75 + 0,5 = 0
L1 x C3 : 0,25 + 0 - 0,25 = 0
L2 x C1 : 0,25 - 0,25 + 0 = 0
L2 x C3 : 0,25 + 0 - 0,25 = 0
L3 x C1 : 0,5 - 0,5 + 0 = 0
L3 x C2 : 0,5 + 0,5 - 1 = 0

B × A = I3 : B est la matrice inverse de A.

Question 4

la justification
     A X = Y
<=>  B A X = B Y
     (B à gauche)
<=>  I3 X = B Y
     (car B A = I3)
<=>  X = B Y
     (car I3 X = X)
le calcul
x :
  0,25 x 26  =    6,5
  0,75 x 6   =    4,5
  0,25 x 0   =      0
      somme  =     11

y :
  0,25 x 26    =    6,5
  (-0,25) x 6  =   -1,5
  0,25 x 0     =      0
        somme  =      5

z :
  0,5 x 26    =     13
  (-0,5) x 6  =     -3
  (-0,5) x 0  =      0
       somme  =     10

x = 11, y = 5 et z = 10.

Question 5

Une phrase, avec ce qu'on compte, puis la vérification dans l'énoncé.

On achète 11 switchs, 5 routeurs et 10 points d'accès.

Vérification :

11 + 5 + 10 = 26 ✓

11 = 5 + 6 ✓

10 = 2 × 5 ✓
