Exercice 1 · 3 points · les dimensions d'abord

On considère trois matrices :

  • A, de dimensions 2 × 3 ;
  • B, de dimensions 3 × 2 ;
  • C, de dimensions 2 × 2.

Les questions

  1. Les produits A × B, B × A, A × C et C × A existent-ils ? Donner les dimensions de ceux qui existent.
  2. La somme A + C existe-t-elle ?

Question 1

On pose les dimensions côte à côte. Les deux nombres du milieu doivent être égaux. Le résultat prend les deux nombres du bord.

le test
A x B : (2x3)(3x2)
        3 = 3  ->  2 x 2

B x A : (3x2)(2x3)
        2 = 2  ->  3 x 3

A x C : (2x3)(2x2)
        3 ≠ 2  ->  impossible

C x A : (2x2)(2x3)
        2 = 2  ->  2 x 3

A × B (2 × 2), B × A (3 × 3) et C × A (2 × 3) existent.

A × C n'existe pas.

Question 2

Une somme demande les mêmes dimensions. 2 × 3 et 2 × 2 ne le sont pas.

A + C n'existe pas.

Exercice 2 · 4 points · un produit, terme par terme

On donne les matrices :

la matrice A
     ( 1   2 )
A =  ( 0  -1 )
     ( 3   1 )
la matrice B
     ( 2  -1   0 )
B =  ( 1   3  -2 )

Les questions

  1. Donner les dimensions de A × B, puis la calculer.
  2. Calculer B × A. Que remarque-t-on ?

Question 1

A est 3 × 2 et B 2 × 3 : A × B est 3 × 3.

Chaque terme est une ligne de A par une colonne de B.

le calcul
ligne 1 de A : (1 ; 2)
  1x2 + 2x1        =  4
  1x(-1) + 2x3     =  5
  1x0 + 2x(-2)     = -4

ligne 2 de A : (0 ; -1)
  0x2 + (-1)x1     = -1
  0x(-1) + (-1)x3  = -3
  0x0 + (-1)x(-2)  =  2

ligne 3 de A : (3 ; 1)
  3x2 + 1x1        =  7
  3x(-1) + 1x3     =  0
  3x0 + 1x(-2)     = -2
le résultat
         (  4   5  -4 )
A x B =  ( -1  -3   2 )
         (  7   0  -2 )

A × B est la matrice 3 × 3 ci-dessus.

Question 2

B est 2 × 3 et A 3 × 2 : B × A est 2 × 2.

le calcul
ligne 1 de B : (2 ; -1 ; 0)
  2x1 + (-1)x0 + 0x3     =  2
  2x2 + (-1)x(-1) + 0x1  =  5

ligne 2 de B : (1 ; 3 ; -2)
  1x1 + 3x0 + (-2)x3     = -5
  1x2 + 3x(-1) + (-2)x1  = -3
le résultat
         (  2   5 )
B x A =  ( -5  -3 )

Les deux produits n'ont même pas la même taille :
le produit n'est pas commutatif.

Exercice 3 · 3 points · deux inconnues dans un produit

On donne les matrices A et B, et leur produit :

les matrices
     ( a   1 )        ( 1   0 )
A =  ( 2  -1 )   B =  ( 3   2 )
le produit
          (  5   b )
A x B =   ( -1  -2 )

Les questions

  1. Déterminer le réel a.
  2. Déterminer le réel b.
  3. Vérifier le résultat avec les deux termes restants.

Question 1

Le terme ligne 1, colonne 1 du produit vaut 5.

le calcul
a x 1 + 1 x 3 = 5
        a + 3 = 5
            a = 2

a = 2

Question 2

Le terme ligne 1, colonne 2 du produit vaut b.

le calcul
a x 0 + 1 x 2 = b
            b = 2

b = 2

Question 3

La ligne 2 de A ne contient pas d'inconnue. Ses deux termes doivent redonner −1 et −2.

la vérification
2x1 + (-1)x3 = -1   ✓
2x0 + (-1)x2 = -2   ✓

Les deux termes concordent : a = 2 et b = 2.

Exercice 4 · 4 points · vérifier une inverse, puis résoudre

On donne les matrices A et B, et un système :

les matrices
     ( 3   1 )        (  2  -1 )
A =  ( 5   2 )   B =  ( -5   3 )
le système
( 3x +  y =  7
( 5x + 2y = 12

Les questions

  1. Calculer A × B. Que peut-on en conclure ?
  2. Écrire le système sous la forme A X = C.
  3. En déduire x et y.

Question 1

le calcul
3x2 + 1x(-5)   =  1
3x(-1) + 1x3   =  0
5x2 + 2x(-5)   =  0
5x(-1) + 2x3   =  1

A × B = I2 : B est la matrice inverse de A.

Question 2

Le produit A X redonne les membres de gauche.

les matrices
     ( x )        (  7 )
X =  ( y )   C =  ( 12 )

Le système s'écrit A X = C.

Question 3

On multiplie par B, à gauche des deux côtés :

la justification
     A X = C
<=>  B A X = B C
<=>  I2 X = B C
<=>  X = B C
le calcul
x = 2x7 + (-1)x12
  = 14 - 12
  = 2

y = (-5)x7 + 3x12
  = -35 + 36
  = 1

x = 2 et y = 1.

Vérification :

3×2 + 1 = 7 ✓

5×2 + 2×1 = 12 ✓

Exercice 5 · 6 points · des câbles pour la salle de TP

Pour équiper une salle de TP, on commande 35 câbles :
x câbles droits, y câbles croisés et z câbles console.

  • Il faut deux fois plus de câbles droits que de câbles croisés.
  • Il faut 5 câbles croisés de plus que de câbles console.
le système
( x +  y + z = 35
( x - 2y     =  0
(      y - z =  5
la matrice B
     ( 0,5    0,5    0,5  )
B =  ( 0,25  -0,25   0,25 )
     ( 0,25  -0,25  -0,75 )

Les questions

  1. Montrer que x, y et z vérifient le système.
  2. Écrire ce système sous la forme A X = Y.
  3. Calculer B × A. Que peut-on en conclure ?
  4. En déduire que X = B × Y, puis calculer X.
  5. Conclure par une phrase.

Question 1

Une phrase de l'énoncé, une équation.

la traduction
Total de 35 :
  x + y + z = 35

Deux fois plus de droits :
  x = 2y
  soit x - 2y = 0

5 croisés de plus :
  y = z + 5
  soit y - z = 5

On retrouve les trois équations du système.

Question 2

Un 0 pour chaque inconnue absente.

les matrices
     ( 1   1   1 )
A =  ( 1  -2   0 )
     ( 0   1  -1 )

     ( x )        ( 35 )
X =  ( y )   Y =  (  0 )
     ( z )        (  5 )

Le système s'écrit A X = Y.

Question 3

Un produit par ligne, signe compris. La diagonale, puis un terme hors diagonale :

le calcul
L1 x C1 :
  0,5 x 1         =  0,5
  0,5 x 1         =  0,5
  0,5 x 0         =  0
            somme =  1

L2 x C2 :
  0,25 x 1        =  0,25
  (-0,25) x (-2)  =  0,5
  0,25 x 1        =  0,25
            somme =  1

L3 x C3 :
  0,25 x 1        =  0,25
  (-0,25) x 0     =  0
  (-0,75) x (-1)  =  0,75
            somme =  1

L1 x C2 :
  0,5 x 1         =  0,5
  0,5 x (-2)      = -1
  0,5 x 1         =  0,5
            somme =  0

B × A = I3 : B est la matrice inverse de A.

Question 4

la justification
     A X = Y
<=>  B A X = B Y
     (B à gauche)
<=>  I3 X = B Y
     (car B A = I3)
<=>  X = B Y
     (car I3 X = X)
le calcul
x :
  0,5 x 35        =  17,5
  0,5 x 0         =  0
  0,5 x 5         =  2,5
            somme =  20

y :
  0,25 x 35       =  8,75
  (-0,25) x 0     =  0
  0,25 x 5        =  1,25
            somme =  10

z :
  0,25 x 35       =  8,75
  (-0,25) x 0     =  0
  (-0,75) x 5     = -3,75
            somme =  5

x = 20, y = 10 et z = 5.

Question 5

Une phrase, avec l'unité, puis la vérification dans l'énoncé.

On commande 20 câbles droits, 10 câbles croisés et 5 câbles console.

Vérification :

20 + 10 + 5 = 35 ✓

20 = 2 × 10 ✓

10 − 5 = 5 ✓
