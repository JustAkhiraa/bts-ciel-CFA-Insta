Exercice 1 · 3 points · les dimensions et l'identité

On considère trois matrices :

  • A, de dimensions 3 × 2 ;
  • B, de dimensions 2 × 2 ;
  • C, de dimensions 2 × 3.

Les questions

  1. Les produits A × B, B × A, C × A et A × C existent-ils ? Donner les dimensions de ceux qui existent.
  2. Par quelle matrice identité faut-il multiplier A à gauche pour retrouver A ? Et à droite ?

Question 1

Les deux nombres du milieu doivent être égaux. Le résultat prend les deux nombres du bord.

le test
A x B : (3x2)(2x2)
        2 = 2  ->  3 x 2

B x A : (2x2)(3x2)
        2 ≠ 3  ->  impossible

C x A : (2x3)(3x2)
        3 = 3  ->  2 x 2

A x C : (3x2)(2x3)
        2 = 2  ->  3 x 3

A × B (3 × 2), C × A (2 × 2) et A × C (3 × 3) existent.

B × A n'existe pas.

Question 2

À gauche, l'identité doit avoir autant de colonnes que A a de lignes : 3.

À droite, autant de lignes que A a de colonnes : 2.

le test
I3 x A : (3x3)(3x2)  ->  3 x 2
A x I2 : (3x2)(2x2)  ->  3 x 2

I3 × A = A et A × I2 = A.

Exercice 2 · 4 points · une matrice par un vecteur

On donne les matrices :

les matrices
     ( 1  2   0 )
A =  ( 0  1  -1 )
     ( 2  0   1 )

     (  3 )
X =  ( -1 )
     (  2 )

Les questions

  1. Donner les dimensions de A × X, puis le calculer.
  2. Le produit X × A existe-t-il ?
  3. Calculer 2A − I3.

Question 1

A est 3 × 3 et X 3 × 1 : A × X est 3 × 1, une seule colonne.

le calcul
1x3 + 2x(-1) + 0x2     =   1
0x3 + 1x(-1) + (-1)x2  =  -3
2x3 + 0x(-1) + 1x2     =   8
le résultat
         (  1 )
A x X =  ( -3 )
         (  8 )

A × X est la colonne ci-dessus.

Question 2

le test
X x A : (3x1)(3x3)
        1 ≠ 3  ->  impossible

X × A n'existe pas. L'ordre compte, ici jusqu'à l'existence.

Question 3

On double chaque terme, puis on retire 1 sur la diagonale seulement : c'est là que I3 a ses 1.

la matrice 2A
      ( 2  4   0 )
2A =  ( 0  2  -2 )
      ( 4  0   2 )
le résultat
           ( 1  4   0 )
2A - I3 =  ( 0  1  -2 )
           ( 4  0   1 )

2A − I3 est la matrice ci-dessus.

Exercice 3 · 3 points · deux inconnues, une à la fois

Les réels a et b vérifient l'égalité :

l'égalité
( 1   a )   ( 2 )   (  8 )
( 2   3 ) x ( b ) = ( 13 )

Les questions

  1. Écrire les deux équations données par ce produit.
  2. Déterminer b.
  3. Déterminer a, puis vérifier.

Question 1

Une ligne de la matrice par la colonne : une équation par ligne.

les équations
ligne 1 : 1x2 + a x b = 8
          2 + ab = 8

ligne 2 : 2x2 + 3 x b = 13
          4 + 3b = 13

2 + ab = 8 et 4 + 3b = 13.

Question 2

On commence par la ligne qui n'a qu'une inconnue.

le calcul
4 + 3b = 13
    3b = 9
     b = 3

b = 3

Question 3

On remplace b dans la première équation.

le calcul
2 + 3a = 8
    3a = 6
     a = 2
la vérification
1x2 + 2x3 =  8   ✓
2x2 + 3x3 = 13   ✓

a = 2 et b = 3.

Exercice 4 · 4 points · une inverse à virgules

On donne les matrices A et B, et un système :

les matrices
     ( 4  2 )
A =  ( 2  2 )

     (  0,5  -0,5 )
B =  ( -0,5     1 )
le système
( 4x + 2y = 22
( 2x + 2y = 14

Les questions

  1. Calculer A × B et B × A. Que peut-on en conclure ?
  2. Écrire le système sous la forme A X = C.
  3. En déduire x et y.

Question 1

Les virgules ne changent rien : ligne par colonne, signe compris.

A x B
4x0,5 + 2x(-0,5)  =   1
4x(-0,5) + 2x1    =   0
2x0,5 + 2x(-0,5)  =   0
2x(-0,5) + 2x1    =   1
B x A
0,5x4 + (-0,5)x2  =   1
0,5x2 + (-0,5)x2  =   0
(-0,5)x4 + 1x2    =   0
(-0,5)x2 + 1x2    =   1

A × B = B × A = I2 : B est la matrice inverse de A.

Question 2

les matrices
     ( x )        ( 22 )
X =  ( y )   C =  ( 14 )

Le système s'écrit A X = C.

Question 3

la justification
     A X = C
<=>  B A X = B C
<=>  I2 X = B C
<=>  X = B C
le calcul
x = 0,5x22 + (-0,5)x14
  = 11 - 7
  = 4

y = (-0,5)x22 + 1x14
  = -11 + 14
  = 3

x = 4 et y = 3.

Vérification :

4×4 + 2×3 = 22 ✓

2×4 + 2×3 = 14 ✓

Exercice 5 · 6 points · trois tailles de serveurs

Une salle serveurs compte 18 machines : x petites, y moyennes et z grandes.

  • Il y a 2 petites de plus que de grandes.
  • Il y a deux fois plus de moyennes que de grandes.
le système
( x + y +  z = 18
( x     -  z =  2
(     y - 2z =  0
la matrice B
     ( 0,25   0,75  -0,25 )
B =  (  0,5   -0,5    0,5 )
     ( 0,25  -0,25  -0,25 )

Les questions

  1. Montrer que x, y et z vérifient le système.
  2. Écrire ce système sous la forme A X = Y.
  3. Calculer B × A. Que peut-on en conclure ?
  4. En déduire que X = B × Y, puis calculer X.
  5. Conclure par une phrase.

Question 1

Une phrase de l'énoncé, une équation.

la traduction
Total de 18 :
  x + y + z = 18

2 petites de plus :
  x = z + 2
  soit x - z = 2

Deux fois plus de moyennes :
  y = 2z
  soit y - 2z = 0

On retrouve les trois équations du système.

Question 2

Un 0 pour chaque inconnue absente : y manque dans la deuxième équation, x dans la troisième.

les matrices
     ( 1  1   1 )
A =  ( 1  0  -1 )
     ( 0  1  -2 )

     ( x )        ( 18 )
X =  ( y )   Y =  (  2 )
     ( z )        (  0 )

Le système s'écrit A X = Y.

Question 3

Un produit par ligne, signe compris. D'abord la diagonale :

la diagonale
L1 x C1 :
  0,25 x 1     =  0,25
  0,75 x 1     =  0,75
  (-0,25) x 0  =     0
        somme  =     1

L2 x C2 :
  0,5 x 1     =   0,5
  (-0,5) x 0  =     0
  0,5 x 1     =   0,5
       somme  =     1

L3 x C3 :
  0,25 x 1        =  0,25
  (-0,25) x (-1)  =  0,25
  (-0,25) x (-2)  =   0,5
           somme  =     1

Puis les six autres termes, qui doivent valoir 0 :

hors de la diagonale
L1 x C2 : 0,25 + 0 - 0,25 = 0
L1 x C3 : 0,25 - 0,75 + 0,5 = 0
L2 x C1 : 0,5 - 0,5 + 0 = 0
L2 x C3 : 0,5 + 0,5 - 1 = 0
L3 x C1 : 0,25 - 0,25 + 0 = 0
L3 x C2 : 0,25 + 0 - 0,25 = 0

B × A = I3 : B est la matrice inverse de A.

Question 4

la justification
     A X = Y
<=>  B A X = B Y
     (B à gauche)
<=>  I3 X = B Y
     (car B A = I3)
<=>  X = B Y
     (car I3 X = X)
le calcul
x :
  0,25 x 18    =    4,5
  0,75 x 2     =    1,5
  (-0,25) x 0  =      0
        somme  =      6

y :
  0,5 x 18    =      9
  (-0,5) x 2  =     -1
  0,5 x 0     =      0
       somme  =      8

z :
  0,25 x 18    =    4,5
  (-0,25) x 2  =   -0,5
  (-0,25) x 0  =      0
        somme  =      4

x = 6, y = 8 et z = 4.

Question 5

Une phrase, avec ce qu'on compte, puis la vérification dans l'énoncé.

La salle compte 6 petites machines, 8 moyennes et 4 grandes.

Vérification :

6 + 8 + 4 = 18 ✓

6 − 4 = 2 ✓

8 = 2 × 4 ✓
