Exercice 1 · 3 points · vrai ou faux, en justifiant

Pour chaque affirmation, dire si elle est vraie ou fausse, et justifier.

  1. Si A est de dimensions 2 × 3 et B de dimensions 3 × 3, alors A × B est de dimensions 2 × 3.
  2. Pour deux matrices carrées A et B de même taille, on a toujours A × B = B × A.
  3. Si A × B est la matrice nulle, alors A ou B est la matrice nulle.

Question 1

le test
A x B : (2x3)(3x3)
        3 = 3  ->  2 x 3

Vrai. Le produit existe et garde les deux nombres du bord : 2 × 3.

Question 2

Un seul contre-exemple suffit à montrer qu'une affirmation « toujours » est fausse.

le contre-exemple
     ( 1  1 )        ( 1  0 )
A =  ( 0  1 )   B =  ( 1  1 )
le calcul
A x B :
  1x1 + 1x1  =   2
  1x0 + 1x1  =   1
  0x1 + 1x1  =   1
  0x0 + 1x1  =   1

B x A :
  1x1 + 0x0  =   1
  1x1 + 0x1  =   1
  1x1 + 1x0  =   1
  1x1 + 1x1  =   2
les résultats
         ( 2  1 )
A x B =  ( 1  1 )

         ( 1  1 )
B x A =  ( 1  2 )

Faux. Ici A × B ≠ B × A : le produit n'est pas commutatif.

Question 3

Encore un contre-exemple : deux matrices non nulles dont le produit est nul.

le contre-exemple
     ( 1  1 )        (  1  -1 )
A =  ( 1  1 )   B =  ( -1   1 )
le calcul
1x1 + 1x(-1)  =   0
1x(-1) + 1x1  =   0
1x1 + 1x(-1)  =   0
1x(-1) + 1x1  =   0

Faux. A × B est nulle alors que ni A ni B ne l'est.

Exercice 2 · 4 points · deux produits et leur différence

On donne les matrices :

les matrices
     (  2  1 )        ( 1  -2 )
A =  ( -1  0 )   B =  ( 3   1 )

Les questions

  1. Calculer A × B.
  2. Calculer B × A.
  3. Calculer A × B − B × A. Que peut-on en conclure ?

Question 1

le calcul
2x1 + 1x3        =   5
2x(-2) + 1x1     =  -3
(-1)x1 + 0x3     =  -1
(-1)x(-2) + 0x1  =   2
le résultat
         (  5  -3 )
A x B =  ( -1   2 )

A × B est la matrice ci-dessus.

Question 2

le calcul
1x2 + (-2)x(-1)  =   4
1x1 + (-2)x0     =   1
3x2 + 1x(-1)     =   5
3x1 + 1x0        =   3
le résultat
         ( 4  1 )
B x A =  ( 5  3 )

B × A est la matrice ci-dessus.

Question 3

Une différence se fait terme à terme.

le calcul
5 - 4      =  1
-3 - 1     = -4
-1 - 5     = -6
2 - 3      = -1
le résultat
           (  1  -4 )
AB - BA =  ( -6  -1 )

La différence n'est pas nulle : A × B ≠ B × A.

Exercice 3 · 3 points · deux inconnues dans un produit

Les réels a et b vérifient l'égalité :

l'égalité
( a   2 )   ( 1   0 )
( 1   b ) x ( 2   1 )

    (  7   2 )
  = ( -3  -2 )

Les questions

  1. Déterminer le réel a.
  2. Déterminer le réel b.
  3. Vérifier le résultat avec les deux termes restants.

Question 1

Le terme ligne 1, colonne 1 du produit vaut 7.

le calcul
a x 1 + 2 x 2 = 7
        a + 4 = 7
            a = 3

a = 3

Question 2

Le terme ligne 2, colonne 1 du produit vaut −3.

le calcul
1 x 1 + b x 2 = -3
       1 + 2b = -3
           2b = -4
            b = -2

b = −2

Question 3

Les deux termes de la colonne 2 doivent redonner 2 et −2.

la vérification
3x0 + 2x1      =  2   ✓
1x0 + (-2)x1   = -2   ✓

Les deux termes concordent : a = 3 et b = −2.

Exercice 4 · 4 points · l'inverse, dans les deux sens

On donne les matrices A et B, et un système :

les matrices
     ( 5  3 )        (  2  -3 )
A =  ( 3  2 )   B =  ( -3   5 )
le système
( 5x + 3y = 29
( 3x + 2y = 18

Les questions

  1. Calculer A × B, puis B × A. Que peut-on en conclure ?
  2. Écrire le système sous la forme A X = C.
  3. En déduire x et y.

Question 1

A x B
5x2 + 3x(-3)  =   1
5x(-3) + 3x5  =   0
3x2 + 2x(-3)  =   0
3x(-3) + 2x5  =   1
B x A
2x5 + (-3)x3  =   1
2x3 + (-3)x2  =   0
(-3)x5 + 5x3  =   0
(-3)x3 + 5x2  =   1

A × B = B × A = I2 : B est la matrice inverse de A.

Question 2

les matrices
     ( x )        ( 29 )
X =  ( y )   C =  ( 18 )

Le système s'écrit A X = C.

Question 3

la justification
     A X = C
<=>  B A X = B C
<=>  I2 X = B C
<=>  X = B C
le calcul
x = 2x29 + (-3)x18
  = 58 - 54
  = 4

y = (-3)x29 + 5x18
  = -87 + 90
  = 3

x = 4 et y = 3.

Vérification :

5×4 + 3×3 = 29 ✓

3×4 + 2×3 = 18 ✓

Exercice 5 · 6 points · retrouver des prix

Un service informatique a passé trois commandes chez le même fournisseur. On note s le prix d'un switch, r celui d'un routeur et p celui d'un point d'accès, en euros.

  • Commande 1 : 2 switchs et 1 routeur, pour 210 €.
  • Commande 2 : 1 routeur et 2 points d'accès, pour 170 €.
  • Commande 3 : 1 switch et 1 point d'accès, pour 100 €.
le système
( 2s + r      = 210
(      r + 2p = 170
(  s     +  p = 100
la matrice B
     (  0,25  -0,25  0,5 )
B =  (   0,5    0,5   -1 )
     ( -0,25   0,25  0,5 )

Les questions

  1. Montrer que s, r et p vérifient le système.
  2. Écrire ce système sous la forme A X = Y.
  3. Calculer B × A. Que peut-on en conclure ?
  4. En déduire que X = B × Y, puis calculer X.
  5. Conclure par une phrase.

Question 1

Une commande, une équation : le nombre d'objets fois leur prix, et le total.

la traduction
Commande 1 :
  2s + r = 210

Commande 2 :
  r + 2p = 170

Commande 3 :
  s + p = 100

On retrouve les trois équations du système.

Question 2

Un 0 pour chaque article absent d'une commande.

les matrices
     ( 2  1  0 )
A =  ( 0  1  2 )
     ( 1  0  1 )

     ( s )        ( 210 )
X =  ( r )   Y =  ( 170 )
     ( p )        ( 100 )

Le système s'écrit A X = Y.

Question 3

Un produit par ligne, signe compris. D'abord la diagonale :

la diagonale
L1 x C1 :
  0,25 x 2     =   0,5
  (-0,25) x 0  =     0
  0,5 x 1      =   0,5
        somme  =     1

L2 x C2 :
  0,5 x 1   =   0,5
  0,5 x 1   =   0,5
  (-1) x 0  =     0
     somme  =     1

L3 x C3 :
  (-0,25) x 0  =     0
  0,25 x 2     =   0,5
  0,5 x 1      =   0,5
        somme  =     1

Puis les six autres termes, qui doivent valoir 0 :

hors de la diagonale
L1 x C2 : 0,25 - 0,25 + 0 = 0
L1 x C3 : 0 - 0,5 + 0,5 = 0
L2 x C1 : 1 + 0 - 1 = 0
L2 x C3 : 0 + 1 - 1 = 0
L3 x C1 : -0,5 + 0 + 0,5 = 0
L3 x C2 : -0,25 + 0,25 + 0 = 0

B × A = I3 : B est la matrice inverse de A.

Question 4

la justification
     A X = Y
<=>  B A X = B Y
     (B à gauche)
<=>  I3 X = B Y
     (car B A = I3)
<=>  X = B Y
     (car I3 X = X)
le calcul
s :
  0,25 x 210     =   52,5
  (-0,25) x 170  =  -42,5
  0,5 x 100      =     50
          somme  =     60

r :
  0,5 x 210   =    105
  0,5 x 170   =     85
  (-1) x 100  =   -100
       somme  =     90

p :
  (-0,25) x 210  =  -52,5
  0,25 x 170     =   42,5
  0,5 x 100      =     50
          somme  =     40

s = 60, r = 90 et p = 40.

Question 5

Une phrase, avec l'unité, puis la vérification dans l'énoncé.

Un switch coûte 60 €, un routeur 90 € et un point d'accès 40 €.

Vérification :

2 × 60 + 90 = 210 ✓

90 + 2 × 40 = 170 ✓

60 + 40 = 100 ✓
