Configuration Cisco — QCM

10 questions. Une seule bonne réponse par question, et l'explication s'affiche dès que vous avez répondu. Le cours · La fiche

0 / 10

1Quels sont les trois modes emboîtés d'IOS, dans l'ordre ?

L'invite dit toujours où l'on est. > ne permet que de regarder ; # ouvre les commandes qui agissent ; (config)# modifie la configuration. On y entre par enable puis configure terminal, et on remonte par exit.

2Vous configurez un switch, tout fonctionne, vous le redémarrez : tout est perdu. Pourquoi ?

La running-config est en mémoire volatile. Sans copy running-config startup-config — ou write memory — rien ne survit à la coupure. C'est l'erreur la plus coûteuse en TP, parce qu'elle ne se voit qu'après avoir tout refait.

3IOS répond « % Ambiguous command ». Que faut-il faire ?

Les trois messages disent trois choses différentes : Ambiguous = trop court, plusieurs commandes correspondent ; Incomplete = juste mais inachevé, ? dira ce qui manque ; Invalid input = une faute, et le ^ pointe l'endroit exact.

4Dans ip address 192.168.10.5 255.255.255.0, que sont les deux nombres ?

Mot-clé = un terme fixé par le système (ip, address) ; argument = une valeur que vous choisissez. L'aide contextuelle ? distingue les deux : elle liste les mots-clés possibles, jamais les arguments — qu'elle ne peut pas deviner.

5Pourquoi Telnet est-il à proscrire au profit de SSH ?

Ce n'est pas une question de confort : Telnet n'est pas « moins bien », il est dangereux. Tout ce qui passe — identifiant, mot de passe, configuration — circule lisible. N'importe quelle capture sur le chemin livre l'accès à l'équipement.

6Un mot de passe est posé sur la ligne console, mais l'accès reste libre. Que manque-t-il ?

password définit le mot de passe ; login demande qu'on le saisisse. Sans la seconde, la première ne sert à rien — et rien ne le signale. Les deux vont toujours ensemble, sur la console comme sur les lignes VTY.

7Quelle différence entre enable secret et service password-encryption ?

enable secret enregistre une empreinte qu'on ne peut pas retourner. service password-encryption applique un codage très faible, cassé en une seconde par n'importe quel outil en ligne : il empêche la lecture par-dessus l'épaule, pas une attaque.

8À quoi sert le préfixe no dans IOS ?

no hostname rend au switch son nom d'origine, no shutdown allume une interface. C'est la commande la plus utile d'IOS parce qu'elle rend toute action réversible : on peut essayer, constater, revenir.

9Quelle règle de nommage IOS est correcte ?

Lettres, chiffres et tirets seulement ; début par une lettre ; fin par une lettre ou un chiffre ; pas d'espace ; moins de 64 caractères. Un nom hors règles est refusé — et l'invite change immédiatement quand il est accepté, ce qui sert de confirmation.

10Une commande mal tapée a lancé une résolution DNS qui bloque le terminal. Que faire ?

IOS prend tout mot inconnu pour un nom d'hôte et tente de le résoudre — trente secondes d'attente à chaque faute de frappe. Ctrl+Maj+6 interrompt immédiatement. En configuration, no ip domain-lookup supprime le problème à la racine.
