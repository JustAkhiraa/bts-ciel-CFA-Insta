02La configuration type

De l'usine à l'administration distante

Switch> enable
Switch# configure terminal
Switch(config)# hostname S1                        ← nom : lettre au début, pas d'espace, < 64 car.
S1(config)# no ip domain-lookup                    ← plus d'attente sur les fautes de frappe

S1(config)# enable secret classe456                ← privilégié — « secret », HACHÉ

S1(config)# line console 0                         ← console
S1(config-line)# password cisco123
S1(config-line)# login                             ← ⚠ SANS ÇA, AUCUN MOT DE PASSE DEMANDÉ
S1(config-line)# exit

S1(config)# line vty 0 15                          ← les 16 lignes distantes
S1(config-line)# password vty789
S1(config-line)# login
S1(config-line)# exit

S1(config)# service password-encryption            ← chiffre les autres mots de passe
S1(config)# banner motd #Acces reserve...#         ← # = délimiteur

S1(config)# interface vlan 1                       ← SVI : administration à distance
S1(config-if)# ip address 192.168.1.2 255.255.255.0
S1(config-if)# no shutdown                         ← ⚠ SINON administratively down
S1(config-if)# exit
S1(config)# ip default-gateway 192.168.1.1         ← pour être joint depuis un AUTRE réseau
S1(config)# end

S1# copy running-config startup-config             ← ⚠ SINON TOUT EST PERDU

03Vérification et diagnostic

Les commandes show

show version               IOS, modèle
show ip interface brief    résumé interfaces
show interfaces status     vitesse, duplex, VLAN
show running-config        config active
show startup-config        config enregistrée
show mac address-table     table MAC

show run | include password    filtrer
show run | section interface

Lire les états d'interface

Status / ProtocolCauseAction
up / upTout va bien—
down / downPhysique : câble, équipement éteintVérifier le câblage
admin. down / downVous : interface désactivéeno shutdown
up / downCouche 2 : encapsulationVérifier des 2 côtés

administratively = c'est vous. Un simple down = c'est le câble.

Les 6 oublis classiques

  1. login après password
  2. no shutdown sur la SVI
  3. copy run start
  4. line vty 0 15, pas 0
  5. enable secret, pas password
  6. ip default-gateway pour l'accès depuis un autre réseau

Les n° 1 et 3 ne produisent aucun message d'erreur : se déconnecter/reconnecter pour vérifier.

⚡ Si vous ne reteniez que trois choses

  • copy run start après chaque bloc réussi — pas à la fin de la séance.
  • password définit, login active. Les deux, ou rien.
  • Un switch route pour lui-même, jamais pour les autres — d'où ip default-gateway.
