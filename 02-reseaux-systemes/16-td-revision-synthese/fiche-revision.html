Le switch segmente les collisions · le routeur et le VLAN segmentent les broadcasts.

MAC · IP · ARP

  • MAC — physique, 48 bits, valable sur le lien local.
  • IP — logique, hiérarchique, identifie l'hôte de bout en bout.
  • ARP — trouve la MAC à partir de l'IP, sur le réseau local.
  • ICMP — ping, traceroute.

VLAN · access et trunk

Cisco IOS
vlan 10
 name DIRECTION

interface range fa0/1 - 5
 switchport mode access
 switchport access vlan 10

interface g0/1
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30

access = 1 VLAN, sans étiquette · trunk = plusieurs VLAN, étiquetés 802.1Q (4 octets, 12 bits → 4 094 VLAN).

Sur un 2960, switchport trunk encapsulation n'existe pas : passer directement à switchport mode trunk.

⚡ Routage inter-VLAN

router-on-a-stick — R1
interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0

interface g0/0
 no ip address
 no shutdown
SVI — switch L3
ip routing
interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown

Les deux lignes qu'on oublie : no shutdown sur l'interface physique (elle porte les sous-interfaces) et ip routing sur le switch L3 (sans lui, rien ne route).

⚡ Diagnostiquer de bas en haut

  1. show ip interface brief → up / up ?
  2. show cdp neighbors → qui est en face ?
  3. show vlan brief → VLAN et ports
  4. show interfaces trunk → VLAN autorisés
  5. show ip route → 3 réseaux en C
  6. ping intra, puis inter
  7. copy running-config startup-config

administratively down = il manque no shutdown.
up/up mais pas de ping = chercher en couche 3.

⚠️ Les cinq pièges

  1. Interfaces du routeur éteintes par défaut.
  2. VLAN absent d'allowed vlan : trames jetées en silence, on accuse le routeur à tort.
  3. no ip address oublié sur la physique du stick.
  4. ip routing oublié sur le switch L3.
  5. Mauvais masque : une partie du réseau répond, l'autre non.

En production

  • VLAN 1 inutilisé — c'est le défaut de tout le monde, il porte CDP/DTP/ STP/VTP, et c'est le premier essayé par un attaquant.
  • Administration dans un VLAN dédié (99).
  • VLAN natif du trunk changé — il circule sans étiquette.
  • ACL après le routage : le VLAN sépare, le routeur relie, l'ACL arbitre.
  • Une ACL sans permit final bloque tout : deny any implicite.
