WSL Containers (wslc)

Chapitre hors programme : ce qu'il faut pouvoir dire en trois phrases, et les commandes. Le cours · Le TP · Le QCM

⚡ En trois phrases

1. Depuis septembre 2026, Windows sait lancer des conteneurs Linux sans Docker Desktop : la commande wslc est livrée avec WSL.

2. Elle s'appuie sur le noyau Linux de WSL 2, qui était déjà là, et emploie les mêmes images que Docker.

3. La syntaxe est volontairement proche : qui sait Docker sait wslc.

Les prérequis

WSL 2.9.3 ou supérieur. La version stable de sortie porte le numéro 3.0.1 — les deux chiffres circulent, le plancher est 2.9.3.

powershell
wsl --version     # ce qu'on a
wsl --update      # la derniere version, puis redemarrer
wslc version      # le moteur repond

La virtualisation doit être activée dans le BIOS/UEFI : sans elle, ni WSL ni wslc ne démarrent.

⚡ Le dehors est à gauche

powershell
-p 8080:80        hote : conteneur

On écrit en premier l'adresse qu'on va taper : localhost:8080 → -p 8080:…. Inversé, rien ne répond et aucun message ne le dit.

run ≠ exec

run part d'une image et crée un conteneur neuf.

exec entre dans un conteneur qui tourne déjà.

Faire un run en croyant entrer dans son serveur donne un second serveur vide — et on cherche ses fichiers longtemps.

Docker → wslc

Dockerwslc
docker run --rm hello-worldwslc run --rm hello-world
docker pswslc container list
docker ps -awslc container list --all
docker imageswslc image list
docker exec -it web bashwslc exec -it web bash
docker logs webwslc container logs web
docker stop webwslc container stop web
docker build -t nom .wslc build -t nom .

wslc met l'objet avant le verbe : container list, image list. C'est la forme moderne de Docker — prenez-la, et les deux outils vous obéissent.

Le Containerfile

Microsoft nomme Containerfile le fichier de construction. Son contenu est la syntaxe du chapitre 18.

RUN s'exécute à la construction ; CMD est ce que fera le conteneur au démarrage. Les confondre produit une image qui ne lance rien.

EXPOSE documente un port, il ne le publie pas : c'est -p qui publie.

Surveiller et nettoyer

powershell
wslc events            # le journal en direct
wslc stats             # processeur et memoire
wslc system info       # l'etat general
wslc container prune   # les conteneurs arretes
wslc image prune       # les images inutilisees

Ce sont les images qui pèsent : une dizaine d'essais occupent déjà un gigaoctet.

⚡ Ce qu'il faut savoir répondre

« Pourquoi c'est intéressant ? » Rien à installer, pas de licence, mêmes images, même syntaxe.

« Pourquoi ça ne remplace pas Docker ? » Windows seulement, pas d'interface graphique, et tout l'écosystème parle encore docker.

« C'est au programme ? » Non — et c'est précisément pour ça que c'est un bon sujet.

Un chapitre daté — à vérifier sur votre machine

Les commandes et les numéros de version viennent de la documentation officielle de Microsoft, relevée le 14 octobre 2026. L'outil a quelques semaines : il bougera encore.

wslc --help décrit la version réellement installée chez vous. C'est la référence la plus sûre, et la seule qui ne vieillit pas — si elle dit autre chose que cette fiche, suivez-la.
