02Installations

Debian 12 « Bookworm » — les 6 choix

  1. Install, pas Graphical install
  2. Nom de domaine : vide
  3. Partitionnement assisté, disque entier
  4. Tout dans une seule partition
  5. ⚠️ DÉCOCHER « Environnement de bureau » et « GNOME » — cochés par défaut
  6. GRUB sur le disque principal

Pas de GUI sur un serveur : ressources, sécurité, administration à distance.

Windows 11 — les prérequis

64 bits · 2 cœurs · 4 Go · 64 Go · UEFI · TPM 2.0

Dans VirtualBox :

  • Système → Carte mère → Activer UEFI
  • Système → Carte mère → TPM v2.0
  • Système → Processeur → 2 vCPU
  • Décocher Proceed with Unattended Installation

⚠️ Avant le premier démarrage — après, il faut tout recommencer.

Partitionnement en production

On sépare ce qui grossit sans prévenir de ce qui doit rester fonctionnel.

03Windows Server et diagnostic

SRVTECH — les 4 réglages

a) IP STATIQUE
   192.168.100.10 / 255.255.255.0
   passerelle 192.168.100.1
   DNS 127.0.0.1  ← car IL EST le serveur DNS

b) Nom : SRVTECH
c) Pare-feu désactivé  ← TP SEULEMENT
d) Mot de passe administrateur

Serveur = IP statique : adresse stable et prévisible.

Après toute installation

  1. Adressage — statique serveur, DHCP poste
  2. Nom de machine explicite
  3. Mises à jour
  4. Accès distant — SSH ou RDP
  5. Snapshot
sudo apt update && sudo apt upgrade
sudo apt install openssh-server
hostnamectl set-hostname srv-debian

⚡ Si vous ne reteniez que trois choses

  • Windows 11 : UEFI + 2 vCPU, réglés avant le premier démarrage.
  • Debian : décocher GNOME. Un serveur n'a pas besoin d'écran.
  • NAT sort mais ne reçoit pas. Pour joindre une VM : mode pont.
