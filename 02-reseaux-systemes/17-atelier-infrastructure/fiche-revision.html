⚡ Ce que le sujet a faux

Il annonce 209.165.200.225 comme passerelle du serveur Internet.

Le lien est 209.165.200.232/29 : utilisables de .233 à .238. Le serveur porte .238, sa passerelle doit donc être 209.165.200.233.

.225 appartient au 209.165.200.224/29 voisin — celui du pool NAT.

Le routeur sur un bâton

Interface physique : sans adresse, mais allumée.

Une sous-interface par VLAN, numérotée comme le VLAN par convention :

interface g0/1.21
encapsulation dot1Q 21
ip address 192.168.21.1 255.255.255.0

Le mot-clé native ne s'ajoute que si le VLAN natif est l'un de ceux-là. Ici le natif est le 1 : aucun native.

⚡ RIPv2 : les quatre lignes

router rip
version 2
no auto-summary
network 172.16.0.0

network prend l'adresse de classe, pas le sous-réseau : une seule ligne couvre les deux /30.

Sans no auto-summary, les /30 sont annoncés en /16 et le découpage est perdu.

Sur R2 : default-information originate, sinon personne n'apprend la sortie Internet.

DHCP

Les exclusions sont globales et se posent avant les pools :

ip dhcp excluded-address 192.168.21.1 192.168.21.20

Puis, dans le pool : network, default-router, dns-server, domain-name.

Une adresse en 169.254.x.x ne dit pas « DHCP est faux », elle dit « personne n'a répondu » — cherchez le VLAN, l'agrégation, la sous-interface.

⚡ NAT : les deux lignes qu'on oublie

ip nat inside sur chaque interface côté réseau privé — les deux liaisons série ici.

ip nat outside sur la sortie Internet.

Sans elles, show ip nat translations reste vide quoi qu'on fasse.

Masque générique = inverse du masque : 255.255.252.0 donne 0.0.3.255.

Lire un état d'interface

administratively down → il manque no shutdown.

down / down → rien en face : câble, équipement éteint, ou horloge DCE manquante.

up / down → le lien existe, le protocole ne s'établit pas : encapsulation, ou l'autre bout n'est pas prêt.

La première colonne est ce que vous avez décidé. La seconde, ce que le câble constate.

Les commandes de contrôle

terminal length 0 — supprime la pagination

show ip interface brief — up/up ?
show ip protocols — RIP : version, résumé, réseaux, passives
show ip route — les réseaux distants sont-ils appris ?
show vlan brief · show interfaces trunk
show ip dhcp binding · show ip nat translations
show ntp status

⚡ IPv6 : la ligne oubliée

ipv6 unicast-routing — en configuration globale.

Sans elle, les interfaces prennent bien leurs adresses, les voisins se voient, mais rien ne traverse : le routeur n'est qu'un hôte.

Route par défaut IPv6 : ipv6 route ::/0 serial 0/0/0.

2001:DB8::/32 est le préfixe réservé à la documentation — l'équivalent de exemple.fr.

NTP

Sur le serveur : clock set 09:00:00 5 March 2016 en mode privilégié, puis ntp master 5 en configuration.

Sur le client : ntp server 172.16.1.2 et ntp update-calendar.

La strate se compte en sauts depuis l'horloge de référence : maître en 5, client en 6.

⚡ Tester du plus proche au plus lointain

1. interface locale up/up
2. ping du voisin direct
3. ping de sa passerelle
4. ping d'un réseau distant
5. bail DHCP obtenu
6. accès au serveur web public
