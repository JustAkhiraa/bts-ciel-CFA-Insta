03Comptes et permissions

Utilisateurs et groupes

sudo adduser bob            crée (interactif)
sudo deluser --remove-home bob
sudo addgroup projet
sudo usermod -aG projet bob    ⚠ -a OBLIGATOIRE
passwd  /  sudo passwd bob
groups  /  id

root a toujours l'UID 0. sudo = 1 commande · su = session root entière.

Les 4 fichiers système

/etc/passwdComptes : UID, GID, /home, shell. Pas de mot de passe
/etc/shadowMots de passe chiffrés

Les droits — r=4 w=2 x=1

-rwxr-xr--   1 la copie A projet ... script.sh
│└┬┘└┬┘└┬┘     └─┬─┘ └─┬──┘
│ u   g   o      prop.  groupe
└ type : - fichier · d répertoire · l lien

rwx=7  rw-=6  r-x=5  r--=4  -wx=3  -w-=2  --x=1

755  script, dossier      644  fichier de données
770  travail d'équipe     600  privé (clé SSH)

Sur un RÉPERTOIRE, ça change tout

DroitSur un fichierSur un répertoire
rLireLister les noms
wModifierCréer / supprimer
xExécuterTraverser (entrer)

Sans x, rien n'est possible dans un répertoire. x sans r : on ouvre un fichier dont on connaît le nom, sans voir la liste.

Modifier les droits

chmod g+w f        symbolique : + - =
chmod u-r f                    u g o a
chmod 755 f        octal : on RÉÉCRIT tout

chown alice:projet f    proprio + groupe
chgrp projet f          groupe seul
chmod g+s dossier       SetGID : héritage
                        du groupe

04Réseau et pièges

Configuration IP statique

ip a                voir les interfaces
ip route            la passerelle

# /etc/network/interfaces
auto ens33                 ⚠ NE PAS OUBLIER
iface ens33 inet static
    address 10.0.0.10      ⚠ sans /24
    netmask 255.255.255.0  ⚠ ligne à part
    gateway 10.0.0.1

sudo systemctl restart networking
sudo ifup ens33

Serveur = IP statique, pour une adresse stable et prévisible.

Les 6 pièges du test

  1. usermod -aG et jamais -G seul
  2. update ≠ upgrade
  3. rm * supprime les fichiers, échoue sur les dossiers
  4. x sur un répertoire = traverser, pas lister
  5. /etc/passwd ne contient aucun mot de passe
  6. chown change proprio et groupe ; chgrp le groupe seul

Sécuriser un partage

sudo addgroup projet
sudo usermod -aG projet alice
sudo chgrp projet /srv/projet
sudo chmod 770 /srv/projet
sudo chmod g+s /srv/projet

Jamais 777. Jamais de compte partagé. Principe du moindre privilège.

⚡ Si vous ne reteniez que trois choses

  • Tout est fichier, tout part de /, tout est sensible à la casse.
  • r=4, w=2, x=1 — et sur un répertoire, x veut dire « traverser ».
  • Le moindre privilège : sudo pour une commande, un groupe pour un partage, jamais 777 ni le mot de passe root.
